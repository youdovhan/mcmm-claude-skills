# Основи ораторської майстерності

> Модуль 5 (27.11–01.12) · 3h 19m 06s · lecturer Денис Чернишов

## Що цей урок дає

Перший і фундаментальний урок наскрізної дисципліни ораторського мистецтва у MCMM. Денис будує не «техніку красномовства», а **філософію проявленості через правду**: оратор — це не той, хто гарно говорить слова, а той, хто передає СТАН [C-l05-061]. Стан не можна підробити; він народжується тільки коли ти говориш правду, яку прожив. Правда тримається на ясному «хто я · для кого я · для чого я» — універсальній рамці під будь-який виступ [C-l05-011].

## Top 5 claims

1. **framework** — Тріада ораторського: ХТО Я · ДЛЯ КОГО Я · ДЛЯ ЧОГО Я як універсальна рамка [C-l05-011]
2. **definition** — Справжня харизма = ясність «хто я» + жагуче бажання іти своїм шляхом, НЕ гучність/манерність [C-l05-016]
3. **classification** — 3 типи аудиторії: Ваші · По конкретику · «Вразь мене» (скептики 5-10%) [C-l05-031]
4. **framework** — Арка Героя 7 пунктів: моя трансформація = мій продукт [C-l05-053]
5. **definition** — Оратор передає СТАН, не текст. Слова — контейнер; стан — зміст [C-l05-061]
