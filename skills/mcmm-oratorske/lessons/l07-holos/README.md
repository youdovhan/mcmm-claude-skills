# Голос лідера. Від конструктивної критики до магнетичних виступів

> Модуль 7 (19.02–23.02) · 4h 01m 19s · lecturer Денис Чернишов

## Що цей урок дає

Другий урок наскрізної дисципліни ораторського мистецтва у MCMM. Якщо L1 — філософія проявленості (хто я · для кого · для чого + Арка Героя), то L2 — операційний інструментарій виступу: техніка «Бутерброд» для конструктивної критики + принцип персонального адресата (PA) + 3 опори тоста. Ключова теза уроку: магнетичний виступ — це не сума технік, а присутність правди в голосі [C-l07-090]. Юрій Довган сам брав участь у цій сесії і отримав публічне підтвердження ораторського голосу від Дениса [C-l07-074].

## Top 5 claims

1. **framework** — Структура 6+1 хвилина: Привітання+хук → 3 факти про себе → План → Метод+історія → Взаємодія → Підсумок [C-l07-006]
2. **framework** — «Бутерброд» зворотного зв'язку: ВИЗНАННЯ → ТОЧКА РОСТУ (X→Y→Z) → ЗАКРІПЛЕННЯ СИЛИ (НЕ повтор) [C-l07-017]
3. **theory** — Принцип персонального адресата: «Ви ніколи не говорите всім. Ви завжди говорите комусь» [C-l07-026]
4. **technique** — Техніка «фото біля камери»: 2-3 фото реальних людей, які викликають легкість, не страх [C-l07-027]
5. **framework** — 3 опори тоста: Вдячність → Визнання → Особистий вплив. Тост = «Бутерброд» БЕЗ начинки [C-l07-041]

## Applied to практик

- **Виступи Юрія (Статус, MCMM Power, прямі ефіри)**: Юрій уже отримав підтвердження від Дениса [C-l07-074] — «чіткий і впевнений чоловічий голос, тобі треба говорити» — peer-validation авторитетного лектора, використовувати в позиціонуванні. Перед виступом — встановити персональний адресат на 2-3 конкретних людей (не «всі підписники»). Після хука обов'язково сформувати ПОТРЕБУ перед закликом [C-l07-048].
- **Detective FM «Розслідування»** (€300, 2 год): workshop з 3 інструментів — техніка «Бутерброд» + персональний адресат + структура 6+1. Тригер для розмови: коли клієнт говорить «мені страшно виступати на велику аудиторію» — застосувати PA через 2-3 фото як перший крок. 3-міс пакет (€1469): діагностичний маркер «зжимаюсь у структурі» [C-l07-084] — типовий запит для довгої роботи.
- **СИНТЕЗ/МАЙСТЕРНЯ** (AI для експертів-психологів/коучів): техніка «Бутерброд» для роботи з учнями + персональний адресат для запису курсу. Анти-GPT-патерн [C-l07-036]: показати ЯК ВИКОРИСТОВУВАТИ GPT (структура) + ЯК ВІДЧОЛОВІЧИТИ після. Демо-кейс: 2 версії одного виступу — GPT-як-є vs відчоловічено.
