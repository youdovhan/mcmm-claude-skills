# Сила присутності. Як будувати виступи, що спонукають до дії

> Модуль 8 (18.03–22.03) · 4h 07m 07s · lecturer Денис Чернишов

## Що цей урок дає

Третя і КУЛЬМІНАЦІЙНА зустріч наскрізного циклу ораторського у MCMM. Якщо L1 — філософія (хто я · для кого · для чого), L2 — артикуляція (голос-інструмент + конструктивна критика), то L3 — присутність: 8 структур виступу (логіка) × 4 тони голосу (стан) + практика «Один фокус». Ключова теза: структура керує логікою, тон керує впливом, спікер передає не текст — він передає СТАН, а виступ існує заради ОДНОЇ дії, яку зробить слухач після [C-l08-002] [C-l08-046] [C-l08-062] [C-l08-112]. Юрій Довган у чаті дав найбільш близьку до канонічної відповідь на ключове питання уроку — «продати одну ідею» = спонукати до дії [C-l08-002] [C-l08-101].

## Top 5 claims

1. **definition** — Головна задача оратора — спонукати слухача до конкретної дії; продати одну ідею [C-l08-002]
2. **framework** — 8 структур публічних виступів: AIDA, Ескалація, Живе коло, 3 контрасти, МРНП, З-В-Д, Шлях за 5 кроків, П-Р-П [C-l08-013]
3. **framework** — 4 тони голосу: Мудрець (Йода/Гендальф) · Воїн · Друг · Чарівник. Ідеальна динаміка: Друг → Мудрець → Воїн → Чарівник [C-l08-036] [C-l08-041]
4. **methodology** — Практика «Один фокус»: «сьогодні я треную ОДИН елемент», не «виступаю ідеально» [C-l08-047]
5. **theory** — Тон керує впливом, структура керує логікою; сильний спікер — той, хто перемикається [C-l08-046]

## Applied to практик

- **Виступи Юрія (Статус, MCMM Power, Pitch для Synthesis)**: на Статусі — Арка Героя L1 (особиста) + вставка Ескалації L3 у фінальній чверті перед оффером; тони переважно Друг → Мудрець → Чарівник, Воїн коротко у точці кипіння. На MCMM Power — Шлях за 5 кроків + З-В-Д, тон Мудрець. На pitch для Synthesis — AIDA + Ескалація, послідовність Воїн → Друг → Чарівник → Воїн. На Reels на холодний таргет — 3 контрасти або МРНП, тон Воїн (хук) → Чарівник (фінал). Фокус щомісяця за ex-14: цикл 8 фокусів = 8 місяців прицільної практики.
- **Detective FM «Розслідування»** (€300, 2 год): ex-15 reflection → виявити позицію клієнта; ex-16 self-rating 8 структур → виявити природні; ex-01 30-сек вибір структури + ex-12 «Один фокус» → план підготовки. **Done when**: клієнт виходить з сесії знаючи (а) яку структуру використати, (б) який ОДИН фокус тренувати, (в) як це робити дома (ex-13 + ex-02). 3-міс пакет (€1469): 6 сесій з повним циклом ex-09 + ex-10 під реальний майбутній виступ.
