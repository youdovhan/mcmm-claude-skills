# Тон у Живому колі — Друг → Мудрець → Воїн → Мудрець → Чарівник

## Мета

Прокласти ТОНАЛЬНУ ПОСЛІДОВНІСТЬ через Живе коло — найлюдянішу структуру L3. Якщо AIDA = холодна аудиторія, Ескалація = емоційна, то Живе коло = ТЕПЛА, ОСОБИСТА аудиторія. Денис прямо: «Найлюдяніша структура». Це 5 блоків з найбагатшим тональним перемиканням з усіх структур L3.

## Інструкція

### Підготовка

1. **Я кажу Юрію**: «Живе коло — найскладніший тональний drill, бо 5 блоків з 5-ма тонами. Послідовність: Історія = ДРУГ → Усвідомлення = МУДРЕЦЬ → Перелом = ВОЇН → Принцип = МУДРЕЦЬ → Завершення = ЧАРІВНИК. Це повне коло — починається з тепла, проходить через сенс, кульмінацію, повертається до сенсу, закінчується баченням.»

2. **Юрій робить**: підтверджує.

### Денисів текст

3. **Я кажу**: «Текст з курсу.

   **Історія — ДРУГ** (теплий тон, розповідаєш як людина): "Я довго уникав великих виступів."

   **Усвідомлення — МУДРЕЦЬ** (уповільнюєшся, тут глибина): "І в якийсь момент я зрозумів…"

   **Перелом — ВОЇН** (точка вибору, коротко): "Я або продовжую виправдовуватися, або виходжу."

   **Принцип — МУДРЕЦЬ** (спокійний висновок): "Структура знижує тривогу."

   **Завершення — ЧАРІВНИК** (м'яке натхнення): "І кожен із вас може пройти цей шлях."

   Готовий?»

4. **Юрій робить**: записує блоки.

### Варіант — свій текст

5. **Я кажу** (опційно після Денисового): «Тепер на власній історії. Згадай момент, коли ти ЗМІНИВСЯ через якийсь крок проявленості. 5 блоків:
   - Історія (Друг): «Я довго уникав / боявся / відкладав ...»
   - Усвідомлення (Мудрець): «І в якийсь момент я зрозумів, що ...»
   - Перелом (Воїн): «Я або ... або ...»
   - Принцип (Мудрець): «...»
   - Завершення (Чарівник): «І кожен з вас ...»»

6. **Юрій робить**: пише і записує.

### Кейс з курсу

7. **Я кажу**: «У курсі цей drill робила Олена. На блоці Чарівник Денис прямо сказав: "О, от це прекрасний волшебник був, Альона. Просто прекрасний". Це показовий момент — коли ти доходиш до останнього блоку (Завершення = Чарівник), якщо вся послідовність витримана, чарівник «розкривається» природно.»

### Post-mortem

8. **Я кажу**: «Послухай 5 блоків. Чи відчуваєш ти "коло"? Тобто історія → інсайт → переломний момент → принцип → відкриття для інших — це повний цикл, який має відчуватись як ціле?»

9. **Юрій робить**: self-фідбек.

10. **Я кажу**: «Мій фідбек: …»

11. **Я кажу**: «Єдиним потоком, плавно з мікро-паузами між блоками. Це покаже, чи можеш ти витримувати 5-тональну дугу без напруги.»

12. **Юрій робить**: єдиний потік.

13. **Я кажу**: «Зверни увагу: у Живому колі ВОЇН — це маленький фрагмент посередині. У AIDA Воїн — на початку і в кінці. У Ескалації — у Точці кипіння. Це показує: одна структура — це не "одне тонове рішення", а РОЗПОДІЛ тонів за метою кожного блоку.»

## Що оцінювати

- [ ] 5 окремих блоків + 1 єдиний потік записані
- [ ] Друг (Історія) — особиста, тепла, без високої позиції
- [ ] Мудрець (Усвідомлення) — уповільнення, відчуття «осідання» в глибину
- [ ] Воїн (Перелом) — найкоротший і найгостріший блок
- [ ] Мудрець (Принцип) — інший від Усвідомлення (там «розумію»; тут «закон»)
- [ ] Чарівник (Завершення) — м'яке натхнення, відкриття для слухача
- [ ] Кругова структура відчувається — починається теплом, закінчується натхненням

## Поширені помилки

- ❌ **Історія занадто лекторсько.** Юрій починає як експерт «давайте проаналізуємо ...». Це не Живе коло. Треба ОСОБИСТО: «Я довго уникав ...».
- ❌ **Усвідомлення і Принцип однакові.** Юрій не чує різниці. Усвідомлення = особистий інсайт «я зрозумів». Принцип = узагальнений закон «структура знижує тривогу».
- ❌ **Перелом затягнутий.** Юрій робить його довшим за Принцип. Денис: Перелом має бути КОРОТКИМ — це точка вибору, не пояснення.
- ❌ **Завершення стає Воїном.** Юрій після Принципу повертається до виклику. Тоді не Чарівник, а ще раз Воїн. Денис: «М'яке натхнення». Чарівник.
- ❌ **Юрій лишається у тоні Друга весь блок.** «Я зрозумів, я зрозумів, я зрозумів» — все Друг. Без переключень Живе коло — це просто історія, а не структура.

## Adaptations

- **Текст**: НЕ ПРАЦЮЄ. Підготовка тексту — можна.
- **Голос (Wispr/audio)**: ОСНОВНИЙ. Я слухаю:
  - **5 окремих pitch-профілів**: середній → низько (мудрець) → коротке низько-середнє (воїн) → знов низько → вище (чарівник).
  - **Tempo evolution**: розслаблено → повільно → швидко → повільно → м'яко.
  - **Емоційна температура**: тепло → глибина → напруга → стабільність → натхнення.
  - **Closure кожного блоку**: чи зрозуміло, де блок закінчується (інакше слухач не переключиться).
- **Відеозапис**: бажано. Дивлюсь на:
  - Тіло (Друг розслаблено → Мудрець стійко → Воїн стиснуто → Мудрець стійко → Чарівник відкрито).
  - Очі (м'які → глибокі → фокусовані → глибокі → відкриті, дивляться вдалечінь).
  - Жести (м'які → мінімум → коротко-чіткі → мінімум → м'які-широкі).
