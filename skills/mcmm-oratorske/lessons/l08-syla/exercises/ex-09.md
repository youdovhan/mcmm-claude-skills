# Тон у AIDA — Воїн → Друг → Чарівник → Воїн

## Мета

Прокласти ПОВНУ ПОСЛІДОВНІСТЬ ТОНІВ через структуру AIDA — від Attention до Action. Це структура для холодної аудиторії, де тон ОСОБЛИВО важливий, бо ведеш людину з нуля до конкретного кроку. Денис: «Тут не можна тиснути. Тут потрібно зблизитися. Тут — зона бачення. Тут — імпульс».

## Інструкція

Це drill з 4-х блоків AIDA + переключень. Можна на дениковому тексті (для першого разу) АБО на власному (рекомендую — для глибшого ефекту).

### Підготовка

1. **Я кажу Юрію**: «Розгорнемо AIDA з повним тональним перемиканням. Послідовність: Attention = ВОЇН → Interest = ДРУГ → Desire = ЧАРІВНИК → Action = ВОЇН (спокійний). Денисів готовий текст, чи хочеш свій?»

2. **Юрій робить**: вибирає (Денисів — швидше; свій — глибше).

### Варіант А — Денисів текст

3. **Я кажу**: «Текст з курсу. 4 блоки. Між ними пауза 3-5 сек.

   **Attention — ВОЇН** (твердий, чіткий, без зайвих емоцій): "Більшість експертів не ростуть не через брак знань."

   **Interest — ДРУГ** (теплий, розуміючий): "Я знаю, як важко вийти в ефір, коли всередині є сумнів."

   **Desire — ЧАРІВНИК** (натхненний, розширює горизонти): "Уявіть, що за рік ви спокійно виступаєте на великих майданчиках."

   **Action — ВОЇН СПОКІЙНИЙ** (впевнений, без агресії): "Якщо хочете системно вибудувати виступи — приходьте."

   Готовий записувати? Кожен блок — окремо.»

4. **Юрій робить**: записує 4 блоки.

### Варіант Б — свій текст

3-б. **Я кажу**: «Свій текст. Тема — твоя експертиза. Я допоможу написати 4 блоки.

Attention: ВОЇН — твердий хук про твою цільову аудиторію. Що для них головна омана?

Interest: ДРУГ — теплий контакт зі знайомим болем. "Я знаю як це, бо сам через це пройшов".

Desire: ЧАРІВНИК — натхненний образ майбутнього. "Уявіть, що за X місяців у вас..."

Action: ВОЇН СПОКІЙНИЙ — заклик до дії. Без тиску, але впевнено.»

4-б. **Юрій робить**: пише 4 блоки.

5-б. **Я кажу**: «Перевіримо:

- Attention НЕ м'який (тільки м'який = провал, бо холодна аудиторія)
- Action НЕ виправдовується (тільки тверда впевненість)
- Interest НЕ зверху (інакше втратиш контакт)
- Desire НЕ абстракція (конкретний образ майбутнього)

Готовий записувати?»

6-б. **Юрій робить**: записує 4 блоки.

### Post-mortem

7. **Я кажу**: «Тепер послухай 4 блоки підряд. Чи відчуваєш переходи? Чи це звучить як ОДИН моноголос, чи як 4 різні енергії в одній особі?»

8. **Юрій робить**: self-фідбек.

9. **Я кажу**: «Мій фідбек: …». Особливо — на ПЕРЕХОДАХ:
   - Воїн → Друг: чи знизилася твердість? Чи з'явилася теплота?
   - Друг → Чарівник: чи pitch піднявся? Чи з'явилися паузи перед сильними словами?
   - Чарівник → Воїн: чи повернулася твердість, але БЕЗ агресії?

10. **Я кажу**: «Тепер запиши все 4 ОДНИМ дублем, без пауз між блоками. Це покаже, чи можеш ти триматися структури і тонів у живому потоці.»

11. **Юрій робить**: 5-й дубль єдиним потоком.

## Що оцінювати

- [ ] Усі 4 блоки записані окремо + 1 єдиний потік
- [ ] Attention (Воїн) — твердість, без м'якості; pitch низько-середній; кінець на відкритому знаку
- [ ] Interest (Друг) — теплота, «ми»-лексика; smile-in-voice
- [ ] Desire (Чарівник) — pitch вище, паузи перед «уявіть», образ майбутнього
- [ ] Action (Воїн спокійний) — впевненість БЕЗ агресії, без виправдовування
- [ ] Переходи відчутні навіть у єдиному потоці
- [ ] Денис прямо: «Тут не можна тиснути» (на Interest) — Юрій не тисне; «Тут не виправдовуватися» (на Action) — Юрій не виправдовується

## Поширені помилки

- ❌ **Attention занадто м'який** (Друг замість Воїна). Денис: «Якщо почати з Друга — буде сильно м'яко. Якщо з Мудреця — нудно. Тут потрібен імпульс».
- ❌ **Action знов агресивний** (Воїн без поліровки). Action = «Воїн СПОКІЙНИЙ». Не примус, а впевнене запрошення.
- ❌ **Interest стає лекторськи** (Мудрець замість Друга). Холодну аудиторію треба ЗБЛИЗИТИ — Друг саме для цього.
- ❌ **Desire стає Мудрецем** (опис без натхнення). Денис: «Уявіть» — ключове слово, тон Чарівника.
- ❌ **Юрій не записує єдиним потоком** — тільки окремі блоки. Тоді не натренує переходи. Зробити обидва типи запису.

## Adaptations

- **Текст**: НЕ ПРАЦЮЄ для самого drill'у. Але підготовку свого AIDA можна писати текстом.
- **Голос (Wispr/audio)**: ОСНОВНИЙ. Я слухаю:
  - **Pitch evolution**: 4 блоки повинні мати ВІДМІННІ pitch-профілі (Attention низько → Interest середньо → Desire високо → Action знов низько).
  - **Tempo evolution**: швидкий → повільний → середній → впевнено-неспішний.
  - **Energy evolution**: tension → empathy → expansion → return-to-action.
  - **Transition smoothness**: у єдиному потоці — чи плавні переходи, чи стрибки.
- **Відеозапис**: дивлюсь на:
  - Постава змінюється з блоку в блок (Воїн — пряма, Друг — розслаблена, Чарівник — трохи відкрита, Action — знов пряма).
  - Жести (Воїн мінімальні, Друг відкриті, Чарівник широкі, Action чіткі).
  - Очі (Воїн фокусовані, Друг м'які, Чарівник «бачать майбутнє», Action знов фокусовані).
