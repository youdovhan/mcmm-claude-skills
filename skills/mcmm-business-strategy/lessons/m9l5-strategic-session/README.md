## Top-5 Takeaways

### 1. Стратсесія = simulated brainstorm проміжок з ритуалом

Не лекція, не консультація. Це **simulated простір** часу де несвідоме поле учасників видає інформацію через ритуал кубика + питання + жорсткий таймінг. "Несвідоме поле дає більше інформації ніж наша логіка" (L835). Sectors поля гри = бізнес-функції що хочуть уваги — "ви потрапляєте не випадково".

### 2. Фокусуюче питання = 80% успіху стратсесії

Перед грою — preprocessing у "розпаковці запиту". Структура: (1) що хочеш (outcome + цифра); (2) чому актуально; (3) які умови/обмеження; (4) які метрики успіху; (5) який термін. Без правильно сформульованого фокусуючого питання гра не працює.

### 3. Жорсткий таймінг створює фокус

"Це все ж таки про ті обмеження, в яких ми існуємо. І цей таймір, він дозволяє вам сфокусуватися" (L1636-1637). Без таймінгу — учасники йдуть у глибину терапії замість стратегії. Розподіл: 2 хв активний → 1 хв помічник → опція guest-фідбек → expert-фідбек фасилітатора.

### 4. Помічник = симетричне дзеркало через антитезу

Помічник = інший активний учасник, обраний на 1 хід. Це не peer-coach і не authority — це **симетричне дзеркало**. Сніжана обирає Юрія: "Він максимально мені здається інший, ніж я, і максимально мені дасть іншу думку" (L891). Принцип: максимальна продуктивність — від helper, який дзеркалить antithesis.

### 5. Розсуждення vs план (Гончар teaching moment з Юрієм)

Гончар L1626-1627: "Юрій, до цього це були **розсуждення**, а ось оце вже звучить як **план**". Розсуждення = загальні роздуми про продукт. План = **конкретні offer-и під конкретні аудиторії з road map**. Стратсесія перетворює розсуждення у план через жорсткий фокус + питання.

## Ключові концепції Гончар (з m9l5)

### "Несвідоме поле видає більше ніж логіка" (L835)

Стратсесія працює через несвідоме поле учасників. Тіні + ірраціональний вибір помічника + "випадковий" сектор кубика = механізми extracting tacit knowledge.

### "Розсуждення vs план" (L1626-1627)

Розсуждение = думки без меж між аудиторіями. План = **конкретні offers для конкретних аудиторій з road map** які можна тестувати завтра.

### "Маленьку ціль і маленький ходок" (L1730-1731)

Анти-overscale principle для людей які reentering бізнес-практику: "Візьми щось маленьке, з'їж маленьке, ковтни маленьке, посмакуй, і тоді ти підеш далі".

### "Стерти всю свою пам'ять" (L266-269)

Фасилітатор інтенціонально не використовує свою експертизу у ніші клієнта (clean space для несвідомого). "Ваше підсвідоме поєднається з несвідомим полем того, кого ви стратегуєте".

### "Капcтон recommendation = жорстка людина" (L1655-1657)

Юрію-серферу-хвиль: "Збалансуйте себе якоюсь жорсткою людиною, яка буде вас повертати в ваш фокус". Стратегія-серфера потребує доповнення партнером структурного мислення.

### "Авторська методологія" (L208-221)

Цінується найбільше — ваш унікальний синтез готових frameworks + бекграунду + адаптації. Не "винайти велосипед", а **компонувати** під клієнта.

### "Виділити час vs зрахувати" teaching moment (L1615-1616)

Глагол визначає результат. "Виділити" = passive дія без outcome, "зрахувати" = active дія з outcome. Precision у мові = precision у дії.

### "Несвідома компетенція" (L1165)

Феномен: експерт знає (екстерналізовано) у блозі/практиці, але **не може це проявити для себе**. Стратсесія = exteriorize tacit knowledge через дзеркало помічника.

### "Bias-метод як методологія" (L218-221, L96)

Анти-imposter рамка: можна на чужому фреймворку + ваші надстроєчки = ваша авторська методологія. "Це вже ваша методологія, ви скористалися в фреймворкі, але за рахунок надстроєчок".

### "Два аудиторії, два офери" (Юрієве L1620-1622)

Capstone insight Юрія: high-ticket (17-Pro Max аудиторія, "не можуть не купити", диктують ринку) + підписка (11-iPhone аудиторія, через місяці за ринком). Один продукт ≠ один сегмент. Bridge до mcmm-marketing продуктова лінійка.

## AI Boundary (особливо важливо для capstone)

| AI може                                            | AI НЕ може                                    |
| -------------------------------------------------- | --------------------------------------------- |
| Pre-session prep розпаковки фокусуючого питання    | Тримати симетричну роль помічника             |
| Post-session analytics + фінансова модель          | Створити простір з несвідомим полем учасників |
| Базові статистичні метрики                         | Підтримувати таймер з присутністю             |
| Підготовка структурованих питань по 7 секторах     | Фізично відчути динаміку групи + резистенс    |
| Прискорення road-map analytics                     | Дати ірраціональну рекомендацію проти логіки  |
| Часткове "жорстке нагадування" (structured prompt) | Замінити людину-фасилітатора в живій сесії    |

### Fundamental Гончар-stance (через capstone подтверджено)

> "AI може допомогти підготовкою матеріалу до стратсесії, але саму стратсесію може провести **тільки фасилітатор-людина**."

Чому?

- Стратсесія працює через **несвідоме поле учасників** (L268-269, L835)
- Фасилітатор тримає симетричні правила + гнеться ad-hoc (L1453-1457)
- Тіні працюють через групову динаміку — AI як медіум не створює цього поля
- Емоційний стан / тембр / тон голосу — AI на тексті без аудіо не може це виявити (L1241-1247)
- Принцип "стерти всю свою пам'ять" — людина може інтенціонально, AI не може unlearn для специфічної сесії

### Що змінюється для Detective FM (Юрієве позиціонування)

Юрій як coach + facilitator може використовувати AI як:

1. **Pre-session prep** — розпаковка фокусуючого питання через діалог/опитувальник
2. **Post-session analytics** — прорахунок фінансової моделі для клієнта
3. **In-session timer + питання** — як structured prompt для Юрія
4. **Capstone recommendation Гончар** — як **частково** "жорстка людина" що повертає у фокус
5. **НЕ** subsiding фасилітатора. Юрій залишається людиною-фасилітатором, AI = helper.

Це fits memory `feedback_ai_helper_not_ai_copy.md`: AI-помічник, не AI-копія живої людини.
