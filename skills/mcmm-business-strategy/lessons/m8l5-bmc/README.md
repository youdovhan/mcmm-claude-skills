## Тема уроку

**Business Model Canvas (BMC)** — фреймворк Александра Остервальдера для аналізу бізнесу, тестування гіпотез і фасилітації стратегічних сесій. Юлія Гончар адаптувала його під свою консалтингову практику, інтегрувала з 7 ключовими бізнес-функціями (з m7l5), і використовує як **must-have інструмент** при запуску продуктів / стратегічному плануванні / тимбілдингу.

**Big Idea уроку:**

> "Бізнес = система з 9 елементів, які взаємопов'язані. BMC — це **контурна карта** бізнесу, яка дозволяє: (1) побачити бізнес цілісно; (2) протестувати гіпотезу ДО її впровадження; (3) знайти 'вузькі місця' як шестерні в годиннику; (4) дозволити клієнту самому знайти рішення."

## Top-5 Takeaways

### 1. BMC = 9 елементів, які присутні у БУДЬ-ЯКОМУ бізнесі

Соло-підприємець, мікробізнес, корпорація — всі мають усі 9 блоків. Питання не "чи є функція" а "як реалізована". Цитата Гончар: _"Бізнес = механізм/годинник. Кожна функція = колесико. Якщо одна шестерня не крутиться — годинник не функціонує."_

### 2. Все взаємопов'язано — зміна одного блоку змінює інші

Підвищення чеку → змінюється сегмент → інший канал → інші відносини → інша пропозиція → інші ресурси → інші витрати. Системне мислення. Кейс: x2 доходу = (а) ріжемо витрати; (б) збільшуємо чек; (в) збільшуємо потік — кожен варіант каскадує по всьому BMC.

### 3. Тестуй гіпотезу ДО впровадження — економить гроші

Кейс виробництва круп/цукру/солі: клієнти хотіли масштабуватись, але після BMC-аналізу побачили що в них касові розриви → треба спочатку змінити фінансову модель. Без BMC — "вбухали б гроші в реалізацію, яка не злетить".

### 4. AS-IS → TO-BE — спочатку точка А, потім точка Б

Для новачків BMC критично розділяти: спочатку повністю розібрати "як є" (AS-IS), потім моделювати "як має бути" (TO-BE). За досвідом Гончар, у **90% випадків** клієнт сам бачить трансформації лише після розбору AS-IS.

### 5. Фасилітатор створює простір, не вирішує за клієнта

Boundary критичний для коучів/менторів/фасилітаторів. Гончар:

> "Фасилітатор не повинен знати всі бізнес-моделі. Експертиза — лише у МЕХАНІЦІ роботи будь-якого бізнесу. Нюанси/ніші — не моя територія."

Юрій Довган (учасник) зробив помилку — пішов розв'язувати проблему ЗА клієнта. Це не фасилітація, а консалтинг ніші.

## Key Frameworks

### 9 елементів BMC (Остервальдер adapted by Гончар)

1. **Цінносна пропозиція / Продукт** — яку роботу клієнта виконує
2. **Сегменти клієнтів** — хто ідеальний (включно з "хто НЕ клієнт")
3. **Канали** — як дізнається + як купує + customer journey
4. **Відносини з клієнтом** — до/після покупки, account-management
5. **Джерела доходів** — разові / підписка / рекурентні
6. **Ключові ресурси** — гроші, час, навики + амортизація себе як ментора
7. **Ключова діяльність** — основні + допоміжні процеси
8. **Ключові партнери** — попередні клієнти, колаборанти, реферальна мережа
9. **Структура витрат** — фіксовані + змінні

### 7 ключових бізнес-функцій (Гончар, з m7l5)

1. Фінанси
2. Персонал (HR)
3. Продукт
4. PR / Маркетинг
5. Продажі і сервіс
6. Контроль бізнесу ⚠️ часто пропускається
7. Розвиток бізнесу ⚠️ часто пропускається

### Express-діагностика (preprocessing для стратсесії)

- Таблиця 7 функцій × 2 оцінки (1-10): задоволеність + важливість у контексті мети
- Час: 20-30 хв
- "Засіює" клієнту думку (метафора "Інсепшн")
- Готує мозок до правильних питань на стратсесії

### 3 канали зростання доходу

1. Оптимізувати витрати (підвищити маржу)
2. Підвищити чек (змінюється сегмент → інший канал)
3. Збільшити потік (більше продажів)

### 4 типи каналів маркетингу

1. Платний
2. Безкоштовний
3. Партнерка
4. Сарафанка

⚠️ Спостереження 2026: "сарафанка вже не так ефективно, партнерка — дуже класно".

## Ключові концепції Гончар

### "Контурна карта бізнесу"

Авторська метафора Гончар для BMC. Не план + не стратегія — а **схема системи** з 9 елементів і їх взаємозв'язків.

### "Амортизація ментора"

Енерго-витрати соло-експерта як "станка": очі онлайн, спина, ТО, голова. "Ви контейнер для вашого продукту." На заводах раховують амортизацію станка — ментора (себе) мало хто. Критично для соло-бізнесу.

### "Інсепшн-засіювання"

Express-діагностика працює як засіювання думки (метафора з фільму). Клієнт ще не зробив висновок, але мозок підготовлений до правильних питань на стратсесії.

### "Платіть SEO зарплату собі"

Розділення ролей: експерт (надає послугу) / власник (стратегує) / SEO (керує). Кожна роль = окрема винагорода. Спочатку SEO у мінусі — нормально, але це окрема роль.

### "Я повертаю людей в реальність"

Бренд-позиція Гончар. Не motivational coach — а бізнес-економіст реальності, що рятує гроші клієнтів через ранню перевірку гіпотез.

## AI Boundary (важливо для Detective FM)

Урок дає **чітку межу між AI-помічником і людським фасилітатором**:

| AI може                   | AI НЕ може                                 |
| ------------------------- | ------------------------------------------ |
| Загальна механіка бізнесу | Створити простір для саморозуміння клієнта |
| Аналіз даних              | Емоційна підтримка ("спокій + ясність")    |
| Питання для розгортання   | Експертиза в специфічній ніші клієнта      |
| Підбір прикладів          | Тимбілдинг + командна динаміка             |
| Підготовка шаблонів       | Фізична присутність як "контейнер"         |

Цитата Гончар (про фасилітатора, applicable до AI):

> "Наша задача — створити простір, у якому клієнт сам знайде рішення."

Це fits Detective FM позиція: "AI-помічник, не AI-копія живої людини" (per memory `feedback_ai_helper_not_ai_copy.md`).
