## Top-5 Claims (найважливіше з уроку)

1. **План ≠ Стратегія** (lines 132-145): План = перелік дій (рівень дій Пiраміди Ділтса). Стратегія = лінія поведінки на рівні цінностей / ідентичності / місії. Стратегія формується на найвищих рівнях Ділтса — план каскадується звідти вниз до рівня дій.

2. **Каскадна модель ритму компанії** (lines 110-122): Стратегічна сесія (раз/рік) → квартальні зустрічі → щомісячні → щотижневі → щоденні. Кожна квартальна зустріч = міні-стратегічна сесія (перегляд курсу). Модель працює для компаній з оборотом 0-10 млн USD/рік (line 124).

3. **Стратегія = поєднання раціонального + ірраціонального** (lines 172-184): Стратегування = масштабна креативна генерація ідей. Магія виникає коли поєднується "солоний + солодкий сніданок" — рацiонал (цифри, логіка, фінанси) + креатив (емоції, генерація ідей). Метафора через типологію сніданку учасників (lines 5-28).

4. **Фокусуюче питання — серце стратегічної сесії** (lines 270, 294, 314-337): Універсальна формула — "За яких трансформацій / умов / дій ми досягнемо <результат> до <дедлайн>?" Має містити: ціль + результат + дедлайн + емоційний booster + обмеження. Приклад (line 332-333): "Які трансформації в бізнес-процесах стануть стартом для виходу компанії на ринок Польщі у 2027-му році?"

5. **Метод ORID (ОРІП) — фокусована дискусія за 4 рівнями** (lines 880-928): Як працює мозок при прийнятті рішень — (1) Об'єктивний (факти, що є зараз), (2) Рефлективний (емоції, реакції), (3) Інтерпретативний (для чого це важливо, наслідки), (4) Decisional (які дії, кроки). Фасилітатор формує питання за всіма 4 рівнями і відчуває де клієнт "застрягає" (line 987-993).
