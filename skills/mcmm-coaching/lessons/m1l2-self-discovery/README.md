## Теза

**Self-discovery — це не окремий модуль, а основа всього коучингу. Ми не можемо вести клієнта туди, де самі не були. Тому коуч мусить мати власну розгорнуту self-discovery практику ДО того, як береться супроводжувати клієнта.** Без неї коуч скочується у позицію спасателя/рецептника/експерта/тренера. З нею — формується **executive-позиція + глибока нейтральність + присутність** = трансформаційний коучинг.

---

## Ключові концепти

- **Self-discovery як стиль мислення** — не духовна практика, а звичка запитувати себе "хто я? чому я обираюсь так?"
- **4 ключові компоненти self-discovery**: сильні сторони / цінності / потреби / автентичність + **внутрішній компас**
- **KPI без self-discovery** = досягається ціною самозради, вигорання, втрати контакту з собою
- **Коуч НЕ встановлює KPI за клієнта** — допомагає сформулювати чітко і вимірювано (передвісник SMART)
- **Присутність (5-та компетенція ICF)** — бути з клієнтом цілком, без внутрішнього шуму
- **Активне слухання (6-та компетенція ICF)** — коуч як чисте дзеркало
- **4 anti-ролі коуча**: спасатель / рецептник / експерт / тренер
- **5 тригерів спасателя**: зітхання клієнта / швидка допомога / емоції+сльози / "я це пройшов" / клієнт ходить навколо
- **Контр-перенос → супервізія**, не сесія з клієнтом
- **5 принципів етичного кодексу ICF**: автономія / конфіденційність / відмова від оцінки / ненаправлений вплив / присутність
- **2 опори трансформаційного коучингу**: executive позиція + глибока нейтральність
- **Метафора ліхтарика** — тримаємо світло, але не направляємо клієнта
- **Метафора чистого дзеркала** — клієнт бачить себе через коуча
- **Метафора археології душі** — шар за шаром знімаємо нав'язані сценарії
- **SMART** як абревіатура для структури мети: Specific / Measurable / Achievable / Relevant / Timebound
- **3 спрощені питання SMART**: що хочете? як зрозумієте? перший крок?
- **Anti-pattern "розмита мета"** — мозок втрачає орієнтири
- **Anti-pattern "вести у свою правду"** — коуч проектує свої цінності
- **Витримка в тиші** = основа присутності
- **Щоденник коуча** — інструмент саморефлексії (50-100 питань)
