# MCMM Psychiatry — Symptom Atlas

> **Призначення:** швидкий lookup "симптом → урок MCMM, де описано". Для (а) клінічних відеозадач на іспиті, (б) coaching-сесій з клієнтами, де опис скарг → суджестія "див. MCMM L<N> synthesis".
>
> **Покриття:** L3 (емоції/воля) → L13 (особистість). 11 уроків. ~190 симптомів/синдромів/маркерів.
>
> **Джерело істини:** виключно `lessons/lXX-<slug>/synthesis.md`. Не екстраполяції.
>
> **Формат індексу:** Симптом · Урок · Секція synthesis · 1-рядкова цитата.
> **Дублі:** один симптом у двох уроках = два рядки.

## §2 — Індекс за уроками (тематичний)

### L3 — Емоції і воля

- 24 розлади емоцій (гіпотимія, гіпертимія, дисфорія, ейфорія, апатія, лабільність, ригідність...)
- 4 типи ступору: депресивний, кататонічний, психогенний (реактивний), апатичний
- Воля: гіпербулія + гіпобулія + парабулія + абулія
- Парабулії: піроманія + клептоманія + дромоманія + трихотиломанія + перверзії
- 4 patological criteria для емоцій (адекватність + сила + тривалість + керованість)

### L4 — Пам'ять і увага

- Закон Міллера 7±2
- 6 законів пам'яті (Ebbinghaus + інші)
- 6 типів амнезій: антероградна + ретроградна + конградна + фіксаційна + прогресуюча + минуща
- Закон Рибо (від нового до старого)
- Парамнезії: déjà vu + jamais vu + presque vu + псевдоремінісценції + конфабуляції + криптомнезії
- Корсаківський синдром (тіамін, поліневрит, фіксаційна амнезія + конфабуляції)
- Деменції: Альцгеймер vs судинна vs Бінсвангер
- Гіпермнезія + гіпомнезія
- 4 параметри уваги: об'єм + стійкість + переключення + розподіл

### L5 — Мислення і мовлення

- 4 темпові розлади (тахіпсіхія + брадіпсіхія + ментизм + sperrung)
- 12 формальних розладів мислення (розірваність, резонерство, тангенціальність, символізм...)
- Зміст мислення (4-рівнева ескалація): афективна → надцінна → настирлива → марення
- 16 типів марення: переслідування, величі, ревнощів, гріховності, винуватості, відносин, спостереження, впливу, релігійне, реформаторства, kохання (érotomania), іпохондричне, нігілістичне (Cotard), Capgras, Fregoli, dysmorphophobia
- Camille Claudel case
- 3 категорії мовленнєвих розладів: афазії (Брока + Верніке + амнестична)

### L6 — Сприйняття

- 7 розладів відчуттів: анестезія, гіпестезія, гіперестезія, парестезії, дизестезія, сенестопатія, аллестезія
- Сенестопатії 4 НЕ (НЕприємні + НЕзвичні + НЕвимовні + НЕвиявні)
- Метаморфопсії: макропсія + мікропсія + дисморфопсія
- Ілюзії: 3 механізми (афективні + парейдолічні + вербальні)
- Галюцинації: 6 модальностей
- Псевдогалюцинації Кандинського

## §3 — Diagnostic pattern recognition (10 паттернів)

### Pattern 1 — «Молода жінка з конверсійним симптомом + audience-dependent»

**Симптоми:** geміплегія / астазія-абазія / blindness / aphonia без anatomical correlation + симптом стихає коли пацієнт сам.

**Differential:**

- F44 конверсійні (L12) — anatomical mismatch + audience-dependent + la belle indifférence + secondary gain
- Органічна неврологія — anatomical correlation + рефлекси патологічні + МРТ позитивна
- Малингер (Z76.5) — свідома продукція з зовнішньою вигодою
- Münchausen (F68.1) — свідома продукція заради ролі хворого

**Lessons:** L12 (F44 механізм) + L7 (differential з кататонією) + L13 (HPD як преморбід F60.4)

---

### Pattern 2 — «Молодий чоловік з раптовим марення + псевдогалюцинації + insight втрачений»

**Симптоми:** марення впливу + 'голоси у голові' з ознакою 'зробленості' + ідеаторні автоматизми + поведінкова дезорганізація + соціальна withdrawal.

**Differential:**

- Параноїдна шизофренія F20.0 (L7) — Кандинського-Клерамбо синдром + Schneider 1-st rank
- Параноя F22 — систематизоване монотематичне марення без галюцинацій
- F22 + органіка — TBI, deменція, інтоксикація
- BAR з psychotic features F31.5 — affective primary

**Lessons:** L7 (Кандинського-Клерамбо) + L5 (марення 16 типів) + L6 (псевдогалюцинації)

---

### Pattern 3 — «50+ людина з раннім пробудженням + вагою втрата + 3Б» (ендогенна депресія)

**Симптоми:** раннє пробудження о 4-5 ранку + втрата ваги > 5% + ранкова астенія + Verаgut складка + 3Б (безнадія + безпорадність + безсенсовість) + anaesthesia psychica dolorosa + плач + загальмованість.

**Differential:**

- F32 ендогенна MDD (L9) — circadian rhythm + anhedonia + 2+2+2 правило
- F31 BAR depressive episode (L8) — анамнез манії
- F34.1 дистимія — chronic > 2 років, не дотягує до F32
- Реактивна депресія (F43.21) — clear precipitant
- Hypothyroidism — TSH check

**Lessons:** L9 (тріада + 3Б) + L8 (differential з BAR) + L4 (deменція vs pseudoдементна депресія)

---

### Pattern 4 — «Молодий ветеран з flashbacks + hyperarousal + numbing»

**Симптоми:** flashbacks + nightmares + intrusive memories + intrusion-triggered дистрес + уникання тригерів + numbing + hypervigilance + startle response + sleep disturbance + irritability + > 1 місяць після травми.

**Differential:**

- ПТСР F43.1 (L11) — повна тріада ВУГ
- Гострий стресовий розлад F43.0 — < 1 місяця
- Розлад адаптації F43.2 — без full ПТСР criteria
- cPTSD ICD-11 — overlap з borderline F60.31
- Dissociative subtype ПТСР DSM-5 — depersonalization / derealization

**Lessons:** L11 (ВУГ + 6 варіантів) + L12 (cross-trauma з F44.0 amnesia + F44.5 PNES) + L13 (cPTSD vs BPD)

---

### Pattern 5 — «Перфекціоніст з рекурсивними сумнівами + контролем + ригідністю»

**Симптоми:** недосяжні стандарти + контроль усього + ригідні правила + повторні перевірки + magical thinking (прикмети + ритуали) + сумліність до перфекціонізму + ego-syntonic.

**Differential:**

- OCPD F60.5 (L13) — особистісна структура, ego-syntonic, не страждає
- ОКР F42 (L10) — симптом nav'язливий, ego-dystonic, страждає
- Ананкастна акцентуація — норма, ситуативна

**Lessons:** L13 (OCPD) + L10 (ОКР з порівнянням) + L3 (амбівалентність як emotion disorder)

---

### Pattern 6 — «Молода жінка з нестабільним self + splitting + self-harm + страх покинутості»

**Симптоми:** хронічна нестійка identity + interpersonal splitting (idealization-devaluation) + impulsivity (risky sex, substance, spending) + self-harm + страх abandonment + emotional dysregulation + chronic feelings of emptiness.

**Differential:**

- BPD F60.31 (L13) — life-long структура, підлітковий дебют
- F31 BAR (L8) — епізоди тижні-місяці, between-episode stable
- cPTSD ICD-11 (L11) — clear childhood trauma + flashbacks
- HPD F60.4 — менш self-destructive, не splitting, attention-seeking

**Lessons:** L13 (BPD vs BAR table §4.4) + L8 (BAR diff) + L11 (cPTSD overlap)

---

### Pattern 7 — «Літня людина з фіксаційною амнезією + конфабуляціями + поліневритом» (Корсаков)

**Симптоми:** не може запам'ятати нову інформацію (повторно знайомиться з лікарем) + заповнює провали fabricated stories without conscious deception + поліневрит (часто алкогольний) + офтальмоплегія + атаксія + дезорієнтація.

**Differential:**

- Корсаківський синдром (L4) — алкоголь / тіамінова дефіцит
- Wernicke encephalopathy — гострий phase
- TGA (transient global amnesia) — раптовий, до 24 годин
- Альцгеймер early — без поліневриту
- Pseudo-dementia (депресія літніх) — ефект лікування АД

**Lessons:** L4 (Корсаков + парамнезії) + L9 (pseudo-dementia ддд)

---

### Pattern 8 — «Раптові вегетативні штурми + страх смерті + тривога антиципаційна»

**Симптоми:** раптові епізоди (max 10 хв) тахікардії + dyspnoea + chest pain + парестезії + dizziness + страх смерті / контролю + post-attack антиципація + agoraphobia secondary.

**Differential:**

- Панічна атака F41.0 (L10) — typical pattern
- ГТР F41.1 — chronic > 6 міс, без discrete attacks
- Pheochromocytoma — endocrine cause
- Гіпертироз — TSH check
- Ішемічна хвороба серця — кардіо обстеження

**Lessons:** L10 (паніка + ГТР + 6 vegetative systems) + L11 (paniка vs flashbacks ПТСР)

---

### Pattern 9 — «Пацієнт з повторюваними somatic скаргами + множинними обстеженнями норма + не задоволений»

**Симптоми:** множинні somatic complaints різних систем + history множинних normal investigations + 'doctor shopping' + переконаність у тяжкій хворобі + не приймає reassurance.

**Differential:**

- F45.0 Соматизований розлад
- F45.2 Іпохондричний розлад (L10)
- F44 Конверсійний — neurological mask, anatomical mismatch (L12)
- Маскована депресія (L9) — алгічна / соматизована форма
- ГТР з somatic complaints (L10)

**Lessons:** L10 (іпохондрія) + L12 (F44 vs F45) + L9 (маскована депресія)

---

### Pattern 10 — «Підліток з раптовою withdrawal + bizarre interests + дивна логіка»

**Симптоми:** раптова social withdrawal + інтерес до незвичних / абстрактних тем + дивна логіка / резонерство + flat affect + бідне emotional engagement + відсутність close friendships.

**Differential:**

- Шизофренія F20 продром (L7) — risk for full F20.0 / F20.1
- Schizotypal F21 — між нормою і F20
- SPD F60.1 (L13) — стабільна особистісна структура
- Підліткова криза — норма, situational
- High-functioning autism (F84.5) — neurodevelopmental

**Lessons:** L7 (продром шизофренії + Bleuler 4А) + L13 (SPD differential) + L4 (увага)

## §4 — Cross-cutting themes (5 наскрізних тем)

### Тема 1 — Ego-syntonic vs ego-dystonic як diagnostic gate

**Концепт:** чи риса/симптом сприймається пацієнтом як 'своя' (syntonic) чи як 'чужа, нав'язана, страждальна' (dystonic).

**Уроки:**

- L5 — марення (ego-syntonic, no insight) vs обсесії (ego-dystonic, insight)
- L7 — психоз (ego-syntonic) vs невроз (ego-dystonic)
- L10 — ОКР F42 (ego-dystonic) vs OCPD F60.5 (ego-syntonic)
- L13 — F60 PD (ego-syntonic) vs F40-F48 невроз (ego-dystonic)

**Coaching impact:** ego-syntonic = погана motivation = коучинг малоефективний; ego-dystonic = motivation присутня = коучинг продуктивний.

---

### Тема 2 — Insight як crucial differentiator (PIN критерій Жане)

**Концепт:** збереження критики як cardinal feature неврозу проти психозу. PIN = Psychogenic trigger + Insight intact + No psychotic features.

**Уроки:**

- L7 — параноїдна шизофренія (insight втрачений, anosognosia)
- L10 — ОКР F42 (пацієнт усвідомлює абсурдність нав'язливих)
- L11 — ПТСР (insight intact для більшості симптомів)
- L12 — F44 істерія (insight intact, gold standard PIN)
- L6 — Charles Bonnet syndrome (insight intact на галюцинації)

**Diagnostic protocol:** запитати пацієнта 'як ви оцінюєте ваш досвід — це реальність чи можливо ваше переживання?' — якщо самокритика збережена → невроз; якщо absent → psychosis.

---

### Тема 3 — Тригер психогенний vs ендогенний (etiological axis)

**Концепт:** зовнішній тригер (psychogenic) vs внутрішній циклічний (endogenous).

**Уроки:**

- L8 — F31 БАР (endogenous) vs F32.x з тригером (psychogenic / reactive)
- L9 — endogenous депресія (без тригера, циркадний ритм, anaesthesia psychica dolorosa) vs reactive (тригер чіткий)
- L11 — ПТСР завжди psychogenic (катастрофічний тригер обов'язковий)
- L12 — F44 завжди psychogenic
- L13 — PD endogenous (life-long, конституціональне) + environmental (виховання)

**Treatment impact:** endogenous → фарма first-line; psychogenic → психотерапія first-line.

---

### Тема 4 — Ригідність як трансдіагностичний marker

**Концепт:** rigidity як inability to adapt patterns of thinking, feeling, behaving despite changing context.

**Уроки:**

- L3 — афективна ригідність (емоційне застрягання)
- L5 — мисленнєва ригідність (резонерство, perseveration)
- L7 — кататонічна ригідність (восковая гнучкість)
- L10 — ОКР ригідність (ритуали, контрольні перевірки)
- L13 — PD core: ригідність cross-type (всі 8 типів)
- L11 — ПТСР post-traumatic ригідність (avoidance + numbing)

**Coaching gate:** rigidity = single best predictor немотивованості / непродуктивності коучингу. Якщо клієнт не може спробувати new behavior на 1 експеримент (24 год) → ригідність → психотерапевт перш ніж коуч.

---

### Тема 5 — Двополюсна модель preсtanding vs decompensation (Ганнушкін)

**Концепт:** поточний 'compensated' state може кардинально відрізнятися від decompensated state під стресом. Премор бід → активація → reverberation.

**Уроки:**

- L7 — шизофренія: продром → дебют → ремісія → дефект
- L8 — БАР: еутимія → манія → змішаний → депресія
- L9 — депресія: компенсована → декомпенсована (стрес, втрата) → suicid risk
- L11 — ПТСР: pre-trauma personality → постtraumatic decompensation → cPTSD
- L12 — F44: преморбід (HPD) → активація конверсією → хронізація
- L13 — Ганнушкінська динаміка: компенсація / декомпенсація / реакція

**Clinical pearl:** «не оцінюй пацієнта виключно за поточним станом — питай про стабільність останніх 5 років, реакції на стрес, decompensation episodes».
