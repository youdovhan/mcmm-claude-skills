## Quick summary

Лекція ~11 хв 30 сек від **Світлани Володимирівни Ісаєнко**. **Нозологічна одиниця №6** модуля 10 — рубрика F44 МКБ-10. Це третя класична форма неврозу (після неврастенії F48.0 і обсесивно-фобічного F40+F42), архетипний феномен історично сформованої неврозології (Charcot → Janet → Freud у Salpêtrière, XIX ст.).

**Ключова теза**: істерія — це **psychogenic + reversible + critical insight + no organic** розлад, де психіка через захисний механізм (конверсія + дисоціація) трансформує психологічний конфлікт у поліморфні симптоми. Класифікація F44: F44.0 амнезія + F44.1 фуга + F44.2 ступор + F44.3 транси + F44.4-7 конверсійні + F44.81 DID + F44.8 істеричні психози. Клініка через **4 групи симптомів** (АВРС — афективні + вегетативні + рухові + сенсорні). Лікування: **psychotherapy first-line** (КПТ + психодинамічна + EMDR + гіпноз) + фарма adjunct (антидепресанти + анксіолітики).

**Двочастинна композиція**: 5 хв core нозологія (механізм + класифікація + 4 групи) + 5 хв клінічні нюанси (преморбід + перебіг + diagnostic test + лікування) + 1.5 хв historic + closing.

**43 секції лекції** (post-hoc реконструкція за transcript timestamps):

1. Перейменування «істерії» (hystera = матка) на дисоціативні / конверсійні розлади + gender myth correction
2. Механізм істерії: дискомфорт → підсвідоме → поліморфні неврологічні прояви + no organic finding
3. Істерія = патологічний механізм психологічного захисту (Freud)
4. DID як «полумифічне роздроєння особи» — теж психологічний захист
5. Механізм DID: травма дитинства → «нова особа» приймає удар + амнезія
6. DID — рідкісний клінічний феномен
7. Визначення дисоціації: автономія психічних комплексів (Janet)
8. **Класифікація F44 за МКБ-10**: F44.0/1/2/3 + істеричні психози
9. Визначення конверсії (conversio = перетворення) + 3 типи (рухові / сенсорні / вегетативні)
10. Клініка: поліморфність + підвищена навіюваність + лабільність + демонстративність + мінливість
11. Симптоми як маніпуляція оточуючими (secondary gain) + захисний характер

13. Преморбід: художній тип + психічний інфантилізм + емоційна незрілість

28. **Патоморфоз**: повна анестезія → парестезії (через популяризацію медзнань)
29. Пафос у скаргах + перебільшення

## Coaching application (DETECTIVE FM)

8 actionable правил для Юрія-Детектива (детально у `synthesis.md` §7):

1. ⭐ **Recognize patterns, не diagnose** — 9 features (поліморфний симптом без верифікації + anatomical mismatch + demonstrative + belle indifférence + audience-dependent + semantic зв'язок + convenient timing + secondary gain + histrionic преморбід); ≥ 4 features → refer
2. **Не reinforce demonstrative behavior** — extinction logic (Pavlov+Skinner); не sympathize «бідний ти бідний»; reframe «що ти сам хочеш зробити?»
3. **Face-saving exit при resistance** — НЕ конфронтувати «у тебе нема нічого, ти симулюєш»; запропонувати легітимний exit («тепер ти зрозумів свою силу — можеш встати»)
4. **Військовий контекст України 2026** — cross-trauma F43+F44 overlap; cultural shift у бік subtle patho-morphosis (парестезії, мігренеподібні, fatigue); destigmatization
5. ⛔ **DID кейси — refer, не coach** — спеціалізований DID-therapist (ISSTD); НЕ викликати alters через гіпноз/асоціативні техніки
6. **Self-screening кожні 3 місяці** для secondary trauma (vicarious traumatization)
7. **STOP signs**: psychotic episode + suicide + severe dissociation + active PNES + child abuse + reality loss
8. **Educational reframing** — пояснення механізму («твій мозок — інженер»; «тіло — мова»; «симптом — повідомлення»; «ти не симулюєш — реально переживаєш»)

**Червоні прапори для НЕГАЙНОЇ дії**:

- **Активний PNES припадок** → emergency 103; НЕ вводити антиконвульсанти; bystander removal
- **Severe dissociative episode** (фуга, ступор, multiple alters активно switching) → psychiatric emergency
- **DID кейси з активним switching** → психіатр + DID-trained therapist
- **F44 + child abuse disclosure** → захист дитини + child protective services
- **Suicidal ideation у F44 з secondary gain контекстом** → direct ask 5 питань (cross-ref L11 / L8); якщо ТАК на 3+ — швидка 103 + Lifeline 7333
- **F44 + комбіноване psychotic + severe MDD** → psychiatric hospitalization

## Lecturer style

Лектор тримає типовий «teplий» tone: «мої милі, мої родні студенти» (C-012-050), обійми. Розгортає матеріал щільно (~1 claim на 10 секунд лекції). Підкреслює клінічні pearls («рука-обличчя» — «який я називаю»), історичні контексти (Фрейд + XIX ст. дами), де-stereotype-ить термін (gender myth).
