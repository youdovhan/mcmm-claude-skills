## §0 — Quick thesis

**Невроз — це psychogenic + reversible + critical insight + no organic finding розлад, у якому психіка через захисний механізм трансформує психологічний конфлікт у поведінкові / тілесні / афективні симптоми; центральний клінічний прототип цієї групи — істерія (дисоціативні + конверсійні розлади F44 за МКБ-10), що розгортається у 4 групи симптомів (афективні + вегетативні + рухові + сенсорні), має 5 підрубрик (F44.0 амнезія / F44.1 фуга / F44.2 ступор / F44.3 транси та одержимість / F44.4-7 рухові-сенсорні-конвульсивні конверсії + істеричні психози), і лікується psychotherapy first-line з фармою як adjunct (антидепресанти + анксіолітики).**

Урок 12 — це **нозологічна одиниця №6** модуля 10 (після нозологічного каркаса L1-L7, афективних L8-L9, тривожних L10, ПТСР L11). Лектор включила цю тему у курс, бо **істерія = архетипний невроз** — на ньому історично сформувалось саме поняття «невроз» (Charcot → Janet → Freud → Breuer, XIX ст. Salpêtrière), і це єдиний розлад, де **психологічний конфлікт буквально перетворюється у тіло** (конверсія) або **дезінтегрує свідомість** (дисоціація). Це урок-міст: між загальною неврологією тривожних/ПТСР розладів (L10, L11) і пограничним полем психіатрії-неврології, який тягнеться у L1 (історія, XIX ст. як епоха формування неврозології), L3 (емоції, інтеграція vs дезінтеграція психічних функцій), L9 (overlap з депресією через дистимію / іпохондрію при хронізації), L11 (ПТСР dissociative subtype, psychogenic amnesia як цей самий механізм), L13 (істероїдний / histrionic PD як преморбід) [C-012-001 → C-012-070].

Лектор побудовує лекцію як **поетапне розгортання конструкту «істерія»**: етимологія + перейменування → механізм (підсвідоме → конверсія в тіло) → DID як крайня форма захисту → дефініція дисоціації + класифікація F44 → дефініція конверсії → 4 групи симптомів → diagnostic pearl (тест «рука-обличчя») → перебіг + патоморфоз + хронізація → лікування (фарма + психотерапія).

**Core insight для коуча**: якщо у клієнта раптом з'являється **поліморфний симптом** (параліч, припадок, тремор, оніміння, біль, афонія, втрата свідомості), який:

1. НЕ підтверджується інструментально (МРТ / ЕЕГ / лабораторія нормальні)
2. НЕ відповідає анатомії нервів (gloves / stockings distribution замість дерматома)
3. Залежить від наявності аудиторії (стихає при усуненні глядачів)
4. Має семантичний зв'язок з психологічним конфліктом / страхом
5. Супроводжується **la belle indifférence** (пафос у скаргах + байдужість до прогнозу)

— це **істерія, F44**. Розслідування: direct ask про психологічний конфлікт + screening 4 груп симптомів (афективні + вегетативні + рухові + сенсорні) + Charcot's анатомічний mismatch + bedside-тест «рука-обличчя» при припадках/непритомності + delegation до психіатра/психотерапевта (КПТ або психодинамічна терапія). Лікування антиконвульсантами / неврологічними препаратами — марне і шкідливе (C-012-025).

**Меседж лекції**: «Недооцінка клінічного значення симптомів неврозу, що трактуються як результат самонавіювання або агравації та симуляції, може призвести до неправильного діагностування та призначення неадекватної терапії» [C-012-042]. Заклик: НЕ розцінювати дисоціацію/конверсію як «вигадку» / симуляцію — пацієнт справді переживає симптом несвідомо. Заклик до integrative підходу: фарма + психотерапія + face-saving exit (дозвіл одужати без втрати лиця) [C-012-046].

**Whisper-критична нота**: транскрипт L12 рясніє помилками розпізнавання (whisper-калькою з російської): «двигатильні» → «рухові», «сенсаторні» → «сенсорні», «акинезій» → «акінезій», «несвідомість» → «невідповідність», «остинії» → «астенії», «повідомлення для зберігання» → «привід для одужання», «втратити увагу» → «втратити свідомість». Slides («Методичка», 7 слайдів) — єдине надійне джерело офіційної термінології. Усі ключові тези синтезу звірені з slides, а не лише з transcript.

## §2 — Key insights / paradigm narrative

### 2.1. Невроз — base concept + 3 критерії Жане

**Робоча дефініція неврозу** (synthesis з claims + cross-ref L1, L10): невроз — це **psychogenic** (психогенно зумовлений) розлад функцій психіки, який є:

1. **Psychogenic** — спричинений психологічним конфліктом / стресом / витісненим переживанням, а НЕ органічним ураженням ЦНС
2. **Reversible** — потенційно зворотний, не призводить до незворотних змін особистості (на відміну від психозу)
3. **Critical insight present** — пацієнт усвідомлює болісність свого стану, шукає допомоги (на відміну від психозу, де інсайт втрачений)
4. **No organic finding** — інструментальні методи (МРТ, ЕЕГ, лабораторія) НЕ підтверджують органічну патологію [C-012-002]

**3 критерії Жане** (P. Janet, 1903 — historical anchor для всієї групи F40-F48):

1. **Психогенне походження** — є чіткий зв'язок з психотравмуючою ситуацією у часі / семантиці
2. **Соматовегетативні + емоційні симптоми** — без власне психотичних проявів (марення, галюцинації відсутні; cross-ref L7 шизофренія)
3. **Збереження критики** — пацієнт здатний усвідомлювати свої симптоми як хворобливі і дистоничні

Ці 3 критерії є **gold standard** диференціації **невроз vs психоз** (cross-ref L7). У L12 явно не сформульовані, але імпліцитно присутні: лектор підкреслює інструментально не верифікований характер (C-012-002 — «підтвердити які інструментальними методами дослідження не вдається») і неорганічну природу як diagnostic anchor.

### 2.2. Три класичні форми неврозу (історична радянська класифікація)

Радянсько-українська психіатрична традиція XX ст. виділяла **3 класичні форми неврозу** як основу нозологічного каркаса F40-F48:

| Форма                                         | Сучасна МКБ-10                 | Core механізм                                                                 | Преморбід                                  |
| --------------------------------------------- | ------------------------------ | ----------------------------------------------------------------------------- | ------------------------------------------ |
| **1. Неврастенія**                            | F48.0 — neurasthenia           | Виснаження НС від тривалого стресу + дисбаланс збудження/гальмування          | Слабкий тип ВНД (Павлов); змішаний         |
| **2. Обсесивно-фобічний (психастенія / ОКФ)** | F40 фобії + F42 ОКР            | Гіперактивація 2-ї сигнальної системи (Павлов) + ригідність мислення          | Психастенічний (ананкастичний); 2-а с.с. ↑ |
| **3. Істеричний (істерія)**                   | F44 дисоціативні + конверсійні | Конверсія психічного конфлікту у тіло + дисоціація свідомості (Фройд + Janet) | Художній тип (Павлов); 1-а с.с. ↑          |

Урок 12 — **це третя класична форма**, найбільш «театральна» і feno-mено-logічно багата. Інші дві (неврастенія, ОКФ) у L12 не розглядаються детально, але згадуються:

- **Неврастенія** — як вторинне приєднання при затяжному перебігу істерії (C-012-041 — «стійка астенія»)
- **Іпохондричні + дистимічні розлади** — як вторинне приєднання при хронізації (C-012-041) — це міст до F45 (соматоформні) + F34.1 (дистимія, cross-ref L9)
- **Сенсорні + рухові розлади** — overlap з F40 фобіями (страх певних ситуацій тригерує симптом)

### 2.3. Етимологія + перейменування «істерії» — gender de-stereotyping

[C-012-001]: **Стара назва** — «істерія», від грецького **ὑστέρα (hystera) = матка** (C-012-069 — Hippocrates + Galen, V-II ст. до н.е. — «wandering uterus» теорія).

**Антична модель**: Гіппократ і пізніше Galen пояснювали симптоми «мандрівкою матки» по тілу — нібито матка «рухається» з нижньої частини живота вгору, тиснучи на інші органи і викликаючи симптоми. Лікування — шлюб / вагітність (як «закотити матку на місце»), ароматерапія (приємні запахи до промежини — щоб «приманити» матку повернутись; неприємні до носа — щоб «відштовхнути» при підйомі). Ця псевдо-теорія дожила до XVIII ст.

**Сучасна МКБ-10**: терм «істерія» замінено на **«дисоціативні (конверсійні) розлади»** з двох причин:

1. **Gender myth correction**: істерія НЕ є жіночим розладом — зустрічається і у чоловіків (C-012-001)
2. **Mechanism correction**: патогенез — психологічний (конфлікт + захист), а не «матковий»

Slide дублює назву уроку як **«Істерія. Дисоціативні (конверсійні) розлади»** — старий і новий термін співіснують у клінічному дискурсі.

**Critical pearl gender**: чоловіча істерія була відома з XVIII ст. (J.-B. Whytt, T. Sydenham), але систематично визнана лише Charcot у Salpêtrière (1880-і), де він демонстрував «mass hysteria» у чоловіків після травм (railway spine, ранніх трудових нещасних випадків). Сучасна епідеміологія F44: ~2-3x частіше у жінок, але **не ексклюзивно**.

### 2.4. Механізм істерії — Freudian conversion model

[C-012-002, C-012-003, C-012-010]: **Робоча модель механізму** (Freudian + Janet):

1. **Психологічний дискомфорт** — суб'єктивне неблагополуччя, нестерпний інтрапсихічний конфлікт (наприклад: бажання vs заборона, любов vs ненависть до близького, амбівалентність ролі)
2. **Невозможність свідомого вирішення** — конфлікт нестерпний для свідомості, treuю свідомістю відхиляється (denied / repressed)
3. **Підсвідоме «вирішення»** — психіка через захисний механізм трансформує конфлікт у **соматичний / неврологічний / поведінковий симптом**
4. **«Конверсія»** (conversio = перетворення, заміна, лат.) — конкретний механізм перекладу психічного у тіло [C-012-010]
5. **Поліморфні неврологічні прояви** — мінливі, багатоманітні, без органічного підтвердження інструментально [C-012-002]

**Slide quote**: «термін «конверсія» (лат. conversio - перетворення, заміна) означає особливий патологічний механізм, що зумовлює трансформацію психологічних конфліктів у соматоневрологічні симптоми».

Це **textbook Freudian формулювання** (Studies on Hysteria, 1895). Перевага конверсії як defense — **психічна тривога зникає** (primary gain — C-012-066): нестерпний конфлікт «знімається» через тілесний симптом. Класичний клінічний приклад: солдат напередодні битви розвиває істеричний параліч руки — несвідомо рятується від необхідності стріляти. Тривога зникає, конфлікт знятий, але ціна — параліч.

**Cross-ref L1**: лекція L1 представляє Freud як ключову постать в історії психіатрії; концепт конверсії — його core внесок. Janet (C-012-053) — конкуруюча школа, яка наголошувала на дисоціації пам'яті / свідомості як механізмі (не репресії несвідомого як Freud).

### 2.5. Дисоціація — визначення Janet

[C-012-008]: **Робоча дефініція дисоціації**: стан, коли на час **окремі психічні комплекси набувають автономії** і управляють психічними процесами **у відриві від цілісності психічного життя**. Це **транзиторне порушення інтеграції** психічних функцій.

Slide quote: «Дисоціація - такий стан, коли на якийсь час деякі психічні комплекси набувають автономії і управляють психічними процесами у відриві від цілісності психічного життя. Це транзиторні порушення інтеграції психічних функций».

**3 ключові елементи**:

1. **Автономія психічних комплексів** — пам'ять / ідентичність / відчуття «відколюються» від ядра «Я»
2. **Управління психічними процесами** — ці комплекси діють як автономний agent, керують поведінкою
3. **Транзиторність** — це **тимчасове** порушення, потенційно зворотне (cross-ref критерій неврозу #2 reversible)

**Janet's desagrégation**: П'єр Жане (1859-1947, C-012-053) вперше ввів термін «dissociation» / «desagrégation» (L'automatisme psychologique, 1889) як механізм нервових розладів і травм. Janet vs Freud — фундаментальна дискусія: Janet наголошував на **дисоціації пам'яті** (травма «відколюється» від свідомості і живе автономним життям як «фіксована ідея»); Freud — на **репресії несвідомого** (травма витісняється і повертається симптомом). Сучасна концепція F44 ближча до Janet (дисоціативна), F44 конверсії — ближча до Freud.

Лектор у L12 **детально розгортає лише конверсійні форми** (F44.4-F44.7) через 4 групи симптомів (афективні + вегетативні + рухові + сенсорні), а підрубрики F44.0-F44.3 ТЯН лише named без детального розгортання. Це дидактичне рішення — фокус на найбільш феноменологічно багатих формах.

#### 2.6.1. F44.0 Дисоціативна амнезія [C-012-055]

Втрата автобіографічної пам'яті на травматичні події або їх частини, що **НЕ пояснюється органічними причинами** (травма голови, делірій, інтоксикація). Може бути:

- **локалізована** (період травми) — найчастіша
- **селективна** (часткова, окремі аспекти)
- **генералізована** (вся життєва історія) — рідкісна
- **постійна** (від певної дати — без формування нових спогадів)

**Cross-ref**: L11 ПТСР — psychogenic amnesia як частина intrusion-кластеру (C-011-015); DID — амнезія між alters (C-012-005).

#### 2.6.2. F44.1 Дисоціативна фуга [C-012-056]

Раптовий мандрівний епізод: пацієнт залишає звичну обстановку (дім / роботу), часто змінює ім'я / ідентичність, може подорожувати на великі відстані. Триває від годин до тижнів. Після епізоду — **амнезія на період фуги**. Тригер — психотравма. Класичний приклад — солдат, що зник з фронту і знайшовся у іншому місті без пам'яті про себе.

**Diagnostic differential**: vs delirium (органіка) — фуга НЕ має дезорієнтації, мовлення не сплутане; vs епілептичний автоматизм — фуга триває довше і складніше координовано.

#### 2.6.3. F44.2 Дисоціативний ступор [C-012-057]

Стан псевдо-зупинки психічної активності: пацієнт **нерухомий, мутичний**, не реагує на оточення, **АЛЕ збережені фізіологічні функції** (тонус м'язів, реакція зіниць, ковтання). Відсутність органічної патології (МРТ, ЕЕГ норма). Тригер — психотравма.

**Differential**: vs кататонічний ступор (психоз, шизофренія, F20) — кататонічний ступор має воскову гнучкість + ехосимптоми; vs депресивний ступор — у депресивному є гіпотимічний афект, у дисоціативному — bel indifférence; cross-ref L9 + L7.

#### 2.6.4. F44.3 Транси та стани одержимості [C-012-058]

Тимчасова втрата відчуття особистої ідентичності + повне усвідомлення оточуючого; пацієнт діє так, ніби ним керує **інша істота, дух, божество** (possession trance). У МКБ-10 — діагностується **ЛИШЕ якщо це не частина культурно-прийнятної релігійної практики** (виняток — релігійний транс шамана, обрядове одержимість у культурно-прийнятому контексті).

**Culture-bound**: в українському секулярному контексті рідко; частіше у країнах з активною шаманською / релігійною практикою (Південна Америка, Африка, Південно-Східна Азія).

#### 2.6.5. F44.81 DID — Dissociative Identity Disorder (множинна особистість) [C-012-004, C-012-005, C-012-006, C-012-007]

**«Полумифічне роздроєння особи»** (whisper) = «напівміфічне роздроєння особистості». У МКБ-10 — F44.81 (раніше — MPD, Multiple Personality Disorder). Класична traumagenic theory (Putnam, van der Kolk):

1. **Тригер** — надсильна емоційна травма у дитинстві (типово — child abuse, fізичне/сексуальне)
2. **Формування «нової особистості»** (alter) — бере на себе емоційний удар замість первинної особи
3. **Первинна особистість «забуває»** — дисоціативна амнезія між alters (C-012-005)
4. **При наступних травмах** — alter знову активується (як «щит»)
5. **Між alters** — змінюються (1) автобіо пам'ять (memory gaps), (2) характер / темперамент, (3) часто голос, манери, суб'єктивний вік (C-012-006)

**Epidemiology**: справжній DID — **рідкісний** (~1% за DSM-5, контроверсійно). Лектор підкреслює це проти медійного перебільшення популярності (фільми, серіали).

**Контроверсійність діагнозу**: DID — один з найбільш дискутованих діагнозів у психіатрії. Прихильники (Putnam, van der Hart, ISSTD) — traumagenic theory; критики (McNally, Spanos) — sociocognitive model (alters виникають через очікування + терапевтичну induction). У L12 лектор тримає нейтральну позицію («полумифічне» — натяк на дискусію).

### 2.7. Конверсія — 3 типи симптомів + 4 групи у клініці

[C-012-010, C-012-011, C-012-019]: **Конверсія** (conversio, лат. = перетворення, заміна) — патологічний механізм, що трансформує психологічні конфлікти у **соматоневрологічні симптоми**.

**3 типи конверсійних симптомів** [C-012-011] — за нейрологічним рівнем:

| Тип             | Симптоми                                                                                | Slide              |
| --------------- | --------------------------------------------------------------------------------------- | ------------------ |
| **Рухові**      | Тіки + тремор + блефароспазм + хорея + судорожні припадки + паралічі                    | Slide 4 (Slide ?5) |
| **Сенсорні**    | Анестезія + парестезії + біль + псевдо-сліпота + псевдо-глухота                         | Slide 6 (Slide ?7) |
| **Вегетативні** | Кардіалгія + серцебиття + непритомність + nудота + блювання + одишка + хибна вагітність | Slide 4 (Slide ?5) |

Однак клініка L12 розгортається через **4 групи симптомів** [C-012-019] (3 типи конверсії + афективні):

1. **Афективні** (емоційні) — лабільність + бурні емоції + театральність
2. **Вегетативні** (autonomic) — соматичні скарги без органічної основи
3. **Рухові** (motor) — гіперкінези + акінезії
4. **Сенсорні** (sensory) — розлад чутливості + біль

Slide дублює: «У клінічній картині неврозу спостерігаються такі групи симптомів: афективні, вегетативні, рухові, сенсорні».

**Мнемоніка для коуча**: **«АВРС»** = Афективні + Вегетативні + Рухові + Сенсорні (4 групи симптомів істерії).

| 3   | **Емоційна лабільність**             | яскраві + швидко мінливі емоції (плач → сміх за хвилини)                      | C-012-012, C-012-020 |
| 4   | **Демонстративність + мінливість**   | для глядача (theatricality) + раптовість появи / зникнення                    | C-012-013            |
| 5   | **Маніпуляція + secondary gain**     | симптом використовується для отримання уваги, співчуття, уникнення обов'язків | C-012-014            |
| 6   | **Захисний характер**                | через симптом психіка «уникає» нестерпного усвідомлення / конфлікту           | C-012-015            |
| 7   | **Зв'язок зі змістом психотравми**   | симптом семантично корелює з конфліктом / страхом (autosuggestion)            | C-012-016            |
| 8   | **«Хамелеон / велика наслідувачка»** | імітує будь-яку органічну хворобу (Charcot epithet)                           | C-012-017            |

Slide quote (C-012-013): «Особливістю цих порушень є їх демонстративний характер, особлива мінливість, раптовість появи та зникнення. Симптоми хвороби нерідко набувають характеру маніпуляції оточуючими, і при вирішенні психотравмуючої ситуації вони слабшають або повністю зникають».

**Diagnostic key**: ці 5+ feature — **diagnostic clues**, що відрізняють істерію від органічної неврології. Якщо симптом раптовий + мінливий + demonstrative + audience-dependent + семантично пов'язаний з конфліктом + інструментально не верифікований — це F44, не органіка.

### 2.9. Преморбід — художній тип за Павловим

[C-012-018]: преморбідні риси, що схиляють до дисоціативного / конверсійного неврозу:

1. **Художній тип** — переважання **першої сигнальної системи** (1-а с.с. за Павловим — образне мислення, чуттєве сприйняття; cross-ref §3.3)
2. **Психічний інфантилізм** — emotional immaturity, регресивні захисти
3. **Емоційна незрілість** — лабільність, нездатність витримувати фрустрацію
4. **Вразливість** («впечатління») — низький поріг до емоційних стимулів
5. **Безпосередність** («непосередження») — імпульсивна реакція без medіативної когнітивної переробки

Slide quote: «Дисоціативний невроз частіше розвивається в осіб художнього типу з ознаками психічного інфантилізму, емоційною незрілістю, вразливими».

**Cross-ref L13 (особистість)**: цей преморбід — субстрат для **істероїдного (histrionic) PD** (F60.4) у дорослому віці. Histrionic PD не тотожний F44 — це **стабільна особистість** (з раннього дорослого віку, pervasive), F44 — **епізодичний розлад** (виникає у відповідь на конфлікт, проходить). Але histrionic PD — фактор ризику для рецидивних F44 епізодів.

### 2.10. Афективні порушення — лабільність + театральність

[C-012-020]: **афективна симптоматика** при істерії:

1. **Надзвичайна лабільність емоцій** — швидкі зміни afекту (хвилини)
2. **Крайня нестійкість настрою** — від ейфорії до плачу за коротке time
3. **Бурні емоційні реакції** — інтенсивність несумісна з тригером
4. **Театральність, демонстративність** — emotional display calibrated до аудиторії

**Класичний приклад** [C-012-020]: «голосно ридати безутішно — через кілька хвилин весело сміятися».

Slide quote: «Хворі можуть голосно ридати, справляючи враження невтішного горя, і за кілька хвилин весело сміятися».

**Cross-ref L3 (емоції / воля)**: цей emotional lability — теж клінічний приклад **порушення інтеграції afективних функцій** (L3 базова концепція). При нормі emotional regulation = integration affект з cognition + context; при істерії — afект «відколюється», емоція виражається без контекстуальної модуляції.

### 2.11. Вегетативні порушення — соматичний спектр

[C-012-027]: істеричні вегетативні симптоми — широкий поліморфний спектр:

| Локус           | Симптоми                                               |
| --------------- | ------------------------------------------------------ |
| **Серце**       | біль у серці (кардіалгія) + серцебиття                 |
| **Свідомість**  | непритомність (обмороки)                               |
| **ШКТ**         | нудота + блювання + біль у животі                      |
| **Дихання**     | задишка + приступи задухи                              |
| **Репродукція** | **псевдовагітність** (pseudocyesis / хибна вагітність) |

Slide quote: «біль у серці, серцебиття, непритомність, нудота, блювання, біль у животі, задишка, «приступи» задухи, хибна вагітність та ін.».

**Pseudocyesis pearl**: класичний феномен (M. Mary Tudor case — англійська королева, 1554). Жінка з сильним бажанням вагітності розвиває **повний клінічний синдром вагітності** — припинення менструацій, ріст живота, відчуття рухів плоду, виділення з грудей — БЕЗ реальної вагітності (тест негативний, УЗД порожня матка). Це **maximum конверсія**: психічне бажання конвертується у повний фізіологічний синдром.

**Cross-ref F45 (соматоформні)**: вегетативні симптоми істерії перетинаються з соматоформними розладами F45.0 (соматизація), F45.3 (соматоформна autonomic dysfункція). Differential — у F44 вегетативні симптоми **епізодичні + demonstrative**, у F45.0 — **persistent + ipochondriac** (cross-ref §4.4).

### 2.12. Рухові порушення — гіперкінези vs акінезії

[C-012-021]: **Дуалізм motor**: істеричні рухові порушення поділяються на дві протилежні категорії — **гіперкінези** (надлишок руху) і **акінезії** (відсутність руху).

#### 2.12.1. Гіперкінези [C-012-022]

Slide quote: «Гіперкінези мають характер тиків, тремору голови та кінцівок, блефароспазму, глосолабільного спазму, хореоформних рухів, судомного нападу».

**7 типових форм істеричних гіперкінезів**:

| #   | Форма                          | Опис                                           |
| --- | ------------------------------ | ---------------------------------------------- |
| 1   | **Тіки**                       | стереотипні короткі рухи (моргання, шморгання) |
| 2   | **Тремор голови**              | ритмічне погойдування голови                   |
| 3   | **Тремор кінцівок**            | ритмічне тряслі рук/ніг                        |
| 4   | **Блефароспазм**               | мимовільне закриття очей (затулка повік)       |
| 5   | **Глосолабіальний спазм**      | спазм язика і губ (порушує вимову)             |
| 6   | **Хореоформні рухи**           | швидкі неконтрольовані рухи, схожі на хорею    |
| 7   | **Судорожний припадок** (PNES) | конвульсії, які можна сплутати з епілепсією    |

**Differential з органічними гіперкінезами** [C-012-028]:

| Параметр                        | Істеричний гіперкінез                      | Органічний (Parkinson, Huntington, тики Tourette) |
| ------------------------------- | ------------------------------------------ | ------------------------------------------------- |
| **Залежність від емоцій**       | СИЛЬНО залежить (↑ при стресі, ↓ у спокої) | Помірно або не залежить                           |
| **Незвичайні пози**             | Часто присутні (theatrical posturing)      | Відсутні (анатомічно «правильні»)                 |
| **Супутні вегет. симптоми**     | Globus hystericus (ком у горлі)            | Відсутні або не пов'язані                         |
| **Реакція на стрес-релаксацію** | Згасають при усуненні тригера              | Не залежать                                       |
| **Залежність від уваги**        | ↑ при глядачах, ↓ наодинці                 | Постійні                                          |

Slide quote (C-012-028): «Гіперкінези на відміну від органічних, залежать від емоційного стану хворих, супроводжуються незвичайними позами, вегетативними симптомами (ком у горлі), вони зникають або слабшають після ліквідації або дезактуалізації психотравмуючих впливів».

**Globus hystericus pearl**: «ком у горлі» — класичний істеричний симптом, описаний Hippocrates. Суб'єктивне відчуття стороннього тіла у горлі без органічної основи (ендоскопія норма). Корелює з conflicted talking / emotional suppression.

#### 2.12.2. PNES — псевдоепілептичні припадки [C-012-023]

**Psychogenic Non-Epileptic Seizures** (PNES, F44.5 у МКБ-10) — істеричні судорожні припадки, які **діагностично складно відрізнити від епілептичних**. Slide: «Іноді подібні напади можна сплутати зі схожими при епілепсії».

**Diagnostic dilemma**: пацієнт з PNES може **роками лікуватися антиконвульсантами без ефекту** — це типовий клінічний приклад, коли неврологи направляють на психіатрію після несвітичних спроб фармакотерапії епілепсії.

**Differential PNES vs епілепсія** [synthesis C-012-064]:

| Параметр                                | PNES (F44.5)                             | Епілепсія (G40)                    |
| --------------------------------------- | ---------------------------------------- | ---------------------------------- |
| **Pre-ictal**                           | Часто емоційний тригер (стрес, конфлікт) | Спонтанна, без емоційного триггера |
| **Ictal pattern**                       | Нестереотипна, асиметрична, мінлива      | Стереотипна, симетрична            |
| **Тривалість**                          | >2-5 хвилин (може бути довгі)            | Зазвичай <2 хв                     |
| **Post-ictal confusion**                | Відсутня або мінімальна                  | Виражена + post-ictal сон          |
| **Мочевипускання + тонгу прикушування** | Рідко                                    | Часто                              |
| **ЕЕГ ictal**                           | Норма                                    | Епілептифорнні розряди             |
| **Reaction на «рука-обличчя»**          | Позитивний (рука уникає лиця)            | Негативний (рука падає на лице)    |
| **Контрольований bystander effect**     | Згасає без глядачів                      | Не залежить                        |

#### 2.12.3. Diagnostic gold — тест «рука-обличчя» (face-hand test) [C-012-024, C-012-047, C-012-049]

**Bedside test для відрізнення PNES / psychogenic непритомності від справжньої органічної непритомності / епілепсії**.

**Процедура**:

1. Беремо руку пацієнта (лежачого, який нібито без свідомості)
2. Піднімаємо вертикально вгору **над обличчям пацієнта**
3. Різко відпускаємо
4. **Спостерігаємо траєкторію падіння**:

**Інтерпретація**:

- **Якщо рука падає прямо на обличчя і боляче вдаряє пацієнта** → це **справжня непритомність / епілепсія** (без свідомості, нема захисного рефлексу)
- **Якщо рука «елегантно» уникає обличчя і опускається на плече / вбік** → це **істеричний епізод** (свідомість збережена на підсвідомому рівні, спрацьовує захисний рефлекс)

**Логіка тесту**: при справжній втраті свідомості мозкові рефлекси на самозбереження відключені — рука падає за гравітацією. При істеричному непритомленні / припадку пацієнт **несвідомо контролює рух руки** так, щоб не вдарити себе.

**Slide quote (C-012-024)**: «Якщо підняти руку людини над її обличчям і різко відпустити, і рука не впаде на обличчя, а дуже елегантно опуститься на землю - значить, ми маємо справу не з великим епілептичним нападом, а з конверсійними судомами».

**Lecturer-coined name pearl**: Slide уточнює — «який я називаю» (the test I call) — це **підкреслює персональну педагогічну формулу лектора**, не загальновизнаний термін у літературі. У англомовній літературі схожий тест відомий як **«arm drop test»** для psychogenic unresponsiveness.

**XIX ст. історичний контекст** [C-012-048]: лектор пов'язує тест з епохою Фрейда, коли «дамам було модно непритомніти». Серед європейських дам XIX ст. (особливо вищого класу) непритомність була **соціально прийнятним способом** привернути увагу + уникнути дискомфортних ситуацій (запропонувати руку чоловіку, перервати скандальну розмову). Це **класичний приклад secondary gain** — соціальний бонус від ролі хворої.

### 2.13. Management істеричного припадку — extinction principle [C-012-025, C-012-026]

**Терапевтична тактика при PNES / істеричному припадку**:

1. **НЕ вводити антиконвульсанти** — марно і шкідливо (фармакологічно нема таргета; нейротоксичний ризик)
2. **Залишити пацієнта наодинці** — прибрати глядачів / sympathizers
3. **Без аудиторії — «show» втрачає сенс → припадок зупиниться сам**

**Slide quote**: «не потрібно вводити сильнодіючі протисудомні препарати, а просто залишити людину наодинці. Оскільки симптоми мають показовий характер - напад припиниться».

**Аналогія: дитяча істерика (tantrum)** [C-012-026]: лектор приводить народно-психологічну аналогію — коли маленька дитина кричить і топає ніжками, треба **прибрати глядачів**, і поведінка згасне. Це **той самий механізм** — symptom audience-dependent, без публіки автоматично припиняється.

**Behavioral pearl extinction**: цей принцип = **extinction** у поведінковій терапії (Skinner). Поведінка, яка раніше підкріплювалась увагою, згасає при її видаленні. Це фундаментальний механізм роботи з psychogenic symptoms.

**Coaching pearl для Юрія**: цей принцип переноситься на коучингову роботу з демонстративними клієнтами:

- Drama тригерується аудиторією (терапевт + значущі інші)
- Не reward demonstrative behavior увагою
- Reframe: «бачу, що тобі важко. Що ти хочеш сам зробити з цим?»
- Не sympathize «бідний ти бідний» — це підкріплює role of хворого

### 2.14. Акінезії — паралічі без органіки [C-012-029, C-012-030, C-012-031]

**Істеричні акінезії** = відсутність / зменшення рухів **без органічної причини**.

#### 2.14.1. Типи [C-012-029]

| Тип            | Опис                                                   |
| -------------- | ------------------------------------------------------ |
| **Моноплегія** | параліч однієї кінцівки (рука АБО нога)                |
| **Геміплегія** | параліч однієї сторони тіла (рука + нога одне стороны) |
| **Параплегія** | параліч обох нижніх кінцівок                           |

Slide quote: «Виникають за типом моно-, гемі- і параплегій».

#### 2.14.2. Астазія-абазія [C-012-030]

**Класичний істеричний синдром**: **astasia-abasia** — неможливість **стояти (астазія)** і **ходити (абазія)** за відсутності органічної патології.

Slide quote: «Характерними є порушення ходи: «астазія-абазія», коли хворі не можуть стояти і ходити за відсутності органічних порушень».

**Клінічна картина**: пацієнт у клініці, що раптом «не може ходити»; МРТ / неврологія повністю норма; немає atrофії м'язів; рефлекси нормальні. У ліжку — рухи кінцівок збережені.

#### 2.14.3. Феноменологія слабкості [C-012-031]

Скарги пацієнта (subjektive presentations):

- ноги стають **«ватними»** (cotton-leg sensation)
- **«важкими»**
- **«заплітаються»** при хвилюванні

**Тригер**: виникає при емоційному хвилюванні; зникає у спокої.

Slide quote: «Деякі хворі скаржаться на слабкість у руках і ногах, що виникають під час хвилювання, коли ноги стають «ватними», «важкими», «заплітаються»».

### 2.15. Anatomical mismatch — gold standard диференціації [C-012-032, C-012-035]

**Ключові diagnostic markers істеричних паралічів / порушень чутливості**:

1. **Невідповідність топографії нервових стовбурів** — параліч НЕ відповідає anatomical distribution of конкретного нерва (radial / median / ulnar тощо)
2. **Невідповідність локалізації вогнища в ЦНС** — нема відповідності корковому representation / pyramidal tract
3. **Відсутність патологічних рефлексів** — нема Babinski, Hoffmann, Rossolimo (signs of pyramidal lesion)
4. **Сухожильні рефлекси не змінені** — нема гіперрефлексії / гіпорефлексії типової для UMN/LMN lesions
5. **Відсутність м'язових atрофій** — навіть при «затяжних» паралічах
6. **Відсутність електрофізіологічних змін** — ЕМГ норма

Slide quote: «Характерною є невідповідність цих порушень їх топографічному розташуванню нервових стовбурів або локалізації вогнища в центральній нервовій системі, відсутність патологічних рефлексів, змін сухожильних рефлексів».

**Класичний приклад: glove / stocking anesthesia** [C-012-035] — анестезія у вигляді **рукавички, панчохи, шкарпетки**: топографія втрати чутливості закінчується точно по краю рукавички / шкарпетки, без переходу. Це **анатомічно неможливо** для органічного ураження (бо межі дерматомів НЕ збігаються з межами одягу). Це **повна psychological топографія** — пацієнт «вимикає» чутливість так, як уявляє у власній mental схемі тіла.

Slide quote (C-012-035): «найчастіше вони локалізуються в області кінцівок у вигляді рукавичок, панчох, шкарпеток».

**Hoover's sign pearl** (не у L12, але класичний): при істеричному паралічі ноги (наприклад, лівої) попросити пацієнта підняти **здорову** (праву) ногу проти опору лікаря — у нормі при цьому несвідомо тисне вниз другою (паралізованою) ногою. Якщо paralyzed нога тисне → це функціональний параліч (істерія). Якщо не тисне → органіка.

### 2.16. Сенсорні + мовні порушення [C-012-033, C-012-034, C-012-036]

#### 2.16.1. Спектр сенсорних розладів [C-012-034]

Slide quote: «Сенсорні порушення представлені розладом чутливості та больових відчуттів у різних органах та частинах тіла».

Два головних типи:

1. **Розлад чутливості**:
   - **Анестезія** — повна втрата чутливості (історично — типово)
   - **Гіпестезія** — зниження чутливості
   - **Парестезії** — патологічні відчуття (мурашки, повзання, оніміння) — сучасно частіше
2. **Больові відчуття**:
   - Кардіалгія
   - Абдомінальні болі
   - Головні болі
   - Болі в кінцівках, спині
   - Pseudoreoseзит (істерична поліартралгія)

#### 2.16.2. Мовні порушення [C-012-033]

- **Афонія** (повна втрата голосу) — нині **рідко** (раніше типово; патоморфоз)
- **Заїкання** (stuttering / stammering) — сучасно частіше
- **Утруднення вимови окремих слів** — інтермітентне

Slide quote: «Останнім часом рідко зустрічаються афонії, частіше хворі скаржаться на заїкуватість, утруднення при проголошенні деяких слів».

#### 2.16.3. Патоморфоз — еволюція клінічної картини [C-012-036]

**Патоморфоз (pathomorphosis)** — еволюція клінічної картини в часі під впливом **культурних / медичних знань**. Лектор спеціально підкреслює цей феномен.

**Історична динаміка**:

| Часовий період          | Типові сенсорні симптоми                        |
| ----------------------- | ----------------------------------------------- |
| **XIX ст. — поч. XX**   | Повна анестезія + повна сліпота + повна глухота |
| **Середина XX**         | Парціальна анестезія + glove/stocking + афонія  |
| **Кінець XX — XXI ст.** | Парестезії + заїкання + мігренеподібні скарги   |

**Slide quote**: «через широку популяризацію медичних знань стався патоморфоз цих проявів. Так, замість повної втрати чутливості... Хворі скаржаться на оніміння кінцівок, відчуття повзання мурашок, почуття жару в кінцівках».

**Механізм патоморфозу**:

1. **Доступ до медичної інформації** — пацієнти знають, які симптоми «реалістичні» з точки зору сучасної медицини
2. **Зрушення симптомів у бік субтильних** — повна анестезія була «вірогідною» у XIX ст., зараз — анахронізм
3. **Subjective модальність зростає** — парестезії (суб'єктивні) важче спростувати інструментально
4. **Стиральна межа з F45** (соматоформні) — сучасна істерія все більше «соматизована»

**Pearl для Юрія**: коли клієнт у XXI ст. приходить з «glove anesthesia» — це **анахронізм**, треба запідозрити свідому симуляцію або глибокий рівень дисоціації. Сучасні презентації — парестезії, мігренеподібні скарги, fibromyalgia-like синдром.

### 2.17. La belle indifférence — Janet-Charcot pathognomonic [C-012-037, C-012-038]

#### 2.17.1. Пафос у скаргах [C-012-037]

Slide quote: «Хворі говорять про свої переживання з пафосом, наголошують на їхньому винятковому характері: болі «жахливі», «нестерпні», ні з чим не порівняти».

Манера презентації:

1. **З пафосом, театрально**
2. **Підкреслюють винятковий характер**
3. **Перебільшення (катастрофізація)**: болі «жахливі», «нестерпні», «ні з чим не порівняти»

#### 2.17.2. Парадокс байдужості [C-012-038]

**La belle indifférence** (фр. «прекрасна байдужість») — класична Janet-Charcot ознака істерії. Slide quote: «У той же час вони не обтяжуються цими порушеннями, як би байдужі до них».

**Парадокс**: попри драматичність опису симптомів («жахливі болі!»), пацієнт **фактично байдужий** до своїх симптомів — НЕ страждає так, як страждав би хворий з реальним органічним пораличем / болем:

- НЕ просить терміновості
- НЕ панікує
- НЕ катастрофізує прогноз
- НЕ обмежує себе у активностях proportionally
- Часто має **посмішку на обличчі**, описуючи «жахливі» симптоми

**Diagnostic clue**: incongruence between **verbal pathos** і **affective neutrality** — pathognomonic для F44.

**Cross-ref L1**: концепт належить **Janet (1894)**, поширений у клінічну практику **Charcot** у Salpêtrière. Це європейська psychiatric tradition XIX ст., яка є базою сучасної feno-фенології істерії.

**Caveat: не universal**: la belle indifférence спостерігається у ~21% пацієнтів з F44 (Stone et al., 2006); відсутність НЕ виключає діагноз. Але присутність — strong diagnostic clue.

### 2.18. Перебіг — acute / chronic / wave-like / fixation [C-012-039, C-012-040, C-012-041]

#### 2.18.1. Дуалізм перебігу [C-012-039]

Slide quote: «Дисоціативні психогенні реакції бувають короткочасними та зникають без лікування. Однак, можлива і тривала (протягом кількох років) фіксація хворобливих симптомів».

| Тип         | Тривалість    | Прогноз                             |
| ----------- | ------------- | ----------------------------------- |
| **Acute**   | Хвилини — дні | Спонтанна ремісія без лікування     |
| **Chronic** | Тижні — роки  | Фіксація симптомів, character shift |

#### 2.18.2. Хвилеподібний перебіг [C-012-040]

Slide quote: «В окремих випадках спостерігається хвилеподібна течія: після згасання розладів залишається схильність до їх виникнення у психологічно несприятливих ситуаціях».

**Wave-like pattern**:

1. Період активних симптомів (тижні-місяці)
2. Ремісія (місяці-роки)
3. Рецидив при наступному психологічному стресі (trigger-dependent)
4. Тенденція до **trigger-залежності** — кожен новий стрес активує симптомокомплекс

**Coaching pearl**: коли клієнт каже «у мене це вже було колись, але минуло» — питати: «А коли? Що тоді сталось? Зараз схожі обставини?» — це **anniversary trigger** або **structural similarity trigger**.

#### 2.18.3. Затяжний перебіг — secondary complications [C-012-041]

При **chronic course** (затяжний перебіг) приєднуються вторинні розлади:

| #   | Вторинний розлад                       | Шифр МКБ-10      | Cross-ref |
| --- | -------------------------------------- | ---------------- | --------- |
| 1   | **Фіксація конверсійної симптоматики** | F44.7            | C-012-039 |
| 2   | **Посилення характерологічних змін**   | (F60.x PD shift) | L13       |
| 3   | **Стійка астенія**                     | F48.0            | L10       |
| 4   | **Іпохондричні розлади**               | F45.2            | L9 + L10  |
| 5   | **Дистимічні розлади**                 | F34.1            | L9        |

Slide quote: «При затяжному перебігу відбувається фіксація конверсійної симптоматики, посилення характерологічних змін, приєднання стійкої астенії, іпохондричних та дистимічних розладів».

**Critical pearl chronification**: chronic F44 без лікування поступово трансформується у складніший клінічний portrait, який включає **F44 + F45 + F48 + character pathology**. Це **довгий шлях інвалідизації**, який можна перервати ранньою психотерапією.

### 2.19. Diagnostic dissociation: subjective vs objective [C-012-042, C-012-043, C-012-044]

#### 2.19.1. Заклик не зневажати симптоми як симуляцію [C-012-042]

Slide quote: «Недооцінка клінічного значення симптомів неврозу, що трактуються як результат самонавіювання або агравації та симуляції, може призвести до неправильного діагностування та призначення неадекватної терапії».

**Pastка для лікаря / коуча**: розцінити F44 як «вигадку» / симуляцію → не призначити адекватну психотерапію → пацієнт хронізується + втрачає довіру до медицини → шукає допомоги у нетрадиційних практик / самолікування → симптоми погіршуються.

**Critical**: F44 — це **несвідомий процес**. Пацієнт **справді відчуває** симптом, **не грає**. Це відрізняє F44 від симуляції (malingering, Z76.5) і від factitious disorder (F68.1, Münchausen) — там симптом свідомо фабрикується. Cross-ref §4.5.

#### 2.19.2. Дисоціація скарг / об'єктивних даних [C-012-043]

Slide quote: «специфіку протікання астенії, що характеризується дисоціацією між скаргами на астенічні прояви і дійсними об'єктивними даними клінічного спостереження».

**Specifічна риса істеричної астенії — gap** між:

- Тим, **як пацієнт скаржиться** (надмірно, театрально, з пафосом)
- Тим, **що насправді показує клінічне спостереження** (об'єктивно)

#### 2.19.3. Парадокс «втома → велика робота» [C-012-044]

**Класичний істеричний парадокс**: пацієнт скаржиться на швидку втомлюваність / слабкість / зниження працездатності — АЛЕ здатний виконати **великий обсяг роботи**, особливо за наявності **позитивно забарвленого стимулу** (інтерес, увага, винагорода).

Slide quote: «хворі під час скарг на швидку стомлюваність, загальну слабкість, знижену працездатність здатні зробити великий обсяг роботи, особливо за наявності позитивно забарвленого стимулу».

**Differential з неврастенією (F48.0)**: при справжній неврастенії втома **objective + universal** (зменшується продуктивність на ВСІХ задачах, у тому числі цікавих); при істерії втома **subjective + selective** (зникає при цікавій / увагою-винагородженій задачі). Cross-ref §4.3.

**Coaching pearl**: коли клієнт каже «я постійно втомлений», але приходить на сесію і **активно говорить 90 хвилин** з усією емоційною інтенсивністю — це **diagnostic clue** на користь dissociative-type перебігу.

### 2.20. Лікування — фарма adjunct + psychotherapy first-line [C-012-045, C-012-046]

#### 2.20.1. Структура лікування [C-012-045]

Slide quote: «Лікування дисоціативних розладів включає фармакотерапію антидепресантами, анксіолітиками. Але особливого значення має психотерапія».

**Лікування дисоціативних розладів — комбіноване, з акцентом на психотерапію**:

| Компонент          | Препарати / методи                                                                                 | Роль                      |
| ------------------ | -------------------------------------------------------------------------------------------------- | ------------------------- |
| **Фармакотерапія** | Антидепресанти (SSRI: сертралін, пароксетин), Анксіолітики (гідроксизин, прегабалін; БДЗ обмежено) | **Adjunct (вторинна)**    |
| **Психотерапія**   | КПТ + психодинамічна терапія + гіпноз + EMDR + family therapy                                      | **First-line (головне!)** |

**Pharm pearl**: при F44 фарма таргетує **comorbid симптоми** (тривога, депресія, інсомнія), не саму конверсію. Конверсія НЕ має специфічної фарма-таргета — це психодинамічний процес, який requires психотерапію.

#### 2.20.2. Психотерапія — 3 ключові завдання [C-012-046]

Slide quote: «Необхідно зрозуміти, які зовнішні чинники призвели до розвитку захворювання, чого жадає пацієнт підсвідомо, і навіть дати йому привід для одужання».

**3 завдання психотерапевта**:

1. **Розшифрувати зовнішні тригери** — які саме чинники спровокували розлад (психотравма? життєвий стрес? конфлікт?)
2. **Виявити несвідоме бажання (secondary gain)** — чого пацієнт прагне неusвідомо (звільнення від обов'язків? увага? уникнення відповідальності?)
3. **Дати «привід для одужання» (face-saving exit)** — дозвіл, виправдання повернутися до здоров'я без втрати лиця

**Face-saving exit pearl**: це **fundamental** концепція для роботи з істерією. Пацієнт «потребує» симптому несвідомо (primary gain) + соціально (secondary gain). Якщо «вилікувати» його прямою конфронтацією («у тебе нема нічого, ти симулюєш») — він втратить face + secondary gains + зрозуміє свою «нечесність» → стане ще гірше або вибере інший симптом.

**Правильний підхід**: запропонувати «легітимний привід» одужати:

- «Тепер ти зрозумів свою силу — можеш встати»
- «Лікування дало результат — тепер ти видужуєш»
- «Бо тепер ти змінив життя — тіло може відпочити»

Пацієнт зберігає face + отримує дозвіл на одужання.

**Classical techniques**:

- **Suggestion + hypnosis** (Charcot, Bernheim) — пряма sugesтія одужання
- **Catharsis** (Freud, Breuer) — відреагування витісненого афекту
- **Insight-oriented therapy** — усвідомлення symbolic значення симптому
- **CBT** — поведінкова робота з тригерами + reframing thoughts
- **Family therapy** — робота з secondary gain через близьких

## §3 — Cross-cutting concepts

### 3.1. 3 критерії неврозу (Жане) — gold standard recognition

**Невроз vs психоз** — фундаментальна психіатрична дихотомія. Розгортається через **3 критерії П. Жане** (1903):

| Критерій                             | Невроз (F40-F48)                                | Психоз (F20-F29, психотичні форми F30-F39)               |
| ------------------------------------ | ----------------------------------------------- | -------------------------------------------------------- |
| **1. Psychogenic тригер**            | ТАК — є чіткий зв'язок з конфліктом / стресом   | Не обов'язково (ендогенно у шизофренії, БАР)             |
| **2. Збереження критики**            | ТАК — пацієнт усвідомлює симптоми як хворобливі | НІ — інсайт втрачений, маячня сприймається як реальність |
| **3. Відсутність psychotic feature** | Нема марення, галюцинацій                       | Є марення / галюцинації / порушення формального мислення |

L12 імпліцитно підтверджує критерії 2-3: істерик усвідомлює свої симптоми як «жахливі» (критика збережена, хоч і dramatized), у F44 нема psychotic features (виняток — істеричні психози F44.8, але вони мають psychogenic тригер і збережену реактивність, на відміну від ендогенних).

**Critical pearl L7 (психоз) vs L12 (невроз)**: при шизофренії пацієнт **не розуміє**, що марить (інсайт втрачений); при істерії пацієнт **відчуває** симптом, **демонструє** його, але fundamental contact з реальністю збережений. Це **критерій інсайту** — найбільш надійний bedside-маркер.

### 3.2. Захисні механізми (Фройд) — конверсія + дисоціація у системі

**Defense mechanisms** (Anna Freud, 1936 — систематизація батьківської theorії):

| Defense                       | Опис                                                | Cross-link L12          |
| ----------------------------- | --------------------------------------------------- | ----------------------- |
| **Repression** (витіснення)   | Вилучення нестерпного матеріалу зі свідомості       | Базовий для всіх F44    |
| **Conversion** (конверсія)    | Перетворення psychic conflict у соматичний симптом  | C-012-010, C-012-002    |
| **Dissociation** (дисоціація) | Відколювання частини психічної функції від ядра «Я» | C-012-008, F44.0-3      |
| **Regression** (регресія)     | Повернення до early developmental stage             | C-012-018 (інфантилізм) |
| **Reaction formation**        | Заміна імпульсу на протилежний                      | (не у L12, але класика) |
| **Displacement** (зміщення)   | Перенесення афекту з істинного об'єкта на безпечний | (не у L12)              |
| **Sublimation** (сублімація)  | Перенаправлення енергії на соціально прийнятні цілі | Healthy defense         |

**Hierarchy of defenses** (Vaillant, 1977):

1. **Mature** — sublimation, humor, anticipation (зрілі)
2. **Neurotic** — repression, displacement, reaction formation (невротичні)
3. **Immature** — projection, acting out (незрілі)
4. **Psychotic** — denial, distortion (психотичні)

**F44 = immature + neurotic mix**: conversion + dissociation + regression = здебільшого **immature/neurotic** defenses. Це — поряд з преморбідом (інфантилізм, C-012-018), сходиться: F44 — це **defensive regression до early developmental level** під тиском нестерпного конфлікту.

**Cross-ref L1 (історія психіатрії)**: Freud — центральна фігура, концепти захисту — його ядерна теоретична спадщина. У L12 без називання Anna Freud, але концепції захисних механізмів імпліцитно скрізь.

### 3.3. I/II сигнальна система (Павлов) — істерики vs ананкасти

**Концепція двох сигнальних систем** (Іван Павлов):

| Сигнальна система | Опис                                                                           | Преморбід                                             |
| ----------------- | ------------------------------------------------------------------------------ | ----------------------------------------------------- |
| **I (перша)**     | Безпосередні сенсорні стимули; образне мислення; emotional, чуттєве сприйняття | **Художній тип** → схильність до **істерії**          |
| **II (друга)**    | Мова, абстракції, символи; логічне, вербальне мислення                         | **Розумовий тип** → схильність до **ОКФ/психастенії** |

[C-012-018]: Slide quote — «у осіб художнього типу з ознаками психічного інфантилізму». Це **прямо павловська** характеристика — «художній тип» = переважання I сигнальної системи.

**Pavlov's typology — 4 types** (на основі властивостей НС: сила, urivновaженість, рухливість):

1. **Сильний неурівноважений (холеричний)** — meltdown під сильним стресом
2. **Сильний urivноважений рухливий (сангвінічний)** — стресостійкий
3. **Сильний urivноважений інертний (флегматичний)** — ригідний, стабільний
4. **Слабкий (меланхолічний)** — низька стресостійкість, схильний до неврозів

**Slabий тип ВНД (Pavlov)** → схильність до **неврастенії** (F48.0) — виснаження НС від тривалого стресу.

**Cross-ref L3 (емоції / воля)**: Pavlov framework — це **дореволюційна базова психофізіологія**, на якій сидить уся радянсько-українська психіатрична традиція. У сучасній західній науці paviлов outdated, але концептуально корисно для типології преморбіду.

### 3.4. Generic F40-F48 mapping — невротичні розлади у системі МКБ-10

**Розгортання F40-F48 у МКБ-10** (для повноти контексту неврозології):

| Шифр    | Назва                                                                                    | Core механізм                               | Класична назва                        |
| ------- | ---------------------------------------------------------------------------------------- | ------------------------------------------- | ------------------------------------- |
| **F40** | Фобічні тривожні розлади (агорафобія, соц. фобія, специфічні фобії)                      | Conditioned fear + avoidance                | (частина невропсихастенії)            |
| **F41** | Інші тривожні розлади (паніка, ГТР, mixed)                                               | Free-floating anxiety                       | (тривога невроз)                      |
| **F42** | Обсесивно-компульсивний розлад (ОКР)                                                     | Intrusive obsessions + compulsions          | **Ананкастичний / обсесивний невроз** |
| **F43** | Реакції на стрес + adjustment disorders                                                  | Trauma-related                              | (ПТСР, гострий стресовий, РА — L11)   |
| **F44** | Дисоціативні + конверсійні розлади                                                       | Defense mechanism (conversion/dissociation) | **Істерія** ← L12                     |
| **F45** | Соматоформні розлади (соматизація, іпохондрія, болевий розлад)                           | Somatization without conversion mechanism   | (соматизована неврозологія)           |
| **F48** | Інші невротичні розлади (неврастенія F48.0, синдром деперсоналізації-дереалізації F48.1) | Exhaustion + chronic stress                 | **Неврастенія**                       |

**Триплет класичних форм неврозу** (історична радянська традиція):

1. **Неврастенія** (F48.0) — слабкий тип ВНД (Pavlov)
2. **Психастенія / ОКФ** (F40+F42) — переважання II с.с. (Pavlov)
3. **Істерія** (F44) — переважання I с.с. (Pavlov), художній тип

L12 — це третя класична форма. L10 раніше розгорнув F40+F41+F42. L11 — F43 (ПТСР+ASD+РА). L9 + дистимія F34.1 — overlap зону. L13 — особистість як преморбідний субстрат.

### 3.5. Соматоформні розлади (F45) — близький сусід F44

**F45 — соматоформні розлади**:

| Шифр      | Назва                                     | Феноменологія                                                                             |
| --------- | ----------------------------------------- | ----------------------------------------------------------------------------------------- |
| **F45.0** | Соматизований розлад (Briquet's syndrome) | Множинні соматичні скарги ≥ 2 років, ≥ 4 болі + ≥ 2 ШКТ + ≥ 1 сексуальні + ≥ 1 neurologic |
| **F45.1** | Недиференційований соматоформний розлад   | Менш виражена картина, коротший термін                                                    |
| **F45.2** | **Іпохондричний розлад**                  | Persistent переконання у важкій хворобі                                                   |
| **F45.3** | Соматоформна autonomic dysfункція         | Скарги на autonomic функції (серце, ШКТ)                                                  |
| **F45.4** | Стійкий соматоформний больовий розлад     | Persistent біль без org причини                                                           |

**F44 vs F45 — diagnostic differential**:

| Параметр                   | F44 (істерія)                                       | F45 (соматоформні)                                          |
| -------------------------- | --------------------------------------------------- | ----------------------------------------------------------- |
| **Тип симптомів**          | Псевдо-неврологічні (параліч, припадок, анестезія)  | Соматичні скарги (біль, серце, ШКТ)                         |
| **Імітує**                 | Неврологію                                          | Внутрішню медицину                                          |
| **Belle indifférence**     | Часто (C-012-038)                                   | Рідко — навпаки, anxious health worry                       |
| **Іпохондрична фіксація**  | Менше                                               | Виражена (особливо F45.2)                                   |
| **Demonstrative behavior** | Виражена (C-012-013)                                | Менш виражена                                               |
| **Mechanism**              | Conversion (psyche → soma зрозумілий механізм)      | Soматизація (психологічний стрес → tonormative презентація) |
| **DSM-5 evolution**        | DSM-5 переніс F44 конверсію у соматичну рубрику FND | Залишилось у soматичній групі (SSD)                         |

**Cross-ref C-012-041**: при затяжному перебігу F44 приєднуються **F45.2 (іпохондрія)** + **F45.3** як вторинні розлади — це **F44→F45 transition**. Аналогічно, у DSM-5 чітке розмежування все більше стирається — концепція **Functional Neurological Disorder** (FND) об'єднує F44 + F45 під спільним парасолем функціональних розладів.

**Pearl для коуча**: F45 пацієнт **боїться** хвороби (anxious); F44 пацієнт **демонструє** хворобу (theatrical). Різний emotional tone — диференційний clue.

### 3.6. Неврастенія (F48.0) — сучасний контекст

**Неврастенія** (J. Beard, 1869 — нервова виснаженість + irritable weakness) — друга з 3 класичних форм неврозу:

**Сучасна МКБ-10 F48.0**: стан, що характеризується:

1. **Persistent розумова втомлюваність** після незначних зусиль
2. **Persistent фізична втомлюваність** + слабкість
3. ≥ 1 з: запаморочення / м'язові болі / напруга / роздратованість / dyspeptic симптоми / sleep disturbance / нездатність розслабитись
4. Тривалість ≥ 3 місяців
5. Не відповідає критеріям депресії, тривожних розладів

**Differential з F44 істеричною астенією**:

| Параметр                 | Неврастенія (F48.0)                                         | Істерична астенія (F44 / при хронізації)                 |
| ------------------------ | ----------------------------------------------------------- | -------------------------------------------------------- |
| **Тип втоми**            | Objective + universal (на всіх задачах)                     | Subjective + selective (selectivnі залежно від інтересу) |
| **Робота при стимулі**   | Нездатний (genuinely exhausted)                             | **Здатний на великий обсяг** (C-012-044 парадокс)        |
| **Belle indifférence**   | Відсутня — пацієнт страждає від виснаження                  | **Часто присутня**                                       |
| **Зв'язок з конфліктом** | Може бути або відсутній                                     | Чітко вираженy                                           |
| **Demonstrative**        | Не виражена                                                 | Виражена (пафос у скаргах)                               |
| **Об'єктивні дані**      | Можуть бути зміни (млявість тонусу, mild cognitive slowing) | Дисоціація скарг / об'єктивних даних (C-012-043)         |

**Сучасна актуальність неврастенії**:

- У DSM-5 термін «неврастенія» **виключений**, замінений на **chronic fatigue syndrome** (CFS) у соматичній медицині + **persistent депресивний розлад / дистимія** у психіатрії
- У МКБ-10 (і МКБ-11) — залишений як **F48.0**
- В Україні / СРСР — широко використовувався протягом XX ст., особливо у військовій психіатрії як «бойова втома», «комбатантне виснаження»

**Pearl**: коли клієнт скаржиться на хронічну втомлюваність + слабкість + irritability — диференційно треба думати про **(1) MDD з мляво-апатичним відтінком (L9)**, **(2) F48.0 неврастенію**, **(3) F44 істеричну астенію (хронізовану)**, **(4) chronic fatigue syndrome (somatic)**, **(5) органіку — гіпотиреоз, B12 deficiency, anemia, sleep apnea**. Без хорошого медичного обстеження + детального інтерв'ю — diagnostic chaos.

### 3.7. Конверсія у нейробіологічному контексті — сучасні знахідки

**fMRI / нейроbiology of conversion** (Stone et al., Voon et al., 2010-2020-і):

1. **Зниження активності primary motor cortex** при істеричному паралічі (показано у конкретних кейсах)
2. **↑ активність TPJ** (temporal-parietal junction) — зона sense-of-agency
3. **↑ ventromedial PFC** — зона emotional regulation
4. **Сполучення лімбіко-моторних структур** змінене — emotional impulses «interfere» з моторним cortex

**Інтерпретація**: істеричний параліч — це **функціонально зміщений** motor control: пацієнт **несвідомо суппресує** активність моторного cortex через emotional regulatory pathways. Це не «вигадка», а реальне нейробіологічне явище.

**Cross-ref L2 (структура НС)**: L12 у транскрипті не торкається нейроbiology, але концептуально розгортається на тлі L2. Сучасні дослідження F44 — на стику психіатрії + нейрології + functional neuroimaging.

### 3.8. Treatment evolution — від гіпнозу Charcot до сучасного multi-modal

**Історична еволюція лікування істерії**:

| Епоха                   | Підхід                                                                  | Postathі                                       |
| ----------------------- | ----------------------------------------------------------------------- | ---------------------------------------------- |

- **Group therapy** — для дисоціативних форм

### 3.9. cPTSD overlap з істерією — preview ICD-11

**Complex PTSD (cPTSD, ICD-11 6B41)** — пов'язана з L11 / L13:

- Тривала травма (child abuse, domestic violence, war captivity)
- 3 кластери ПТСР + 3 кластери: affective dysregulation + negative self-concept + relational disturbances
- **Overlap з F44**: child abuse → dissociation + DID (C-012-005); cPTSD часто має **dissociative subtype**

**Cross-ref L11**: L11 §3.4 розгорнув cPTSD; L12 — це механізм, через який cPTSD дисоціативний субтип фенотипічно реалізується.

### 3.10. Coaching та психотерапія — межі компетенції

**Що коуч робить НЕ повинен** при F44:

1. НЕ діагностувати — це робота клінічного психіатра / лікаря
2. НЕ працювати з активним конверсійним епізодом — це emergency psychiatric або neurological consultation
3. НЕ ігнорувати симптом як «вигадка»

**Що коуч робить МОЖЕ**:

1. Recognize patterns (4 групи симптомів + anatomical mismatch + belle indifférence)
2. Refer до психіатра / неврологa з detailed observations
3. Працювати з **post-acute** клієнтом у **stable** фазі — на тригерах, копінгу, secondary gain awareness
4. Не reinforce demonstrative behavior увагою / sympathy
5. Працювати з self-other boundaries + assertiveness

## §4 — Diagnostic logic

L12 — це **діагностичний апарат для розрізнення істерії (F44) від суміжних розладів** + базова логіка «невроз vs психоз». 7 ключових точок розгалуження:

### 4.1. F44 vs органічна неврологія — anatomical mismatch + reflex sparing

| Параметр                    | F44 (істерія)                                    | Органічна неврологія (CVA, MS, ALS, Parkinson, epilepsy) |
| --------------------------- | ------------------------------------------------ | -------------------------------------------------------- |
| **Топографія**              | Не відповідає нерву / дерматому (glove/stocking) | Відповідає anatomical distribution                       |
| **Патологічні рефлекси**    | Відсутні (нема Babinski тощо)                    | Часто присутні                                           |
| **Сухожильні рефлекси**     | Не змінені                                       | Гіпер- або гіпорефлексія                                 |
| **М'язові атрофії**         | Відсутні                                         | Можуть бути (при LMN lesion)                             |
| **ЕМГ / NCS**               | Норма                                            | Часто abnormal                                           |
| **МРТ / КТ / ЕЕГ**          | Норма                                            | Часто abnormal (lesion видно)                            |
| **Залежність від емоцій**   | СИЛЬНО залежить                                  | Не залежить (чи помірно)                                 |
| **Belle indifférence**      | Часто (~21%)                                     | Рідко                                                    |
| **Залежність від глядачів** | Так — згасають без аудиторії                     | Не залежить                                              |
| **Demonstrative behavior**  | Виражена                                         | Не виражена                                              |

**Diagnostic key**: **anatomical mismatch + reflex sparing + normal instrumental + symptom variability** = F44 high probability. Якщо є **patologічні рефлекси / нейроimagining lesion** → це органіка (CVA, MS, tumor), F44 виключається.

**Скрипт коуча**: «Ти проходив МРТ / ЕЕГ / неврологічне обстеження? Що сказали? Лікар нашов щось чи нічого?» — якщо «нічого» + клієнт скаржиться роками = high probability F44 (або інший психіатричний/psychosomatic розлад).

### 4.2. F44 vs F43.1 ПТСР (істерія vs ПТСР)

| Параметр                   | F44 (істерія)                                                        | F43.1 ПТСР (L11)                                    |
| -------------------------- | -------------------------------------------------------------------- | --------------------------------------------------- |
| **Тригер**                 | Психологічний дискомфорт (будь-який, не обов'язково extreme)         | Екстремальна травма (загроза життю)                 |
| **Перитравматична тріада** | Не обов'язково (страх + переляк + безпорадність відсутні специфічно) | Обов'язкова (DSM Criterion A2)                      |
| **Феноменологія**          | Конверсія / соматизація / DID                                        | Тріада: вторгнення + уникнення + гіперактивація     |
| **Психогенна амнезія**     | F44.0 — окремий розлад                                               | Частина intrusion-кластеру (peri-traumatic amnesia) |
| **Преморбід**              | Художній тип + інфантилізм + emotional immaturity                    | Універсальний (немає specific preморбіду)           |
| **Прогноз**                | Часто хронізується з secondary gain                                  | Може ремітувати + має evidence-based treatment      |
| **Treatment**              | Psychotherapy first-line (фарма adjunct)                             | TF-CBT + EMDR + SSRI/SNRI                           |
| **DSM-5 evolution**        | Перенесено у Functional Neurological Disorder (FND)                  | Trauma-related disorders chapter                    |
| **Overlap**                | Dissociative subtype ПТСР — інтерфейс                                | F44.0 амнезія може супроводжувати ПТСР              |

[C-012-062]: лектор у L12 не розгортає differential з ПТСР, але імпліцитно — через звертання до Freud (XIX ст.) і concentration на psychogenic discomfort, а не extreme trauma.

**Скрипт коуча**: «Чи було щось критично загрозливе у твоєму житті — війна, ДТП, насильство, загроза смерті? Чи це більше — внутрішній конфлікт, який тебе перевантажує?» — якщо ТАК до екстремальної травми = ПТСР подивитися; якщо ні + є dramatic symptoms + конфлікт = F44 подивитися.

### 4.3. F44 vs F48.0 неврастенія — astenia subjektive vs objective

| Параметр                      | F44 істерична астенія (хронізована)               | F48.0 неврастенія                                  |
| ----------------------------- | ------------------------------------------------- | -------------------------------------------------- |
| **Тип втоми**                 | Subjective + selective                            | Objective + universal                              |
| **Робота при позит. стимулі** | **Здатний на великий обсяг** (C-012-044 парадокс) | Нездатний (genuinely exhausted)                    |
| **Belle indifférence**        | Часто присутня                                    | Відсутня — пацієнт страждає                        |
| **Demonstrative**             | Виражена (пафос у скаргах, C-012-037)             | Не виражена                                        |
| **Об'єктивні дані**           | Дисоціація скарг / об'єктивних даних              | Конгруентність скарг + об'єктивних змін            |
| **Тригер**                    | Психологічний конфлікт + secondary gain           | Тривалий стрес + виснаження НС (Pavlov)            |
| **Преморбід**                 | Художній тип + інфантилізм                        | Слабкий тип ВНД                                    |
| **Treatment**                 | Психотерапія + face-saving + boundary work        | Rest + анксіолітики + neurodepressants + lifestyle |

**Скрипт коуча**: «Коли ти кажеш "втомлений" — ти однаково втомлений на всіх задачах чи тільки на тих, що тебе НЕ цікавлять? Якщо я зараз скажу "поїхали у твоїй улюблений ресторан" — чи матимеш ти сили?» — якщо відповідь «так, на цікаве маю» = можливо F44 (dissocial fatigue); якщо «ні, всюди втомлений» = можливо F48.0 / MDD.

### 4.4. F44 vs F45 соматоформні — neurological vs somatic mask

| Параметр                  | F44 (істерія / конверсія)                          | F45 (соматоформні)                            |
| ------------------------- | -------------------------------------------------- | --------------------------------------------- |
| **Тип симптомів**         | Псевдо-неврологічні (параліч, припадок, анестезія) | Соматичні скарги (біль, серце, ШКТ)           |
| **Імітує**                | Неврологію                                         | Внутрішню медицину                            |
| **Demonstrative**         | Виражена (theatrical)                              | Менш виражена                                 |

2. **F44 vs malingering**: лектор спеціально підкреслює — НЕ розцінювати F44 як симуляцію. Цей акцент — anti-стигматизація пацієнтів. У коуч-контенті повторювати: «пацієнт справді відчуває симптом, не грає».

4. **Тест «рука-обличчя»**: добре screening, але **НЕ definitive**. False positives (свідомий пацієнт «помиляється» і опускає руку на обличчя) і false negatives (deeply dissocial pacient справді не контролює рух) можливі. Gold standard — відео-ЕЕГ моніторинг.

5. **Преморбід «художній тип»** [C-012-018]: це Pavlov framework. У сучасній західній традиції — не використовується. Сучасний еквівалент — **histrionic / dramatic personality features** (DSM-5 Cluster B). У коуч-контенті можна використовувати з caveat.

6. **Wandering uterus + gender stereotypes**: лектор спеціально дез-stereotype-ить термін (C-012-001). У коуч-контенті — НЕ повторювати античні теорії як «істину», NS лише як історичний контекст. Чоловіча істерія реальна.

7. **«Face-saving exit»** [C-012-046] (whisper «повідомлення для зберігання»): це **ключова техніка**, але потребує клінічного навику. Коуч може використовувати reframing для secondary gain awareness, але **не імітувати психотерапевтичну роботу з F44 безпосередньо**.

8. **F44 vs DSM-5 FND**: МКБ-10 vs DSM-5 differences. У L12 використовується ICD-10 framework. У сучасній західній літературі — FND (Functional Neurological Disorder) як спільна рубрика. Це **термінологічна еволюція**, не зміна феноменології.

9. **«Велика наслідувачка»** [C-012-017]: epithet Charcot. У L12 не атрибутований авторству. Це **класична термінологія**, не оригінальна лектора.

10. **Хибна вагітність (pseudocyesis)** [C-012-027]: дуже рідкісний феномен у XXI ст. (через широкий доступ до УЗД-тестів). У L12 згаданий як «класика». У коуч-контенті — використовувати як **historical example максимума конверсії**, а не як live diagnostic concern.

## §7 — Applied to coaching (Detective FM)

L12 — це **третій великий нозологічний блок** після L11 (ПТСР) і L9-L10 (депресія + тривога). Для коуча-Детектива з клієнтською базою з 21-50-річних експертів / помагаючих практиків, у воєнному контексті України:

### 7.1. Правило 1 — Recognize patterns, не diagnose

**Перш за все**: коуч **НЕ діагностує F44**. Це робота клінічного психіатра / лікаря.

**Що коуч може recognize** (4+5 features):

1. **Поліморфний симптом** без медичної верифікації (МРТ / неврологія норма)
2. **Anatomical mismatch** (glove/stocking, не за нервом)
3. **Demonstrative behavior** (для аудиторії)
4. **La belle indifférence** (пафос у скаргах + байдужість до прогнозу)
5. **Symptom audience-dependent** (стихає наодинці)
6. **Semantic зв'язок симптому з конфліктом** (страх захворіти → симптом саме цієї хвороби)
7. **Convenient timing** (симптом виникає перед розмовою, що клієнт уникає)
8. **Secondary gain** (отримує увагу / звільнення від обов'язків / маніпуляцію близькими)
9. **Hystoric type преморбід** (художній тип + інфантилізм + лабільність)

**Якщо ≥ 4 features присутні** → **рекомендувати психіатричну консультацію + неврологічну консультацію для виключення органіки**. Не намагатися «коучити» симптом — це може поглибити хронізацію.

### 7.2. Правило 2 — Не reinforce demonstrative behavior

**Для усіх клієнтів** (не лише підозрюваних F44) — Pavlov + Skinner extinction logic:

1. **НЕ sympathize «бідний ти бідний»** — це reward для drama
2. **НЕ ескалувати увагу** при demonstrative escalation
3. **Reframe**: «Бачу, що тобі важко. Що ти сам хочеш зробити з цим?»
4. **Set boundaries**: «Я тут, щоб допомогти тобі думати, не щоб слухати твою драму»
5. **Не задовольняти secondary gain** — атрибутувати симптом як sign що клієнт сам собі важливий, не лікаря

**Coaching translation principle extinction**: extinction працює коли (a) reward можливий тільки в одному місці і (b) пацієнт не може його отримати в іншому місці. Це обмежено для коучингу — якщо клієнт отримує sympathy від родини, друзів — твоя neutral позиція не достатня. **Family therapy** інколи потрібна.

### 7.3. Правило 3 — Face-saving exit при resistance

**Якщо клієнт «застряг» у симптомі або pattern**:

- **НЕ конфронтувати прямо** («у тебе нема нічого, ти симулюєш») — це руйнує face → клієнт втрачає secondary gain → шукає інший симптом або уникає тебе
- **Запропонувати legitimate exit**:
  - «Тепер ти зрозумів свою силу — можеш встати»
  - «Лікування дало результат — тепер ти видужуєш»
  - «Бо тепер ти змінив життя — тіло може відпочити»
  - «Цей етап завершується, наступний буде кращим»
- Клієнт зберігає face + отримує дозвіл на одужання

**Coaching pearl**: face-saving — це **класична Janet-Charcot техніка**. Працює не тільки при F44, а й при опору в стандартному коучингу.

### 7.4. Правило 4 — Військовий контекст України 2026

У контексті війни в Україні:

1. **Cross-trauma overlap F44 + F43 (ПТСР)**: ветерани / жертви війни / біженці можуть мати F43 + F44 одночасно (dissociative subtype ПТСР, F44.0 амнезія на конкретні події війни, F44.5 PNES при flashbacks). Differential — складний.
2. **Cultural acceptance dissociation**: український контекст менш толерує F44 demonstrative форми ніж XIX ст. Європа. Сучасні форми — переважно **subtle patho-морфоз** (парестезії, мігренеподібні скарги, fibromyalgia-like, fatigue).
3. **Stigma**: F44 досі стигматизована («симулянт», «нервова баба»). Коуч може зробити велику роботу — **destigmatize**: «це реальне переживання, не вигадка».
4. **Resource shortage**: професійних психотерапевтів з F44 expertise в Україні мало. Коуч може бути **mediator** між клієнтом і фаховою допомогою.

### 7.5. Правило 5 — DID кейси — refer не coach

**Якщо клієнт описує DID-like феномени** (memory gaps + sense of «інших» особистостей всередині + дитяча травма):

1. **НЕ працювати з alters самостійно** — це робота для **спеціалізованого DID-therapist** (ISSTD-trained)
2. **Не «викликати» alters** через гіпноз / асоціативні техніки — це може дестабілізувати
3. **Refer до клінічного психолога / психотерапевта** з DID expertise
4. **Якщо немає такого спеціаліста** — рекомендувати **psychodynamic therapy** з тривалим horizon (≥ 2 роки)
5. **Підтримати клієнта** у пошуку допомоги — це може зайняти тижні

### 7.6. Правило 6 — Self-screening коуча для secondary trauma

**Якщо коуч працює з ветеранами / жертвами насильства**:

- F44 / dissociative клієнти **transferuють** dissociation на терапевта (counter-transference)
- Коуч може почати **«відчувати симптом» як свій** (vicarious traumatization)
- **Self-screening кожні 3 місяці**: чи ти переживаєш intrusive thoughts / numbing / hypervigilance / dissociation у житті?
- **Регулярна супервізія** з фахівцем
- **Особиста терапія** — обов'язкова для коуча з травмо-фокусованою практикою

### 7.7. Правило 7 — Coaching boundaries при ризику

**STOP signs** — коли треба ОБОВ'ЯЗКОВО передати:

1. **Active психотичний епізод** (марення, галюцинації)
2. **Suicidal ideation з планом / методом**
3. **Severe dissociative episode** (фуга, ступор, multiple alters активно switching)
4. **Гострий PNES припадок** (call emergency)
5. **Child abuse disclosure** з продовжуваним ризиком
6. **Втрата контакту з реальністю**
7. **Self-harm з активною ескалацією**

**Coach toolkit**:

- Контакти екстреної психіатричної допомоги (Lifeline Ukraine — 0800 500 335)
- Список фахівців з F44 expertise
- Список neurologов для виключення органіки
- Plan B для emergency

### 7.8. Правило 8 — Educational reframing

**Часто допомагає клієнту просто пояснити механізм**:

1. **«Твій мозок — інженер, який рятує тебе»** — конверсія як захист, а не як «дефект»
2. **«Психіка обрала тіло як мову, бо інша мова заблокована»** — конверсія як translation
3. **«Симптом — це повідомлення»** — semantic зв'язок з конфліктом
4. **«Тіло пам'ятає те, що розум забув»** — соматоформна метафора (van der Kolk)
5. **«Ти не симулюєш — ти переживаєш реально»** — destigmatization

Це не діагностика, не терапія — це **educational coaching** + **psychoeducation**. Це безпечно і часто катартично для клієнта.
