## Quick summary

Лекція 15:03 від **Світлани Володимирівни Ісаєнко**. **Capstone урок модуля 10 «Психіатрія»** — після 7 нозологічних одиниць (L7-L13: шизофренія → БАР → депресія → тривога → ПТСР → істерія → особистість) лектор збирає весь terapeutic toolbox у coherent framework. Це **structural mirror** до L7 (історія психіатрії): як L7 показав, **звідки** ми прийшли — від «негуманних методів» до 1952 amizine — так L14 показує, **куди** ми прийшли і **чим лікуємо**.

**Ключова теза**: Психофармакотерапія = виключна компетенція психіатра. **4 канонічних класи** (антипсихотики + антидепресанти + нормотиміки + транквілізатори) покривають усю F-нозологію МКБ-10. **3 наскрізні принципи**: tiered first/second/third-line + індивідуальна титрування + моно > політерапія. Сучасні препарати (SSRI, атипові антипсихотики) — well-tolerated, але потребують пропорції очікувань: 6-місячний курс SSRI, не «магічна таблетка», не залежність.

**П'ятирівнева композиція**: 1 хв opening/scope + 3.5 хв antipsychotics + 5.5 хв antidepressants (longest single section) + 1.5 хв mood stabilizers + 2.5 хв tranquilizers + 1 хв closing.

21. **Subclass 1 — MAOI**: перший клас AD сер. ХХ ст.
22. MAO mechanism: фермент розщепляє нейромедіатори; блокада → накопичення
23. Therapeutic rationale: акумуляція DA + 5-HT + NE → лікування core depression
24. **«Сирний синдром»** — hypertensive crisis від tyramine foods
25. MAOI status в Україні — extinct, «літопись»
26. **Subclass 2 — TCA**: reuptake inhibition 5-HT + NE + indirect DA
27. TCA side-effect profile: anticholinergic, antihistamine, antiadrenergic, cardiac
28. TCA = третя лінія для важких/treatment-resistant depression
29. «Anxious generation» — модерн епідеміологія тривоги + депресії
30. **Subclass 3 — SSRI**: «найяскравіший випадок ХХ ст. в психіатрії»
31. SSRI mechanism: selective SERT inhibition; clean profile
32. SSRI indications — депресія + тривога + панічні розстройства; first-line outpatient
33. **NOT addictive, NOT controlled substance**, NO euphoria
34. **Cumulative**, terapevtic effect after weeks
35. **6-month treatment course** = «гіпс на нервову систему»
36. **Discontinuation syndrome** — NOT addiction; «brain zaps», dizziness
37. **FINISH mnemonic**: Flu-like + Insomnia + Nausea + Imbalance + Sensory + Hyperarousal
38. Discontinuation = uncomfortable but NOT life-threatening
39. **Австралія over-prescription critique**
40. **Class 3 — Нормотиміки** opening: «Я що епілептик?»
41. Terminology equivalence: normothymic = thymoleptic = thymostabilizer
42. Indications: бар + депресія + тривога + паніка + PD з emotional dysregulation
43. Smooth both poles + **first-line BAR**
44. Historical: anticonvulsants → mood stabilizers serendipity; lithium = exception
45. Mechanism: slow propagation + Ca-channel block + GABA-glutamate balance
46. **Class 4 — Транквілізатори** opening: «гідазепам — всіма любимий»
47. Cultural reputation paradox: «candy» abuse OR categorical fear
48. BZD risk-benefit: effective AND dangerous
49. **Strong anxiolytics, IMMEDIATE onset** — opposite of SSRI
50. Mechanism: positive allosteric modulator GABA-A
51. **6 dose-dependent effects**: anxiolytic → sedative → hypnotic → myorelaxant → anticonvulsant → amnestic
52. Anterograde amnesia at high doses — forensic significance
53. **Dependence liability**: indirect dopaminergic reward activation
54. Duration discipline: 2-4 weeks max; situational PRN use preferred
55. All 6 effects = BZD class property
56. **Non-BZD light tranquilizers**: weak sedation, cumulative onset (buspirone, hydroxyzine, afobazole)
57. GP-prescribed + TV-advertised = consumer OTC market
58. **Closure**: 4 groups discussed; quiz exhortation
59. Intentionally omitted: nootropics (Q1 distractor), stimulants, z-drugs, cholinesterase inhibitors

**Червоні прапори для НЕГАЙНОЇ дії**:

- **Psychosis** (бред, галюцинації, дезорганізована поведінка) → психіатр невідкладно
- **Mania / hypomania** (sleep < 4 год, расход грошей, racing speech) → психіатр невідкладно
- **Severe depression з suicidal ideation** → direct ask 5 питань + 103 + Lifeline 7333
- **PTSD з активними flashbacks** → психіатр + TF-CBT therapist
- **BPD з self-harm** → DBT therapist + психіатр для emotional dysregulation pharma
- **BZD chronic use > 1 місяця daily** → психіатр для безпечного taper (seizure risk)
- **Mixed substance use + AD** → addiction medicine + психіатр coordination
