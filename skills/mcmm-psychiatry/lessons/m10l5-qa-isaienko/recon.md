## Format

**Live відеосесія Q/A.** Учасниці (студентки MCMM I потоку, переважно жінки-психологи / коучи / менторки) задають заздалегідь не модеровані запитання після проходження курсу психіатрії Академії Ісаєнко. Бережний відповідає по протоколу професійного клінічного психіатра: diferentially diagnosis → причина → симптоматика → що робити (медикаментозно і психотерапевтично) → boundary для не-психіатрів.

Загалом ~8 окремих діалогів (рідко питання + відповідь, частіше — кейс або серія підпитань).

## Q/A themes overview (12 макро-тем)

1. **РДУГ (СДВГ)** — діагностика, нейровідмінність, переростання, гіперфіксація, лікування (метилфенідат / атомоксетин), парадокс «кава заспокоює» (`L82-294`) [Аліна]
2. **ПТСР vs розлад адаптації** — диф.діагностика, БДГ-сон як механізм невідбулої переробки, EMDR, медикаментозний підхід (`L297-390`) [Маша]
3. **Психостимулятори — побочки + критика** (атомоксетин, метилфенідат) — наскільки безпечно (`L406-465`) [Анастасія-1]
4. **Дитячі мононеврози / тики після стресу** — переростання, нейропластичність, BDNF (`L466-532`) [Анастасія-1]
5. **Сертралін / есциталопрам — безпека (вагітність, груди, алкоголь)** (`L534-571`) [Анастасія-1 + Ліна]
6. **Тривожно-депресивний розлад** — диф.діагностика, гострий стрес vs соматоформне vs ендогенна депресія, прикриття антидепресантів транквілізаторами (гідазепам, атаракс, прегабалін) у перші 2-3 тижні (`L575-786`) [Юрий]
7. **Гіпертонус у дітей — псих-нейро-ендокрина вісь** (гіпофіз → надниркові → кортизол → м'язи) (`L791-858`) [Олена]
8. **Антидепресанти — як з них зійти?** Тривожні розлади тривають 10 років незалежно від медикації. КПТ = перша лінія. (`L867-1003`) [Юлия]
9. **Біполярка vs шизофренія** — диф.діагностика. Маніакальна тріада. Бредові ідеї грандіозності vs параноїдні (`L1006-1068`) [Юлия]
10. **Родственники хворих на шизофренію** — як підтримувати, «правило відкритих дверей» в Європі vs «не довіряти на слово» в УА (`L1069-1170`); приклад дебюту шизофренії від ПДН-посилання (`L1180-1235`) [Юлия]
11. **Три типи суїциду** — демонстративно-шантажний / істинний / афективний (`L1238-1394`) [Юлия]
12. **Ангедонія / субдепресія** — після раку + хімічна менопауза + СДВГ (`L1396-1533`) [Анастасія-2]
13. **Дисоціативний розлад ідентичності** (split personality) — крайно рідке заболевання (`L1534-1601`) [Татьяна]
14. **Межовий розлад особистості (BPD)** — маркери для коучів, страх покинутості, primary scanning, виборене (burnout) (`L1606-1773`) [Ліна + Кристина]

## Key terminology (мова лектора)

- **Нейровідмінність** (neurodivergence) — РДУГ, аутизм спектру, деякі розлади особистості як варіанти норми
- **Дисимуляція** — приховування симптомів пацієнтом (на відміну від симуляції — придумування симптомів)
- **Гіперфіксація** — як ознака РДУГ (втрата відчуття часу як диференційна ознака)
- **Гіпергоністика / гіподіагностика** РДУГ
- **МКБ vs DSM** (міжнародна vs американська класифікація)
- **МОКСО** — тест для РДУГ
- **Тест МОКСО, 15 хвилин монотонної роботи**
- **BDNF (brain-derived neurotrophic factor)** — каскад від антидепресантів через серотонінові рецептори → нейропластичність
- **EMDR (eye movement desensitization and reprocessing) / десенсибілізація рухами очей** — метод проти ПТСР
- **Травмо-фокусована терапія**
- **Гіпофізарно-гіпоталамо-наднирникова вісь** (HPA axis)
- **Соматоформне / соматизоване розладство** — телесна реакція на психічне
- **Острая реакція на стрес** як окремий діагноз
- **Емоційна лабільність** vs **роздвоєння особистості**
- **Ажитована депресія** — depression with агітацією (а не з пригнобленням)
- **Ангедонія** — відсутність задоволення (від грец. an- + hedonia)
- **Дисфорія** — тяжке емоційне страждання, як у BPD
- **Афективні ілюзії** — у BPD з сильних емоцій дорисовуються об'єкти (як «у страху ока великі»)
- **«Правило відкритих дверей» / open doors policy** — у європейській психіатрії
- **Дисимуляція vs симуляція vs аггравація**
- **Прогрессуюча миорелаксація** — техніка КПТ для тіла → мозок
- **Бредові ідеї грандіозності** (мания) vs **параноїдні** (шизофренія)
- **Маніакальна тріада** — прискорене мислення + прискорені рухи + патологічно підвищений настрій
- **Дезорганізація** як спільний знаменник psychosis (mania + schizophrenia)
- **Деменція ріба-закон** — старі спогади зберігаються довше
- **Аутоагресія / селф-харм** — як спосіб BPD регулювати емоції

## Tone / stance

Бережний — **обережний, без надмірної впевненості, з чорним гумором.** Часто визнає «це не моя специфіка» (психотерапія, специфіка ПТСР-консультування). На запитання «А что опасно?» відповідає «Жить опасно, я розуміюю. У життя є побачний эффект смерти.» (`L541-542`).

**На питання «Чому ваші психіатри витримують це слухати?»:** «Ко всьому чоловік привыкає.» (`L1231`).

**Стиль:** російсько-український міксований (часто російською — «понимаете», «то есть», «случай», «работает» — особливо в технічних описах). Хвилинами переходить повністю на російську, особливо коли описує клінічні кейси.
