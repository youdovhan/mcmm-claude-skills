## Audience-tier legend (added 2026-05-24 per Critic E P0)

Кожен claim тепер має `**Tier:**` field — для безпечного re-use у public контенті.

- **[UNIVERSAL]** — безпечно для будь-якої аудиторії (cold / warm / trusted); academic concepts, public methodologies
- **[WARM-CONDITIONAL]** — тільки для warm-аудиторії (subscribers / lead-magnet downloaders); потребує trust context
- **[WARM-BLOCKED-COLD-BREAK]** — НЕ використовувати у cold marketing; у warm контексті — з explicit framing
- **[HIDDEN-IN-WARM]** — раніше тримати приватно; включати тільки коли клієнт сам уже у глибокій довірі
- **[TRUSTED-ONLY]** — 🚫 НЕ для public marketing / Detective FM landing / Threads / IG; тільки 1-on-1 coach-mentor контекст
