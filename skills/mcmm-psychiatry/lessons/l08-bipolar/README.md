## Key claims (top 18 — пріоритет для тесту)

1. **БАР визначення** [C-008-004]: захворювання з афективними фазами (манія + депресія), розділеними інтермісіями, **без формування дефекту особистості**; стара назва — МДП (Крепелін 1899)
2. **2 міфи** [C-008-002, 003]: БАР ≠ роздвоєння особистості (DID); БАР ≠ амбівалентність (Bleuler — це шизо)
3. **4 етіологічні теорії** [C-008-007..010]:
   - **Нейротрансмітерна**: ↓ норадреналіна + серотоніна у депресію
   - **Генетична**: хромосоми **11 і 18**; 1 з 5 пацієнтів (20%) має батька з БАР
   - **Натрієва**: дефекти переносу Na+ через мембрани → **раціонал літію**
   - **Нейроанатомічна**: достовірне ↑ амігдали
4. **6 типів БАР** [C-008-011..016] — мнемоніка **«ІІЦЯДУ»**: I (full) / II (hypomania) / Циклотимія / Ятрогенна / Депресія+family / Уніполярна манія
5. **Тріада Крепеліна манії** [C-008-021]: **↑ настрій + прискорене мислення (тахіфренія) + психомоторне збудження**
6. **Тріада Крепеліна депресії** [C-008-031]: **↓ настрій (вітальна туга) + сповільнене мислення (брадифренія) + рухова загальмованість**
7. **F30 манія МКБ-10** [C-008-018..020]:
   - **F30.0 гіпоманія** — легкий ↑, БЕЗ психозу, БЕЗ грубого порушення; ≥ кількох днів
   - **F30.1 манія без психозу** — порушення проф. + соц.; ≥ 1 тиждень
   - **F30.2 манія з психозом** — маячіння величі/переслідування + галюцинації; ≥ 2 тижні
8. **F32 депресія МКБ-10** [C-008-038..041]:
   - **F32.0** легкий (.00 без / .01 з соматикою)
   - **F32.1** помірний (**ранкові пробудження** pathognomonic)
   - **F32.2** тяжкий без психозу (**суїцид = прогностичний критерій**)
   - **F32.3** тяжкий з психозом (гріховність, **Котар** нігілістичне, переслідування, іпохондричні + галюцинації)
9. **Гіпермнезія** [C-008-022, 078] — підвищена пам'ять у манії (cross-ref L4)
10. **Anaesthesia psychica dolorosa** [C-008-037] — pathognomonic ендогенної депресії: «як робот», не може плакати, не відчуває любові — diagnostic value high
11. **Дисимуляція суїцидальної ідеації** [C-008-034] — приховування реальних намірів; clinical pearl при «раптовому покращенні» — посилити нагляд

## Coaching application (DETECTIVE FM)

7 actionable правил для Юрія-Детектива (детально у `synthesis.md` §7):

1. **Маніакальний клієнт = НЕВІДКЛАДНА психіатрія** — не «творчий злет»! 3+ маркерів (↓ сон + скачка ідей + ризиковані рішення + анозогнозія) = психіатр невідкладно
2. **Тригерна тріада** — скачка ідей + < 4-5 год сну + ризиковані рішення (gambling/кредити/секс) = red flag манії F30.1+
3. **Депресивний клієнт ≥1 тиждень ангедонії** = SSRI зона, не «мотивація» — ранкове погіршення + камінь у грудях + anaesthesia psychica dolorosa = psychiatr невідкладно
4. ⭐ **Дисимуляція суїцидальної ідеації — direct ask** 5 питань. Direct ask НЕ провокує суїцид. При ТАК на 3+ — швидка 103 + Lifeline 7333
5. **Anaesthesia psychica dolorosa** — найважчий маркер ендогенної: «як робот», не може плакати, не відчуває любові — мотиваційні методи НЕ діють
6. **Цикли в 4 пори року** — pattern recognition БАР з seasonal pattern vs SAD
7. **Кейс пацієнтки А** — 5-річний шлях до точного діагнозу як patient education; антистигматизаційний урок: точний діагноз + compliance = повернення до повноцінного життя

**Червоні прапори для НЕГАЙНОЇ дії**:

- **Маніакальний епізод F30.2** з публічною дезорганізованою поведінкою + маячіння величі/впливу → виклик швидкої або вмовляння родини на госпіталізацію
- **Імперативні голоси при F30.2 / F32.3** («вбий, підпали») → 103 / госпіталізація НЕГАЙНА
- **Раптове «покращення» у тяжкій депресії БЕЗ адекватної терапії** → підозра на дисимуляцію, не послаблювати нагляд
- **Парадоксальний суїцид при ранній антидепресантній терапії** (1-2 тижні) → особливий нагляд у перший місяць SSRI
- **Anaesthesia psychica dolorosa + втрата ваги > 5 кг + ідеї гріховності** → ризик F32.3 + Котар → psychiatr / ECT
