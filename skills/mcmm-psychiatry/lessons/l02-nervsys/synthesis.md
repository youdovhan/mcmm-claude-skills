## §0 — Quick thesis

**Психіка = функція нейробіологічного «харду», а синапс — точка втручання у патологію.** Урок 2 — нейрофізіологічний фундамент усього модуля «Психіатрія». Без нього шизофренія (L7), депресія (L9), тривога (L10), фармакотерапія (L14) залишаються «магічними категоріями» — після L2 вони стають **наслідками кількісного дисбалансу 4 ключових нейромедіаторів** (дофамін / серотонін / норадреналін / ГАМК-глутамат) у конкретних анатомічних шляхах.

Лектор Світлана Ісаєнко вибудовує лекцію як **триярусну зміну рівнів узагальнення**: (1) метафора «мозок як комп'ютер» — хард і софт ([C-002-004]); (2) клінічний прев'ю-приклад тривоги — взаємодія таламус → амигдала → префронтал → гіпоталамус ([C-002-009..020]); (3) мікро-рівень — нейрон, потенціал спокою −70 мВ, потенціал дії +20 мВ, синапс, нейромедіатори, клінічні шляхи. Кожен рівень готує наступний.

Core insight для коуча: **«ваш клієнт каже „у мене депресія/тривога“ — питай, на якому рівні»** — на рівні харду (нейромедіатори, нейробіологічна основа, потенційна медикаментозна корекція), на рівні софту (адаптація, когніції, поведінка — коучингова зона) чи на рівні соматики (соматичні симптоми як наслідок). L2 дає коучу анатомічну рамку для **діагностики делегування**: якщо клініка вкладається у нейромедіаторний дисбаланс — це психіатр з препаратами; якщо це адаптаційна реакція без структурних змін — це коуч.

## §2 — Key insights / paradigm narrative

### 2.1. Хард і софт — психіка як похідна нейробіології

**Перший inversion для слухача**: побутове розуміння «у мене депресія» рідко включає, що це **також біохімія**. Лектор у [C-002-004] вибудовує клініко-методологічну рамку:

```
ХАРД (нейрон, потенціал, синапс, нейромедіатори) → СОФТ (емоції, думки, поведінка)
                                                          ↑
                                                СИМПТОМ як проявлення дисбалансу
                                                          ↓
                                                ПРЕПАРАТ як корекція харду
```

Це **прихована теза Авіценни** (L1 [C-007-028]: «душа = функція мозку») у сучасній нейробіологічній обгортці. L2 не атрибутує Авіценну, але вся структура лекції — це доведення його тези через сучасні дані.

**Coaching application**: коли клієнт каже «у мене ХХХ», задавай питання трирівневою рамкою:

- **Хард**: чи є соматика? сон, апетит, енергія, лібідо, концентрація? хронічні захворювання, гормональні зміни? — якщо ≥3 системно порушено = можливий нейробіологічний компонент → психіатр
- **Софт**: що клієнт говорить про себе? які когніції-петлі? які адаптаційні стратегії? — це коучингова зона
- **Контекст**: середовище, ресурси, життєві обставини?

### 2.2. Контур тривоги — 6 структур, 1 функціональна логіка

Прев'ю-приклад уроку — формування тривожного розладу через взаємодію 6 структур мозку ([C-002-009..014]):

| Структура                                  | Функція                                  | Що буває «не так»                          |
| ------------------------------------------ | ---------------------------------------- | ------------------------------------------ |
| **Таламус**                                | приймає сенсорну інфу, передає у кору    | надмірне «перевантаження» сигналів         |
| **Кора**                                   | розуміння того, що відбувається          | гіперінтерпретація («а якщо інсульт?»)     |
| **Префронтальна кора**                     | гальмо для тривоги, «вимикач»            | слабка регуляторна функція                 |
| **Мигдалина (амигдала)**                   | емоційний центр, «реакція страху»        | гіперактивація на нейтральні стимули       |
| **Опорне ядро термінальної смужки (BNST)** | хронізує реакцію страху                  | закріплює тривожний розлад                 |
| **Гіпоталамус**                            | активує соматику «бий або біжи»          | викид адреналіну/норадреналіну без причини |
| **Гіпокамп**                               | пам'ять про подію після оцінки амигдалою | «досьє на змію» закріплюється помилково    |

Дві ключові аналогії описують **норму vs патологію** [C-002-018, C-002-019]:

**Норма** — справна сигналізація. Таламус → кора (читає сигнал) → гіпокамп (досьє на змію) → префронтал каже амигдалі «узбагойся» → дія пропорційна загрозі. Якщо була справжня змія — «дати драпу, але не сильно швидко» [C-002-017].

**Патологія** — «дім на сигналізації, який орє на вітер і котенка» [C-002-019]. Через порушення нейромедіаторів (дефіцит серотоніну, дисбаланс ГАМК-глутамату) — таламус → амигдала → гіпоталамус → викид адреналіну/норадреналіну → паніка → ніякої змії не було, було лише «а якщо я зараз помру?» [C-002-020]. Префронтал не встигає загальмувати — і весь каскад крутиться у замкнутому колі (BNST хронізує). Це **тривожний розлад**.

**Найважливіший методологічний висновок** [C-002-021]: лектор окремо критикує психологів-немедичних, які кажуть «я залічився від тривожних розладів через розмови». Лектор: тривожний розлад — це нейробіологічна патологія, її **не вилікувати розмовами**. Це авторська позиція курсу — і це межа коучингу теж.

### 2.3. Потенціал спокою (−70 мВ) — енергозатратна тиша

Один з найзапам'ятовуваніших фактів уроку — **−70 мВ** [C-002-051]. Це не довільне число: це різниця концентрацій іонів (Na+, K+, Cl−) усередині й зовні клітини, яка підтримується **активним натрій-калієвим насосом** ([C-002-050]) — він «нерівномірно качає»: піднімає 2 частинки, опускає 3. Це і створює перевагу негативних іонів усередині = −70 мВ.

**Парадокс уроку**: основна частина енергії мозку йде НЕ на думку, а на підтримку «сплячої» клітини [C-002-052]. Тому глюкоза («шоколадку перед контрольною») потрібна — мозок є **енергозатратним органом не від навантаження, а від базального стану**. Це ламає інтуїцію, що «думання вимагає енергії, відпочинок не вимагає».

**Coaching application**: фізіологічний фон важливий. Клієнт з хронічним недосипом + дефіцитом їжі + гіпоглікемією — об'єктивно не може «нормально мислити», бо нейрони не тримають −70 мВ через дефіцит АТФ. Сесія з ним = марнування часу. Спочатку соматика, потім коучинг.

### 2.4. Потенціал дії (+20 мВ) — все або нічого

Сигнал нижче +20 мВ ігнорується [C-002-054], сигнал ≥ +20 мВ запускає **повний** потенціал дії [C-002-055]. Це принцип «все або нічого». Як тільки активуються потенціал-залежні канали («двері на магніті»), позитивні іони ринуть всередину, заряд стрімко долає 0 і досягає позитивних значень. Потім реполяризація — повернення до −70 мВ через відкриття інших каналів [C-002-058].

Метафора «бенгальський вогник» [C-002-059] — поширення сигналу від точки активації у всі сторони (особливо по аксону). Швидкість сигналу + одночасна паралельна робота мільярдів нейронів = «мозок як сервер компанії Майкрософт» [C-002-069].

**Клінічна імплікація**: чому деякі стимули не «зчитуються» (низькі), а інші — переламують пацієнта. Це непрямий міст до **сенсорних розладів** у L4 (сприйняття), де поріг + чутливість пояснюють галюцинації і гіпестезії.

### 2.5. Синапс — точка втручання у психіатричну патологію

Перехід від внутрішньо-нейронної фізики до міжнейронної хімії [C-002-122] — ключовий концептуальний місток. Синапс — це **щілина** між аксоном одного нейрона і дендритом/тілом іншого, з трьома компонентами: пресинаптична мембрана + щілина + постсинаптична мембрана [C-002-062].

Каскад передачі через синапс:

```
ПОТЕНЦІАЛ ДІЇ доходить до кінця аксона
   → відкриваються КАЛЬЦІЄВІ канали ([C-002-063])
      → Ca²⁺ заходить у клітину
         → активує ВЕЗИКУЛИ з нейромедіатором ([C-002-064])
            → екзоцитоз — медіатор виливається у щілину
               → дифундує до РЕЦЕПТОРА ([C-002-068])
                  → принцип КЛЮЧ-ЗАМОК ([C-002-070])
                     → запуск потенціалу дії на постсинаптичному нейроні
                        → ДАЛІ
```

Після виконання функції «ключ» (нейромедіатор) має 3 варіанти долі [C-002-071]: (1) повторно зв'язатися; (2) бути зруйнованим ферментом; (3) повернутися через **зворотне захоплення** (reuptake) — пасивно або через спеціальний транспортний білок.

**Клінічна важливість**: пункт 3 — це механізм SSRI (антидепресантів) [C-002-089]. Блокатори зворотного захоплення серотоніну не дозволяють медіатору повернутися додому, він залишається у синапсі і **продовжує активувати рецептори**. Метафора «листоноша, який не може потрапити додому, і змушений знов і знов розносити пошту» [C-002-090]. Це найдетальніша фармакологічна метафора уроку — і вона універсальна для SSRI, SNRI, TCA.

**Уточнення метафори «ключ-замок»** [C-002-072]: вона не зовсім точна. Один медіатор може зв'язуватися з кількома підтипами рецепторів (норадреналін: α1, α2, β1, β2 і т.д.). Це і пояснює, чому **серотонін має 14 типів рецепторів** (5-HT1A, 5-HT2A...) і чому SSRI можуть мати побічні ефекти на ШКТ (там теж серотонінові рецептори, бо 95% серотоніну у тілі — у шлунково-кишковому тракті [C-002-085]).

### 2.6. Дофамін — 3 шляхи, 3 клінічні зони

Найбагатша секція уроку клінічно. Дофамін — нейромедіатор + гормон [C-002-074], розташований у 3 основних шляхах [C-002-075]:

| Шлях                 | Латинська назва | Функція                                       | Клінічна патологія                                                                                                  |
| -------------------- | --------------- | --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| **Мезолімбічний**    | mesolimbic      | система винагороди, мотивація, задоволення    | **↑ дофамін → продуктивні симптоми шизофренії** ([C-002-080]): псевдогалюцинації, сенестопатії, маячні ідеї         |
| **Мезокортикальний** | mesocortical    | вищі когнітивні функції, планування, контроль | **↓ дофамін → негативні симптоми шизофренії** ([C-002-081]): апатія, абулія, соц. дезадаптація, когнітивний дефіцит |
| **Нігростріарний**   | nigrostriatal   | руховий контроль, координація                 | **↓ дофамін → хвороба Паркінсона** ([C-002-083])                                                                    |

**Принципова симетрія**: шизофренія — це **одночасний дисбаланс** у двох дофамінових шляхах (надлишок у мезолімбічному + дефіцит у мезокортикальному). Це пояснює, чому **антипсихотики класичні (галоперидол, аміназин)** часто **посилюють негативну симптоматику** — вони блокують D2 рецептори всюди, включно з мезокортикальним шляхом. Атипові антипсихотики (рисперидон, оланзапін) дозволяють обходити цей побічний ефект.

**Експеримент Олдза-Мілнера** [C-002-078]: щур з електродом у дофаміновій ділянці тиснув кнопку до виснаження. Це **модель наркотичної залежності** [C-002-079]: амфетамін, МДМА, кокаїн — речовини, що штучно стимулюють дофаміновий викид. Кнопка щура = доза наркотика людини. Мотиваційна петля «передчуття результату → дофамін → дія → ще дофамін» працює нейробіологічно, а не «по слабкості волі».

**Cross-ref до L7 (Шизофренія)**: продуктивні vs негативні симптоми у L7 матимуть **готовий нейробіологічний субстрат** з L2.

### 2.7. Серотонін — переважно гальмівний, переважно не у мозку

Серотонін має дві несподіванки [C-002-084, C-002-085]:

1. **95% у ШКТ** (шлунково-кишковому тракті), не в мозку — тому SSRI часто дають GI побічки (нудота, діарея, запор перші 2 тижні)
2. Його ім'я походить від **«серо-тонін»** = тонізує **серозну** оболонку судин — тобто історично відкритий як тканинний гормон, а не нейромедіатор

У мозку серотонін **переважно гальмівний** [C-002-087]: контролює больові відчуття, придушує негативні емоції, фокусує увагу. **Дефіцит серотоніну** = недостатнє придушення негативних емоцій = тривожні, панічні, дистимічні, депресивні стани [C-002-088].

Антидепресанти SSRI [C-002-089] блокують зворотне захоплення → серотонін накопичується у синапсі → ефект придушення негативних емоцій посилюється. Метафора «листоноша і поштові скриньки» [C-002-090] — **детальніше з усіх описаних механізмів** уроку.

**Парадокс дозування**: антидепресанти діють 4-6 тижнів не через те, що «препарат накопичується», а через **upregulation рецепторів** [C-002-091] — постсинаптичний нейрон у відповідь на підвищену концентрацію медіатора **збільшує кількість рецепторів** на мембрані. Це адаптація системи, яка потребує тижнів. Тому пацієнт каже «нічого не діє» першу-другу неділю — препарат уже діє, але клінічного ефекту ще немає.

**Цікавий клінічний місток**: ЛСД діє переважно на 5-HT2A рецептор [C-002-093]. Якщо «прибрати фільтр» (інформаційний шум) — отримаєш галюцинації. Це той самий механізм, що працює при шизофренії (надлишок дофаміну в мезолімбічному шляху + 5-HT2A гіперстимуляція). Тому атипові антипсихотики є блокаторами і D2, і 5-HT2A.

### 2.8. Норадреналін — стрес, неспання, азарт

Норадреналін — хімічний родич адреналіну [C-002-094], діє у двох системах:

1. **Симпатична нервова система** (периферія) — активується при стресі: «бий або біжи» [C-002-096] — зіниці розширюються, тиск підвищується, бронхи розширюються (для дихання), судини звужуються (щоб кров йшла до м'язів).
2. **Блакитне ядро (locus coeruleus)** у мозку [C-002-099] — підготовка до стресу + неспання + зниження больових відчуттів.

Дефіцит норадреналіну [C-002-102] — один з патогенетичних факторів депресії. Тому **SNRI** (Serotonin-Norepinephrine Reuptake Inhibitors, наприклад венлафаксин, дулоксетин) блокують зворотне захоплення обох. Це другий клас антидепресантів після SSRI — корисний при депресії з низькою енергією, апатією, болем (норадреналін має знеболюючу дію).

**Cross-ref до L3 (емоції)** [C-002-014, C-002-020]: гіпоталамус активує соматику тривожного нападу — це і є викид норадреналіну. **Cross-ref до L11 (ПТСР)**: гіперактивація блакитного ядра — нейробіологічна основа гіперзбудження при ПТСР.

### 2.9. ГАМК + глутамат — газ і гальмо

Найкоротша секція уроку, але ключова концептуально [C-002-103..110]:

| Медіатор     | Тип           | Дія                                                                                           | Клінічний приклад                                                                     |
| ------------ | ------------- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| **ГАМК**     | гальмівний    | гіперполяризація мембрани до −90 мВ ([C-002-108]) — потенціал дії потребує сильнішого сигналу | транквілізатори (бензодіазепіни — діазепам, феназепам, клоназепам) посилюють дію ГАМК |
| **Глутамат** | збуджувальний | деполяризація мембрани — потенціал дії запускається легше                                     | NMDA-антагоністи (мемантин при Альцгеймері), кетамін як швидкодіючий антидепресант    |

**Порушення балансу ГАМК-глутамат** [C-002-110] — причина:

1. Порушень настрою
2. **Епілепсії** — надлишок глутамату або дефіцит ГАМК → надмірне збудження → судомні напади

Епілепсія — фінальний клінічний приклад уроку [C-002-117]. Лектор не розгортає її, але закріплює зв'язок: «нейромедіатори → клініка», де **дисбаланс двох медіаторів призводить до структурних епізодичних розладів**.

**Cross-ref до L13 (Аномалії особистості)**: епілептоїдні зміни особистості [C-003-037] мають нейрохімічний субстрат у дисбалансі ГАМК-глутамат.

### 2.10. Хімія психіатрії на одній сторінці

Підсумкова таблиця, яку варто запам'ятати [C-002-126, C-002-128]:

| Нейромедіатор    | Функція в мозку                           | Дефіцит → клініка                      | Препарати                                                           |
| ---------------- | ----------------------------------------- | -------------------------------------- | ------------------------------------------------------------------- |
| **Дофамін**      | винагорода, мотивація, рух                | ↓ Паркінсон, негативна шизофренія      | L-DOPA (Паркінсон) / антипсихотики (шизофренія)                     |
| **Серотонін**    | придушення негативних емоцій, увага, біль | ↓ депресія, тривога, ОКР               | SSRI (флуоксетин, сертралін, есциталопрам)                          |
| **Норадреналін** | стрес, неспання, азарт, знеболення        | ↓ депресія з апатією, втомою           | SNRI (венлафаксин, дулоксетин) / бета-блокатори (соматична тривога) |
| **ГАМК**         | гальмо, контроль збудження                | ↓ паніка, тривога, безсоння, епілепсія | Бензодіазепіни (короткостроково), вальпроат                         |

Це і є **основний клінічний takeaway уроку** — все інше у модулі L7-L14 будується на цьому фундаменті.

## §3 — Cross-cutting concepts

### 3.1. Триєдиний мозок — еволюційна ієрархія

Лектор використовує модель Пола Маклейна (без атрибуції) [C-002-025..033]:

```
НЕОКОРТЕКС  → людина, кора великих півкуль → розуміння, навчання, мораль
   ↑
ЛІМБІЧНА СИСТЕМА → ссавці → «кузня емоцій»: страх, сум, радість, любов
   ↑
РЕПТИЛЬНИЙ МОЗОК → рептилії → життєзабезпечення: тиск, серце, дихання, рефлекси
```

**Дидактичний жарт лектора**: «навряд чи ви коли-небудь бачили грустого крокодила або сміючусь кобру» [C-002-027]. Рептилії не мають кори емоцій — у них тільки життєзабезпечення.

**Coaching application**: коли клієнт «зривається» — за ним стоять різні рівні. Соматична реакція (серцебиття, піт, тремор) = рептильний+лімбічний. Усвідомлене рішення = неокортекс. Якщо клієнт «знає, що йому це шкодить, але робить» — це конфлікт неокортексу (хочу зупинити) і лімбіки (хочу винагороди). Це **не «слабка воля»**, це структурна нейробіологія.

### 3.2. Нейрон — функціональна одиниця

3 відділи нейрона [C-002-039..042]:

| Відділ       | Функція                                              |
| ------------ | ---------------------------------------------------- |
| **Тіло**     | життєдіяльність, органели                            |
| **Дендрити** | короткі відростки, приймають інформацію («порти»)    |
| **Аксон**    | довгий відросток, передає інформацію далі («провід») |

**Кількісно**: мільярди нейронів, аксони до 1 метра [C-002-037], мозок = «моток мільярдів проводів» [C-002-038] + «сервер Майкрософт» [C-002-069].

**Анатомічний місток**: сіра речовина = тіла нейронів, біла = аксони з мієліном (мієлін у L2 не згаданий [C-002-116] — лакуна для L4+).

### 3.3. Двох-фазна передача: фізика → хімія

Ключовий концепт уроку [C-002-122]:

```
ВСЕРЕДИНІ НЕЙРОНА — ФІЗИЧНА (електрична) передача
   потенціал спокою (−70 мВ) → стимул (≥ +20 мВ) → потенціал дії → поширення по аксону

МІЖ НЕЙРОНАМИ — ХІМІЧНА передача
   аксон → синапс → кальцій → везикули → нейромедіатор → рецептор постсинаптичного нейрона
```

**Чому це важливо**: вся психіатрична фармакологія діє на **хімічну фазу**. Препарати не можуть міняти потенціал спокою чи поширення сигналу всередині нейрона — тільки модулюють синаптичну хімію. Тому **точка втручання** = синапс.

### 3.4. Принцип «ключ-замок» і його обмеження

Метафора «ключ-замок» [C-002-070] — нейромедіатор пасує до свого рецептора як ключ до замка. **Обмеження** [C-002-072]:

1. Один медіатор → багато підтипів рецепторів (норадреналін: α1, α2, β1, β2)
2. Один підтип рецептора → різні ефекти у різних тканинах (5-HT3 в ШКТ → нудота; 5-HT3 в мозку → інше)
3. Препарати-агоністи + антагоністи: одні «ключі» відкривають замок, інші — блокують

**Coaching application**: коли клієнт каже «препарат не діє» — це може бути (а) неправильний підтип рецептора (треба інший препарат); (б) ще не сталася upregulation (треба чекати 4-6 тижнів); (в) побічка переважає основний ефект (треба корекція дози). У всіх 3 випадках — психіатр, не коуч.

### 3.5. Зв'язок «нейромедіатор → симптом → препарат» — основа всієї психофармакології

Структура мислення психіатра, яку L2 закладає:

```
СИМПТОМ (клініка) → ймовірний дефіцит/надлишок медіатора → препарат, що корегує
```

Приклади:

- **Псевдогалюцинації** → надлишок дофаміну в мезолімбічному → антипсихотик (блокатор D2)
- **Тривога з панічними нападами** → дефіцит серотоніну → SSRI
- **Депресія з апатією, втомою** → дефіцит серотоніну + норадреналіну → SNRI
- **Паніка з гіпервентиляцією** → недостатня ГАМК → бензодіазепін (короткочасно)
- **Маніакальний епізод** → надлишок глутамату (припущення) → стабілізатор настрою (літій, вальпроат)
- **Шизофренія з негативними симптомами** → дефіцит дофаміну в мезокортикальному → атиповий антипсихотик

**Це не «вгадування»** — це **алгоритмічна нейропсихіатрія**, що ґрунтується на дослідженнях останніх 70 років (від аміназину 1950 до сучасних агентів).

## §4 — Diagnostic logic

L2 не вчить діагнозу як такому (це функція L7-L13), але задає **анатомо-фізіологічну логіку прийняття рішень**. 5 ключових точок розгалуження:

### 4.1. «Тривога: фізіологічна, патологічна чи розлад?»

Лектор розгалужує [C-002-008..020]:

- **Фізіологічна тривога**: справжня загроза → корекція через префронтал → проходить, коли загроза зникла
- **Адаптаційна тривога**: повторне переживання + хибна тривога іноді → ще не розлад, але вже не норма
- **Тривожний розлад**: BNST хронізує реакцію → каскад без причини → дисбаланс нейромедіаторів (серотонін↓, ГАМК↓) → **нейробіологічна патологія**

**Якщо нейромедіаторний компонент** → психіатр + SSRI + можливо бензодіазепін короткочасно. Розмовами не вилікувати (позиція лектора [C-002-021]).

### 4.2. «Депресія: настрій, реактивна чи клінічна?»

- **Знижений настрій** = тимчасова реакція, проходить за дні
- **Реактивна депресія** = після конкретної події (втрата, розлучення), проходить з часом
- **Клінічна депресія** = дефіцит серотоніну ± норадреналіну → антидепресанти + ймовірно психотерапія

**Маркер делегування**: тривалість >2 тижні + соматика (сон, апетит, енергія) порушена + думки про смерть — це SSRI/SNRI територія, не коучинг.

### 4.3. «Психотичні симптоми: чи це шизофренія?»

3 продуктивні маркери з L2 [C-002-080]:

1. **Псевдогалюцинації** — голоси «зсередини голови», без зовнішнього подразника
2. **Сенестопатії** — тілесні відчуття «чужого» (рухи, ворушіння, неприємні дотики)
3. **Маячні ідеї** — стійкі помилкові переконання (переслідування, велич, ревнощі)

3 негативні маркери [C-002-081]:

1. Апатія
2. Абулія
3. Когнітивний дефіцит / соц. дезадаптація

**Якщо ≥1 продуктивний АБО ≥2 негативних** → невідкладна психіатрія, антипсихотик, психотерапія тільки після стабілізації.

### 4.4. «Стрес: компенсована реакція чи зрив?»

- **Компенсована реакція**: «бий або біжи» спрацьовує адекватно, після події стан повертається до норми
- **Гострий зрив**: гіперактивація блакитного ядра + парасимпатична недостатність → ПТСР (L11)

**Маркер**: «спалахи» (flashbacks), уникнення тригерів, нічні кошмари, гіперзбудження >1 місяця після події = ПТСР, не коучингова робота.

### 4.5. «Епілепсія в анамнезі»

Епілепсія = дисбаланс ГАМК-глутамат [C-002-110]. Це **критерій делегування з коучингу**:

- Якщо клієнт каже про судоми, абсанси, аури — це невропатолог + протиепілептичні препарати
- **Специфічні неврологічні маркери**:
  - **Аура** — передприпадкова сенсорна/вісцеральна симптоматика (особливо скронева епілепсія: déjà vu, неприємні запахи, епігастральне відчуття «підйому»)
  - **Стан Тодда** — післяприпадкова минуща неврологічна симптоматика (фокальні паралічі 24-48 год)
  - **Сутінковий стан свідомості** — амбулаторний автоматизм, фуга, post-ictal сплутаність
- Якщо клієнт має епілепсію + психічне порушення — **епілептоїдні зміни особистості** [L3 C-003-037], дисфорія, гнівливість — це психіатр + невропатолог разом

**Доп критерій тривалості для шизофренії** (стане в нагоді в L7): МКБ-10 потребує ≥6 міс безперервної симптоматики; DSM-5 — ≥1 міс active phase + ≥6 міс загалом. До цих термінів — «psychotic episode», після — F20.0 шизофренія.

## §7 — Applied to coaching (DETECTIVE FM)

Юрій-Детектив працює з клієнтами в коучинговій рамці. L2 дає **7 actionable правил** з найвищим клінічним пріоритетом — це найбільш «делегувальний» урок усього модуля.

### 7.1. Розпізнавай нейробіологічний vs психологічний компонент

Default-чек-ліст із 4 питань:

1. **Сон**: <6 годин ≥4 ночі на тиждень → нейробіологічний компонент → психіатр
2. **Енергія**: спадає до ≤30% від базового рівня + апатія → можливий дефіцит дофаміну/норадреналіну
3. **Концентрація**: різке падіння, «не можу зосередитись» 2+ тижні → серотонін, можливо ADHD-нейрохімія
4. **Фон**: депресивні думки + соматика (втрата ваги, лібідо, ранкові пробудження о 4-5 ранку) → клінічна депресія

**Якщо ≥2 з 4 = клінічна зона**, делегувати психіатру. **Тільки нейробіологічна корекція може звільнити простір для коучингу.**

### 7.2. Тривожний розлад — не лікується розмовами (позиція лектора)

Лектор у [C-002-021] прямо критикує психологів-немедичних, які «лікують від тривожних розладів через розмови». Якщо клієнт демонструє:

- **Панічні атаки** (3+ соматичних симптомів: тахікардія, задишка, тремор, нудота, дереалізація)
- **Хронічна тривога** з періодичним загостренням (BNST хронізує)
- **Уникнення** через тривогу (агорафобія, соц. фобія обмежують життя)

→ це **психіатрична зона + SSRI**, не коучинг. Коуч може **підготувати до прийняття лікування** (терапевтичний альянс перед фармакологією), але не лікувати тривожний розлад сам по собі.

**Фраза для клієнта**: «Я бачу, що тривога значно обмежує твоє життя. Це той рівень, де комбінація психіатра + терапевта дає швидші результати, ніж тільки одне. Я можу підготувати тебе до візиту — про що питати, як описати симптоми».

### 7.3. Шизофренія — критерій термінового делегування

3 продуктивні симптоми з L2 [C-002-080]:

- **Псевдогалюцинації** (голоси «зсередини», без зовнішнього подразника)
- **Сенестопатії** (тілесні «рухи», «ворушіння» без причини)
- **Маячні ідеї** (стійкі помилкові переконання, не піддаються переконуванню)

3 негативні симптоми [C-002-081]:

- Апатія
- Абулія (відсутність ініціативи)
- Соціальна дезадаптація + когнітивний дефіцит

→ якщо ≥1 продуктивний АБО ≥2 негативних → **психіатр невідкладно**, антипсихотик, психотерапія тільки після стабілізації. У жодному разі не «опрацьовуй маячення» — це не невротичний конфлікт, це психотичний спектр.

### 7.4. Депресія за феноменологією → SSRI/SNRI зона

Маркери клінічної депресії (L2 + L3 разом):

- Тривалість >2 тижні, не зникає
- Сон: ранкові пробудження о 4-5, «не сплю по 2-3 години після цього»
- Апетит: втрата >5% ваги без зусиль АБО переїдання (≠ типове)
- Лібідо: ↓↓ або відсутнє
- Енергія: «не можу встати», «навіть умитися — подвиг»
- Думки: «навіщо я живу», «всім було б краще без мене»

→ **SSRI/SNRI зона** [C-002-089..091, C-002-102]. Антидепресанти діють 4-6 тижнів — це **upregulation рецепторів**. Коуч **не починає** роботу до часткової стабілізації; **продовжує** паралельно з фармакологією після 4-6 тижнів.

### 7.5. Залежності — це нейробіологія дофаміну, не «слабка воля»

Експеримент Олдза-Мілнера [C-002-078] + наркотики [C-002-079] — це нейробіологічний субстрат залежності. **Дофамінова петля** «передчуття → стимул → дофамін → ще» працює фізіологічно, не «по слабкості».

**Coaching application**:

- НЕ кажи клієнту з алкогольною/нікотиновою/харчовою залежністю «треба просто захотіти»
- Розпізнавай, що це **дофамінова нейробіологія** + поведінкові патерни
- Делегуй наркологу + психіатру (бо часто кокаментоз з тривогою, депресією)
- Сам можеш працювати з **середовищем** (тригери) + **смислом** (нащо змінити), не з фізіологічним потягом

### 7.6. «Бий або біжи» — соматичні сигнали стресу як діагностичні

Соматична реакція через гіпоталамус + симпатичну НС [C-002-014, C-002-094..096]:

- Розширені зіниці
- Прискорене серцебиття (тахікардія)
- Підвищений тиск
- Прискорене дихання
- Звуження судин (бліда шкіра, холодні кінцівки)
- Пітливість (особливо долоні, чоло)

**Якщо клієнт у сесії показує 3+ симптомів** + говорить про «не контрольований стан» → це гостра стресова реакція, не «нервозність».

**Дії**:

1. Заземлення (5-4-3-2-1: 5 предметів зором, 4 звуки, 3 дотики, 2 запахи, 1 смак)
2. Дихання діафрагмою (4-7-8 або box breathing)
3. Якщо повторюється >2 раз на тиждень — психіатр (можливо панічний розлад, ПТСР)

### 7.7. Парадигмальне розуміння — психіатрія = модуляція хімії

Лектор у [C-002-005] формулює методологічну рамку: «розберемося, які можуть бути поломки в харді і софті, і до чого вони приводять». Це задає **рамку розмови з клієнтом про психіатрію**:

- Психіатрія = модуляція синаптичної хімії = **не «з'їсти таблетку щоб не думати», а механізм підтримки системи**
- Антидепресант не «робить щасливим» — він **знімає блок** на природну емоційну регуляцію
- Антипсихотик не «робить овочем» — він **зменшує надлишок дофаміну**, щоб людина могла повернутися до реальності
- Коучинг + фармакологія = два рівні втручання, які підсилюють один одного, а не альтернативи

**Coaching framing**:

> «Ти знаєш, що психіатрія — це не магія і не „зробити з тебе іншу людину“. Це модуляція нейромедіаторів у синапсі — щоб баланс хімічних сигналів повернувся до того, який був до того, як система зірвалась. SSRI не „робить щасливим“ — він просто дозволяє серотоніну довше працювати у синапсі. А вже ця нормалізація дає тобі простір думати про себе тверезо. Ось у цьому просторі я і працюю з тобою як коуч.»

Це **демістифікує психіатрію** для клієнта і знімає стигму. Це **продовження дестигматизації** з L1 [C-007-087] — на новому рівні.

## §8 — Key facts чек-ліст для тесту

1. **Потенціал спокою** [C-002-051]: **−70 мВ**, підтримується пасивними каналами + натрій-калієвим насосом (активний транспорт)
2. **Потенціал дії запускається при** [C-002-055]: стимул ≥ **+20 мВ** → відкриваються потенціал-залежні («магнітні») канали → деполяризація → реполяризація → −70 мВ
3. **3 дофамінові шляхи** [C-002-075]:
   - **Мезолімбічний** — винагорода, мотивація → надлишок → продуктивні симптоми шизофренії
   - **Мезокортикальний** — вищі функції → дефіцит → негативні симптоми шизофренії
   - **Нігростріарний** — рух → дефіцит → хвороба Паркінсона
4. **Дофамін у системі винагороди** [C-002-076..078]: експеримент Олдза-Мілнера (щур + електрод) → модель наркотичної залежності (амфетамін, МДМА, кокаїн)
5. **Серотонін** [C-002-084..088]: **95% у ШКТ**, у мозку переважно гальмівний; контроль негативних емоцій, біль, увага; дефіцит → депресія, тривога, ОКР
6. **Антидепресанти SSRI** [C-002-089..091]: блокують зворотне захоплення → концентрація серотоніну ↑ у синапсі → upregulation рецепторів (4-6 тижнів)
7. **Норадреналін** [C-002-094..102]: симпатична НС («бий або біжи»), блакитне ядро (locus coeruleus), неспання, азарт, знеболення; дефіцит → депресія з апатією/втомою → SNRI
8. **ГАМК — гальмо** [C-002-104, C-002-108]: гіперполяризація мембрани до **−90 мВ**, потрібен сильніший стимул; транквілізатори (бензодіазепіни) посилюють ГАМК
9. **Глутамат — газ** [C-002-105, C-002-109]: деполяризація мембрани, NMDA-рецептори; антагоністи (мемантин, кетамін)
10. **Дисбаланс ГАМК-глутамат** [C-002-110]: причина епілепсії + порушень настрою
11. **Нейрон** [C-002-039]: 3 відділи — тіло (органели), аксон (передає, довгий, до 1 м), дендрити (приймають, короткі)
12. **Синапс** [C-002-062..065]: пресинаптична мембрана + щілина + постсинаптична мембрана; передача через нейромедіатор (хімічна), потенціал — електрична
13. **«Ключ-замок»** [C-002-070]: нейромедіатор пасує до свого рецептора, але один ключ → багато підтипів замків (норадреналін: α1, α2, β1, β2)
14. **3 шляхи долі нейромедіатора** [C-002-071]: (1) повторне зв'язування; (2) ферментне руйнування; (3) зворотне захоплення
15. **Триєдиний мозок** [C-002-025..033]: рептильний (життєзабезпечення) + лімбічний (емоції) + неокортекс (розуміння, мораль)
16. **Контур тривоги** [C-002-009..014]: таламус → кора + амигдала + BNST + гіпоталамус + гіпокамп
17. **«Дім на сигналізації»** [C-002-019] — модель тривожного розладу через хибну гіперактивацію амигдали
18. **Шизофренія = дофамінова гіпотеза**: ↑ мезолімбічний (продуктивні) + ↓ мезокортикальний (негативні); лікування — антипсихотики (D2-блокатори)
19. **Депресія = серотонін + норадреналін дефіцит**: SSRI (флуоксетин, сертралін, есциталопрам) + SNRI (венлафаксин, дулоксетин)
20. **«Фізика → хімія»** [C-002-122]: всередині нейрона — електрика, між нейронами — хімія; вся психіатрична фармакологія діє на хімічну фазу

## §9 — Mnemonic devices for the exam

### 9.1. «−70 / +20 / −90» — три ключові напруги

- **−70 мВ** — потенціал спокою (норма, «сплячий» нейрон)
- **+20 мВ** — поріг активації потенціалу дії (стимул має досягти, щоб запустився каскад)
- **−90 мВ** — гіперполяризація під ГАМК (нейрон стає ще «холоднішим», важче активувати)

### 9.2. «4 нейромедіатори + 1 пара» — структура L2

**ДСНГГ** — Дофамін / Серотонін / Норадреналін / Глутамат + ГАМК

| Літера | Медіатор     | 1 факт для запам'ятовування                |
| ------ | ------------ | ------------------------------------------ |
| **Д**  | Дофамін      | 3 шляхи: нігростр. / мезокорт. / мезолімб. |
| **С**  | Серотонін    | 95% у ШКТ                                  |
| **Н**  | Норадреналін | «бий чи біжи», блакитне ядро               |
| **Г**  | ГАМК         | гальмо, −90 мВ                             |
| **Г**  | Глутамат     | газ, NMDA                                  |

### 9.3. «3 шляхи дофаміну»: НМП → СПР

- **Н**ігростріарний → рух → **Паркінсон**
- **М**езокортикальний → когнітивні → **н**егативна шизофренія
- **М**езолімбічний → винагорода → **п**родуктивна шизофренія + наркотики

### 9.4. «Хімічна тріада депресії»

**С + Н = SSRI + SNRI**: дефіцит **С**еротоніну → SSRI (флуоксетин, сертралін); дефіцит **Н**орадреналіну → SNRI (венлафаксин, дулоксетин).

### 9.5. «Газ і гальмо»

**Г**люТАМАТ = **газ** (збуджує) / **ГА**МК = **гальмо** (гальмує). Дисбаланс = епілепсія.

### 9.6. «5 структур контуру тривоги»

**Т-К-А-Б-Г-Г** — Таламус → Кора → Амигдала ↔ префронтал → BNST → Гіпоталамус → Гіпокамп.

### 9.7. «Метафори у послідовності»

1. **Мозок** = комп'ютер (хард + софт)
2. **Нейрон** = провід
3. **Мембрана** = шарик з водою
4. **Канал** = ворота (пасивні) / ліфт (активні) / двері на магніті (потенціал-залежні)
5. **Потенціал дії** = бенгальський вогник
6. **Везикула** = тележка
7. **Кальцій** = колеса
8. **Рецептор** = порт / замок
9. **Серотонін** = листоноша
10. **ГАМК+глутамат** = газ і гальмо
11. **Лімбічна система** = інструмент душі
12. **Тривожний розлад** = дім на сигналізації
