## Quick summary

Лекція ~37 хв від **Світлани Володимирівни Ісаєнко** (та сама лекторка, що читає L1 і L3 у курсі MCMM «Психіатрія»). **Фундаментальний нейробіологічний урок** модуля 10 — без нього шизофренія (L7), депресія (L9), тривога (L10), фармакотерапія (L14) залишаються «магічними категоріями». **Ключова теза**: психіка = функція нейробіологічного «харду», а синапс = **точка втручання** у психіатричну патологію. Сучасна психофармакологія діє виключно на хімічну фазу передачі (між нейронами, у синапсі), а не на електричну (всередині нейрона).

## Key claims (top 15 — пріоритет для тесту)

1. **Потенціал спокою −70 мВ** [C-002-051] — стандартний заряд клітинної мембрани в стані спокою, підтримується натрій-калієвим насосом
2. **Потенціал дії запускається при ≥ +20 мВ** [C-002-055] — стимул нижче ігнорується (+10 мВ → −60 мВ, не досягає 0)
3. **3 дофамінові шляхи** [C-002-075]: мезолімбічний (винагорода → продуктивна шизофренія при ↑); мезокортикальний (когніції → негативна шизофренія при ↓); нігростріарний (рух → Паркінсон при ↓)
4. **Шизофренія = дофамінова гіпотеза** [C-002-080, C-002-081]: ↑ мезолімбічний дофамін → псевдогалюцинації, сенестопатії, маячні ідеї; ↓ мезокортикальний → апатія, абулія, соц. дезадаптація. Лікування — антипсихотики (D2-блокатори) [C-002-082]
5. **Серотонін: 95% у ШКТ** [C-002-085], у мозку — переважно гальмівний, контроль негативних емоцій + увага + біль [C-002-087]
6. **Дефіцит серотоніну** [C-002-088] → тривожні, панічні, дистимічні, депресивні стани. SSRI блокують зворотне захоплення → концентрація ↑ у синапсі + upregulation рецепторів за 4-6 тижнів [C-002-089..091]
7. **Норадреналін у симпатичній НС** [C-002-094..096] — «бий або біжи»: розширені зіниці, тахікардія, ↑ тиск, бронходилатація, вазоконстрикція. У мозку — блакитне ядро (locus coeruleus) [C-002-099]
8. **ГАМК — головний гальмівний медіатор** [C-002-104, C-002-108]: гіперполяризація мембрани до −90 мВ, для запуску потенціалу дії потрібен сильніший сигнал. Транквілізатори (бензодіазепіни) посилюють ГАМК
9. **Глутамат — головний збуджувальний медіатор** [C-002-105, C-002-109]: деполяризація мембрани, NMDA-рецептори. Дисбаланс ГАМК-глутамат [C-002-110] → епілепсія + порушення настрою
10. **Контур тривоги** [C-002-009..014]: таламус (приймає інфу) → кора (розуміє) ↔ амигдала (емоційний центр) ↔ префронтал (гальмо) → BNST (хронізує) → гіпоталамус (активує соматику) → гіпокамп (пам'ять)
11. **Триєдиний мозок** [C-002-025..033]: рептильний (життєзабезпечення) → лімбічний (емоції, кузня душі) → неокортекс (розуміння, мораль)
12. **Нейрон — 3 відділи** [C-002-039]: тіло (органели) + аксон (довгий, до 1 м, передає) + дендрити (короткі, приймають). Сіра речовина = тіла; біла = аксони
13. **Синапс — щілина** [C-002-062]: пресинаптична + щілина + постсинаптична мембрана. Каскад: потенціал дії → Ca²⁺ канали → везикули з медіатором → екзоцитоз → рецептор → новий потенціал дії
14. **«Ключ-замок» неточно** [C-002-072]: один медіатор → багато підтипів рецепторів (норадреналін: α1, α2, β1, β2; серотонін: 14 типів). Цим користуються при дизайні препаратів
15. **3 шляхи долі нейромедіатора** [C-002-071]: (1) повторне зв'язування; (2) фермент-руйнівник; (3) зворотне захоплення (точка втручання SSRI/SNRI)

## Coaching application (DETECTIVE FM)

7 actionable правил для Юрія-Детектива (детально у `synthesis.md` §7):

1. **Чек-ліст нейробіологічного компонента** — сон / енергія / концентрація / соматика. ≥2 з 4 порушено = делегувати психіатру до коучингу.
2. **Тривожний розлад не лікується розмовами** [C-002-021] — авторська позиція лектора. Панічні атаки + хронічна тривога + уникнення → психіатр + SSRI, коучинг паралельно.
3. **Шизофренія — невідкладна психіатрія**: ≥1 продуктивний (псевдогалюцинації / сенестопатії / маячення) АБО ≥2 негативних (апатія / абулія / соц. дезадаптація) → антипсихотик, не «опрацьовуй».
4. **Депресія за феноменологією → SSRI/SNRI зона** [C-002-088, C-002-102]: тривалість >2 тижні + соматика (сон, апетит, лібідо, енергія) + думки про смерть. Антидепресанти діють 4-6 тижнів (upregulation).
5. **Залежності — нейробіологія дофаміну, не «слабка воля»** [C-002-078, C-002-079]: дофамінова петля працює фізіологічно. Делегуй наркологу. Сам працюй з середовищем + смислом.
6. **«Бий або біжи» — соматичні маркери стресу** [C-002-014, C-002-094..096]: зіниці / серцебиття / тиск / дихання / шкіра / піт. 3+ симптомів у сесії = заземлення + дихання + якщо повторюється — психіатр.
7. **Демістифікуй психіатрію клієнту**: «SSRI не „робить щасливим“ — він дозволяє серотоніну довше працювати у синапсі. А вже ця нормалізація дає простір думати тверезо. У цьому просторі я працюю з тобою як коуч.»
