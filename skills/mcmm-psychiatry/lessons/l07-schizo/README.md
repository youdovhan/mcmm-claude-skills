## Quick summary

Лекція ~26:41 від **Світлани Володимирівни Ісаєнко** — **перша клінічна нозологічна одиниця** курсу після фундаменту (L1-L6). Якщо L2 заклав нейробіологію, L3 — емоції+волю, L4 — пам'ять+увагу, L5 — мислення, L6 — сприйняття, то L7 **синтезує все** через найскладнішу психічну хворобу.

**Ключова теза**: шизофренія — це **розпад єдності психіки на 4 модусах** (мислення / емоції / воля / поведінка) через **дисбаланс дофамінових шляхів** (мезолімбічний↑ → продуктивні / мезокортикальний↓ → негативні). 4 форми = 4 різні ландшафти симптомів. Прогноз — rule of thirds: 1/3 одужує / 1/3 хроніка / 1/3 дефект. Хвороба важка, але **не приговор** при compliance + реабілітації + family support.

**Дидактичний стиль L7**: гібрид клінічного оповідання + наративу кейсами + методологічного маніфесту:

- Літературний епіграф (Ремарк «Чорний обеліск»)
- Авторська метафора розбитого пазлу для пояснення схизису
- Класичні кейси (черв'яки в селезінці, шапочка з фольги, віддача в космос)
- **Холлмарк-кейс малпрактики** (3 хв) — психолог відмінив антипсихотик → психоз
- Фінал: Джон Неш + «Ігри розуму» як антистигма + neurodiversity

1. **Дофамінова гіпотеза** [C-007m10-019, C-007m10-117]: **мезолімб ↑ → продуктивні** / **мезокорт ↓ → негативні**. Cross-ref L2 4 шляхи
2. **4 форми шизофренії** [C-007m10-020]: **П**араноїдна / **Г**ебефренічна / **П**роста / **К**ататонічна (ПГПК)
3. **2 групи симптомів** [C-007m10-016..018]: **продуктивні** (плюс — додають: галюцинації, марення) vs **негативні** (мінус — вбирають: апатія, абулія, емоційне сплощення)
4. **Марення впливу** (Beeinflussungswahn) [C-007m10-032, C-007m10-124]: «промені, лазер, гіпноз, інопланетні технології впливають на думки/тіло» = **Schneider's 1st rank symptom**. Predicted Quiz Q1
5. **Псевдогалюцинації Кандинського** [C-007m10-028]: голоси «всередині голови», коментуючі/імперативні. Cross-ref L6
6. **Синдром Кандинського-Клерамбо** [C-007m10-033]: 3 автоматизми — ідеаторний (вкладання думок) + сенсорний (псевдогалюцинації) + моторний (вплив на рухи)
7. **Anosognosia** [C-007m10-035]: відсутність критики до хвороби. **Один з найбільших прогностичних критеріїв**. «Сам пей свої таблетки»
8. **Bleuler 4А (імпліцитно)** [C-007m10-050]: **А**соціації / **А**фект / **А**мбівалентність / **А**утизм
9. **Параноїдна форма** [C-007m10-021..023]: найпоширеніша, дебют **20-35 років**, провідний синдром = марення + псевдогалюцинації, **найкращий прогноз** з 4-х
10. **Гебефренічна форма** [C-007m10-063..068]: одна з найзлоякісніших, дебют **13-15 років**, дитяча безглуздя + неологізми + неадекватний сміх. **Інвалідизація до початку трудової діяльності**
11. **Проста форма** [C-007m10-057..062]: майже виключно **негативна** симптоматика, підлітково-юнацький дебют, прихована, часто плутають з підлітковим бунтом
12. **Кататонічна форма** [C-007m10-069..082]: **рухові розлади** + симптом повітряної подушки + капюшона + внутрішньоутробна поза + **каталепсія (восковая гнучкість)** + мутизм + ехо-симптоми. Cross-ref L3
13. **Прогностичний парадокс** [C-007m10-056]: яскраві продуктивні → кращий прогноз (respondent на антипсихотики); проста + гебефренічна (без продуктивних) → гірший
14. **Імперативні голоси → ст. 14** [C-007m10-038]: примусова госпіталізація, ЗУ «Про психіатричну допомогу»
15. **Expressed Emotion (EE)** [C-007m10-100]: high EE родини (критика + гіперопіка) → relapse risk × 4-5

## Coaching application (DETECTIVE FM)

8 actionable правил для Юрія-Детектива (детально у `synthesis.md` §7):

1. **«Голос у голові» — distinguishing question Кандинського** [C-007m10-028, C-007m10-120]: уточни — це твоя думка / ззовні (справжня гал-я) / всередині не твоя (псевдогалюцинація Кандинського → психіатр) / наказує небезпечне (ст. 14)
2. **Марення впливу — НЕ обговорювати з критикою** [C-007m10-032, C-007m10-035]: при anosognosia argument-resistant. Joining без agreement → м'яко перевести на функціонал → делегація через близьких
3. **Молодий клієнт 13-15 років + дезорг + school dropout → red flag** [C-007m10-068, C-007m10-059]: гебефренія / проста форма — інвалідизація до початку трудової діяльності. **Mandatory referral до підліткового психіатра**
4. **Кататонічна риса — невідкладно** [C-007m10-070..082]: повітряна подушка / капюшон / воскова гнучкість / мутизм → швидка психіатрична допомога. Differential з NMS / encephalitis / B12
5. **Поступове зниження мотивації — диференціал** [C-007m10-045, C-007m10-051, C-007m10-057]: burnout (1 міс) vs депресія (1-6 міс + соматика) vs **проста шизо** (6+ міс + ангедонія до улюбленого + підлітковий дебют). При 4-6 критеріях → mandatory referral
6. **«Психолог замість психіатра» — malpractice prevention** [C-007m10-039..041]: НІКОЛИ не пропонуй припинити медикаменти. НІКОЛИ не диагноз самостійно. При підозрі на психотичні симптоми — mandatory referral
7. **Family Expressed Emotion — як впливає на relapse** [C-007m10-100]: high EE родини → relapse × 4-5. Психоосвіта + low-EE training + multi-family group
8. **John Nash як антистигма + bridge для empathy** [C-007m10-103, C-007m10-104]: параноїдна шизо + Нобель 1994 + «A Beautiful Mind» 2001. Хвороба ≠ присуд. Compliance + family + maintenance — twoа базові опори. Reframe з «зламана психіка» на «інше мислення» [C-007m10-102]
