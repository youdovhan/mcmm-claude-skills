## Quiz Q1 — Тривожний (уникаючий) розлад особистості F60.6

> **PREDICTION ONLY** — це передбачення на основі контенту лекції, **БЕЗ витягування з MCMM** (Chrome MCP до quiz page не виконувалося в межах цієї задачі).

### Питання

**До лікаря звернувся 28-річний чоловік зі скаргами на боязкість, постійне відчуття власної неповноцінності, страх осміяння у соціальних ситуаціях. Він уникає роботи, що передбачає тісні міжособистісні контакти, бо боїться критики. У стосунках намагається сподобатися, але постійно відчуває внутрішнє напруження і тривогу. У дитинстві був тихою, сором'язливою дитиною. Який найбільш імовірний діагноз?**

### Варіанти відповіді (predicted)

A. F60.0 — Параноїдний розлад особистості
B. F60.1 — Шизоїдний розлад особистості
C. F60.2 — Дисоціальний розлад особистості
D. F60.5 — Ананкастний розлад особистості
E. **F60.6 — Тривожний (уникаючий) розлад особистості** ✅
F. F60.7 — Залежний розлад особистості

### Правильна відповідь

**E. F60.6 — Тривожний (уникаючий) розлад особистості (AvPD, сенситивна психопатія)**

### Пояснення

**Ключові ознаки в умові, що однозначно вказують на F60.6**:

1. **«Боязкість»** — core feature AvPD (timidity is a hallmark).
2. **«Постійне відчуття власної неповноцінності»** — це **inferiority complex** (Adler), classic marker AvPD per slide 7 та C-013-034.
3. **«Страх осміяння у соціальних ситуаціях»** — fear of humiliation / criticism — direct AvPD criterion DSM-5 (Criterion 2 — preoccupation with being criticized or rejected in social situations).
4. **«Уникає роботи, що передбачає тісні міжособистісні контакти»** — DSM-5 AvPD Criterion 1 (avoids occupational activities involving significant interpersonal contact).
5. **«Намагається сподобатися, але... напруження і тривога»** — approach-avoidance pattern (C-013-035) — typical for AvPD.
6. **«У дитинстві був тихою, сором'язливою дитиною»** — stable from childhood / adolescence per критерій Кербікова стабільності (C-013-011).

**Чому НЕ інші варіанти**:

| Варіант          | Чому неправильно                                                                                                                                                                                                                                          |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **A** F60.0 PPD  | Нема підозр / недовіри / сверхцінних ідей; домінує СТРАХ і самозневага, не АГРЕСИВНА підозра                                                                                                                                                              |
| **B** F60.1 SPD  | Шизоїд **не прагне** соціальних контактів (він байдужий); AvPD прагне, але боїться (approach-avoidance) — це key differential                                                                                                                             |
| **C** F60.2 ASPD | Нема порушення норм, безвідповідальності, lack of guilt; пацієнт прагне approval, а не violation                                                                                                                                                          |
| **D** F60.5 OCPD | Нема перфекціонізму, контролю, ритуалів, magical thinking; домінує emotional vulnerability, не cognitive rigidity                                                                                                                                         |
| **F** F60.7 DPD  | **Закидати найбільш**: DPD має боязкість + низьку самооцінку, але **core fear DPD = покинутість + потреба у догляді**; у AvPD **core fear = осміяння / критика**; пацієнт у завданні **уникає** контактів (AvPD), а DPD пацієнт **активно шукає** опікуна |

**Critical differential AvPD F60.6 vs DPD F60.7**:

| Ознака         | AvPD F60.6                          | DPD F60.7                       |
| -------------- | ----------------------------------- | ------------------------------- |
| **Core fear**  | Осміяння, критика, відкидання       | Покинутість, потреба у догляді  |
| **Engagement** | Passive avoidance, withdraw         | Active clinging, dependence     |
| **Self-image** | Inferior (комплекс неповноцінності) | Helpless (безпорадний)          |
| **Relations**  | Уникають через страх                | Шукають / тримають дисфункційні |
| **Behavior**   | Withdrawn, supplicating             | Submissive, dependent           |

У завданні пацієнт **уникає** (не активно шукає опікуна), має **комплекс неповноцінності** (не self-image «безпорадний»), боїться **осміяння** (не покинутості) → **AvPD F60.6**, не DPD F60.7.

**Cross-refs**: C-013-034 (AvPD core), C-013-035 (approach-avoidance), C-013-036 (cognitive core), C-013-037 (behavioral pattern), C-013-064 (Quiz Q1 prediction).

### Q2 — Критерії Кербікова

**До психіатра звернулася пацієнтка 35 років зі скаргами на хронічну невпевненість, страх соціальних контактів. Симптоми відмічаються з 14 років, проявляються у всіх сферах життя (вдома, на роботі, з друзями), і не пов'язані з конкретною травмою чи переїздом. Які 3 критерії розладу особистості за Кербіковим?**

A. Гострота, інтенсивність, ремісійність
B. **Тотальність, стабільність, дезадаптація як наслідок рис, не середовища** ✅
C. Афективність, когнітивність, поведінковість
D. Спадковість, виховання, травма

**Пояснення**: Це канон Кербікова (C-013-009 → C-013-013):

1. **Тотальність** — риси проявляються в усіх сферах життя [C-013-010].
2. **Стабільність** — зберігаються протягом всього життя, дебют найчастіше у підлітковому віці [C-013-011].
3. **Соціальна дезадаптація як наслідок рис, не зовнішнього середовища** [C-013-013].

У завданні всі 3 критерії виконані: тотально (всі сфери), стабільно (з 14 років), не від середовища (нема тригера).

### Q3 — Акцентуація vs психопатія

**У чому ключова відмінність акцентуації характеру від психопатії (розладу особистості)?**

A. Акцентуація — це психотичний стан, психопатія — невротичний
B. Акцентуація — це симптом, психопатія — синдром
C. **Акцентуація — крайня межа норми (ситуативна, може регресувати з віком), психопатія — патологія (тотальна, стабільна, з дезадаптацією)** ✅
D. Акцентуація лікується психотерапією, психопатія — фарма
E. Акцентуація у жінок, психопатія у чоловіків

**Пояснення**: Це fundamental distinction уроку 13 (C-013-001, C-013-002, C-013-063):

- **Акцентуація** (Леонгард 1968, Лічко 1977) — виділення однієї характерологічної риси, у верхніх межах норми, ситуативна, може регресувати з віком.
- **Психопатія** — патологія, відповідає 3 критеріям Кербікова (тотальність + стабільність + дезадаптація).

Це **qualitative leap**, не просто degree difference.

### Q5 — Класичний афоризм Ганнушкіна

**Який афоризм Ганнушкіна найкраще описує двосторонній клінічний імпакт психопатії?**

A. «Душа — це поле, на якому борються Бог і Сатана»
B. «Невроз — це конфлікт між Я і Воно»
C. **«Психопат — це людина, яка не може жити сама і не дає жити іншим в силу особливостей свого характеру»** ✅
D. «Психопатія — це симуляція хвороби»
E. «Психопат живе у власному світі, де він і єдиний герой»

**Пояснення**: Це класичний афоризм П.Б. Ганнушкіна (C-013-008), що підкреслює:

1. **Інтрапсихічний дискомфорт** — «не може жити сам» (страждання від власного характеру).
2. **Interpersonal damage** — «не дає жити іншим» (нестерпність для оточуючих).

Це формула про **двосторонню дезадаптацію** psychopath. У завданні є інформація з C-013-061 — «Такі особистості не можуть самі пристосуватися до вимог суспільства і при цьому істотно заважають жити іншим».

B. **Синдромологічний (за переважанням клінічних проявів з провідним розладом емоційно-вольової сфери)** ✅

### Q7 — F60.4 Істеричний розлад особистості

**Які 4 ключові ознаки істеричного розладу особистості (HPD, F60.4)?**

A. Замкнутість, холодність, ригідність, підозрілість
B. Імпульсивність, агресивність, безвідповідальність, безкарність
C. Перфекціонізм, контроль, сумніви, ритуали
D. **Демонстративність, театральність, манерність, неумісна емоційність** ✅
E. Безпорадність, виснаженість, низька самооцінка, боязкість

**Пояснення**: Це core 4 риси HPD (C-013-023):

1. **Демонстративність** (бажання бути показним).
2. **Театральність** (як на сцені — рухи, голос перебільшені).
3. **Манерність** (вигадливі, неприродні манери).
4. **Неумісна емоційність** (буряні емоції в ситуаціях, що цього не вимагають).

Слід відрізняти від замкнутості (SPD, варіант A), імпульсивності (ASPD, B), перфекціонізму (OCPD, C), безпорадності (DPD, E).

**Стрижнева риса** HPD (C-013-025) — постійне бажання уваги.

**Епідеміологія** (C-013-076): частіше у жінок (≈ 2-4:1).

### Q8 — Ананкастний розлад особистості — magical thinking

**Який феномен характерний для ананкастного (обсесивно-компульсивного) розладу особистості F60.5 поряд з тривожною недовірливістю і повторними перевіряннями?**

A. Сверхцінні ідеї переслідування
B. Флешбеки травматичної події
C. **Віра в добрі і погані прикмети, заклинання, ритуали (магічне мислення)** ✅
D. Демонстративні суїцидальні жести
E. Дисоціативні fugue стани

**Пояснення**: Це специфічна риса OCPD (C-013-033): «Рука об руку з тривожністю та побоюваннями неприємностей йде віра в добрі та погані прикмети, заклинання, ритуали». Магічне мислення коморбідно з cognitive loop сумніву (C-013-078) і доповнює клінічну картину.

Це structurally близько до F42 OCD compulsions, але у OCPD — ego-syntonic (вбудовано в character).

### Q9 — Параноїдний розлад: core психопатологія

**Що є основною психопатологічною рисою (core feature) параноїдальних психопатів?**

A. Дисоціативна амнезія
B. Афективна лабільність
C. **Схильність до утворення сверхцінних ідей, підкріплених високою емоційністю** ✅
D. Магічне мислення з ритуалами
E. Hypervigilance до травматичних тригерів

**Пояснення**: Core PPD (C-013-046, C-013-065): «Основна риса паранояльних психопатів — схильність до утворення надцінних ідей. Перебуваючи під владою цієї ідеї, підкріпленої високою емоційністю, вони підпорядковують реалізації цієї ідеї всі свої думки, прагнення, спонукання, бажання, вчинки».

**Сверхцінні ідеї** (overvalued ideas, Wernicke 1900):

- Між нормальною ідеєю і маренням;
- Когнітивно — non-bizarre, формально логічна;
- Емоційно — high charge;
- Функціонально — підпорядковує всі думки і вчинки.

**Differential vs марення** (delusion):

- При параноях F22 та параноїдальній шизофренії F20.0 — повноцінне марення.
- У PPD — лише сверхцінні ідеї.

Класичні приклади: винахідник-переслідувач, сутяжник, ревнивець.

### Q10 — Етіологія психопатії за лектором

**Які два полюси виховання, за лектором, припускає психопатія?**

A. Перфекціонізм vs lassez-faire
B. **Максимальна вседозволеність vs тотальне обмеження** ✅
C. Авторитарність vs демократичність
D. Раннє відлучення vs пізнє відлучення від грудей
E. Спартанське vs аристократичне

**Пояснення**: C-013-047, цитата лектора: «Психопатия предполагает, что личность воспитывалась в определенных условиях либо максимальной вседозволенности, либо тотального ограничения».

Це класична двополюсна модель (А. Адлер; пізніше Diana Baumrind 1971 з 4 styles):

- **Вседозволеність** (permissive) → формує імпульсивні, нарцистичні, антисоціальні риси (ASPD, NPD, HPD).
- **Тотальне обмеження** (authoritarian) → формує параноїдні, ананкастні, депресивні риси (PPD, OCPD, AvPD, DPD).

Це environmental factor у bio-psycho-social моделі PD (C-013-082).

### Q11 — Терапія психопатії

**Чому психопатія погано піддається терапії?**

A. Тому що це генетична хвороба, нездатна змінитися
B. Тому що психотерапія ще не розроблена для PD
C. **Тому що риси ego-syntonic, пацієнт «й так добре в житті», нема мотивації на зміни** ✅
D. Тому що фарма не доступна на ринку
E. Тому що страховка не покриває

**Пояснення**: Це фундаментальний principle PD (C-013-048):

1. **Ригідність структури** — нема пластичності.
2. **Ego-syntonic природа** — риси сприймаються «своїми», нема страждання від них.
3. Пацієнти **«й так добре в житті»** — низька мотивація на зміни.

Це contrast до неврозів (F40-F48, F42), де симптоми ego-dystonic — пацієнт хоче змін, бо страждає.

**Лікування** (C-013-049, C-013-077):

- **Психотерапія = primary modality** (DBT для borderline, CBT для AvPD/OCPD/DPD, schema therapy, MBT, TFP);
- **Фарма — adjunct, симптоматична** (нормотиміки, коректори поведінки).

### Q12 — Епідеміологія: збудлива + істерична = 3/4

**За лектором, які два типи психопатії разом складають близько 75% усіх психопатологічних розладів?**

A. Шизоїдний + параноїдний
B. **Збудлива (експлозивна / епілептоїдна) + істерична** ✅
C. Ананкастний + тривожний
D. Антисоціальний + borderline
E. Залежний + сенситивний

**Пояснення**: Епідеміологічна теза лектора (C-013-052), slide 4: «Відомо, що найпоширенішими формами є збудлива та істерична психопатії, які становлять 3/4 всіх психопатичних розладів».

**Збудлива** = expansion експлозивної / епілептоїдної (F60.3 / F60.30). Це дисбаланс показує, чому ці два типи отримують найбільше клінічної уваги в радянсько-пострадянському просторі. Інші типи разом — ~25%.

Сучасна US-епідеміологія дає інший розподіл (OCPD — найпоширеніший ≈ 4-8%; HPD ≈ 1-3%; BPD ≈ 1.6%; ASPD ≈ 0.6-3.6%; AvPD ≈ 2.4%), але це різниця у diagnostic patterns.

### Q13 — DSM-5 кластери

## Quiz-prep чек-листи

### Чек-ліст 1 — Diagnostic gate для PD (5 кроків)

1. **Чи тотально?** — проявляються везде (вдома, на роботі, в стресі, у спокої)?
2. **Чи стабільно?** — починалося ще в підлітковому віці (іноді з дитинства, рідко з дорослого)?
3. **Чи самі по собі дезадаптують?** — не через зовнішні фактори (війна, міграція, бідність, культурний бар'єр)?
4. **Чи ego-syntonic?** — пацієнт вважає це нормою, не страждає від рис?
5. **Чи ригідні?** — нема пластичності, не може змінити навіть на 1 експеримент?

**3+ з 5 «так»** → PD ймовірний → диференц.діагностика типу F60.0–F60.7 + ескалація до психотерапевта / психіатра.

### Чек-ліст 3 — Differential дiff diagnosis (5 critical pairs)

1. **AvPD F60.6 vs соц.фобія F40.1**: AvPD = тотальне + ego-syntonic + life-long; F40.1 = обмежене + ego-dystonic + може дебютувати у дорослому.
2. **OCPD F60.5 vs ОКР F42**: OCPD = ego-syntonic perfectionism; F42 = ego-dystonic obsessions + явні compulsions.
3. **BPD F60.31 vs F31 БАР**: BPD = години-дні + interpersonal triggers + stable identity disturbance; БАР = тижні-місяці + endogenous + episodic.
4. **PPD F60.0 vs параноя F22 / шизофренія F20**: PPD = сверхцінні ідеї (логічні, формально реальні); F22 = повноцінне марення (bizarre, illogical).
5. **DPD F60.7 vs AvPD F60.6**: DPD = active clinging + fear of abandonment; AvPD = passive avoidance + fear of humiliation.

### Чек-ліст 5 — Терапія PD (4 принципи)

1. **Психотерапія — primary modality**:
   - **DBT** для borderline F60.31 (gold standard, Marsha Linehan);
   - **CBT** для AvPD F60.6, OCPD F60.5, DPD F60.7;
   - **Schema therapy** (Young) для BPD, NPD, AvPD;
   - **Психоаналіз / psychodynamic** для HPD F60.4, NPD;
   - **MBT** (Bateman / Fonagy) для BPD;
   - **TFP** (Kernberg) для BPD.

2. **Фарма — adjunct, симптоматична**:
   - **Нормотиміки** (літій, вальпроат, ламотриджин) для emotionally unstable / borderline / impulsive;
   - **Антипсихотики у малих дозах** (рисперидон, оланзапін, кветіапін) для BPD / paranoid;
   - **SSRI** для anger / impulsivity / depressive comorbidity.

3. **Прогноз — погано**:
   - Ego-syntonic природа → погана мотивація;
   - Ригідність структури → нема пластичності;
   - «Й так добре в житті» — низька прагнення змін.

4. **Контраст до неврозів / афективних**:
   - F20 шизофренія — антипсихотики first-line;
   - F31 БАР — нормотиміки first-line;
   - F32 депресія — SSRI/SNRI first-line;
   - **F60 PD — психотерапія first-line, фарма adjunct**.
