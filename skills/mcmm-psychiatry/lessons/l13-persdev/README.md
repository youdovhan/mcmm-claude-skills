## Quick summary

Лекція ~11 хв 08 сек від **Олени Левченко**. **Нозологічна одиниця №7** модуля 10 — рубрика F60 МКБ-10 (психопатії, розлади особистості). Це окрема рубрика, що стоїть «осторонь» від «справжніх» хвороб (F20 шизофренія, F30-F33 афективні, F40-F48 невротичні), бо це **аномалії характеру, не процесу**: ригідні стійкі структури, які зберігаються все життя без ремісій-загострень.

**Ключова теза**: Розлади особистості (F60) — це **стійкі аномалії характеру**, що проявляються **дисгармонією емоційно-вольової сфери і переважно афективним мисленням**, ригідно перешкоджають соціальній адаптації, відповідаючи **трикритерію Кербікова** (тотальність + стабільність + дезадаптація як наслідок рис, не середовища). Поділяються у МКБ-10 на **8 типів F60.0–F60.7** з еквівалентністю до **DSM-5 кластерів A/B/C**. Слід жорстко відрізняти від **акцентуацій характеру** (Леонгард-Лічко) як крайніх варіантів норми. Терапія — **переважно психотерапія** (DBT, CBT, schema therapy), бо психопатія ego-syntonic і пацієнти «й так добре в житті».

**Двочастинна композиція**: 3 хв вступна частина (акцентуація + визначення + критерії Кербікова) + 6 хв класифікація F60.0–F60.7 + 1 хв терапія + 1 хв lecturer self-disclosure («Монстри, з якими ми живемо»).

## Key claims (top 15 — пріоритет для тесту)

1. **Психопатія = стара назва розладу особистості (F60)** [C-013-005] — terminology equivalence.
2. **Робоче визначення PD** [C-013-014, C-013-058]: стійкі аномалії характеру з (1) дисгармонією емоційної та ефекторно-вольової сфер, (2) переважно афективним мисленням, (3) перешкодами соціальній адаптації.
3. **3 критерії Кербікова** [C-013-009 → C-013-013] — мнемоніка **«ТСД»**: **Т**отальність + **С**табільність + **Д**езадаптація як наслідок рис, не середовища.
4. **Акцентуація = верхні межі норми** [C-013-001, C-013-063] — концепт Леонгарда (1968) + Лічка (1977); ситуативна, може регресувати з віком.
5. **Бехтерєв 1886** [C-013-006] — введення терміна «психопатія».
6. **Ганнушкін definition + афоризм** [C-013-007, C-013-008]: «психопатія = аномалія характеру, що накладає владний відбиток на весь душевний склад»; «Психопат — не може жити сам і не дає жити іншим».
7. **Синдромологічний принцип** [C-013-053] — основа МКБ-10 класифікації F60 (не етіологія).
8. **8 типів F60.0–F60.7** [C-013-017, C-013-075] — мнемоніка **«ПШДЕНІАЗ»**:
   - **F60.0** Параноїдний (PPD) — підозри + сверхцінні ідеї
   - **F60.1** Шизоїдний (SPD) — замкнутість + flat affect + закритий внутрішній світ
   - **F60.2** Дисоціальний (ASPD) — безвідповідальність + no guilt
   - **F60.3** Емоційно нестійкий (impulsive + borderline) — explosive + epileptoid
   - **F60.4** Істеричний (HPD) — демонстративність + увага
   - **F60.5** Ананкастний (OCPD) — недовірливість + сумніви + ригідність
   - **F60.6** Тривожний / уникаючий (AvPD) — вразливість + неповноцінність
   - **F60.7** Залежний (DPD) — безпорадність + виснаженість
9. **DSM-5 кластери A/B/C** [C-013-062] — мнемоніка:
   - **A** odd/eccentric: PPD, SPD, schizotypal
   - **B** dramatic/emotional: ASPD, BPD, HPD, NPD
   - **C** anxious/fearful: AvPD, DPD, OCPD
10. ⭐ **Quiz Q1 answer** [C-013-064]: 28-річний з боязкістю + комплексом неповноцінності = **F60.6 Тривожний (уникаючий)** РО (сенситивна психопатія, AvPD).
11. **Виховання як етіологія** [C-013-047]: два полюси — **вседозволеність** (permissive) або **тотальне обмеження** (authoritarian).
12. **Епідеміологія** [C-013-052]: **збудлива + істерична = 3/4** усіх психопатологічних розладів.
13. **Дебют типово підлітковий** [C-013-011, C-013-012, C-013-057] — рідше з дитинства, рідко у дорослому віці.
14. **Психотерапія = primary modality** [C-013-049, C-013-077]: DBT для borderline, CBT для AvPD/OCPD/DPD; фарма (нормотиміки + коректори поведінки) — adjunct.
15. **Ego-syntonic → погана мотивація на зміни** [C-013-048]: пацієнти «й так добре в житті».

## Coaching application (DETECTIVE FM)

8 actionable правил для Юрія-Детектива (детально у `synthesis.md` §7):

1. ⭐ **Скринінг ригідності в першу сесію** — 5 питань для diagnostic gate (тотальність + стабільність + дезадаптація). 3+ з 5 «так» → PD → не коучабельно → психотерапевт.
2. ⛔ **Не діагностувати — кодувати риси, не діагнози**. «Сильна потреба у видимості» замість «HPD»; «високий перфекціонізм» замість «OCPD».
3. **Червоні прапорці для відмови** — ASPD-like, активний self-harm borderline, активне переслідування PPD, повна ізоляція schizoid, severe OCPD без flexibility.
4. **Зелені прапорці для роботи з акцентуаціями** — гіпертимна, тривожна, сенситивна, циклоїдна, епілептоїдна (не F60.31), демонстративна, шизоїдна (не F60.1).
5. **Ригідність як non-coachability marker** — single best predictor немотивованості.
6. **Recognition типів у клієнтський presentation** — таблиця 8 фенотипів × стратегія коуча.
7. **Виховання як діагностичний ключ** — питати про стиль батьків: вседозволеність / тотальне обмеження / хаотичне / authoritative.
8. **Психотерапія — primary, фарма — adjunct, коучинг — після стабілізації**.
