### P1 — F43.1 діагностичні критерії (Quiz Q1 recon mirror)

**Q**: Які з критеріїв характеризують посттравматичний стресовий розлад (F43.1) за МКБ-10?

**Варіанти**:

1. Тривалість симптомів більше 1 місяця після травми
2. Симптоми вторгнення (інтрузивні спогади, кошмари, флешбеки)
3. Симптоми уникнення (думок, місць, людей)
4. Симптоми гіперактивації (інсомнія, hypervigilance, ↓ концентрації)
5. **Усе перелічене вище**

**Correct**: 5

**Пояснення**: За claims [C-011-008, C-011-025] / transcript [01:30, 03:30] / slides Slide 3-4: **ПТСР F43.1** діагностується при поєднанні **усіх 4 критеріїв**:

1. **Часовий критерій** [C-011-025]: симптоми спостерігаються **більше 1 місяця** після травми + порушують адаптацію в соц/проф/інших сферах
2. **Кластер вторгнення (intrusion)** [C-011-009..012]: нав'язливі повторювані спогади + кошмарні сновидіння + флешбеки (миттєве re-living з патологічною достовірністю) + тригер-реакції на зовнішні/внутрішні cues
3. **Кластер уникнення + negative alterations** [C-011-013..020]: уникнення думок/місць/людей + психогенна амнезія + ауто-/гетероагрессія + ангедонія + numbing + ↓ вищих емоцій + foreshortened future
4. **Кластер гіперактивації (hyperarousal)** [C-011-021..024]: інсомнія + дратівливість/спалахи гніву + ↓ концентрації + hypervigilance + exaggerated startle response

**Мнемоніка кластерів**: **«ВУГ»** = Вторгнення + Уникнення + Гіперактивація.

Окремо кожен критерій (опції 1-4) недостатній — потрібна **тріада кластерів + критерій 1 місяця + функціональне порушення**. Якщо тривалість < 1 міс → це **F43.0 гострий стресовий розлад**, не ПТСР. Це і є **Q1 за recon** курсу — типова MCQ-структура «Усе перелічене вище».

**Source**: C-011-006, C-011-008, C-011-025 / transcript [01:00, 01:30, 03:30]

### P2 — Перитравматична тріада

**Q**: Які три суб'єктивні переживання має людина у момент перебування у травматичній ситуації за визначенням ПТСР?

**Варіанти**:

1. Інтенсивний страх, ейфорія, дисоціація
2. Тривога, депресія, агресія
3. **Інтенсивний страх, переляк, почуття безпорадності**
4. Гнів, провина, сором
5. Шок, ступор, амнезія

**Correct**: 3

**Пояснення**: За claim [C-011-007] / transcript [01:30] / slides Slide 3: **перитравматична тріада** — це 3 суб'єктивні переживання у момент травми, які формують ключовий **A2 критерій** ПТСР (за раніми DSM версіями):

1. **Інтенсивний страх** (fear) — primary fear response, амігдало-driven
2. **Переляк** (horror) — більш складна реакція; виглядає як шок + жах
3. **Почуття безпорадності** (helplessness) — неможливість захиститися, врятувати близьких; corruption of agency

**Whisper-помилка**: у транскрипті [01:30] записано «спокій» — це **груба whisper-помилка** розпізнавання. Slide Slide 3 чітко уточнює: «інтенсивний страх, **переляк** та почуття безпорадності». Правильно — **переляк** (horror).

Опція 1 — ейфорія НЕ характерна для травми (це маніакальний симптом, cross-ref L8). Опція 2 — це наслідки, а не перитравматичні переживання. Опція 4 — combat guilt + moral injury — характерні для дисфоричного варіанту ПТСР (C-011-037), але не перитравматична тріада. Опція 5 — шок/ступор — це дисоціативна реакція, можлива але не canonical три-фактор перитравматики.

**Diagnostic value**: anamnestic — питати клієнта «що ти відчував у момент події?» — якщо ТАК на 2/3 — likelihood ПТСР ↑.

**Source**: C-011-007 / transcript [01:30] / slides Slide 3

### P3 — 4 симптоми вторгнення (intrusion)

**Q**: Що НЕ є симптомом вторгнення (intrusion) при ПТСР?

**Варіанти**:

1. Нав'язливі повторювані спогади травматичних подій
2. Жахливі сновидіння, що повторюються, про пережиту подію
3. Флешбеки — миттєве відродження з патологічною достовірністю
4. **Психогенна амнезія — неможливість пригадати ключові аспекти травми**
5. Інтенсивні переживання на зовнішні/внутрішні нагадування про травму

**Correct**: 4

**Пояснення**: За claims [C-011-009..012, C-011-015] / transcript [02:00-02:30, 02:30-03:00] / slides Slide 3-4: **кластер вторгнення (intrusion)** при ПТСР включає **4 симптоми**:

1. **Нав'язливі повторювані спогади** [C-011-009] — мимовільні образи, думки, відчуття, без волі пацієнта
2. **Кошмарні сновидіння** [C-011-010] — нічні кошмари з елементами травми
3. **Флешбеки** [C-011-011] — миттєве re-living травми з патологічною достовірністю; пацієнт ВТРАЧАЄ контакт з «тут і зараз»
4. **Тригер-реакції** [C-011-012] — інтенсивні переживання на зовнішні (звук, запах) або внутрішні (думка) cues, буквальні або символічні

**Психогенна амнезія** [C-011-015] — це симптом **кластеру уникнення + negative alterations** (DSM-5 кластер D), не кластеру вторгнення. Механізм: травматична пам'ять зберігається як **sensory fragments**, не семантично зінтегровані; при тригері спливають як сомато-сенсорні дисоціативні прояви. Це **dissociative phenomenon**, що належить до іншого кластеру.

**Differential** з фобіями (L10): при фобії — pre-existing страх специфічного об'єкта; при ПТСР інтрузії tied to traumatic event. **Differential** з ОКР (L10): при ОКР ego-dystonic obsessions (контамінація, симетрія), при ПТСР — re-living травми.

**Source**: C-011-009..012, C-011-015 / transcript [02:00-03:00] / slides Slide 3-4

### P4 — 6 клінічних варіантів ПТСР

**Q**: Який варіант ПТСР характеризується витісненням психотравмуючих переживань, що заміщуються збільшенням соматичних скарг переважно кардіологічного, церебрального або гастроентерологічного характеру?

**Варіанти**:

1. Тривожний варіант
2. Астенічний варіант
3. Дисфоричний варіант
4. Іпохондричний варіант
5. **Соматоформний варіант**

**Correct**: 5

**Пояснення**: За claims [C-011-042, C-011-043] / transcript [07:00-07:30] / slides Slide 7: **соматоформний варіант ПТСР** характеризується **психодинамічним механізмом витіснення** (Фройдове repression): психотравмуючі переживання витісняються → заміщуються **соматичними скаргами**.

**3 типові локуси соматизації**:

1. **Кардіологічні** — серце (біль у грудях, тахікардія, ↑ АТ, страх інфаркту)
2. **Церебральні** — голова (мігрень, запаморочення, неврологічні симптоми)
3. **Гастроентерологічні** — живіт (СРК, нудота, диспепсія)

**У структурі розладу** [C-011-043]: домінують симптоми **емоційної неврівноваженості** + **уникаюча поведінка**.

**Differential** з іпохондричним варіантом [C-011-039..041]:

| Параметр               | Іпохондричний                                            | Соматоформний                          |
| ---------------------- | -------------------------------------------------------- | -------------------------------------- |
| **Соматичні скарги**   | Постійні різні                                           | Кардіо/церебро/ШКТ specific            |
| **Уникаюча поведінка** | Стійка                                                   | Поєднана з емоційною неврівноваженістю |
| **Numbing/flashback**  | Рідко                                                    | Можливі                                |
| **Депресивний афект**  | Недиференційована гіпотимія + тривожно-фобічні включення | Емоційна неврівноваженість             |
| **Механізм**           | Гіпохондрична фіксація                                   | Витіснення → соматизація               |

**Differential** з соматизованим розладом (F45.0): при соматоформному варіанті ПТСР існує **верифікована психотравма в анамнезі** (війна, ДТП, насильство), при F45.0 — psychogenic основа без specific trauma anchor.

**Cross-ref L1**: Фройд + soldiers' heart + conversion — психодинамічна спадкоємність. У XIX ст. Da Costa описав «soldiers' heart» (irritable heart syndrome) — прототип соматоформного варіанту ПТСР у ветеранів громадянської війни.

**Мнемоніка 6 варіантів**: **«ТАДI С З»** = Тривожний / Астенічний / Дисфоричний / Іпохондричний / Соматоформний / Змішаний.

**Source**: C-011-042, C-011-043 / transcript [07:00-07:30] / slides Slide 7

### P5 — F43.21 пролонгована депресивна реакція

**Q**: Жінка, 38 років, через 2 місяці після важкого розлучення (тривав суд 1.5 року) має легкий депресивний стан (↓ настрій, плаксивість, втома). Стан утримується 14 місяців. Стресор припинив дію вже 4 місяці тому, але депресія залишається. Який найбільш ймовірний діагноз?

**Варіанти**:

1. F43.20 — короткочасна депресивна реакція
2. **F43.21 — пролонгована депресивна реакція**
3. F43.22 — змішана тривожно-депресивна реакція
4. F32.1 — помірний депресивний епізод
5. F33.1 — рекурентна депресія, помірний поточний епізод

**Correct**: 2

**Пояснення**: За claims [C-011-049, C-011-052] / transcript [08:30-09:00] / slides Slide 8: **F43.21 пролонгована депресивна реакція** — **виняток із загального правила** «6 місяців» для розладів адаптації [C-011-052]:

- **Легкий депресивний стан** — НЕ «помірний» (як F32.1) і не «тяжкий»
- **Реакція на затяжну ситуацію** — стресор тривав довго (у кейсі — 1.5 року суду)
- **Тривалість до 2 років** — можна довше 6 міс ceiling загального F43.2

**Differential з опціями**:

- **F43.20** (опція 1) — тривалість ≤ 1 міс; не підходить (14 місяців)
- **F43.22** (опція 3) — змішана тривога + депресія; не підходить (чиста депресивна симптоматика)
- **F32.1** (опція 4) — помірний депресивний епізод вимагає **виражені** симптоми + ранкові пробудження + ангедонія + ↓ ваги; тут — «легкий депресивний стан»
- **F33.1** (опція 5) — рекурентна депресія вимагає **≥ 2 епізодів**; у кейсі — 1 епізод

**Diagnostic key F43.2** [C-011-045]:

1. **Стресор «звичайний значущий»** — розлучення (а не загроза життю → це не ПТСР)
2. **Гострий початок** — через 2 міс після початку стресової ситуації [C-011-046]
3. **Перешкоджає соц. функціонуванню** — присутнє

**6 місяців ceiling** [C-011-052]: РА триває **≤ 6 місяців** з моменту припинення стресу. **ВИНЯТОК F43.21** — до 2 років для пролонгованої депресивної реакції. Якщо стан триває > 6 міс і не F43.21 — діагноз треба переглянути.

**Мнемоніка**: «**20-21-22-24**» = 4 шифри F43.2.

**Source**: C-011-045..052 / transcript [08:00-09:30] / slides Slide 8

### P6 — Кластер гіперактивації

**Q**: Що з наведеного НЕ є симптомом гіперактивації (hyperarousal) при ПТСР?

**Варіанти**:

1. Порушення сну (інсомнія)
2. Дратівливість або спалахи гніву
3. Труднощі у зосередженні уваги
4. Постійне очікування загрози (hypervigilance)
5. **Відчуття відсутності перспективи (foreshortened future)**

**Correct**: 5

**Пояснення**: За claims [C-011-021..024, C-011-020] / transcript [03:30] / slides Slide 4: **кластер гіперактивації (hyperarousal)** при ПТСР включає **4 симптоми**:

1. **Інсомнія** [C-011-021] — важко заснути, поверхневий сон, нічні пробудження
2. **Дратівливість + спалахи гніву** [C-011-022] — постійна підвищена дратівливість + раптові спалахи
3. **Труднощі з концентрацією** [C-011-023] — через intrusion thoughts + hypervigilance
4. **Hypervigilance + exaggerated startle response** [C-011-024] — постійне сканування на загрозу + гіпертрофована реакція переляку

**Відчуття відсутності перспективи** (foreshortened future) [C-011-020] — це симптом **кластеру негативних змін настрою/когніції** (negative alterations in mood/cognition, DSM-5 кластер D), а не кластеру гіперактивації. DSM-термін: «sense of foreshortened future» — пацієнт не бачить майбутнього, не може планувати кар'єру, сім'ю, життєві цілі. Часто supraposes suicidal ideation.

**Cross-ref**: foreshortened future — частина emotional numbing + alienation patterns (C-011-017..020).

**Clinical phenotype hyperarousal**: типовий ветеран сидить спиною до стіни, контролює виходи, на різкий звук реагує сильно (jumpiness). Це observable клінічна ознака для лікаря/коуча на першому контакті.

**Терапевтична мішень**: пропранолол (β-блокатор) + prazosin (α1-блокатор) — для sleep + nightmares + autonomic hyperarousal.

**Source**: C-011-020..024 / transcript [03:30] / slides Slide 4

### P7 — Sleep avoidance у тривожному варіанті

**Q**: Чоловік, 28 років, ветеран. Скаржиться на безсоння. При уточненні з'ясовується: лягає о 2:00-3:00 ночі, грає в комп'ютерні ігри, читає, дивиться відео — **навмисно відтягує засинання**. Каже: «Не хочу засинати, бо знаю, що знову буде той самий сон». Який клінічний варіант ПТСР найбільш ймовірний?

**Варіанти**:

1. **Тривожний варіант**
2. Астенічний варіант
3. Дисфоричний варіант
4. Іпохондричний варіант
5. Соматоформний варіант

**Correct**: 1

**Пояснення**: За claim [C-011-030] / transcript [04:00-04:30] / slides Slide 5: класична **парадоксальна sleep avoidance** — характерний симптом **тривожного варіанту ПТСР**.

**Тривожний варіант — 8 симптомів** (за slide Slide 5):

1. Високий рівень **немотивованої тривоги** (free-floating) [C-011-027]
2. Часто на фоні зниженого настрою
3. **Нав'язливі переживання + уявлення подій** (інтрузії яскраві) [C-011-028]
4. Внутрішній дискомфорт + напруження + дратівливість [C-011-029]
5. ⭐ **Sleep avoidance** — тяжкість засинання через **страх перед кошмарними сновидіннями** (епізоди бойових дій, насильства, смерті родних, сцени розправи) [C-011-030]
6. ⭐ **Пацієнт НАВМИСНО відтягує настання сну** [C-011-030]
7. Кошмари типового змісту
8. **Нічні панічні атаки** з повним вегетативним симптомокомплексом (задишка, тахікардія, пітливість, озноб/жар) [C-011-031]

**Clinical pearl** [C-011-030]: пацієнт спочатку каже «не можу спати», насправді — **«боюсь спати»**. Direct ask коуча/лікаря: «Ти боїшся засинати? Уявляєш кошмари перед сном? Чи навмисно відтягуєш?»

**Differential варіантів**:

- **Астенічний** [C-011-032..034] — порушення сну характеризуються **unrestorative sleep** (немає відчуття відпочинку), а не sleep avoidance
- **Дисфоричний** [C-011-035..038] — sleep issues secondary, не центральні
- **Іпохондричний** [C-011-039..041] — соматичні скарги + ↓ numbing/flashback (sleep — не центральна жалоба)
- **Соматоформний** [C-011-042..043] — кардіо/церебро/ШКТ скарги домінують

**Терапевтична тактика sleep avoidance**:

1. Psychoeducation (це нормальна реакція)
2. **Prazosin** (α1-блокатор) — first-line off-label для PTSD nightmares
3. **Пропранолол** (β-блокатор) — autonomic симптоми
4. **TF-CBT** — exposure до nightmares через imagery rehearsal therapy (IRT)
5. **EMDR** — для core trauma

**Coaching pearl**: НЕ нав'язувати «sleep hygiene» (це не допоможе при sleep avoidance) — це робота травмо-терапевта.

### P8 — Психотерапія як основний метод

**Q**: Який метод є **основним** у лікуванні посттравматичного стресового розладу за лекцією?

**Варіанти**:

1. Антидепресанти (SSRI/SNRI)
2. Бензодіазепіни
3. Атипові антипсихотики (кветіапін, оланзапін)
4. **Психотерапія**
5. ECT (електросудомна терапія)

**Correct**: 4

**Пояснення**: За claim [C-011-054] / transcript [09:30] / slides Slide 9: лектор **прямо заявляє**: «Основним методом лікування є психотерапія».

**Ключове положення L11**: при ПТСР та РА **препарати — допоміжні**, **ОСНОВНИЙ метод — психотерапія**. Це принципово відрізняє ПТСР від:

- **БАР (L8)** — нормотиміки (літій, вальпроат) first-line + ECT при тяжкій депресії
- **Шизофренія (L7)** — антипсихотики first-line + соц. реабілітація
- **MDD рекурентна (L9)** — SSRI/SNRI + CBT/IPT — інтегративний підхід, але фарма центральна

**4 цілі психотерапії при ПТСР** [C-011-055..059]:

1. **Створення нової когнітивної моделі життєдіяльності** [C-011-056] — травма зруйнувала assumptions (світ безпечний, я компетентний), потрібна **інтеграція травматичного досвіду у нову, більш реалістичну але прийнятну модель світу**
2. **Афективна переоцінка травматичного досвіду** [C-011-057] — зміна emotional meaning травми (зі страху + сорому + вини → на сум + смирення + сенс)
3. **Відновлення почуття цінності особистості** [C-011-058] — повернення self-worth
4. **Відновлення здатності існувати у світі** [C-011-059] — existential restoration

**Gold standard psychotherapy** [C-011-060]: **КПТ (CBT) + травмо-фокусована терапія** (TF-CBT, PE, CPT, EMDR). Це **світовий стандарт** (APA, WHO, NICE guidelines).

**Фармакотерапія — adjunct** [C-011-053]:

| Група                             | Препарати                                            | Застосування                                            |
| --------------------------------- | ---------------------------------------------------- | ------------------------------------------------------- |
| **Антидепресанти**                | SSRI: сертралін, пароксетин (FDA), SNRI: венлафаксин | First-line adjunct                                      |
| **Транквілізатори**               | гідроксизин, прегабалін                              | Короткострокова анксіоліза                              |
| **Анксіолітики** (бензодіазепіни) | alprazolam, clonazepam                               | ОБЕРЕЖНО — ризик залежності + погіршення PTSD long-term |
| **Атипові антипсихотики**         | кветіапін, оланзапін, рисперидон                     | Тяжкі форми, кошмари, psychotic features                |

**Скрипт коуча для клієнта з ПТСР**: «Те, що ти описуєш — це класична ПТСР-картина. Основа лікування — це психотерапія, бажано травмо-фокусована (TF-CBT або EMDR). Препарати (SSRI типу сертраліну) — допоміжні. Я як коуч можу допомогти зі стратегіями життя поряд з цим, але саму травму ми НЕ опрацьовуємо разом — це потребує спеціалізованого фахівця».

### P9 — Gold standard psychotherapy

**Q**: Який метод психотерапії визнаний найбільш ефективним при лікуванні пацієнтів з ПТСР за лекцією?

**Варіанти**:

1. Психоаналіз
2. Гештальт-терапія
3. **Когнітивно-поведінкова терапія (КПТ) + травмо-фокусована терапія**
4. Системна сімейна терапія
5. Транзакційний аналіз

**Correct**: 3

**Пояснення**: За claim [C-011-060] / transcript [10:00-10:30] / slides Slide 9: лектор прямо вказує: «Найбільш ефективним методом психотерапії при лікуванні пацієнтів з ПТСР є **когнітивно-поведінкова терапія і травмо-фокусована терапія**».

**Evidence-based методи для ПТСР** (APA, WHO, NICE guidelines):

| Метод                                             | Скорочення | Кількість сесій | Основа                                                   |
| ------------------------------------------------- | ---------- | --------------- | -------------------------------------------------------- |
| **Trauma-Focused CBT**                            | TF-CBT     | 8-25            | Cognitive restructuring + exposure + relaxation          |
| **Prolonged Exposure**                            | PE         | 8-15            | In vivo + imaginal exposure до травматичних cues         |
| **Cognitive Processing Therapy**                  | CPT        | 12              | Cognitive restructuring + identification of stuck points |
| **Eye Movement Desensitization and Reprocessing** | EMDR       | 8-12            | Bilateral stimulation (eye movements) + reprocessing     |
| **Narrative Exposure Therapy**                    | NET        | 4-10            | Constructing chronological narrative of life trauma      |

**Чому інші опції excluded**:

- **Психоаналіз** (опція 1) — низький evidence base для ПТСР; не recommended APA для PTSD (хоча Фройд історично описав conversion + soldiers' heart)
- **Гештальт-терапія** (опція 2) — корисна для емоційного contact, але НЕ first-line для ПТСР
- **Системна сімейна терапія** (опція 4) — корисна для cPTSD + family dysfunction, але adjunct, не основний
- **Транзакційний аналіз** (опція 5) — не evidence-based для PTSD

**EMDR — найшвидший evidence-based метод** (Shapiro 1989):

- 8-12 сесій (швидше за CBT)
- Особливо ефективний для **single-incident trauma** (ДТП, насильство, military events)
- Менш вербальний — добре для клієнтів, які не люблять «розмовляти»
- Не вимагає homework (на відміну від CBT)

**Cross-ref**: 4 цілі psychotherapy [C-011-055..059]:

1. Cognitive model — нова assumptions про світ
2. Affective reappraisal — emotional reprocessing травми
3. Self-worth — відновлення цінності особистості
4. Existential restoration — здатність існувати у світі

**Coaching pearl**: якщо клієнт описує ПТСР-симптоми — **delegate до EMDR-сертифікованого фахівця (EMDRIA)** або TF-CBT терапевта. Це **робота травмо-терапевта**, не коуча.

**Source**: C-011-060 / transcript [10:00-10:30] / slides Slide 9

### P10 — F43.24 з порушенням поведінки

**Q**: Підліток, 15 років. Через 3 місяці після смерті матері — агресивна поведінка у школі (бійки), уникнення занять, дрібні крадіжки. Раніше — гарна поведінка, успішне навчання. Тривалість симптомів 4 місяці. Який найбільш ймовірний діагноз?

**Варіанти**:

1. F91 — розлад поведінки (conduct disorder)
2. F60.2 — антисоціальний розлад особистості
3. **F43.24 — розлад адаптації з переважанням порушення поведінки**
4. F32.1 — помірний депресивний епізод
5. F43.1 — ПТСР

**Correct**: 3

**Пояснення**: За claim [C-011-051] / transcript [09:00] / slides Slide 8: **F43.24 — розлад адаптації з переважанням порушення поведінки** — клінічно специфічна форма для **підлітків після значущої втрати**:

- **Стресор**: значуща зміна / втрата (у кейсі — смерть матері)
- **Тривалість**: ≤ 6 місяців з моменту припинення стресу
- **Поведінка**: **агресивні або асоціальні форми поведінки** у структурі реакції горя
- **Вік**: підлітковий (12-18, найчастіше 13-17)
- **Преморбідно**: збережене функціонування (гарна поведінка, успішне навчання) — нове порушення

**Clinical pearl** [C-011-051]: підлітки з агресивною/делінквентною поведінкою після втрати близького часто мають **F43.24, а не conduct disorder (F91)**. Цей differential — **clinical pearl** уроку.

**Differential опцій**:

- **F91 conduct disorder** (опція 1) — хронічна (мінімум 12 міс) + ранній початок (часто до 10) + persistent pattern violation of rights of others; не tied to specific stressor; у кейсі — нова поведінка після травми, не persistent
- **F60.2 антисоціальна PD** (опція 2) — діагностується ≥ 18 років; у кейсі — 15 років (preview L13)
- **F32.1 помірний депресивний епізод** (опція 4) — depression centric; у кейсі — поведінка центральна, не настрій
- **F43.1 ПТСР** (опція 5) — потребує **екстремального стресора з загрозою життя**; смерть близького — значуща втрата, але не EXTREME трagический stressor (хоча у DSM-5 expanded criteria смерть близького = potential PTSD trigger якщо «traumatic»)

**Differential з PTSD** — критичне розрізнення:

| Параметр                       | F43.1 ПТСР                                        | F43.24 РА                           |
| ------------------------------ | ------------------------------------------------- | ----------------------------------- |
| **Стресор**                    | Екстремальний (загроза життю, серйозне поранення) | Значущий, але «звичайний» (втрата)  |
| **Інтрузивні спогади**         | ТАК (центральні)                                  | НІ (можуть бути, але не центральні) |
| **Avoidance specific**         | ТАК                                               | НІ                                  |
| **Hyperarousal**               | ТАК                                               | НІ                                  |
| **Поведінкова дезорганізація** | Можлива                                           | **Центральна** при F43.24           |
| **Тривалість критерій**        | > 1 міс, без верхньої межі                        | ≤ 6 міс                             |

**4 МКБ-10 шифри F43.2** [C-011-048..051] — мнемоніка «**20-21-22-24**»:

| Шифр       | Назва                               | Тривалість  | Особливість                                     |
| ---------- | ----------------------------------- | ----------- | ----------------------------------------------- |
| **F43.20** | Короткочасна депресивна реакція     | ≤ 1 місяць  | перехідна, легка                                |
| **F43.21** | Пролонгована депресивна реакція     | ≤ 2 років   | реакція на затяжний стресор; ВИНЯТОК            |
| **F43.22** | Змішана тривожно-депресивна реакція | ≤ 6 місяців | найчастіша                                      |
| **F43.24** | З переважанням порушення поведінки  | ≤ 6 місяців | агресивні/асоціальні форми; підліток після горя |

**Coaching pearl**: підлітки з раптовою поведінковою декомпенсацією після смерті близького — обов'язково **screening на recent loss/trauma** + **family therapy referral** + delegation до child/adolescent psychiatrist. НЕ ярликовувати як «conduct disorder» (стигматизуючий діагноз з гіршим прогнозом).

**Cross-ref L13**: антисоціальна PD не діагностується до 18 років; F43.24 — це **тимчасова** реакція, прогноз кращий.
