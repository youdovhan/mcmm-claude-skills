## Quick summary

Лекція ~11 хв 13 сек від **Світлани Володимирівни Ісаєнко**. **Нозологічна одиниця №5** модуля 10 — рубрика F43 МКБ-10 (включена попри формально окрему рубрику, оскільки фенотипічно близька до тривожних розладів L10 + critical public health значення в умовах війни в Україні 2022+).

**Ключова теза**: ПТСР — це **дисрегуляція амігдало-гіпокамп-PFC системи** після екстремальної травми, з **трикластерною клінічною презентацією** (вторгнення + уникнення + гіперактивація), діагностичним порогом **1 місяця** і **6 клінічними варіантами**. Розлади адаптації F43.2 — її легший аналог із порогом до **6 місяців**. Терапія = **психотерапія first-line** (TF-CBT, EMDR) + SSRI/SNRI як adjunct.

**Трирівнева композиція**: 3 хв загальна нозологія ПТСР + 3.5 хв 6 варіантів + 1.5 хв F43.2 + 2 хв терапія + 1 хв epilogue.

## Key claims (top 15 — пріоритет для тесту)

1. **ПТСР визначення** [C-011-006]: **відстрочена/затяжна реакція** на екстремальну (травматичну) подію загрозливого/катастрофічного характеру (загибель / серйозне поранення); людина = очевидець АБО жертва
2. **Перитравматична тріада** [C-011-007]: **інтенсивний страх + переляк + почуття безпорадності** (whisper-помилка: «спокій» → правильно «переляк»)
3. **3 кластери симптомів ПТСР** [C-011-008] = мнемоніка **«ВУГ»**:
   - **Вторгнення (intrusion)** — 4 симптоми
   - **Уникнення + negative alterations** — 8 симптомів
   - **Гіперактивація (hyperarousal)** — 4 симптоми
4. **4 симптоми вторгнення** [C-011-009..012]: нав'язливі спогади + кошмари + **флешбеки** (миттєве re-living) + тригер-реакції (зовнішні + внутрішні cues)
5. **Психогенна амнезія** [C-011-015] — травматична пам'ять як **sensory fragments**, не семантично зінтегровані; при тригері → сомато-сенсорні дисоціативні прояви
6. **4 симптоми гіперактивації** [C-011-021..024]: інсомнія + дратівливість/спалахи гніву + ↓ концентрації + **hypervigilance** + exaggerated startle response
7. **Часовий критерій ПТСР** [C-011-025]: **> 1 місяця** + функціональне порушення = F43.1; < 1 міс — F43.0 acute stress disorder
8. **6 клінічних варіантів ПТСР** [C-011-026..044] — мнемоніка **«ТАДI С З»**:
   - **Тривожний** — немотивована тривога + sleep avoidance + нічні панічні стани
   - **Астенічний** — слабкість + млявість + інтрузії бліді
   - **Дисфоричний** — агресія + projection + сцени насильства з активною участю
   - **Іпохондричний** — соматичні скарги + ↓ флешбеків (diagnostic pitfall!)
   - **Соматоформний** — витіснення → соматизація (кардіо/церебро/ШКТ)
   - **Змішаний** — combo варіантів (найчастіший у практиці)
9. **F43.2 розлади адаптації** [C-011-045]: суб'єктивний дистрес + емоційний розлад → перешкоджає соц. функціонуванню; гострий початок; стресор «звичайний значущий»
10. **4 МКБ-10 шифри РА** [C-011-048..051] — мнемоніка **«20-21-22-24»**:
    - **F43.20** короткочасна депресивна реакція (≤ 1 міс)
    - **F43.21** пролонгована депресивна реакція (≤ 2 років, ВИНЯТОК)
    - **F43.22** змішана тривожно-депресивна (≤ 6 міс)
    - **F43.24** з порушенням поведінки (агресивні/асоціальні форми; reaction горя у підлітків)
11. **Часовий ліміт РА** [C-011-052]: **≤ 6 місяців** з моменту припинення стресу (виняток F43.21 до 2 років)
12. **Фармакотерапія ПТСР + РА** [C-011-053] — **4 групи**: антидепресанти (SSRI/SNRI) + транквілізатори + анксіолітики (бензодіазепіни ОБЕРЕЖНО) + атипові антипсихотики (кветіапін, оланзапін)
13. ⭐ **Психотерапія = основний метод** [C-011-054] — на відміну від БАР (L8)/шизофренії (L7), де фарма first-line
14. **4 цілі психотерапії** [C-011-055..059]: нова когнітивна модель + афективна переоцінка травми + відновлення self-worth + existential restoration
15. **Gold standard psychotherapy** [C-011-060]: **КПТ (CBT) + травмо-фокусована терапія** (TF-CBT, PE, CPT, EMDR)

## Coaching application (DETECTIVE FM)

7 actionable правил для Юрія-Детектива (детально у `synthesis.md` §7):

1. ⭐ **Direct ask про травму — обов'язкова частина anamnesis** — 5 scripts від м'якого до прямого; direct ask НЕ ретравматизує (це міф); якщо ТАК на 1+ + симптоми > 1 міс → screening 3 кластерів
2. **Тригер-recognition + trigger-map** — 5 типів тригерів (сенсорний буквальний/символічний + емоційний + anniversary + інтерперсональний); psychoeducation + anticipatory coping
3. ⛔ **NOT pushing exposure** — це **робота травмо-терапевта**, не коуча. Можна grounding (5-4-3-2-1), box breathing, safe place. НЕ можна reliving / detailed exposure / EMDR (потрібна сертифікація)
4. **EMDR delegation** — найшвидший evidence-based метод (8-12 сесій); особливо для single-incident trauma (ДТП, насильство); EMDRIA certified therapist only
5. **Soldiers/refugees context — Україна 2022+** — масштаб 20-30% ветеранів + 10-15% цивільних; адаптації: «нормальна реакція на ненормальну ситуацію» + practical first (sleep+безпека) + anniversary 24.02 / 22.06
6. **Anniversary effect** — інтрузії посилюються за 2-4 тижні до date; coaching preparation: календарне планування + meaning-making rituals + therapy boost
7. **Self-screening для коуча — secondary trauma** — vicarious traumatization реальний ризик; self-screening кожні 3 міс (інтрузивні думки про чужу травму / уникнення певних клієнтів / hyperarousal / цинізм / sleep issues); якщо ТАК на 2+ → супервізія + лімітування кейслоду

**Червоні прапори для НЕГАЙНОЇ дії**:

- **Дисфоричний варіант з гетероагресією** + домашнє насильство → психіатр невідкладно + screening близьких
- **Сцени насильства з активною участю** (combat guilt у ветерана) → ризик ауто/гетероагресії; обов'язкове делегування
- **Foreshortened future + suicidal ideation** → direct ask 5 питань (cross-ref L8 §4.5 / coaching pearl 8.5); якщо ТАК на 3+ — швидка 103 + Lifeline 7333
- **Психогенна амнезія + dissociative episodes** → НЕ робити exposure work; делегувати спеціалізовано
- **Іпохондричний варіант з diagnostic pitfall** — клієнт скаржиться на соматику, а не на травму → direct ask анамнезу травми обов'язковий
