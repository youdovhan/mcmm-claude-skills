## Quick summary

Лекція ~27,5 хв від **Світлани Володимирівни Ісаєнко** — **гносеологічний фундамент** модуля 10. Якщо L2 закладає нейробіологічний субстрат, L3 — емоційно-вольовий цикл, то L4 закриває «мозаїку психіки» **когнітивними воротами**: пам'ять + увага як фільтр і архів реальності. Без них психіка не реєструє світ, не утримує особистості у часі, не диференціюється від нейрокогнітивного занепаду.

**Ключова теза**: пам'ять і увага — **дзеркальна пара** з паралельною структурою (мимовільна/довільна форми), де **увага = фільтр для енкодингу пам'яті**. Закон Міллера 7±2 — обсяг уваги і обсяг STM одночасно. **Корсаківський синдром** — холлмарк синдромологічний приклад модуля: 5+1 симптомів пам'яті, єдиний нейробіологічний субстрат (hippocampus + mammillary bodies + thalamus).

## Key claims (top 15 — пріоритет для тесту)

1. **7±2 — закон Міллера** [C-004-008, C-004-109]: обсяг уваги (= обсяг STM). Якщо матеріал новий — лише **1 предмет** одночасно [C-004-009]
2. **3 види уваги** [C-004-002..005]: мимовільна (тригери — яскравість/сила/несподіванка/динамізм) / довільна (вольовим зусиллям) / **післядовільна** (свідома мета + flow без зусилля)
3. **4 властивості уваги** [C-004-007]: обсяг / розподіл / перемикання (фізіологічна основа — переміщення вогнища збудження) / концентрація
4. **4 процеси пам'яті** [C-004-028]: запам'ятовування (фіксація) → збереження (ретенція) → відтворення (репродукція) → забування
5. **Емоційний закон пам'яті** [C-004-041]: емоційно заряджене запам'ятовується глибше → амигдала-гіпокамп coupling, flashbulb memories. **Танечкина історія** [C-004-069] — анкер уроку
6. **Ефект краю** [C-004-044]: при запам'ятовуванні довгого ряду найкраще пам'ятаєш **початок + кінець** (Ebbinghaus, serial position effect: primacy у LTM + recency у STM)
7. **Закон Рібо** [C-004-067]: динаміка прогресуючої амнезії — **від нового до старого**, дитячі спогади тримаються найдовше. Théodule Ribot 1881
8. **Spaced repetition 5-6 / 4 / 2-3** [C-004-052]: день 1 — 5-6 повторень; день 2 — 4; день 3 — 2-3. Front-loaded schedule, відповідає Ebbinghaus forgetting curve
9. **6 типів амнезії** [C-004-061]: ретроградна (до події) / антероградна (після) / антероретроградна / прогресуюча (Альцгеймер, закон Рібо) / афектогенна (кататимічна = психогенна = dissociative DSM-5) / фіксаційна (Корсаков)
10. **3 парамнезії** [C-004-071..078]: **криптомнезія** (стерті межі чужого/свого, привласнення/відчуження) + **конфабуляції** (фантастика, чого не було — «галюцинації пам'яті») + **псевдоремінісценції** (реальні події, зміщений час/місце — «ілюзії пам'яті»)
11. **Дежавю** [C-004-080]: вперше бачене сприймається як знайоме, **критика збережена**. У 60-70% — норма. Якщо >2 раз на тиждень + аура → **скронева епілепсія** [cross-ref L2]
12. **Жамевю** [C-004-082]: знайоме сприймається як чуже («не впізнаю свою кімнату»). Критика збережена
13. **Прескевю** [C-004-084]: «на кінчику язика» (TOT phenomenon, Brown & McNeill 1966)
14. **Корсаковський синдром** [C-004-086]: 5+1 компонентів = **фіксаційна амнезія + ретроградна + антероградна + псевдоремінісценції + конфабуляції + дезорієнтація**. Етіологія — інфекції / **алкогольна інтоксикація (Wernicke-Korsakoff)** / ЧМТ / судинна
15. **Таблиці Шульте** [C-004-097]: 1-25 на 60×60см, фіксація часу/таблицю + кількість чисел/30 сек. **Крива виснажуваності** [C-004-098] — характерна форма для різних станів (норма / астенія / манія / шизофренія)

## Coaching application (DETECTIVE FM)

7 actionable правил для Юрія-Детектива (детально у `synthesis.md` §7):

1. **Чек-ліст «що пам'ятає про дитинство»** — ретроградна dirfdiагностика. «Не пам'ятаю **взагалі нічого**» → афектогенна амнезія [C-004-070] → травматерапевт
2. **Танечкина історія як модель емоційного закону** [C-004-069] — лекторська ілюстрація, що переключає клієнта з «у мене погана пам'ять» на «я просто не надавав значення тоді»
3. **9 способів покращення пам'яті як toolkit для study-coaching** [C-004-047..056] — клієнтам у фазі іспитів / нової професії; особливо **spaced repetition 5-6/4/2-3** та **elaborative encoding**
4. **Шульте-таблиця як швидкий self-screening** [C-004-097]: норма 35-45 сек/таблицю; >50 сек + виснаження → астенія/депресія; >90 сек → невролог/психіатр
5. **«Я не пам'ятаю свого дитинства» — red flag для делегації**. НЕ копай самостійно (ретравматизація + false memory implantation, cf. Loftus [C-004-043]) → травматерапевт + психіатр
6. **Confabulation у клієнтів з Корсаковим алкогольним** [C-004-086]: хронічний алкоголізм + забуває нещодавнє + розповідає фантастичне → **психіатр + B1 невідкладно** (Wernicke-зворотний, Korsakoff-незворотний)
7. **Cryptomnesia у клієнтів-експертів** [C-004-073]: «я сам придумав» — у 30% випадків переоткриття чужого. Поради: reading log + literature review + цитування
