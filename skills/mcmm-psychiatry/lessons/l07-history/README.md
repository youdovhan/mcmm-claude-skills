## Quick summary

Лекція 27 хв від жінки-психіатра (кандидат наук ~2020, працює у Сабуровій дачі, Харків). Перший психіатр в Україні з відкритим Instagram (2018). **Базовий вступний урок** модуля з 14 уроків.

**Ключова теза**: 2500-річна траєкторія психіатрії від «одержимих» до «пацієнтів» через 3 парадигмальні повороти:

1. **1793 — медикалізація** (Пінель, Бісетр: ланцюги зняті, «душевнохворий» замість «біснуватого»)
2. **1950 — фармакологізація** (аміназин/хлорпромазин, перший нейролептик)
3. **Зараз — дестигматизація** (лектор сама — частина цієї парадигми)

**4 секції slides**: визначення понять / спеціалісти / історія психіатрії / Стаття 14.

## Coaching application (DETECTIVE FM)

5 actionable правил для Юрія-Детектива (детально у `synthesis.md` §7):

1. **Знай межі компетенції** — коуч НЕ діагностує, НЕ призначає медикаменти. При клінічних ознаках → психіатр.
2. **Стаття 14 — критерій термінового делегування** — небезпека для себе/інших → 103/швидка, не «опрацьовуй» коучингoво.
3. **Психо-соматика — твоя зона** (Кіплінг: «причина виразки в тому що з'їдає»).
4. **Дестигматизація — частина роботи** — Юрій-Детектив через публічну роботу робить аналогічну до лектора парадигмальну зміну.
5. **Як називаєш — так і працюєш** — парадигма визначає лікування; коуч обирає рамку («виклик» vs «розлад»).
