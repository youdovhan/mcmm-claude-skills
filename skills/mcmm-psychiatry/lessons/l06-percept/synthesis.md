## §0 — Quick thesis

**Сприйняття = синтез відчуттів + інтерпретація. Поломки реальності — від парестезій до галюцинацій — це шлях розпаду на 7 рівнях.** Урок 6, який лектор сама називає «найважливішим з нашого курсу модулем» [C-006-066], — це феноменологічний словник усієї нозології, що йде далі (шизофренія, алкогольні психози, епілепсія, деменція, органічні розлади). Без точного розрізнення «ілюзія / галюцинація / метаморфопсія / сенестопатія / парестезія» наступні діагнози залишаються розмитими ярликами. Після L6 — це **впізнавані сліди певних мозкових процесів**, кожен з яких вказує на конкретну етіологію.

Лектор вибудовує лекцію за принципом **«як детектив розгадати, що з пацієнтом»** [C-006-043]: модальність + характер + супутні симптоми = диференційно-діагностичний ключ. Зорова галюцинація → екзогенно-органічна патологія (алкоголь, інтоксикація, інфекція). Слухова стійка вербальна → ендогенний процес (шизофренія). Нюхова → скронева епілепсія. Смакова присмак отрути → нейровізуалізація на пухлину. Тактильна (волоси на язику) → сурогати алкоголю + важкі метали [C-006-037, 040, 041, 042].

**Core insight для коуча**: між «дивно я себе почуваю» клієнта і психіатричною патологією є **феноменологічний градієнт** з чітко описаними одиницями. Сенестопатії, псевдогалюцинації Кандинського, імперативні голоси — це не «складні переживання», це **named-diseases** з конкретними руховими маркерами поведінки [C-006-059]. Коуч, який знає цю мапу, бачить ред-флаги раніше, ніж клієнт усвідомить, що з ним не так.

## §2 — Key insights / paradigm narrative

### 2.1. Трирівнева тріада: відчуття → сприйняття → уявлення

Перша концептуальна рамка уроку — диференціація трьох рівнів сенсорно-перцептивної діяльності [C-006-003, 004, 005]:

| Рівень         | Що це                                                                                              | Анатомічна основа           |
| -------------- | -------------------------------------------------------------------------------------------------- | --------------------------- |
| **Відчуття**   | найпростіший психологічний акт — відображення окремих властивостей предметів (колір, форма, тембр) | аналізатор + первинна кора  |
| **Сприйняття** | цілісне відображення предметів + синтез з минулим досвідом                                         | вторинна / асоціативна кора |
| **Уявлення**   | пожвавлення образів, сприйнятих у минулому, сліди колишніх відчуттів                               | пам'ять (гіпокамп + кора)   |

**4 відмінності уявлення від сприйняття** [C-006-006] — ключове розрізнення для розуміння псевдогалюцинацій далі:

1. **Узагальнений характер** (не конкретна машина — а «машина взагалі»)
2. **Різна ступінь яскравості у різних людей** (хтось «бачить» як фото, хтось як ескіз)
3. **Фрагментарні** (без повноти, як сон)
4. **НЕ проектуються у зовнішній простір** — створюються у суб'єктивному світі

Останнє — **критично важлива властивість** для всього подальшого уроку: відсутність екстрапроекції — це маркер уявлення. Коли псевдогалюцинація Кандинського «не проектується назовні, а існує у голові» [C-006-048] — феноменологічно вона ближча до уявлення, ніж до повного сприйняття. Тому лектор закладає цю властивість заздалегідь.

### 2.2. Моне і катаракта — соматика впливає на сприйняття

Прикладна аналогія для відкриття теми «розладів»: Клод Моне, основоположник імпресіонізму [C-006-007]. Прожив більше половини життя, отримав «подвійну катаракту», переніс дві операції. Після операцій бачив світ по-іншому — «лівим оком ультрафіолет», що змінило колірну гаму картин («Водяні лілії» у лілових відтінках, бо так він їх бачив).

**Дидактичний меседж** [C-006-008]: на сприйняття часто впливає **цілий ряд факторів, у тому числі соматичний і психічний стан**. Це фундаментальна теза, що зв'язує соматику з психопатологією сприйняття: будь-яке захворювання тіла (катаракта, інтоксикація, лихоманка) може спотворити перцепцію.

**Suspicious token**: «лівим оком ультрафіолет» — поширений культурний міф/гіпотеза. Фізіологічно правда, що афакія (видалення кришталика) відкриває око для UV-діапазону (кришталик блокує UV). Але прив'язка саме до «лілових Water Lilies» — артовий міф; науково не доведено. Лектор не атрибутує і не уточнює. Для коуча важливий не точний приклад, а **принцип**: «бачите щось дивне — спочатку перевірте соматику».

### 2.3. Порушення відчуттів — 7 типів

Тут лектор накопичує термінологію [C-006-009 → C-006-015]:

| Тип               | Що це                                                                              | Клініка                                                              |
| ----------------- | ---------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| **Гіпестезія**    | зниження суб'єктивної яскравості/інтенсивності відчуттів                           | може бути нормою — при втомі, зниженні тонусу                        |
| **Анестезія**     | повне виключення відчуттів (сліпота, глухота, відсутність болю)                    | психічна або органічна — функціональна сліпота при істерії, наркоз   |
| **Агнозія**       | при локальних ураженнях кори: предмет видно, але не можуть назвати                 | предметна, лицьова, пальцева, слухова, тактильна (нейропсихологія)   |
| **Гіперестезія**  | загострення сприйняття нейтральних подразників                                     | астенічні стани, неврози, ранні стадії інтоксикацій                  |
| **Парестезія**    | поколювання, повзання мурашок, приплив крові, спека у ділянках шкіри               | поверхнева; невропатолог: радикуліти, нейропатії                     |
| **Сенестопатія**  | незвичайні, вкрай неприємні відчуття з внутрішніх органів БЕЗ соматичної патології | психіатрична зона; ред-флаг шизофренії, депресії з соматизацією      |
| **Метаморфопсія** | спотворене сприйняття форми/розміру РЕАЛЬНИХ предметів з критикою                  | мігрень, епілепсія (синдром Аліси), інтоксикації, скронева патологія |

**Ключова диференціація: парестезія vs сенестопатія**:

- **Парестезія** — поверхнева (шкіра), локалізована, зрозуміла («ніби мурашки»), часто зв'язана з реальним нейропатологічним субстратом
- **Сенестопатія** — глибока (внутрішні органи), невловима, незрозуміла («розм'якшення кісток», «дірка у шлунку»), БЕЗ соматичної патології

**4 «НЕ» сенестопатій** [C-006-015] — дидактична мнемоніка лектора:

1. **Незвичайні** (нетипові, неподібні до знайомих болів)
2. **Неприємні** (завжди суб'єктивно дисфоричні)
3. **Невідступні** (не проходять, циклічно повертаються)
4. **Невластива локалізація соматичного захворювання** (там, де не може бути соматичної причини)

**Quiz Q1 курсу = сенестопатії**. Це найважливіша одиниця секції.

**КРИТИЧНА термінологічна плутанина whisper**: транскрипт повсюди дає «синестопатія», що змішується з «синестезією». Це **різні речі**:

- **Синестезія** — крос-модальне сприйняття (норма у частини людей: «бачити звук кольором», «нюхати літери»)
- **Сенестопатія** — патологічне відчуття у внутрішньому органі без органічної патології

### 2.4. Метаморфопсії — Аліса і Гауді

Метаморфопсії — зорові психосенсорні розлади: реально існуючий предмет видно зі зміненою формою/розміром, але **значення та сутність зберігаються + критика збережена** [C-006-016]. Тобто хворий бачить, що ложка деформована, але розуміє, що це ложка.

Підвиди [C-006-017, 018, 019, 020]:

| Підвид                   | Що змінено                                                          |
| ------------------------ | ------------------------------------------------------------------- |
| **Дисморфопсії**         | форма предметів                                                     |
| **Макропсії**            | розмір — предмети бачаться більшими                                 |
| **Мікропсії**            | розмір — предмети бачаться меншими                                  |
| **Порушення схеми тіла** | подовження, укорочення, викривлення власних кінцівок/голови/органів |

**Synthetic syndrome**: Аліса у Країні Чудес [C-006-021] — комплекс мікропсій + макропсій + порушень схеми тіла + телеопсій, описаний J. Todd 1955 як «Alice in Wonderland syndrome». Зустрічається при мігрені (Льюїс Керрол сам страждав мігренню з аурою!), епілепсії, інтоксикаціях, вірусних інфекціях у дітей.

**Контрприклад мистецтва**: Антоні Гауді [C-006-022] — «одержимий ідеєю фантастичності виліплених форм, чого до фанатизму вимагав у роботах». Це **не патологія**, бо: критика збережена + продуктивність висока + соціальна адаптація збережена + творення керовано. Метаморфоза форми у мистецтві ≠ метаморфопсія у клініці. Цей контрприклад — частина «спектру норма-патологія» курсу (див. §3.2).

### 2.5. Ілюзії — 3 типи + 3 психічні підтипи

**Ключова диференціація з метаморфопсіями**: при ілюзіях ЗМІНЮЄТЬСЯ зміст і значення предмета (хворий «бачить» не той об'єкт, що є насправді) + критика часто втрачається [C-006-023]. При метаморфопсіях форма/розмір змінені, але об'єкт впізнається коректно.

**3 механізми ілюзій** [C-006-026]:

| Тип              | Механізм                                | Приклад                                                 |
| ---------------- | --------------------------------------- | ------------------------------------------------------- |
| **Фізичні**      | поза людиною — оптика, фізика           | заломлення ложки у склянці, міражі                      |
| **Фізіологічні** | особливості функціонування аналізаторів | motion after-effect, перспективне сходження паралельних |
| **Психічні**     | зміна психічної діяльності              | афективні, вербальні, парейдолічні                      |

**ВАЖЛИВО**: фізичні і фізіологічні ілюзії — **норма у всіх здорових людей**. Це не патологія. Психічні — спектр від норми (тривожне очікування, перевтома) до патології (зміна свідомості).

**3 підтипи психічних ілюзій** [C-006-029, 030, 031, 032]:

| Підтип           | Опис                                                           | Приклад                                                                      |
| ---------------- | -------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| **Афективні**    | під впливом сильних емоцій (страх, напруга)                    | «у темному провулку замість пня — бандит»                                    |
| **Вербальні**    | хибне сприйняття СМИСЛУ слів оточуючих                         | хворий чує у поясненнях медпрацівників невідомі слова, інтерпретує по-своєму |
| **Парейдолічні** | складні чуттєві образні ілюзії — прочитане раніше накладається | у малюнках шпалер бачить «чудовиськ», страшні образи                         |

**Парейдолії у літературі**: Гете «Лісовий упир» / «Erlkönig» [C-006-033] — хворий у гарячці бачить у нічному лісі простягнуті лапи лісового упиря. Це описаний випадок парейдолії на тлі лихоманки.

**Парейдолії у нормі**: бачити лиця у хмарах, у пляму на стелі, у тостер'і — це **face pareidolia**, нормальний феномен pattern recognition. Патологія — коли стійкі, страшні, на нейтральному матеріалі, втрата критики.

### 2.6. Галюцинації — теорія Попова + 6 модальностей

**Визначення** [C-006-034]: галюцинація — уявне сприйняття **БЕЗ реального подразника** у даний час. Це ключова теза різниці з ілюзіями: ілюзія = є реальний об'єкт + спотворене розуміння; галюцинація = реального об'єкта взагалі немає.

**Теорія Попова** [C-006-035]: фазно-гальмівна теорія Є.О. Попова (1899–1961) пояснює патоморфологічну основу галюцинацій через **зрівняльну та парадоксальну фази неповного позамежного гальмування**. Тобто на фоні охоронного гальмування у корі формуються вогнища патологічного збудження, які генерують образи без зовнішнього стимулу. Базується на павловському вченні. Сучасна нейрохімія додає дофамінову гіпотезу (надлишок дофаміну в мезолімбічному → продуктивні симптоми, в т.ч. галюцинації [C-002-080]) і ЛСД-модель через 5-HT2A [C-002-093].

**6 модальностей галюцинацій** [C-006-036 → C-006-044]:

| Модальність     | Опис                                                 | Етіологічна підказка                                                       |
| --------------- | ---------------------------------------------------- | -------------------------------------------------------------------------- |
| **Зорові**      | «змії під ліжком», образи, сцени                     | **гострий стан**, ЕКЗОГЕННО-ОРГАНІЧНА (алкоголь, наркотики, інфекція, ЧМТ) |
| **Слухові**     | оклики, розмови, музику, спів                        | **хронічний стан**, ендогенний — шизофренія                                |
| **Нюхові**      | різкі запахи гарі, бензину, газів                    | СКРОНЕВА ЕПІЛЕПСІЯ (нюхова аура, uncinate seizure)                         |
| **Смакові**     | присмак отрути, ртуті, свинцю                        | **ОНКОЛОГІЧНИЙ ред-флаг** — пухлина головного мозку                        |
| **Тактильні**   | температурні, волога, волоси на язику                | **ІНТОКСИКАЦІЇ** — сурогати алкоголю, важкі метали                         |
| **Вісцеральні** | образ всередині органа («змія заповзла у стравохід») | **сенестопатичний галюциноз** — додає предметний образ до сенестопатії     |

**Слухові — підвиди за оцінкою** [C-006-038, 039]:

- Нейтральні / коментуючі / ворожі / погрозливі / доброзичливі / **антагоністичні** (одні добрі, інші злі — спорідненість з афективною амбівалентністю L3)
- **Імперативні** — наказують особі зробити щось → **КЛІНІЧНА НЕБЕЗПЕКА**: можуть наказати вбити, підпалити, викинути цінні речі. Показання для НЕГАЙНОЇ госпіталізації.

**Принцип «як детектив»** [C-006-043]: модальність + характер + супутні симптоми = диференційно-діагностичний ключ. Це авторська метафора лектора, що рефреном проходить через увесь курс.

### 2.7. Істинні vs псевдогалюцинації Кандинського — КЛЮЧОВЕ розрізнення

Це найважливіше диференціально-діагностичне розрізнення уроку [C-006-047, 048].

**Істинні (повні) галюцинації** [C-006-047] — мають **ВСІ властивості сприйняття**:

1. **Чуттєва жвавість** (яскравість, конкретність)
2. **Екстрапроекція** (об'єкт сприймається ЗОВНІ — «у кімнаті», «під ліжком», «на стіні»)
3. **Відсутність довільної мінливості** (хворий не може «вимкнути» або «змінити» образ)

Це створює **почуття реальності** — хворий впевнений, що це справді є. Приклад: «бачив відьму. Докладно, жваво, яскраво описував подробиці зовнішності — мертвенно блідий колір тіла, кігті. Сиділа в кімнаті, кривлялася, лякала, а він нічого не міг вдіяти. Відьма була реальною».

**Псевдогалюцинації Кандинського** [C-006-048] — НЕМАЄ якоїсь з властивостей сприйняття, **головно — НЕМАЄ екстрапроекції**:

- Хворий чує голоси **«всередині голови»** (не «з кімнати», не «з-за стіни»)
- Бачить **«внутрішнім оком»** «розташованих на звивинах мозку чоловічків»
- Втрачено **почуття реальності** — хворий часто розуміє, що це «не зовсім» сприйняття

Описав В.Х. Кандинський (1849–1889) [C-006-049], рос. психіатр, на основі **власного психотичного досвіду** (він сам страждав на психоз і документував). Цим класичний опис — поєднання «лікар + пацієнт» у одній особі. Опублікував монографію «Про псевдогалюцинації» (1890, посмертно).

**Чому це КЛЮЧОВЕ для діагнозу**:

- Псевдогалюцинації частіше → шизофренія (синдром Кандинського-Клерамбо: псевдогалюцинації + марення впливу + психічні автоматизми)
- Істинні галюцинації частіше → екзогенно-органічна патологія (делірій, інтоксикації, енцефаліт)

**Питання-ключ для коуча/лікаря**: «Голос який ти чуєш — він у тебе у голові чи звідкись з кімнати?». Це **один питання, що відкриває шлях у синдромальну діагностику**. Деталі у §4.3.

### 2.8. Особливі види — норма-патологія континуум

8 особливих видів галюцинацій [C-006-050 → C-006-058]:

| Тип                | Опис                                                                                | Норма / Патологія                                                                                             |
| ------------------ | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **Гіпнагогічні**   | при засинанні, при закритих очах                                                    | у виснажених здорових (недосип, астенія) → норма; яскраві + катаплексія → нарколепсія                         |
| **Гіпнопомпічні**  | при пробудженні                                                                     | значно рідше — як правило, корелює з порушеннями виходу з REM                                                 |
| **Екстракампінні** | поза полем зору («бачу когось за спиною без повороту голови»)                       | часто шизофренія + марення переслідування                                                                     |
| **Функціональні**  | паралельно з реальним подразником (у шумі води — голоси у воді)                     | важлива диференціація з вербальними ілюзіями (там реальний звук ЗАМІНЯЄТЬСЯ галюцинаторним; тут — паралельно) |
| **Рефлекторні**    | реальний подразник переноситься в інше місце («веретено у руці → дзижчить у серці») | шизофренія, тяжкі інтоксикації                                                                                |
| **Навіяні**        | індуковані гіпносуггестією                                                          | експериментальний феномен; використовується у методі Рігера-Рейхардта                                         |
| **Негативні**      | відсутність сприйняття реально існуючих предметів                                   | гіпноз (експеримент); дисоціативні розлади                                                                    |
| **Шарль Бонне**    | у психічно ЗДОРОВИХ з втратою зору/слуху + критика збережена                        | sensory deprivation → мозок «заповнює порожнечу»; дозволена психотика                                         |
| **Фантом**         | у ампутованих — наявність кінцівки, біль у ній + критика збережена                  | пластичні зміни у соматосенсорній корі (Ramachandran)                                                         |

**КЛЮЧОВИЙ ПАТЕРН**: гіпнагогічні + Шарль Бонне + фантом — це **«дозволена психотика» у психічно здорових людей**. Це частина dimensional підходу курсу (§3.2): немає чіткої межі між «нормою» і «патологією» — є градієнт, де однакові феноменологічні явища у різних контекстах мають різне клінічне значення.

### 2.9. Методи дослідження — 4 іменні симптоми

Класична семіотика галюциноза [C-006-061 → C-006-065]:

| Симптом              | Метод                                                 | Показання                                                     |
| -------------------- | ----------------------------------------------------- | ------------------------------------------------------------- |
| **Ліпмана**          | легке натискання на очні яблука                       | алкогольний делірій — провокація/посилення галюцинацій        |
| **Рігера-Рейхардта** | пред'явити чистий аркуш + попросити прочитати «текст» | будь-яка галюцинаторна готовність + сугестивна піддатливість  |
| **Бехтерева**        | вслухатися у монотонний метроном/годинник             | гострий/хронічний алкогольний галюциноз — провокація слухових |
| **Ашаффенбурга**     | поговорити у відключений телефон                      | слухова галюцинаторна готовність — провокація                 |

Усі 4 — **провокаційні проби**: лікар штучно активує/підсилює галюцинаторний феномен для підтвердження діагнозу. Працюють переважно при станах з **лабільними** галюцинаціями (алкогольні психози) + сугестивна піддатливість. При шизофренії — менш чутливі (галюцинації менш «провокабельні»).

**Поведінкова діагностика «без проб»** [C-006-059, 060]: пацієнт не завжди розповість про галюцинації, але видасть себе **поведінковими маркерами**:

- Слухові → прислухається, розмовляє з «голосами»
- Зорові → придивляється до порожнього кута
- Тактильні → скидає з себе щось (павуки, мурашки)
- Нюхові → морщиться без видимого стимулу
- Смакові → відпльовує

«**Психіатрія — це наука спостереження**» [C-006-060] — методологічне твердження лектора. Габітус пацієнта (зовнішній вигляд, поза, міміка, погляд) — фундаментальний діагностичний інструмент.

## §3 — Cross-cutting concepts

### 3.1. «4 НЕ» сенестопатій як named-mnemonic

Лектор дидактично подає сенестопатії через 4 «НЕ» [C-006-015]:

```
НЕзвичайні + НЕприємні + НЕвідступні + НЕвластива локалізація соматичному захворюванню
```

Це не випадково — це **методологічна модель сенестопатії як цілісної категорії**:

- **НЕзвичайні** + **НЕприємні** = суб'єктивна якість (різні від знайомих болів)
- **НЕвідступні** = темпоральна характеристика (не проходять)
- **НЕвластива локалізація** = просторово-соматична характеристика (там, де не має органічного субстрату)

Якщо клієнт каже «у мене дивне жжіння в грудях кілька днів» — питай за всі 4 «НЕ». Якщо ≥3 з 4 = сенестопатія → психіатр. Якщо 1-2 «НЕ» — терапевт + кардіолог + невропатолог по соматиці.

### 3.2. Спектр норма-патологія: dimensional підхід

L6 неодноразово підкреслює **континуум здоров'я → хвороби** [C-006-082]:

| Феномен             | Норма (контекст)               | Патологія (контекст)                              |
| ------------------- | ------------------------------ | ------------------------------------------------- |
| Фізичні ілюзії      | у всіх (міражі, оптика)        | —                                                 |
| Фізіологічні ілюзії | у всіх (perspective)           | —                                                 |
| Психічні ілюзії     | тривожне очікування, перевтома | зміна свідомості, делірій                         |
| Парейдолії          | хмари → лиця, творчість        | стійкі, страшні, на нейтральному + втрата критики |
| Гіпнагогічні        | здорові виснажені (недосип)    | нарколепсія + катаплексія                         |
| Синдром Бонне       | здорові з втратою зору/слуху   | —                                                 |
| Фантом ампутованих  | здорові з критикою             | хронічний phantom pain                            |
| Сенестопатія        | —                              | завжди патологія (шизофренія, депресія)           |
| Псевдогалюцинації   | —                              | завжди патологія (шизофренія)                     |
| Імперативні голоси  | —                              | гострий клінічний випадок (шизофренія, психоз)    |

**Висновок для коуча**: ілюзії і парейдолії у клієнта самі по собі — НЕ патологія, якщо: тимчасові + критика збережена + соціально-функціонально не обмежують. Сенестопатії, псевдогалюцинації, імперативні голоси — завжди патологія, незалежно від контексту.

### 3.3. Кандинський як named-disease

В.Х. Кандинський (не плутати з художником Василем Кандинським — родич, двоюрідний дядько!) — це **eponym** [C-006-049]. У клінічному вжитку:

- **«Псевдогалюцинації Кандинського»** — голоси/образи всередині голови, без екстрапроекції
- **«Синдром Кандинського-Клерамбо»** — псевдогалюцинації + марення впливу + психічні автоматизми (комплекс, патогномонічний для шизофренії)

Це **обов'язково знати**, бо у MCMM-quiz Q1 і у наступних модулях (шизофренія) ці терміни повертаються постійно. Це не «суперечливе сприйняття», це **named-disease з конкретною топологією**.

### 3.4. Етіологічна прив'язка модальностей — clinical pattern recognition

Лектор дає implicit etiology→symptom map [C-006-083]:

```
ЗОРОВІ галюцинації (особливо різкого початку)
   → ЕКЗОГЕННО-ОРГАНІЧНА патологія
   → алкоголь / наркотики / інфекція / ЧМТ / енцефаліт / Lewy body деменція

СЛУХОВІ ВЕРБАЛЬНІ (особливо стійкі, антагоністичні)
   → ЕНДОГЕННИЙ процес
   → шизофренія

НЮХОВІ (різкі неприємні запахи)
   → СКРОНЕВА ЕПІЛЕПСІЯ (uncinate seizure)
   → можливо ольфакторна менінгіома

СМАКОВІ (присмак отрути, ртуті, свинцю)
   → ОНКОЛОГІЧНИЙ РЕД-ФЛАГ → МРТ головного мозку
   → пухлина головного мозку (доброякісна / злоякісна, залежно від локалізації)

ТАКТИЛЬНІ (волоси на язику, формікація)
   → ІНТОКСИКАЦІЇ
   → сурогати алкоголю / спирт / важкі метали / кокаїн

ВІСЦЕРАЛЬНІ (предмет всередині органа)
   → СЕНЕСТОПАТИЧНИЙ ГАЛЮЦИНОЗ
   → шизофренія, тяжкі соматичні + психотичні стани

ІМПЕРАТИВНІ (наказують)
   → КЛІНІЧНА НЕБЕЗПЕКА — гомицид/суїцид/підпал
   → негайна госпіталізація
```

Це і є **«як детектив розгадати»** — модальність як ключ до етіології.

### 3.5. Афект ↔ сприйняття — місток до L3

Афективні ілюзії [C-006-030] — це **афект-індуковане спотворення сприйняття**. Сильна емоція (страх, напруга) → змінює інтерпретацію нейтрального стимула (пень → бандит). Це прямий місток до L3:

- **Норма**: афективна ілюзія у стресовій ситуації проходить, коли стрес зникає
- **Патологія**: систематичні афективні ілюзії при тривожному розладі, ПТСР, депресії з тривогою

**Інверсія**: антагоністичні голоси у L6 [C-006-038] — корелюють з афективною амбівалентністю у L3 [C-003-029]. Це не випадково — психічні автоматизми у шизофренії проявляються одночасно у багатьох сферах (сприйняття + афект + воля).

## §4 — Diagnostic logic

L6 — це **діагностичний словник**. 5 ключових точок розгалуження для прийняття рішень:

### 4.1. Парестезія vs сенестопатія

| Питання                 | Парестезія              | Сенестопатія              |
| ----------------------- | ----------------------- | ------------------------- |
| Локалізована конкретно? | ✅ так (поверхня)       | ⛔ ні (плаваюча)          |
| Зрозуміла суб'єктивно?  | ✅ «ніби мурашки»       | ⛔ «не знаю як описати»   |
| Тимчасова чи постійна?  | може бути обом          | **невідступна**           |
| Є відповідний орган?    | ✅ можливо (нейропатія) | ⛔ невластива локалізація |
| Куди делегувати?        | **невропатолог**        | **психіатр**              |

**Скрипт**: «Це відчуття можеш конкретно показати рукою де? Воно зрозуміле тобі — на щось схоже з твого досвіду? Чи приходить-уходить, чи весь час?»

### 4.2. Ілюзія vs галюцинація

| Питання                                     | Ілюзія                             | Галюцинація                   |
| ------------------------------------------- | ---------------------------------- | ----------------------------- |
| Є реальний об'єкт?                          | ✅ є (пень, кактус, шум вітру)     | ⛔ немає (порожнеча)          |
| Якщо забрати «провокатор» — феномен зникне? | ✅ так (немає пню — немає бандита) | ⛔ ні (немає об'єкта взагалі) |
| Критика збережена?                          | часто частково ✅                  | переважно ⛔                  |

**Скрипт**: «Коли ти бачиш цю істоту — це у конкретному місці кімнати? Якщо ти зараз вийдеш у іншу кімнату — вона теж там буде?»

### 4.3. Істинна vs псевдогалюцинація Кандинського ⭐ КЛЮЧОВЕ

**Один питальник вирішує все**:

> «Цей голос — він у тебе **у голові**, чи **звідкись з кімнати / з-за стіни / зовні**?»

| Відповідь                                | Тип                                                                       | Імовірний діагноз                          |
| ---------------------------------------- | ------------------------------------------------------------------------- | ------------------------------------------ |
| «У голові, всередині»                    | **Псевдогалюцинація Кандинського**                                        | Шизофренія (синдром Кандинського-Клерамбо) |
| «Звідкись з кімнати, з тієї стіни»       | **Істинна галюцинація**                                                   | Екзогенно-органічна (делірій, енцефаліт)   |
| «У голові, але я знаю що це не справжнє» | можлива псевдогалюцинація з критикою або уявлення з підвищеною яскравістю | дисоціативний стан, депресія, OКР          |
| «У вухах ніби, але я бачу що нема»       | можлива гіпнагогічна (при засинанні)                                      | норма (астенія) або нарколепсія            |

**Це ключове питання Юрія коучингу**: не «що ти чуєш», а «**ЗВІДКИ ти це чуєш**».

### 4.4. Гіпнагогічні норма vs патологія

| Параметр         | Норма (астенія, недосип)                               | Патологія (нарколепсія / psychosis)                                                                 |
| ---------------- | ------------------------------------------------------ | --------------------------------------------------------------------------------------------------- |
| Контекст         | при засинанні, закриті очі                             | може бути будь-коли                                                                                 |
| Критика          | збережена («я бачу, але знаю що це сон підкрадається») | втрачена                                                                                            |
| Емоційна якість  | нейтральна або цікаво                                  | страх, мотивує дії                                                                                  |
| Супутні симптоми | втома, недосип                                         | катаплексія, паралічі сну, денна сонливість (нарколепсія) АБО маячення/інші продуктивні (psychosis) |
| Зникає зі сном?  | ✅ так                                                 | ⛔ ні                                                                                               |

### 4.5. Парейдолії норма vs патологія

| Параметр         | Норма (творчість, face pareidolia) | Патологія (шизофренія, делірій)       |

### 4.6. Етіологія за модальністю — швидкий патерн

```
зорові гострі + дезорієнтація + тремор → алкогольний делірій → СМП
```

## §7 — Applied to coaching (DETECTIVE FM)

Юрій-Детектив працює з клієнтами у коучинговій рамці. L6 дає **7 actionable правил** для розпізнавання феноменологічних маркерів і коректного делегування:

### 7.1. Сенестопатії як ред-флаг — телефон спеціаліста одразу

Якщо клієнт описує **глибокі, незрозумілі, постійні відчуття у внутрішніх органах без соматичного діагнозу** ([C-006-014, 015]) — це психіатрична зона.

**4 «НЕ» перевірочних питання**:

1. «Це відчуття — на щось схоже з твого досвіду чи зовсім нове?» (НЕзвичайне?)
2. «Воно приємне, нейтральне чи погане?» (НЕприємне?)
3. «Воно приходить-уходить чи тримається?» (НЕвідступне?)
4. «Тебе вже обстежував терапевт/гастро/кардіолог — нічого не знайшли?» (НЕвластива локалізація соматичного захворювання?)

Якщо ≥3 «так» — НЕ працювати з цим у коучингу. Це може бути:

- Шизофренія з продуктивними симптомами (сенестопатії — частий дебют)
- Депресія з соматизацією
- Соматоформний розлад

**Фраза для клієнта**: «Те, що ти описуєш — це не невроз, це феномен, який потребує психіатричної оцінки. Я не лікар, але я знаю мапу — і ця мапа каже „спочатку психіатр“. Можу підготувати тебе до візиту».

### 7.2. Парестезії — невропатолог, не коуч

Якщо клієнт описує **поверхневі, локалізовані шкірні відчуття** (поколювання, мурашки, оніміння) [C-006-013] — це **невропатологічна зона**. Можливі причини:

- Радикуліти (защемлення нерва)
- Полінейропатії (діабетичні, алкогольні, дефіцит B12)
- Розсіяний склероз (раннє начало)
- Тунельні синдроми

**Скрипт**: «Ці мурашки — конкретно у якій частині руки/ноги? Постійно чи тимчасово? Не падає чутливість, коли натискаєш у одне місце? Тобі треба до невропатолога — це не моя зона. Як виключать неврологію — можна повертатись до коучингу».

### 7.3. Метаморфопсії — мігрень або епілепсія

Якщо клієнт описує **зміни розмірів/форм предметів** («все навколо стало велике / маленьке») [C-006-016 → 022] — це може бути:

- **Мігрень з аурою** (синдром Аліси у Країні Чудес перед мігренозним нападом)
- **Скронева епілепсія** (метаморфопсії + інші аури)
- **Інтоксикації** (наркотики, ЛСД)
- **Вірусні інфекції у дітей** (доброякісний синдром Аліси)

**Скрипт**: «Це буває після / перед головним болем? Часто? Скільки триває? Куди дивишся, що сприймається змінено? Це не до коуча — це до невропатолога з обстеженням ЕЕГ + МРТ».

### 7.4. Гіпнагогічні — норма vs патологія

Клієнт каже «у мене дивні видіння при засипанні» [C-006-050, 051]:

**Норма**:

- Тільки при засинанні / пробудженні
- Швидко минають
- Критика збережена («я знаю що це сон підкрадається»)
- Контекст втоми / недосипу
- Не страшні, не мотивують до дій

**Скрипт «норма»**: «Це гіпнагогічні галюцинації — норма у виснаженого мозку. Поспи стабільно тиждень — побачимо, чи зникнуть. Якщо лишаться + з'являться інші симптоми (запаморочення, провали свідомості, паралічі сну) — до невропатолога».

**Патологія**:

- Яскраві, з страхом, мотивують до дій
- Денна сонливість + катаплексія + паралічі сну → **нарколепсія** (невропатолог)
- Поза контекстом засинання → можливі продуктивні симптоми психозу

### 7.5. Шарль Бонне — у літніх з катарактою/глухотою — норма

Якщо клієнт **літній з втратою зору або слуху** описує яскраві образи/звуки, але **з критикою** («бачила як дівчина іде вздовж паркану, знаю що це ілюзія») [C-006-057] — це **синдром Шарля Бонне**, **дозволена психотика у здорових**.

**Скрипт**: «Це феномен Шарля Бонне — нормальна реакція мозку на сенсорну депривацію. Мозок „заповнює порожнечу“ старими образами. Це не психоз, не деменція. Проста рекомендація — посилити сенсорну стимуляцію (краще освітлення, чіткіші окуляри, гучніший слуховий апарат). Якщо це турбує — психіатр може коротко призначити малі дози антипсихотика».

### 7.6. Як питати «голос у голові чи зовні» — Кандинський flow ⭐

Це **найважливіший питальник з усього уроку**. Якщо клієнт каже «я чую голоси» — НЕ панікувати, а пройти Кандинський flow [C-006-047, 048]:

```
Q1: «Ці голоси — як ти їх чуєш? Розкажи деталі»

Q2: «Вони у тебе у голові, чи звідкись з кімнати / з-за стіни / зовні?»
   → «У голові, всередині» → ПСЕВДОГАЛЮЦИНАЦІЯ → шизофренія імовірна
   → «Звідкись зовні, з конкретного місця» → ІСТИННА → екзогенно-органічна
   → «Не знаю, неясно» → уточнити

Q3: «Що вони кажуть? Тобі чи про тебе? Накази?»
   → Накази «зроби це» → ІМПЕРАТИВНІ → НЕГАЙНА госпіталізація
   → Коментарії «він іде, він сів» → коментуючі → шизофренія (синдром Кандинського-Клерамбо)
   → Антагоністичні (одні за, інші проти) → шизофренія
   → Прості оклики / мелодії → можливо органічна або галюциноз

Q4: «Це безперервно чи епізодично? Як давно?»
   → Стійко >1 міс → психіатрія невідкладно
   → Гостро + з тремором / дезорієнтацією → СМП (можливий делірій)

Q5: «Ти можеш їх керувати? „Вимикати“?»
   → Ні (відсутність довільної мінливості) → класична галюцинація
   → Так (керує) → можливо уявлення з підвищеною яскравістю / магічне мислення
```

**Червоні прапори для НЕГАЙНОЇ дії**:

- Імперативні голоси → 112 / госпіталізація
- Голос «у голові», стійко, > 1 міс → психіатр невідкладно
- Гостре начало + дезорієнтація → СМП (можливо делірій / енцефаліт)

### 7.7. Парейдолії клієнта — OK creativity; парейдолії + страх — делегувати

Клієнт каже «я бачу в малюнку шпалер чудовиськ» [C-006-032]:

**Норма** (творча уява, face pareidolia):

- Бачить періодично, легко перемикається
- Образи нейтральні / гумористичні
- Критика збережена («це ж я фантазую»)
- Не порушує функціонування
- **Дія коуча**: похвалити креативність, не патологізувати

**Патологія** (стійкі парейдолії, психоз або делірій):

- Бачить постійно, не може перемикатись
- Образи страшні, загрозливі
- Критика втрачена («це справді чудовиська»)
- Тривога, страх, поведінкові зміни
- Стійкий феномен > 2 тижні
- **Дія коуча**: делегувати психіатру

**Скрипт перевірки**: «А якщо я подивлюсь на цю саму шпалеру — я побачу те саме? Чи це тільки тобі видно? Ти можеш переключитись і знов побачити шпалеру нейтрально? Тебе ці образи тривожать чи це просто гра уяви?»

## §8 — Key facts чек-ліст для тесту

1. **Відчуття** [C-006-003] = найпростіший психологічний акт, відображає окремі властивості предметів через аналізатори
2. **Сприйняття** [C-006-004] = цілісне відображення + синтез з минулим досвідом (уявленням)
3. **Уявлення** [C-006-005] = пожвавлення образів минулого, сліди колишніх відчуттів; не проектується у зовнішній простір
4. **7 типів порушень відчуттів** [C-006-009..015]: гіпестезія, анестезія, агнозія, гіперестезія, парестезія, **сенестопатія**, метаморфопсія
5. **Сенестопатії — 4 «НЕ»** [C-006-015]: **НЕзвичайні + НЕприємні + НЕвідступні + НЕвластива локалізація соматичного захворювання** — це QUIZ Q1 курсу
6. **Метаморфопсії** [C-006-016..020]: спотворення форми/розміру РЕАЛЬНИХ предметів **з критикою**; підвиди — дисморфопсії / макропсії / мікропсії / порушення схеми тіла
7. **Аліса у Країні Чудес** [C-006-021] — комплекс метаморфопсій + порушень схеми тіла (мігрень, епілепсія)
8. **Антоні Гауді** [C-006-022] — контрприклад: спотворення форми як мистецтво ≠ метаморфопсія
9. **Ілюзії vs метаморфопсії** [C-006-023]: ілюзія = змінений ЗМІСТ (об'єкт сприймається як інший); метаморфопсія = змінена ФОРМА (об'єкт впізнається коректно)
10. **3 механізми ілюзій** [C-006-026..029]: фізичні (поза людиною), фізіологічні (аналізатор), психічні (психіка)
11. **3 підтипи психічних ілюзій** [C-006-029..032]: афективні / вербальні / парейдолічні (НЕ 4 — recon TOC помилково додавав «вероятні»)
12. **Парейдолії у літературі** [C-006-033]: Гете «Erlkönig» / «Лісовий упир»
13. **Галюцинації** [C-006-034]: уявне сприйняття БЕЗ реального подразника; на відміну від ілюзії (реальний об'єкт є)
14. **Теорія Попова** [C-006-035]: фазно-гальмівна теорія — патоморфологічна основа галюцинацій (зрівняльна + парадоксальна фази позамежного гальмування)
15. **6 модальностей галюцинацій** [C-006-036..044]: зорові / слухові / нюхові / смакові / тактильні / вісцеральні
16. **Етіологія за модальністю** [C-006-037, 040, 041, 042]:
    - Зорові → екзогенно-органічна патологія (алкоголь, інтоксикація)
    - Слухові → ендогенне (шизофренія)
    - Нюхові → скронева епілепсія (uncinate seizure)
    - Смакові (присмак отрути) → **онкологічний ред-флаг** (МРТ мозку)
    - Тактильні (волоси на язику) → сурогати алкоголю, важкі метали
17. **Імперативні голоси** [C-006-039] — наказують зробити щось → **клінічна небезпека** (вбити, підпалити) → негайна госпіталізація
18. **Антагоністичні голоси** [C-006-038] — одні добрі, інші злі → шизофренія (корелює з афективною амбівалентністю L3)
19. **Прості vs складні галюцинації** [C-006-045, 046]: прості = фотопсії / акоазми (без змісту); складні = образи / сцени / діалоги
20. **Істинні vs псевдогалюцинації — КЛЮЧОВЕ** [C-006-047, 048]:
    - Істинні = ВСІ властивості сприйняття (жвавість + **екстрапроекція** + неуправляність) → почуття реальності
    - Псевдогалюцинації Кандинського = НЕМАЄ ЕКСТРАПРОЕКЦІЇ → голоси «у голові», образи «внутрішнім оком» → шизофренія
21. **В.Х. Кандинський (1849–1889)** [C-006-049] — рос. психіатр, описав псевдогалюцинації на основі власного психотичного досвіду
22. **Гіпнагогічні** [C-006-050] = при засинанні, при закритих очах; **можуть бути у здорових при виснаженні**
23. **Гіпнопомпічні** [C-006-051] = при пробудженні; значно рідше
24. **Екстракампінні** [C-006-052] = поза полем зору («бачу за спиною без повороту голови»)
25. **Функціональні** [C-006-053] = паралельно з реальним подразником (шум води + голоси у воді — обидва є). На відміну від вербальної ілюзії, де шум води ЗАМІНЯЄТЬСЯ голосами
26. **Рефлекторні** [C-006-054] = реальний подразник переноситься в інше місце (веретено у руці → дзижчить у серці)
27. **Навіяні** [C-006-055] = індуковані гіпносуггестією
28. **Негативні галюцинації** [C-006-056] = відсутність сприйняття реально існуючих предметів
29. **Синдром Шарля Бонне** [C-006-057]: у психічно ЗДОРОВИХ з втратою зору/слуху + критика збережена; sensory deprivation → мозок «заповнює»
30. **Фантом** [C-006-058]: у ампутованих — наявність кінцівки + біль; критика збережена
31. **4 методи дослідження** [C-006-061..065]:
    - **Ліпман** — натискання на очні яблука (алкогольний делірій)
    - **Рігер-Рейхардт** — чистий аркуш + просьба прочитати (навіяні)
    - **Бехтерев** — метроном (алкогольний галюциноз)
    - **Ашаффенбург** — відключений телефон (слухові)
32. **«Психіатрія — наука спостереження»** [C-006-060]: габітус + поведінкові маркери — фундамент діагностики
33. **«Як детектив розгадати»** [C-006-043]: модальність + характер + супутні симптоми = диференційно-діагностичний ключ

## §9 — Mnemonic devices for the exam

### 9.1. «4 НЕ» сенестопатій — Quiz Q1

```
Незвичайні + Неприємні + Невідступні + Невластива локалізація
```

Це **4 «НЕ»**, які лектор сама пропонує. Запам'ятай як скоромовку.

| Літера | Порушення        | 1 факт                              |
| ------ | ---------------- | ----------------------------------- |
| **Г**  | Гіпестезія       | зниження інтенсивності              |

### 9.3. «3 механізми ілюзій» — ФФП

| **Н**  | Нюхові      | епілепсія (uncinate)      |
| **С**  | Смакові     | **ОНКО** ред-флаг         |
| **Т**  | Тактильні   | сурогати, метали          |
| **В**  | Вісцеральні | сенестопатичний галюциноз |

### 9.5. «Кандинський — голос у голові» ⭐

**Один питальник**: «Голос у тебе **у голові**, чи **з кімнати**?»

- У голові → **Кандинський (псевдогалюцинація)** → шизофренія
- З кімнати → **істинна** → екзогенна (делірій, енцефаліт)

### 9.6. «4 методи дослідження» — ЛРБА

- **Л**іпман → очні яблука → алкоголь делірій
- **Р**ігер-Рейхардт → чистий аркуш → навіяні
- **Б**ехтерев → метроном → алкоголь галюциноз
- **А**шаффенбург → відключений телефон → слухові

### 9.7. «Особливі види — норма/патологія матриця»

| Тип          | Норма?                    |
| ------------ | ------------------------- |
| Гіпнагогічні | ✅ виснажені здорові      |

### 9.8. «3 ознаки істинних» — ЕЖН

- **Е**кстрапроекція (зовні)
- **Ж**вавість (яскравість)
- **Н**еуправляність (немає довільної мінливості)

При відсутності хоч однієї → псевдогалюцинація.

8. **Змії під ліжком** = алкоголь делірій
9. **Чоловічки на звивинах мозку** = Кандинський
