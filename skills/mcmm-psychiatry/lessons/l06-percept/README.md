## Key claims (top 15 — пріоритет для тесту)

1. **Сенестопатії — 4 «НЕ»** [C-006-015] = **НЕзвичайні + НЕприємні + НЕвідступні + НЕвластива локалізація соматичного захворювання**. Це **QUIZ Q1 курсу** (за recon)
2. **Сенестопатія vs синестезія** [C-006-014]: КРИТИЧНА термінологічна різниця — сенестопатія = патологія внутрішнього органа без органічного субстрату; синестезія = крос-модальне сприйняття (норма)
3. **Метаморфопсії** [C-006-016..020]: спотворення форми/розміру РЕАЛЬНИХ предметів **з критикою**; підвиди — дисморфопсії / макропсії / мікропсії / порушення схеми тіла + Аліса у Країні Чудес [C-006-021]
4. **Ілюзії vs метаморфопсії** [C-006-023]: ілюзія = змінений ЗМІСТ (об'єкт сприймається як інший); метаморфопсія = змінена ФОРМА (об'єкт впізнається коректно)
5. **3 механізми ілюзій** [C-006-026..029]: фізичні (оптика) + фізіологічні (аналізатор) + психічні (психіка)
6. **3 підтипи психічних ілюзій** [C-006-030..032]: афективні / вербальні / парейдолічні (НЕ 4 — recon TOC помилково додавав «вероятні»)
7. **Галюцинації** [C-006-034]: уявне сприйняття БЕЗ реального подразника; на відміну від ілюзії
8. **Теорія Попова** [C-006-035]: фазно-гальмівна теорія — патоморфологічна основа галюцинацій
9. **6 модальностей галюцинацій** [C-006-036..044]: зорові / слухові / нюхові / смакові / тактильні / вісцеральні
10. **Етіологія за модальністю** [C-006-037, 040, 041, 042]:
    - Зорові → екзогенно-органічна (алкоголь, інтоксикація, делірій)
    - Слухові → ендогенне (шизофренія)
    - Нюхові → скронева епілепсія (uncinate seizure)
    - Смакові присмак отрути → **онкологічний ред-флаг** (МРТ мозку)
    - Тактильні «волоси на язику» → сурогати алкоголю, важкі метали
11. **Імперативні голоси** [C-006-039] — наказують → **клінічна небезпека** → негайна госпіталізація
12. **Істинні vs псевдогалюцинації Кандинського — КЛЮЧОВЕ** [C-006-047, 048]:
    - Істинні = всі властивості сприйняття (жвавість + **екстрапроекція** + неуправляність)
    - Псевдогалюцинації = НЕМАЄ ЕКСТРАПРОЕКЦІЇ → голоси «у голові» → шизофренія
13. **В.Х. Кандинський (1849–1889)** [C-006-049] — рос. психіатр, описав псевдогалюцинації на основі власного психотичного досвіду; не плутати з художником Василем Кандинським (родич)
14. **Особливі види норма-патологія** [C-006-050, 057, 058]: гіпнагогічні + синдром Шарля Бонне + фантом — «дозволена психотика» у психічно здорових
15. **4 методи дослідження** [C-006-061..065]: **Ліпман** (очні яблука / алкогольний делірій) + **Рігер-Рейхардт** (чистий аркуш / навіяні) + **Бехтерев** (метроном / алкогольний галюциноз) + **Ашаффенбург** (відключений телефон / слухові)

## Coaching application (DETECTIVE FM)

7 actionable правил для Юрія-Детектива (детально у `synthesis.md` §7):

1. **Сенестопатії як ред-флаг** — 4 «НЕ» перевірочний питальник → психіатр одразу (не коучинг)
2. **Парестезії — невропатолог**, не коуч (радикуліти, нейропатії, можливо РС)
3. **Метаморфопсії — мігрень або епілепсія** → невропатолог + ЕЕГ/МРТ
4. **Гіпнагогічні норма vs патологія** — при засинанні + критика + швидко минають = норма; з страхом + катаплексією = нарколепсія
5. **Шарль Бонне у літніх з катарактою/глухотою** — норма; рекомендація — посилити сенсорну стимуляцію
6. **Кандинський flow ⭐** — «Голос у тебе **у голові** чи **з кімнати**?» — найважливіший питальник; визначає шизофренію vs екзогенно-органічну
7. **Парейдолії клієнта** — OK creativity з критикою; парейдолії + страх + втрата критики → психіатр

**Червоні прапори для НЕГАЙНОЇ дії**:

- **Імперативні голоси («вбий, підпали»)** → 112 / госпіталізація
- **Голос «у голові», стійко > 1 міс** → психіатр невідкладно
- **Гостре начало + дезорієнтація + тремор** → СМП (можливий делірій)
- **Смак отрути + втрата ваги + головний біль** → МРТ головного мозку
