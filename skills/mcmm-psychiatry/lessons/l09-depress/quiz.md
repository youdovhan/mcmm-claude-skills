### P1 — Анатомо-фізіологічний субстрат депресії

**Q**: Що є анатомо-фізіологічним субстратом емоційного реагування, активність якого змінюється при депресії?

**Варіанти**:

1. Кора великих півкуль (лобна частка)
2. Базальні ганглії
3. **Лімбіко-ретикулярні структури мозку**
4. Мозочок
5. Стовбур мозку

**Correct**: 3 (Лімбіко-ретикулярні структури)

**Пояснення**: За claim [C-009-013] / [C-009-014] / slide 3: «**Субстратом емоційного реагування є лімбіко-ретикулярні структури мозку. При депресії під впливом вищеперечисних факторів активність лімбіко-ретикулярного комплексу змінюється, що клінічно проявляється депресивним розстрійством**».

**Декомпозиція**:

- **Лімбічна система** (cingulate / amygdala / hippocampus / hypothalamus / nucleus accumbens) — генератор емоційних реакцій
- **Ретикулярна формація** (ретикулярна активуюча система) — модулятор активаційного тонусу
- **Лімбіко-ретикулярний комплекс** = функціональна єдність: емоції × активація
- **Зміна активності** комплексу — це **функціональне (не структурне) порушення**

**Нейромедіаторний рівень** [C-009-015]: дефіцит **серотоніну** (5-HT) + дизрегуляція **норадреналіну** (NA). Це **класична моноамінова гіпотеза** Schildkraut 1965 / Coppen 1967. SSRI/SNRI targets directly. Cross-ref L2.

**Differential з шизо (cross-ref L7)**: при шизо — **дофамінова hypothesis** (мезолімб ↑ продуктивні / мезокорт ↓ негативні). При depression — **моноаміни ↓** (5-HT/NA). Це два різних нейрохімічних profilе.

**Coaching implication**: коли клієнт каже «у мене депресія» — м'яке уточнення про **біологічну природу**: це не «лінь», а **функціональне порушення лімбіко-ретикулярних структур + дефіцит моноамінів**. Frame для anti-stigma.

**Source**: C-009-013, C-009-014, C-009-015 / transcript [02:00] / slide 3

### P2 — 2+2+2 правило діагностики МКБ-10

**Q**: Який критерій діагностики депресії за МКБ-10 (правило 2+2+2)?

**Варіанти**:

1. 3 основні + 5 додаткових + 1 місяць
2. **≥ 2 основних + ≥ 2 додаткових + ≥ 2 тижні**
3. 1 основний + 6 додаткових + 6 тижнів
4. 4 основних + 4 додаткових + 4 тижні
5. 5 основних + 0 додаткових + 1 тиждень

**Correct**: 2 (≥ 2 основних + ≥ 2 додаткових + ≥ 2 тижні)

**Пояснення**: За claim [C-009-029] / slide 5: «А наличність депресивного розстрійства можна говорити, коли є **як мінімум два основних і мінімум два доповнених симптоми в течію мінімум останніх двох тижнів**».

**3 основні симптоми** [C-009-027]:

1. **Знижений, пригнічений настрій** (depressed mood)
2. **Втрата інтересу та чувства задоволення** (anhedonia)
3. **Підвищена втомлюваність, втрата енергії, зниження активності** (fatigue / anergy)

**7 додаткових симптомів** [C-009-028]:

1. Знижена самооцінка та невпевненість у собі
2. Труднощі концентрації та уваги
3. Ідеї провини та неповноцінності
4. Ажітація або загальмованість (psychomotor agitation OR retardation)
5. Порушення сну
6. Втрата апетиту
7. Суїцидальні думки та спроби

**Severity grading** (не з транскрипту, але класично):

- **F32.0 легкий** — 2 основні + 2 додаткові
- **F32.1 помірний** — 2 основні + 3-4 додаткові
- **F32.2 тяжкий без психотики** — 3 основні + 4+ додаткові
- **F32.3 тяжкий з психотикою** — F32.2 + маячня самозвинувачення/гріховності/Котара

**Cross-ref до DSM-5** [C-009-134]: паралельна система — 9 критеріїв, ≥ 5 з ≥ 1 будучи anhedonia або depressed mood + ≥ 2 тижні. **МКБ-10 і DSM-5 в основі ідентичні**.

**Coaching implication**: **2+2+2** — це **швидкий чек-лист** для коуча. Запитуй послідовно: настрій (1), задоволення / интерес (2), енергія (3). Якщо ≥ 2 — додаткові. Якщо ≥ 2 + ≥ 2 тижні → **mandatory referral**.

**Source**: C-009-027, C-009-028, C-009-029 / transcript [04:30-05:30] / slide 5

### P3 — Тріада Крепеліна (-) у депресії

**Q**: Які три компоненти класичної депресивної тріади (тріади Крепеліна зі знаком мінус)?

**Варіанти**:

1. Тривога + страх + панічні атаки
2. Манія + гіпоманія + ейфорія
3. **Гіпотимія + брадифренія + брадикінезія** (пригнічений настрій + уповільнене мислення + рухова загальмованість)
4. Маячня + псевдогалюцинації + ілюзії
5. Деперсоналізація + дереалізація + флешбеки

**Correct**: 3 (Гіпотимія + Брадифренія + Брадикінезія)

**Пояснення**: За claim [C-009-016] / slide 4: «Клінічна картина характеризується **депресивною тріадою**: пригніченим, сумним, тужливим настроєм, **уповільненням мислення** та **руховою загальмованістю**».

**Декомпозиція**:

| Компонент        | Опис                                                                                 | Об'єктивний маркер                                             | Claim                |
| ---------------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------------- | -------------------- |
| **Гіпотимія**    | Пригнічений / тужливий настрій, від легкої пригніченості до глибокої туги, вітальної | Скорботна міміка, сум                                          | C-009-016, C-009-017 |
| **Брадифренія**  | Уповільнення асоціативного процесу, збідніння мислення, мало думок, повільне течія   | Односкладові відповіді + довгі паузи між питанням і відповіддю | C-009-020, C-009-022 |
| **Брадикінезія** | Рухова загальмованість, тиха повільна мова, скорботна міміка, одноманітні рухи       | Може досягати **депресивного ступору** [C-009-025]             | C-009-023, C-009-024 |

**Symmetry argument**:

- **L7 (шизо)**: симптоматична тріада **Bleuler 4A** — асоціації / афект / амбівалентність / автизм
- **L8 (манія)**: тріада Крепеліна **(+)** — гіпертимія + тахіфренія + гіперкінезія
- **L9 (депресія)**: тріада Крепеліна **(-)** — гіпотимія + брадифренія + брадикінезія

Це foundation для розуміння **БАР** (L8): пацієнт перетікає між (+) і (-) полюсами.

**Когнітивна тріада Бека (related)** [C-009-019]: темне сприйняття **минулого + теперішнього + майбутнього**. Beck 1976 — negative view of self / world / future.

**Coaching implication**: коли клієнт сидить «скорботно», говорить тихо, відповідає односложно з паузами — це **об'єктивна тріада**. Якщо вона тримається 2+ тижнів — clinical depression.

**Source**: C-009-016 → C-009-025 / transcript [03:00-04:30] / slide 4

### P4 — Anaesthesia psychica dolorosa (вітальна туга, найважчий маркер)

**Q**: Що таке «вітальна туга» (anaesthesia psychica dolorosa) у депресії, і чому це важливий маркер?

**Варіанти**:

1. Звичайний сум у відповідь на втрату
2. Тривога з панічними атаками
3. **Соматизована меланхолійна туга з відчуттям тяжкості, болю у грудях, безперспективності + болісної анестезії емоцій («не можу нічого відчувати, і це болить») — класичний маркер ендогенної депресії з високим суїцидальним ризиком**
4. Гіперреактивність на негативні події
5. Ангедонія легкого ступеня

**Correct**: 3 (Соматизована меланхолійна туга + болісна анестезія + high suicide risk)

**Пояснення**: За claim [C-009-018] / [C-009-138]: «**глибокої тоски, при якій хворі спитують тяжкість, болю в груді, безперспективність, нічтожність (правильно: нікчемність) існування**».

**Вітальна туга** — це **соматизована меланхолійна туга** з:

- Фізичним відчуттям **тяжкості у грудях**
- **Болю у передсердцевій ділянці**
- **Безперспективністю** (cognitive)
- **Нікчемністю існування** (cognitive)

**Anaesthesia psychica dolorosa** (Esquirol 1838, далі Krepelin) — **болісна психічна анестезія**:

- Пацієнт скаржиться що **«нічого не може відчувати»**
- **«Я мертвий усередині»**
- **«Не плачу, коли треба, бо немає сліз»**
- **«Не люблю дітей, і це жахливо»**
- АЛЕ цей anhedonic numbness **сам болить**, причиняє страждання

**Парадокс**: «не можу нічого відчути, і це болить».

**Phenomenology**: пацієнт втрачає здатність плакати у відповідних ситуаціях (на похороні близького), не реагує на смішне, не відчуває любові до дітей. Це **anhedonia глибокого рівня**.

**Diff від плоского афекту шизо**: при шизо — це **отстороненість**, без суб'єктивного страждання. При anaesthesia psychica — **сам анестезичний стан причиняє біль**.

**Клінічна значимість**:

- **Класична ознака ендогенної melancholic depression** (DSM-5 «with melancholic features»)
- **Сильний suicide predictor** — у комбінації з hopelessness
- **ECT-показання** часто розглядається
- **Immediate referral** до психіатра

**Coaching implication**: коли клієнт каже «я не можу нічого відчути, я як кам'яний, я мертвий усередині» — це **класична anaesthesia psychica dolorosa**, **immediate referral**.

**Source**: C-009-018, C-009-138 / transcript [03:00-03:30] / slide 4

### P5 — Маскована (соматизована) депресія: 3 типи масок

**Q**: Які 3 основні типи масок маскованої (соматизованої) депресії?

**Варіанти**:

1. Дитяча / підліткова / стареча
2. Гостра / хронічна / латентна
3. **Біоритмова (безсоння/гіперсомнія) + Вегето-соматизована (ВСД, кардіоневроз, СПК) + Алгійна (цефалгія, кардіалгія, фіброміалгія)**
4. Чоловіча / жіноча / дитяча
5. Зимова / літня / весняна

**Correct**: 3 (Біоритмова + Вегето-соматизована + Алгійна)

**Пояснення**: За claims [C-009-034, C-009-035, C-009-036, C-009-038] / slide 6:

**Маска 1: Біоритмова** [C-009-035] — порушення біологічного ритму:

- **Безсоння** (insomnia) — особливо early morning awakening при ендогенній
- **Гіперсомнія** — спить 10+ годин, але не відпочиває (atypical депресія)

**Маска 2: Вегето-соматизована** [C-009-036, C-009-037]:

- **Синдром вегето-судинної дистонії** (ВСД)
- **Синдром гіпервентиляції**
- **Кардіоневроз** (постійні болі в серці)
- **Синдром подразненої кишки** (СПК)
- Нейродерміт, кожний свербіж
- Анорексія, булімія
- Імпотенція, порушення менструального циклу

**Маска 3: Алгійна (больова)** [C-009-038]:

- **Цефалгія** (головні болі)
- **Кардіалгія** (болі в серці)
- **Абдоміналгія** (болі в животі)
- **Фіброміалгія**
- Невралгії (трійчастий, лицьовий, міжреберна)
- Попереково-крижовий радикуліт, спондіалгія
- Псевдоревматичні артралгії

**Концепція** [C-009-034]: маскована депресія — це варіант, де **емоційний компонент мінімальний**, а **превалюють соматовегетативні скарги**. Пацієнт ходить роками по терапевтах, ендокринологах, кардіологах — нічого не знаходять. Тому «доctor shopping» — diagnostic clue.

**7 diagnostic clues** [C-009-039..044]: ранкове максимум переживань + поліморфізм + negative work-up + розлад вітальних функцій + сезонність (весна/осінь) + doctor shopping + відсутність ефекту від соматичної терапії.

**Therapeutic trial як diagnostic test**: пробний курс SSRI 4-6 тижнів. Якщо вегетативно-соматичні скарги зникають — diagnosis confirmed (depression unmasked).

**Coaching pearl**: якщо клієнт скаржиться на «втому + головні болі + проблеми зі сном + lit's worse mornings + ходив до 3 лікарів — нічого не знайшли» — **класична маскована депресія**.

**Source**: C-009-034..044 / transcript [06:30-09:00] / slide 6

**Q**: Скільки груп антидепресантів існує в арсеналі лікаря-психіатра, за класифікацією, поданою у лекції?

2. 5 груп
3. **8 груп**
4. 12 груп
5. 15 груп

**Correct**: 3 (8 груп)

**Пояснення**: За claim [C-009-050] / slide 7: «**В арсеналі лікарів в настояще часу знаходяться 8 груп антидепресантів**, різних за механізмом дій і даючих можливість ефективно лікувати пацієнтів з різними варіантами депресії».

**8 груп** (стандартна класифікація):

| #   | Група                | Приклади                                                                                        | Механізм                                                    |
| --- | -------------------- | ----------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| 1   | **SSRI**             | Флуоксетин (Prozac), сертралін (Zoloft), есциталопрам (Lexapro), пароксетин (Paxil), циталопрам | Селективні інгібітори зворотного захоплення серотоніну      |
| 2   | **SNRI**             | Венлафаксин (Effexor), дулоксетин (Cymbalta), мілнаципран                                       | Інгібітори зворотного захоплення серотоніну і норадреналіну |
| 3   | **ТЦА (Tricyclic)**  | Амітриптилін, іміпрамін, кломіпрамін, нортриптилін                                              | Multi-receptor блокада, ефективні, але більше побічних      |
| 4   | **MAO Inhibitors**   | Моклобемід (reversible); фенелзін, транилципромін (irreversible)                                | Блокада моноаміноксидази → ↑ моноаміни                      |
| 5   | **Тетрациклічні**    | Мапротилін, міансерин                                                                           | Подібні до TCA, але вибірковіші                             |
| 6   | **NaSSA**            | Міртазапін (Remeron)                                                                            | Норадренергічні + специфічні серотонінергічні               |
| 7   | **SARI**             | Тразодон, нефазодон                                                                             | Серотонін антагоністи + reuptake inhibitors                 |
| 8   | **Atypical / Other** | Бупропіон/Wellbutrin (NDRI), агомелатин (melatonergic), вортіоксетин (multimodal)               | Різні унікальні механізми                                   |

**4 frontline групи** [C-009-051]:

1. **SSRI** — first-line у 80% випадків
2. **SNRI** — для anxiety / pain comorbidity
3. **Mixed mechanism** — міртазапін (NaSSA), тразодон (SARI) — особливо при insomnia
4. **Мелатонінергіки + 5-HT antagonists** — агомелатин (циркадні), вортіоксетин (cognitive symptoms)

**Critical pharmacological facts**:

- **Latency to response** [C-009-052]: 1-2 тижні до відчутного ефекту (на практиці часто 2-4 тижні). **Window of suicidality risk** — перші 1-3 тижні
- **No addiction** [C-009-053]: фізична залежність відсутня, але **withdrawal syndrome** при різкій відміні (особливо пароксетин, венлафаксин)
- **Tolerability модерних АД** значно краща за ТЦА [C-009-049]
- **Prescribe + discontinue ONLY by psychiatrist** [C-009-048]

**Cross-ref до L14**: детальний розбір механізмів, побічних, інтеракцій.

**Source**: C-009-050, C-009-051, C-009-052, C-009-053 / transcript [09:30-11:00] / slide 7

### P7 — Психотична депресія + синдром Котара

**Q**: Які особливості психотичного варіанту депресивного синдрому (F32.3)?

**Варіанти**:

1. Тривога з нав'язливими думками
2. Маячня переслідування + псевдогалюцинації-коментатори
3. **Маячня самозвинувачення, самознищення, гріховності, винності (mood-congruent) — може включати синдром Котара (нігілістичне марення заперечення існування); часто веде до суїциду; показання до ECT**
4. Деперсоналізація з розщепленням особи
5. Ехо-симптоми + кататонічна феноменологія

**Correct**: 3 (Маячня вини/гріховності + Котара + ECT)

**Пояснення**: За claim [C-009-026] / slide 4 / [C-009-143]: «Для **психотичного варіанту депресивного синдрому** характерні **бредові ідеї самообвинення, самоуничтоження, гріховності, виновності**, які теж можуть приводити до думки про самоубійство».

**Психотична депресія (F32.3)**:

- **Mood-congruent delusions** — маячня збігається з пригніченим настроєм
- **Темы маячні**:
  - Самозвинувачення («я нікчемний, винний у нещастях інших»)
  - Гріховність («я великий грішник, мене покарають»)
  - Винність («через мене страждають всі»)
  - Збідніння / руїну («я / моя сім'я в нужді, помру з голоду»)
  - **Котара (нігілістична)** [C-009-143]: «у мене немає органів, немає душі, я вже мертвий, світ не існує»
- **Mood-congruent hallucinations**: голоси-обвинувачі («ти грішник», «ти заслужив»)

**Синдром Котара** (Cotard's syndrome) — детально у L6:

- **Нігілістичне марення** — заперечення existence власних органів, тіла, душі, світу
- Описаний Жулесом Котара 1880
- Класично associated з severe melancholia + іноді schizoaffective disorder
- ECT — найшвидший response

**Differential з шизо (cross-ref L7)**:

| Ознака         | Психотична депресія (F32.3)          | Шизо параноїдна                            |
| -------------- | ------------------------------------ | ------------------------------------------ |
| Mood           | Глибоко пригнічений                  | Може бути нейтральним, інконгруентним      |
| Delusions      | Mood-congruent (вина, гріх, Котара)  | Mood-incongruent (переслідування, впливу)  |
| Hallucinations | Mood-congruent голоси (звинувачують) | Mood-incongruent (коментуючі, імперативні) |
| Treatment      | AD + antipsychotic + ECT             | Antipsychotics first-line                  |
| Course         | Episodic з повними ремісіями         | Chronic-progredient частіше                |
| Anosognosia    | Не характерна                        | Класична [L7]                              |

**Treatment**:

- **AD + antipsychotic combination** (olanzapine-fluoxetine combo, або quetiapine, або aripiprazole)
- **ECT** — gold standard, найшвидший ефект (1-3 тижні)
- **Lithium augmentation** при resistant
- **Hospitalization** через high suicide risk

**Coaching pearl**: при описі клієнтом ідей вини / гріховності / нікчемності у комбінації з пригніченим настроєм + 2+2+2 → **immediate referral** до психіатра. Це **не зона коучингу**.

**Source**: C-009-026, C-009-143 / transcript [04:00-04:30] / slide 4

### P8 — Differential депресія vs БАР (критичне)

**Q**: Чому критично важливо перед призначенням антидепресанту відрізнити уніполярну депресію від депресивної фази біполярного афективного розладу (БАР)?

**Варіанти**:

1. Це не важливо, антидепресанти діють однаково
2. БАР краще реагує на психотерапію
3. **Антидепресант solo у пацієнта з БАР може спровокувати манію, змішаний епізод або rapid cycling; БАР-депресія потребує mood stabilizer first, AD only as adjunct**
4. Уніполярна не лікується
5. БАР не лікується

**Correct**: 3 (AD solo у БАР → induction манії; mood stabilizer first)

**Пояснення**: За claim [C-009-058] / [C-009-135] / [C-009-145] / slide 8: «существують різні види депресії. **Депресія може бути як при біполярному аффективному розстрійстві**, може бути рекурєнтною депресією...».

**Critical differential**:

| Аспект            | Уніполярна MDD (F32/F33)  | БАР-депресія (F31.3-F31.5)                      |
| ----------------- | ------------------------- | ----------------------------------------------- |
| Family history    | Heritability ~37%         | Heritability **~85%**                           |
| Mania in past     | НЕМАЄ                     | Є (≥ 1 episode in BAR I) або гіпоманія (BAR II) |
| Onset             | Пізніший (середній 25-35) | Раніший (середній 18-25)                        |
| Episodes          | Менш часті                | Часті, шорсткіші                                |
| Treatment         | AD моноtetрapija          | **Mood stabilizer FIRST**, AD adjunct           |
| AD-induced switch | Rare                      | **Часто** (особливо BAR II)                     |
| Rapid cycling     | Не характерно             | ≥ 4 episodes/рік possible                       |

**Чому критично**:

- **AD solo у BAR** = ризик **induction манії** (12-25%) або **mixed episode** (висок suicide risk!) або **rapid cycling** (резистентність до подальшого лікування)
- **BAR Type II** особливо ризикує switch (часто missed diagnosis)
- **Suicidality** при mixed episode — найвища серед усіх mood disorders

**Pre-AD screening (з L8 + поза транскриптом)** — обов'язковий перед AD:

1. Чи були в житті періоди (≥ 4-7 днів) **підвищеної енергії, мало сну (3-4 год), високого настрою, ідей грандіозності, ризикованих рішень**?
2. Чи родичі мали БАР, манію, гіперактивні цикли?
3. Чи попередні AD provokували раптову зміну стану на гіперактивний?

**Якщо ≥ 1 «так»** → подозрівати БАР → MDQ (Mood Disorder Questionnaire) + careful history → психіатр зі specialized BAR experience.

**Treatment BAR-D**:

- **Lithium** — gold standard, особливо для prevention
- **Valproate** — для mixed states
- **Lamotrigine** — особливо для BAR depression (rare AD-like efficacy)
- **Antipsychotics**: quetiapine (BAR-D specific), olanzapine, lurasidone
- **AD only as adjunct** — short-term, with mood stabilizer

**Coaching implication**: при підозрі на депресію — обов'язково запитати про **попередні періоди гіперактивності + family history БАР**. Цю інформацію передати психіатру.

**Source**: C-009-058, C-009-135, C-009-145, C-009-148 / transcript [12:00] / slide 8 / cross-ref L8

### P9 — 5 мотивів суїцидального поведіння

**Q**: Які 5 основних мотивів суїцидальної поведінки за класифікацією (Амбрумова, Тіхоненко)?

**Варіанти**:

1. Любов / страх / надія / гнів / печаль
2. **Помста / Заклик (cry for help) / Уникнення (escape) / Самопокарання / Відмова (від існування)**
3. Емоція / логіка / інстинкт / культура / релігія
4. Сім'я / робота / гроші / здоров'я / друзі
5. Минуле / теперішнє / майбутнє / вічність / небуття

**Correct**: 2 (Помста / Заклик / Уникнення / Самопокарання / Відмова)

**Пояснення**: За claims [C-009-076 → C-009-081] / slide 9: «Мотиви суцидального поведіння можуть бути абсолютно різними».

**5 мотивів**:

1. **Помста** [C-009-077] — гетероагресія трансформується в аутоагресію. Конкретна форма протесту, нанесення шкоди ворожому оточенню. Висока самооцінка, активна-агресивна позиція. «Прощальні листи з обвинуваченнями»

2. **Заклик (cry for help)** [C-009-078] — активація допомоги ззовні з метою змінити ситуацію. Позиція менш активна. Зазвичай менш леtalal, але потребують exтрено response (іноді ескалюють у completed якщо ignored)

3. **Уникнення** [C-009-079] — самоустранення від загрози (тюрма, ганьба, біль). Висока self-value vs нестерпна загроза. Самовбивство як «вихід». Типове для F32 без психотики

4. **Самопокарання** [C-009-080] — внутрішній протест. **2 варіанти**:
   - **«Від судді»** (зверху) — знищення в собі ворога (superego attack)
   - **«Від підсудного»** (знизу) — спокута вини (guilt offering)
   - Часто associated з psychotic depression з маренням вини / Котара

5. **Відмова** [C-009-081] — від existence при невиліковній хворобі. Класичний trigger — terminal illness (онкологія, ALS), тяжка інвалідність. Cross-ref rational suicide debate в bioethics. **Robin Williams** [C-009-111] — приклад motive «refusal» (діагноз Lewy body dementia)

**Phenomenology кожного мотиву** — це **diagnostic interview structure** для clinical assessment.

**Coaching pearl**: при підозрі на суїцидальність — м'яко з'ясувати **мотив** через open-ended questions. «Що б це принесло?» «Кому ти хочеш щось довести?» «Чого ти хочеш уникнути?» — це **screening для мотивації**, не «провокація».

**Source**: C-009-076 → C-009-081 / transcript [14:30-16:00] / slide 9

### P10 — 3 види суїцидальної поведінки

**Q**: Які 3 види суїцидальної поведінки виділяє лектор за плановістю і афективністю?

**Варіанти**:

1. Активна / пасивна / змішана
2. Мужча / жіноча / дитяча
3. **Істинне (planned, secrecy, isolation) + Афективне (raptus, tunnel vision, regret) + Демонстративно-шантажне (public, pre-announce, conditionally safe)**
4. Острый / хронический / латентный
5. Дома / в общественному місті / в роботі

**Correct**: 3 (Істинне + Афективне + Демонстративно-шантажне)

**Пояснення**: За claims [C-009-088 → C-009-109] / slide 10-11: «Уділяють **три види суїцидального поведіння**. Тут ви увагу, просто уважно послухайте».

**Тип 1: Істинне** [C-009-089..097]:

- **Pre-suicide**: тривалий (1 тиждень – 7 місяців) [C-009-091]
- **Average trauma duration**: 1.5 року [C-009-092]
- **Early warnings**: невнятні переживання за 1-1.5 року до спроби [C-009-093]
- **Early marker**: ранкова думка «Зачем я проснувся?» [C-009-094]
- **Internal readiness phase**: за кілька днів-тиждень допускаються думки про смерть (passive), але ще не самогубство (active) [C-009-095]
- **Безпосередньо перед**: душевний біль, безвихідь, непотрібність, виснаження [C-009-096]
- **Метод**: **ретельно спланований** [C-009-097]
- **Контекст**: **таємниця + самотність** [C-009-097]
- **«Lethal calm»**: пацієнт раптом «спокійніший» — це не покращення, а peace після прийняття рішення
- **Найбільш fatal** з 3 типів

**Тип 2: Афективне** [C-009-098..104]:

- **Pre-suicide**: короткий (хвилини, на висоті афекту) [C-009-099]
- **Тригер**: суб'єктивний крах життя в очах людини / ссора з значимою особою [C-009-101]
- **Метод**: перше потрапляюче під руку, **tunnel vision** [C-009-099]
- **Контекст**: сам, без demonstrativity [C-009-102]
- **Емоції**: душевний біль + страх + потреба у духовному контакті [C-009-100]
- **Alcohol** часто тригерує
- **Post-attempt regret**: 90% survivors не повторюють — argument for **means restriction** [C-009-103]
- **Особливість**: psychological meaning ≠ death wish [C-009-104]

**Тип 3: Демонстративно-шантажне** [C-009-105..109]:

- **Мета**: НЕ смерть, а **маніпуляція**, шантаж, тиск на відносини значимих [C-009-105]
- **Pre-suicide**: короткий (хвилини – 1 година), з сумнівами [C-009-106]
- **Емоції**: **НЕ депресивні** — образа, жаль до себе, агресія, страх. Афект НЕ глибокий [C-009-107]
- **Метод**: **умовно безпечний** (поверхневі порізи, низькі дози) [C-009-108]
- **Контекст**: **на очах у значимих** + **pre-announcement** [C-009-109]
- **Risk**: «accidental» success якщо невірно оцінив дозу або не врятували вчасно

**КРИТИЧНА differential для коуча**:

- **Істинне = lethal calm**: «спокійніший», «домовив справи», «листи» — це не покращення
- **Афективне = post-attempt regret**: argument for means restriction
- **Демонстративне ≠ безпечне**: «accidental» success — справжній суїцид «з помилки». Не списувати як «show»

**Coaching pearl**: **direct ask + клінічне assessment** при будь-якому з 3 типів. **Pre-announcement** (#3) НЕ означає «просто пугає» — це **clinical assessment indication**.

**Source**: C-009-088 → C-009-109 / transcript [17:30-20:30] / slide 10-11

### P11 — «Три Б» — корінь суїцидальної готовності

**Q**: Що означає «три Б» у контексті суїцидальної готовності?

**Варіанти**:

1. Бідність / Безробіття / Біль
2. **Безпорадність + Безсилля + Безнадія**
3. Боротьба / Біг / Бутерброд
4. Біль / Багатство / Бутель
5. Біль / Бунт / Брат

**Correct**: 2 (Безпорадність + Безсилля + Безнадія)

**Пояснення**: За claim [C-009-112] / slide 11: «**Соціальне поведіння визникає, коли життя, по суті, загнано в глухий угол**, коли визникає **чувство трьох „Б“ – безпомощність, безсилля, безнадіжність**».

**Декомпозиція**:

- **Безпорадність** (helplessness) — «нічого не можу зробити, я марний»
- **Безсилля** (powerlessness) — «не маю ресурсу, не вистачає сил»
- **Безнадія** (hopelessness) — **«це не зміниться, ніколи»** ← найсильніший single predictor suicide

**Класичні моделі**, на які мapping «3Б»:

1. **Seligman learned helplessness** (1967) — депресія = вивчена безпомічність. Експерименти з шоковими тваринами, які перестали уникати болю
2. **Beck's hopelessness theory** (1989, 1990) — **Beck Hopelessness Scale (BHS)**, 20-item scale, score ≥ 9 = significant suicide risk. Hopelessness — найсильніший single predictor completed suicide, сильніший за depression severity або diagnosis
3. **Shneidman's psychache** (1993) — біль психічної агонії; уникнення psychache мотивує суїцид

**Hopelessness ≠ depression severity**: пацієнт може мати тяжкий MDE, але якщо він зберігає **надію** («це пройде, я знаю»), suicide risk нижчий. І навпаки — менш тяжка MDE + сильна hopelessness = вищий risk.

**Coaching intervention**: НЕ «давай знайдемо позитив» (це invalidating + ефективно глухе при hopelessness). **Joining**: «розумію, зараз усе виглядає безнадійно. Я з тобою. Що було б першим маленьким кроком, якби була мінімальна можливість змін?» — і **immediate referral**.

**Therapeutic targets** для hopelessness:

- **CBT for suicide prevention** (Wenzel et al)
- **Reasons for Living Inventory** (Linehan)
- **Future-oriented imagery exercises**
- **Behavioral activation** (Lewinsohn)

**Source**: C-009-112 / transcript [21:00] / slide 11

### P12 — 7 verbatim фраз — emergency vocabulary

**Q**: Яка з наведених фраз є найвищим прямим маркером суїцидального ризику?

**Варіанти**:

1. «Мені сумно»
2. «У мене багато проблем»
3. **«Наступного понеділка мене вже не буде живих»**
4. «Мені треба відпочити»
5. «Я втомився»

**Correct**: 3 («Наступного понеділка мене вже не буде живих» — date specification)

**Пояснення**: За claim [C-009-128] / slide 13: «**Я вирішив покінчити собі. Наступного понеділка мене вже не буде живих**...».

**7 verbatim фраз** для emergency vocabulary [C-009-128]:

1. **«Я вирішив покінчити з собою»** — direct intent
2. **«Наступного понеділка мене вже не буде живих»** ← **DATE SPECIFICATION — найвищий ризик** (час визначено = план визначено = метод досить ймовірно)
3. **«Без мене життя гірше не буде»** — worthlessness, нікчемність
4. **«Ненавиджу своє життя»** — глобальна неприязнь
5. **«Єдиний вихід — померти»** — escape motive, cognitive narrowing
6. **«Ти віриш у переселення душ? Коли-небудь, може, я вернусь у цей мир»** — preoccupation з посмертям
7. **«Виходжу з гри. Набридло»** — finality, withdrawal

**Чому date specification (#2) = найвищий ризик**:

- Час визначено → план у розробці
- План визначено → метод вибрано
- Метод вибрано → засоби доступні
- Це **rехеarsed suicidality** — high probability of execution

**Інші лінгвістичні маркери** [C-009-125..130]:

| Тип                         | Зміст                                                     |
| --------------------------- | --------------------------------------------------------- |
| **Прямі висловлювання**     | «Хочу померти», «не хочу жити»                            |
| **Slips of tongue**         | «Якщо я не буду…», незавершені умовні                     |
| **Незавершені думки**       | «Коли мене не стане…»                                     |
| **Директивні дієслова**     | «Вирішив», «не буде», «вихожу», «закінчу»                 |
| **Hedonic vocabulary loss** | Зникає мова про задоволення, радість, плани               |
| **Paralinguistic**          | Уповільнена мова + глибокі зітхання + монотонна інтонація |

**Coaching imperative**: якщо клієнт скаже одну з 7 фраз — **immediate detailed risk assessment** + ескалація до психіатра + не залишати самого.

**Special case — escalation triggers**:

- **Date specification** (#2) → 911-level emergency
- **Method specification** («з вікна», «з мотузкою») → 911-level emergency
- **Recently acquired means** (купив таблетки, купив оружие) → 911-level emergency

**Coaching framing для близьких клієнта**:

- НЕ списувати «це він просто пугає»
- НЕ «не вживай це слово, не накликай» (магічне мислення)
- ТАК: документувати фразу, дату, контекст — передати психіатру

**Source**: C-009-128 / transcript [23:00] / slide 13

2. Кофеїн у високих дозах

5. Спорт на свіжому повітрі будь-який час доби

**Correct**: 3 (Phototherapy 10 000 lux 30-60 хв вранці)

**Пояснення**: За claim [C-009-150] (implicit) / [C-009-043] (сезонність): сезонна афективна депресія (SAD) — підtype депресії з осінньо-зимовим (у північних широтах) або весняно-осіннім (за уроком) onset, асоційованим зі **зменшенням expозиції до денного світла**.

**Mechanism**:

- Зменшення denного світла → **посилення секреції мелатоніну** у denній час (норма — тільки вночі) + дисбаланс серотоніну
- Циркадна desynchronization з GeoCycle
- **Phototherapy 10 000 lux**:
  - Reset циркадного ритму
  - Зменшення melatonin secretion в denній час
  - Поліпшення серотонінергічної передачі
  - Effect через 1-2 тижні (швидше за AD)

**Параметри стандартного протоколу**:

- **Intensity**: 10 000 lux (стандарт)
- **Duration**: 30-60 хв
- **Timing**: вранці (зразу після пробудження)
- **Distance**: 30-60 см від light box
- **Eyes open** (НЕ дивитися прямо в світло, але eyes відкриті)
- **Frequency**: щодня в осінньо-зимовий період

**Evidence base**: Cochrane reviews (2015, 2020) — phototherapy efficacy comparable AD for SAD, особливо seasonal MDD specifier. У non-seasonal melancholic depression — adjunct ефект.

**Devices**: доступні (€80-200), portable LED light boxes.

**Diff seasonality за уроком vs північний SAD**:

- Лектор каже **«весна-осінь»** [C-009-043] — це характерно для **постradянської психіатричної традиції** (rapid weather changes triggering)
- **Northern hemisphere SAD** (DSM-5) — **зимовий** (зменшення daylight у листопаді-лютому)
- **Summer SAD** — рідкісний підтип у тропічних регіонах (heat-related)

**Coaching pearl**: якщо клієнт скаржиться на щорічне погіршення у певні сезони + sleep changes + carbohydrate craving + weight gain → **SAD candidate** → рекомендувати психіатру discuss phototherapy + (опціонально) рекомендувати device.

**Source**: C-009-150 (implicit), C-009-043 / standard psychiatric care

### P14 — ECT — показання у депресії

**Q**: Які основні показання до електросудорожної терапії (ECT) у депресії?

**Варіанти**:

1. Будь-який депресивний епізод
2. Тільки легка депресія
3. **Психотична депресія (Котара) + депресивний ступор + treatment-resistant depression + suicidal emergency**
4. Тільки старечий вік
5. ECT не використовується у депресії

**Correct**: 3 (Психотична + ступор + resistant + suicidal emergency)

**Пояснення**: За claim [C-009-151] (implicit) / [C-009-025] (ступор) / [C-009-026] (психотична): ECT — **gold standard для тяжкої депресії з конкретними показаннями**.

**4 основні показання**:

1. **Психотична депресія (F32.3)** [C-009-026]:
   - З маренням вини / гріховності / нікчемності / **синдромом Котара** (нігілістичне марення)
   - AD + antipsychotic combination може бути недостатньою або повільною
   - ECT — найшвидший response (1-3 тижні)

2. **Депресивний ступор** [C-009-025]:
   - Повна нерухомість, неспроможність їсти / пити
   - Life-threatening через dehydration + malnutrition
   - ECT може швидко відновити функціонування

3. **Treatment-resistant depression (TRD)**:
   - Definition: відсутність response після **≥ 2 adequate AD trials** (з адекватною дозою + тривалістю ≥ 4-6 тижнів)
   - Steps before ECT: Lithium augmentation, T3 augmentation, antipsychotic add-on, esketamine
   - ECT — після цих steps або при critical state

4. **Suicidal emergency**:
   - Imminent suicide risk з planned method
   - Immediate hospitalization + 24/7 supervision + ECT consideration
   - **Найшвидший anti-suicidal ефект** з усіх tретmenta

**Mechanism**:

- Controlled seizure induction під загальною анестезією + м'язовим релаксантом
- Stimulation глибоких структур мозку → масивний release neurotransmitters + neuroplasticity changes
- BDNF (brain-derived neurotrophic factor) ↑
- Hippocampal neurogenesis ↑

**Course**:

- 6-12 sessions (зазвичай 3/тиждень)
- Maintenance ECT (1/2-4 тижні) для prevention рецидиву

**Modern safety**:

- Загальна анестезія + м'язовий релаксант (NO classical convulsion appearance)
- Side effects: short-term memory loss (часто transient), headache, muscle ache
- Mortality: comparable to general anesthesia (1 per 50 000)

**Stigma vs evidence**:

- Класичний stigma (One Flew Over the Cuckoo's Nest, 1975) — outdated
- Modern ECT — найефективніший і безпечний для severe cases
- WHO + APA endorse як gold standard для tяжкої melancholic

**Coaching pearl**: при підозрі на показання ECT (психотика / ступор / resistant / suicidal) — **передати психіатру** з підкресленою рекомендацією consideration ECT. **НЕ боятися рекомендувати** — це life-saving intervention для правильних кандидатів.

**Source**: C-009-151 (implicit), C-009-025, C-009-026 / standard psychiatric care
