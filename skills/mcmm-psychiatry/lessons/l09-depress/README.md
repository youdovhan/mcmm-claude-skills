## Quick summary

Лекція ~24:47 від **Світлани Володимирівни Ісаєнко** — **другий клінічно-нозологічний** урок після L7 (шизо) і L8 (БАР), **найважчий за смертельними наслідками** через суїцид. Якщо L7 був про **дисципліну делегації** до психіатра, L9 — про **раннє розпізнавання + прямий опит про суїцид + means restriction**.

**Ключова теза**: депресія — це **поломка лімбіко-ретикулярної системи** (моноаміни ↓: дефіцит серотоніну + дизрегуляція норадреналіну), яка маніфестує **класичною тріадою Крепеліна (-)**: гіпотимія + брадифренія + брадикінезія. **30% депресій масковані** (соматизовані). Суїцид = **800 000/рік, кожні 40 секунд** на планеті. Є **5 мотивів × 3 види поведінки × 10 markers × 7 verbatim фраз** + «3Б» (безпорадність + безсилля + безнадія) — це **emergency vocabulary** для коуча.

## Coaching application (DETECTIVE FM)

8 actionable правил для Юрія-Детектива (детально у `synthesis.md` §7):

1. **2+2+2 правило — швидкий чек-лист** [C-009-029]: 3 основні (настрій / інтерес / енергія) → ≥ 2 → 7 додаткових → ≥ 2 → ≥ 2 тижні → mandatory referral до психіатра
2. **7 clues маскованої — pattern recognition** [C-009-039..044]: ранкове max + поліморфізм + negative work-up + розлад вітальних функцій + сезонність + doctor shopping + відсутність ефекту від соматичної терапії. ≥ 4 з 7 → delegации
3. **Direct ask про суїцид — НЕ табу** [evidence-base meta-analysis]: НЕ провокує суїцид. «Чи буваєш у тебе думки про самогубство?» / «Чи є план?» / «Чи буваєш ранкова думка „зачем я проснувся?“»
4. **7 verbatim фраз — emergency vocabulary** [C-009-128]: запам'ятати слово-в-слово. **Date specification (#2 «наступного понеділка не буду») = найвищий ризик**
5. **«Три Б» — поведінкові маркери hopelessness** [C-009-112]: безпорадність + безсилля + **безнадія** (найсильніший single predictor suicide). Joining + immediate referral, НЕ «давай знайдемо позитив»
6. **Anaesthesia psychica dolorosa — найважчий маркер** [C-009-138]: «я мертвий усередині, не можу любити, і це болить» = melancholic high-risk. Immediate referral, можливо ECT, hospitalization, 24/7 supervision
7. **SSRI 4-6 тижнів window — клієнт-психіатр співпраця** [C-009-052]: перші 1-3 тижні = critical suicidality window. Coach роль: compliance + side effects normalization + anti-stigma + NOT discontinue + communication з психіатром
8. **Phototherapy SAD — сезонне розпізнавання** [C-009-150 implicit]: щорічне погіршення восени/взимку + sleep changes + carbohydrate craving + weight gain → SAD → phototherapy 10,000 lux 30-60 хв вранці
