## §0 — Quick thesis

**Емоції і воля — це не дві окремі функції, а єдина «ефекторно-вольова мозаїка»**, яка перетворює потреби (біологічні + соціальні) на дії через ланцюг **«потреба → потяг → мотив → бажання → намір → воля → дія»**. Психіатрія L3 описує не норму волі, а **типологію її поломок** на кожному рівні цього ланцюга — від ослаблення на полюсі емоцій (апатія, депресія) до перекручення на полюсі дії (анорексія, self-harm, кататонічний ступор).

Лектор Світлана Ісаєнко вибудовує лекцію як **термінологічний фундамент** (~123 терміни) для подальших клінічних модулів: «з цих термінів складаються симптоми, з симптомів — синдроми, з синдромів — нозологічні одиниці» [C-003-105]. Без цієї базової мозаїки L9 (Депресія), L10 (Тривожні розлади), L7 (Шизофренія) не складуться. **Це урок-каталог, а не урок-наратив** — і це задумано.

Core insight для коуча: **межа норма vs патологія** в емоційній сфері визначається не самим переживанням, а **4 критеріями патологічного** [C-003-030a] — інтенсивність, відхилення від норми, порушення функціонування, поведінка уникнення. Це готовий чек-ліст диференціації «нормальне горе» vs «клінічна депресія», «здорова тривога» vs «ГТР», «гнів» vs «дисфорія».

**Внутрішня логіка**: лектор рухається **від простого до складного**:

1. Емоції (короткочасні стани) → 2. Розлади емоцій (статичні відхилення) → 3. Воля (динамічна функція) → 4. Розлади волі (поведінка) → 5. Психомоторика (граничний стан, де воля=рух) → 6. Ступор (повна зупинка волі/руху).

**Хіба не Маслоу?** Лектор НЕ використовує Маслоу, але імпліцитно повторює його драбину: «біологічні потреби (їжа, безпека, продовження роду) → соціальні потреби (самовдосконалення, повага, етика)» [C-003-049, C-003-050]. У L3 ця ієрархія — основа для розрізнення порушень: збій біологічної потреби (анорексія, гіперсексуальність) ≠ збій соціальної потреби (моральна нестабільність, амбівалентність).

## §2 — Key insights / paradigm narrative

### 2.1. Емоції і воля — це єдина система «ефекторно-вольова сфера»

**Перший inversion для слухача**: те, що в побуті вважається двома різними речами («емоції» — пасивне переживання, «воля» — активне зусилля), у психіатрії — **дві фази одного циклу**:

```
ПОТРЕБА (біол./соц.) → ПОТЯГ (неусвідомлений мотив) → МОТИВ (усвідомлена причина)
   → БАЖАННЯ (усвідомлена потреба + шлях задоволення) → НАМІР (програма дій)
      → ВОЛЯ (саморегуляція на шляху до мети) → ДІЯ (поведінка)
```

Емоції — це **датчик зворотного зв'язку** на кожному рівні цього ланцюга: позитивні емоції = напрямок OK, негативні = щось блокує. Воля — це **виконавчий механізм**, що рухає організм по ланцюгу всупереч опору.

Звідси — **симетрія патологій**: збій на полюсі емоцій (↓ настрій → депресія) дзеркально відповідає збою на полюсі волі (↓ спонукання → абулія). Депресія + абулія + апатія = апатико-абулічний синдром [C-003-089]. Це **не три розлади, а одна поломка циклу**.

### 2.2. Норма vs патологія — 4 критерії, а не «відчуття»

Найважливіший методологічний intuition уроку — **діагностика не зводиться до самого переживання**, а до 4 параметрів (на прикладі тривоги [C-003-030a], але узагальнено на всі емоції):

1. **Інтенсивність + тривалість значно перевершують** очікувану реакцію на ситуацію
2. **Рівень значно відрізняється** від звичного реагування (соціальних, сімейних, культуральних стереотипів)
3. **Стан викликає порушення** соціально-трудового та особистісного функціонування
4. **Пацієнт уникає ситуацій** для зниження стану, чим порушує повсякденне функціонування

Це **переноситься на всю емоційну сферу**: гнів → дисфорія, смуток → депресія, ентузіазм → ейфорія/манія, страх → фобія. Критерії універсальні. Для коуча — це **готовий чек-ліст диференціації** клінічного від нормативного.

### 2.3. Афект фізіологічний vs патологічний — критерій свідомості

Лектор зупиняється на одній з найклінічніше важливих відмінностей уроку — **фізіологічний афект vs патологічний афект** [C-003-017, C-003-018]:

| Параметр            | Фізіологічний афект           | Патологічний афект                                |
| ------------------- | ----------------------------- | ------------------------------------------------- |
| Привід              | Сильний подразник, адекватний | Зовні **незначний** привід                        |
| Свідомість          | **Збережена** (контроль)      | **Порушена** (сутінковий стан свідомості)         |
| Поведінка           | Бурхлива, але керована        | Руйнівні дії, втрата контролю                     |
| Вегетатика          | Помірна                       | Різка (почервоніння, піт, гіпергідроз)            |
| Після епізоду       | Пам'ятає, можливе виправдання | **Сон** + **повна амнезія** епізоду               |
| Кримінально-правове | Звичайна реакція              | Підстава для **зменшеної осудності** (експертиза) |

**Це Q1 квіза** (Юрій вже бачив у recon): молодий чоловік з ЧМТ в анамнезі, який зруйнував кухню, ударив брата, заснув і потім нічого не пам'ятав → **патологічний афект**, не фізіологічний. Маркери — ЧМТ + амнезія + сон + повна десинхронізація з приводом.

### 2.4. Амбівалентність — діагностичний маркер шизофренії

Серед 24+ окремих порушень емоцій лектор **окремо виділяє амбівалентність** як «один з найважливіших діагностичних критеріїв шизофренії» [C-003-038]:

> Виникнення до одного й того самого об'єкта **одночасно** двох протилежних почуттів (любові і ненависті).

**Чому це не просто «амбівалентність» у побутовому сенсі**: у нормі людина може любити і ненавидіти когось у різні моменти. У шизофренії — **одночасно**, без можливості переходу. Це не амбівалентність вибору («хочу і не хочу»), а амбівалентність **співіснування** на одному й тому самому об'єкті. Cross-ref: кататонічна **амбітендентність** [C-003-093] — те саме на рівні дій.

### 2.5. Анорексія — модельний приклад біопсихосоціального розладу

Анорексія — найдетальніше розкритий приклад у лекції (~7 claims + 2 історичні кейси). Лектор використовує її як **демонстрацію патогенезу розладів волі**:

- **Біологічний рівень**: BMI ≤17,5 (індекс Кетле); ↓ вага як мінімум на 15% [C-003-065]
- **Поведінковий рівень**: уникнення «повної» їжі + блювання / проносні / надмірні вправи / діуретики [C-003-066]
- **Когнітивний рівень**: спотворення образу тіла як **надцінна ідея** [C-003-066a] («жах перед ожирінням як нав'язлива надцінна ідея»)
- **Соціальний рівень**: ідеал краси епохи (Мерлін Монро vs модельні стандарти 2000-х) [C-003-066c]
- **Драматичні кейси**: **Luisel Ramos** (Уругвай, 2006, 40 кг при 175 см, смерть від серцевої недостатності на показі) [C-003-066e]; **Isabelle Caro** (Франція, 2010, померла у 28 років, 25 кг, кампанія Toscani «No-l'Anorexia») [C-003-066d]

**Ключова теза кейсів**: «До приходу такого розуміння краси у психіатрії поняття анорексії не було» [C-003-066c]. Анорексія — **продукт парадигми краси**, не просто збій біології. Тому лікувати — не лише соматично (відновлення ваги), а й через зміну референтної рамки (групова, сімейна терапія).

### 2.6. Self-harm vs суїцид — різні явища, різні втручання

Лектор окремо розводить **самогубство** (усвідомлене позбавлення життя [C-003-070]) і **self-harm** (самоушкодження **без суїцидальної мети** [C-003-073]). Це не одна шкала «слабкий → сильний», а **дві різні поломки** інстинкту самозбереження:

- **Самогубство** = ослаблення інстинкту (особливо при депресивному афекті)
- **Self-harm** = перекручення інстинкту, частіше у молоді/підлітків, замість слів «мені погано» — рани на тілі

**Терапевтична імплікація**: при self-harm у підлітка лікувати ВСЮ СІМ'Ю [C-003-074a]: «коли підліток self-harm-ом приходить до батьків, він таким способом привертає увагу. Але батьки зайняті своїми життями, не чують, не бачать — це може призвести до незворотних наслідків». Self-harm = сигнал у комунікації, а не симптом сам по собі.

### 2.7. Ступор — гранична поломка волі (4 типи)

Кінцева точка лекції — ступор як **повна зупинка волі/руху** [C-003-095]. Лектор виділяє 4 типи за етіологією, кожен з власним клінічним маркером:

| Тип ступору      | Етіологія                     | Маркер                                                           | Claim     |
| ---------------- | ----------------------------- | ---------------------------------------------------------------- | --------- |
| **Кататонічний** | Шизофренія (часто)            | Воскова гнучкість, каталепсія, **«повітряна подушка»**, мутизм   | C-003-096 |
| **Депресивний**  | Тяжка депресія                | Уповільнення мови, ідеї самозвинувачення, страждальницька міміка | C-003-098 |
| **Апатичний**    | Емоційна тупість (шизофренія) | Повна байдужість, відсутність реакцій                            | C-003-099 |
| **Психогенний**  | Раптова психотравма           | Заціпеніння після катастрофи/стихійного лиха                     | C-003-100 |

**«Повітряна подушка»** [C-003-097] — найзапам'ятовуваніший клінічний маркер уроку. Пацієнт лежить так, ніби під головою подушка, але насправді подушки нема — м'язи тримають голову у позі сна. Це **патогномонічний знак** кататонічного ступору. Лектор спеціально описує процедуру перевірки (відсунути руку пацієнта — він зберігає позу; забрати свою — повертається у вихідну).

## §3 — Cross-cutting concepts

### 3.1. Чотири осі класифікації емоцій

Лектор повторно проводить **4 паралельні класифікації**, які не перетинаються:

| Вісь                       | Категорії                                            | Claim         |
| -------------------------- | ---------------------------------------------------- | ------------- |
| Суб'єктивний тон           | Позитивні / Негативні                                | C-003-004     |
| Вплив на діяльність        | Стенічні / Астенічні                                 | C-003-005     |
| Механізм виникнення        | Реактивні / Вітальні                                 | C-003-006-007 |
| Складність                 | Вищі (моральні / естетичні / інтелектуальні) / Нижчі | C-003-008-012 |
| Тривалість і сила (окремо) | Настрій / Пристрасть / Афект                         | C-003-013-016 |

Це **квадрат класифікації** — кожна емоція може бути одночасно позитивною/стенічною/реактивною/вищою (напр. радість від наукового відкриття) або негативною/астенічною/вітальною/нижчою (напр. тривога без причини, пов'язана з голодом). **Coaching application**: коли клієнт каже «я в депресії», коуч може уточнити по осях — чи це настрій (тимчасовий), чи депресія (клінічна; перевір 4 критерії з C-003-030a). Якщо клінічна — делегувати психіатру.

### 3.2. 4 групи порушень емоцій (за slide 5)

Це структурний кістяк уроку — **всі окремі терміни** (24+) розпадаються на 4 групи:

| Група                          | Перелік розладів                                                               | Claim Range                       |
| ------------------------------ | ------------------------------------------------------------------------------ | --------------------------------- |
| **Сила емоцій ↑ (посилення)**  | Гіпертимія, ейфорія, морія, депресія, тривога, гнівливість, екстаз             | C-003-021 → C-003-030a            |
| **Сила емоцій ↓ (ослаблення)** | Апатія, емоційне сплощення, емоційна тупість, параліч емоцій                   | C-003-031 → C-003-034             |
| **Рухливість емоцій**          | Лабільність, слабодушність, ригідність, експлозивність                         | C-003-035 → C-003-039             |
| **Адекватність емоцій**        | Неадекватність, амбівалентність, фобії, дисфорія, дистимія, патологічний афект | C-003-018, C-003-040 → C-003-044a |

**Mnemonic**: «**С-С-Р-А**» (Сила↑ / Сила↓ / Рухливість / Адекватність) — простіше запам'ятати при підготовці до тесту. Коли в тесті трапляється термін → визнач до якої з 4 груп належить → це звужує до 3-7 термінів і дозволяє вгадати визначення.

### 3.3. Біопсихосоціальний патерн анорексії

Анорексія в уроку — приклад **повного біопсихосоціального розладу**:

- **Біо**: BMI Кетле ≤17,5, реальна гіпотрофія, серцева недостатність (смерть Луісель Рамос)
- **Психо**: надцінна ідея ожиріння, спотворення образу тіла, нав'язлива думка про худобу
- **Соціо**: ідеал краси епохи (Барокко → Ренесанс → Мерлін Монро → 2000-ні), модельна індустрія, мода

Це **методологічний шаблон**, який лектор повторить у L9 (депресія) і L10 (тривожні розлади). Коли коуч бачить пацієнта з розладом — слід шукати причини на ВСІХ трьох рівнях, не лише психологічному.

### 3.4. Ступор → каталепсія — bridge до неврології

Лектор окремо виділяє кататонічний ступор як **bridge до неврології** [C-003-096, C-003-097]:

- **Воскова гнучкість (catalepsia / waxy flexibility)** — клінічна ознака порушення базальних гангліїв
- **Каталепсія** — стан, у якому пацієнт зберігає надану ззовні позу
- **«Повітряна подушка»** — підвид каталепсії; голова тримається на висоті без опори

Це зв'язок з **L2 «Структура нервової системи»** (попередній урок) — кататонія = поломка premotor + basal ganglia + frontal lobes. Для коуча: каталептичні ознаки — це **психіатрично-неврологічна зона**, не коучингова.

### 3.5. Ієрархія гіпо/гіпер/булія/абулія

Воля має свою власну 4-точкову шкалу:

```
ГІПЕРБУЛІЯ (↑↑↑) — патологічно посилене прагнення (манія, наркомани, параноя)
ГІПОБУЛІЯ   (↓)   — хворобливе зниження спонукання
АБУЛІЯ      (↓↓↓) — повна відсутність спонукання
АПАТО-АБУЛІЯ      — абулія + апатія (шизофренія, ЧМТ, інтоксикації)
```

Це паралель з гіпо/гіпертимією на емоційному полюсі. Симетрія волі та емоцій підкреслює структурну логіку уроку.

### 3.6. Психомоторне збудження — 3 типи з ключовими маркерами

Лектор у §11 розгалужує психомоторне збудження за **наявністю цілі руху + додатковими feature-маркерами**, які підказують нозологію. Це критично для дифдіагностики у тесті — без цих маркерів 3 типи зливаються в один «хворий метушиться».

| Тип          | Цілеспрямованість руху           | Додаткові маркери                                                                                                               | Нозологія                 |
| ------------ | -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ------------------------- |
| Маніакальне  | Ціль є (множинна, мінлива)       | **Flight of ideas / асоціативні стрибки**, говіркість, відволікаємість на стимули, ейфорія, скорочена потреба сну               | БАР (маніакальний епізод) |
| Гебефренічне | Цілі немає (інфантильна дезорг.) | **Дурашливість, гіперсексуальність**, нелогічне сміяття, дитячі витівки, манірування                                            | Гебефренічна шизофренія   |
| Кататонічне  | Цілі немає (ехо-домінанта)       | **Стереотипії** (свої повторні рухи) ↔ **ехопраксія** (повтор чужих рухів) ↔ **ехолалія** (повтор чужих слів), амбітендентність | Кататонічна шизофренія    |

**Mnemonic**: «**МГК → ЦСЕ**» — Маніакальне Говорить, Гебефренічне Кривляється, Кататонічне Ехо-копіює. Або диференціал за одним питанням до спостерігача: «Чи зрозуміло куди хворий хоче?» — Так → маніакальне; Ні+смішно → гебефренічне; Ні+повторює оточуючих → кататонічне.

## §4 — Diagnostic logic

Лектор не лише дає визначення, а й вибудовує **диференційну логіку**. 4 ключові точки розгалуження:

### 4.1. «Афект»: фізіологічний чи патологічний?

Розгалуження за 6 параметрами (див. §2.3 таблиця). **Найшвидший маркер**: амнезія + сон після епізоду = патологічний. Це Q1 квіза.

### 4.2. «Сум»: норма чи депресія?

Розгалуження за 4 критеріями патологічного [C-003-030a]:

1. Тривалість + інтенсивність значно перевершують привід?
2. Рівень значно відхиляється від соціальної норми?
3. Порушено функціонування (робота, стосунки, побут)?
4. Пацієнт уникає ситуацій / соціальної активності?

Якщо ≥2 з 4 = клінічна зона, делегувати психіатру. Якщо 0-1 = можлива коучингова робота (адаптація).

### 4.3. «Тривога»: фізіологічна / адаптаційна / патологічна?

- **Фізіологічна** [C-003-028]: є реальна загроза, інтенсивність пропорційна, тимчасова
- **Адаптаційна** [C-003-029]: до травмуючої ситуації, нетривала, не перешкоджає діяльності
- **Патологічна** [C-003-030]: безпідставна, передчуття «катастрофи», не пов'язана з реальною загрозою

При патологічній → провірити 4 критерії [C-003-030a] → можливо генералізований тривожний розлад або ПТСР → психіатрична зона.

### 4.4. «Зміна емоцій»: норма vs шизофренія?

3 діагностичні маркери шизофренії, які трапляються в L3:

1. **Емоційна тупість** [C-003-033] — стійка повна байдужість, у тому числі до страждань інших
2. **Амбівалентність** [C-003-038] — одночасні протилежні почуття до одного об'єкта
3. **Кататонічні ознаки** [C-003-096, C-003-097] — воскова гнучкість, повітряна подушка

Якщо ≥1 з 3 → психіатр, не коуч. Цей маркер також згадується в L7 (Шизофренія), куди L3 робить direct cross-ref.

### 4.5. «Тривала депресія» — критерій делегування з коучингу

Лектор окремо описує клінічний феноменологічний портрет депресії [C-003-026, C-003-026b]:

- «Внутрішня порожнеча, яку нема чим заповнити»
- «Чорно-біле життя»
- Метафора: «п'явка присосалась в душу, ти не живеш, ти існуєш»
- «Єдиний вихід для пацієнта з тяжкої депресії — вийти з життя»

Це **не настрій**, не «у мене погано» — це **клінічна тяжка депресія**. Коли коуч чує таку феноменологію — це **зона делегування**, не «опрацьовуй».

## §7 — Applied to coaching (DETECTIVE FM)

Юрій-Детектив працює з клієнтами в коучинговій рамці. L3 дає **7 actionable правил** з найвищим клінічним пріоритетом:

### 7.1. 4 критерії патологічного — твій default-чек-ліст диференціації

Якщо клієнт у сесії описує сильну емоцію (сум / тривога / гнів / захоплення / безсилля) — проведи його через **4 критерії** [C-003-030a]:

1. **Інтенсивність + тривалість** значно перевершують привід?
2. **Рівень відхиляється** від соціальних/культурних норм реагування?
3. **Порушено функціонування** (робота, стосунки, побут, сон, їжа)?
4. **Уникає ситуацій** для зниження стану, чим звужує життя?

**Якщо ≥2 з 4 = клінічна зона**, делегувати психіатру. Якщо 0-1 = коуч може працювати з адаптацією/інсайтом/інтегруванням.

**Приклад фрази для клієнта**: «Я чую, що це триває довше і сильніше, ніж зазвичай. Розкажи, чи вплинуло це на сон, роботу, апетит? Скільки сфер життя зачеплено?»

### 7.2. Червоні прапори патологічного афекту (Q1 квіза)

Якщо клієнт розповідає про епізод **бурхливої реакції** з:

- **Втратою свідомості / провалом пам'яті** про епізод
- **Сном після епізоду** (заснув одразу)
- **Зовні незначним приводом** (зруйнував кухню за неприбраний посуд)
- **ЧМТ в анамнезі / епілепсія / органіка**

→ це **патологічний афект** [C-003-018], не «емоційне зриве». Це **психіатрично-правова зона** (тенденція до зменшеної осудності). Дії: переадресувати до психіатра + неврологом для діагностики, **не вести коучингово**.

### 7.3. Self-harm vs суїцид — різні втручання, обидва — психіатр

Якщо клієнт показує self-harm (рани на тілі, **не з суїцидальною метою** — щоб «відчути», «заспокоїтись», «привернути увагу») [C-003-073, C-003-074]:

- Це **окремий розлад**, не «шлях до суїциду»
- Лікування — **системне** (підліток + сім'я; якщо клієнт дорослий — дослідити комунікативний контекст: до кого спрямований сигнал «мені погано»)
- **Не «давай поговоримо»** — це психіатрична зона + травматерапевт

Якщо клієнт демонструє **активну суїцидальну ідеацію** (план, метод, термін):

- **Стаття 14 Закону «Про психіатричну допомогу»** діє автоматично — небезпека для себе
- Дзвонити **103** + супровід до приймального психіатричного покою
- НЕ «дай поговоримо ще раз», НЕ «давай зустрінемось завтра»

### 7.4. Розпізнавай клінічну депресію за феноменологією, не за побутовим терміном

У побуті «депресія» = знижений настрій 2 дні. У клініці [C-003-026] — це **внутрішня порожнеча**, метафорично — «п'явка на душі» [C-003-026b]. Сигнали клінічної депресії:

- «Не можу прокидатись», «існую, не живу»
- «Нічого не радує», «втратив інтерес до людей»
- «Думаю про смерть як про вихід»
- Тривалість >2 тижні + не зниклий між

→ **Психіатр + антидепресанти**, не коучинг. Антидепресанти діють 4-6 тижнів — коучингова робота може початись **паралельно або після** стабілізації стану, не замість.

### 7.5. Амбівалентність — сигнал шизофренії, не «складна особистість»

Якщо клієнт каже **«я одночасно люблю і ненавижу X»** і це не метафора, а описує реальне співіснування протилежних почуттів — перевір на інші ознаки [C-003-038]:

- Емоційна тупість (байдужий до близьких)
- Дивні рухові реакції (стереотипії, ехолалії)
- Дезорганізоване мислення

→ якщо ≥2 з 3 збігається → **психіатрична зона + диференційний діагноз шизофренії**. **Не «опрацьовуй амбівалентність» коучингово** — це не невротичний конфлікт, це симптом психотичного спектра.

### 7.6. Розлад харчової поведінки — рання діагностика і **сімейний контекст**

Сигнали анорексії [C-003-064-066e]:

- BMI <17.5 + продовжує худнути / не визнає проблему
- Знає калорії «1/4 полуниці» (надмірний контроль) [C-003-066b]
- Спотворений образ тіла («я товста» при <40 кг)
- Compensation behaviors (блювання / клізми / надмірні вправи)

→ **психіатр + дієтолог + сімейна терапія**. Коуч може **підготувати клієнта до прийняття лікування**, але не лікувати анорексію коучингово.

**Сигнали булімії**: цикли переїдання + очищення; вага може бути в нормі, тому маскується довше. Якщо клієнт описує «приховую їжу», «їм потайки» — це teaser.

### 7.7. Психо-соматика працює в обидва боки

L1 [C-007-005] Кіплінг: «причина виразки в тому, що з'їдає вас» — психіка → тіло. **L3 показує зворотний полюс**: тіло → психіка може діяти через **порушення базових інстинктів** — їжа (анорексія), самозбереження (self-harm, суїцид), статеві потяги (гіпер/гіпо).

**Coaching application**: коли клієнт скаржиться на «емоційну» проблему (тривога, депресія, апатія), завжди питай:

- **Сон**: скільки годин, чи висипається, parasomnia?
- **Їжа**: апетит, регулярність, BMI, надмірний контроль
- **Тіло**: вага, рух, секс, енергія
- **Інтоксикація**: алкоголь, наркотики, медикаменти

Якщо ≥2 з 4 системно порушені — це **не «вирівнюй мислення»**, це **психіатрично-соматичний контур**, де коуч приходить **після** медикаментозної стабілізації.

## §8 — Key facts чек-ліст для тесту

1. **4 критерії патологічного емоційного прояву** [C-003-030a]: інтенсивність / відхилення / порушення функціонування / поведінка уникнення
2. **Афект патологічний** [C-003-018]: незначний привід + порушення свідомості + руйнівні дії + сон + амнезія епізоду (vs фізіологічний — свідомість збережена)
3. **Анорексія**: BMI Кетле ≤17,5 або вага ↓ ≥15% від норми [C-003-065]; кейси Луісель Рамос (Уругвай, 2006, 40 кг при 175 см, серцева недостатність) [C-003-066e] і Ізабель Каро (Франція, 2010, 28 років, 25 кг, кампанія Toscani) [C-003-066d]
4. **Self-harm** [C-003-073] = самоушкодження **БЕЗ суїцидальної мети**, ≠ суїцид [C-003-070]
5. **Амбівалентність** [C-003-038] — діагностичний критерій шизофренії: одночасно дві протилежні емоції до одного об'єкта
6. **Кататонічний ступор** [C-003-096-097]: воскова гнучкість + каталепсія + симптом **«повітряної подушки»** + мутизм
7. **Гіпо/гіпер/булія/абулія** [C-003-087-089]: ↑↑↑ → ↓ → ↓↓↓ → апато-абулічний синдром
8. **Трансгендери МКБ-10 vs МКБ-11** [C-003-080]: у МКБ-10 — психічний розлад, у МКБ-11 виключені, перенесені у рубрику сексуального здоров'я
9. **Топ-10 фобій** [C-003-044]: авіа / клаустро / акро / танато / канцеро / ахлуо / кіно / арахно/музо / аблюто / ауто
10. **Гнівливість** [C-003-025] — найвищий ступінь дратівливості, входить у структуру дисфорії + сутінкових станів + психоорганічного синдрому
11. **Дромоманія / клептоманія / піроманія / дипсоманія / трихотиломанія** [C-003-084-086c] — імпульсивні розлади з потяг-кореню («-манія»)
12. **Морія** [C-003-023] — підйом настрою + дурашливість + плоскі жарти → ураження **лобових часток мозку**
13. **Ефекторно-вольова сфера** [C-003-045-046]: ефекторне (рух) + вольове (саморегуляція) → ланцюг «потреба → потяг → мотив → бажання → намір → воля → дія» [C-003-047-056]
14. **«Терміни → симптоми → синдроми»** [C-003-105] — методологічний принцип усього курсу психіатрії
15. **Ст. 14 Закону «Про психіатричну допомогу»** (з L1 [C-007-081-083]) — критерій делегування при self-harm/суїциді з L3
