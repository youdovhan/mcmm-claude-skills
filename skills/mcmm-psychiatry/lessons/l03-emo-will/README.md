## Quick summary

Лекція ~42 хв від **Світлани Володимирівни Ісаєнко** — кандидата наук, психіатра Сабурової дачі (Харків). **Базовий термінологічний урок** «Мозаїки психіки» (секція 3-6 модуля 10): з ~123 термінів складаються симптоми → з симптомів синдроми → з синдромів нозологічні одиниці [C-003-105].

**Ключова теза**: емоції і воля — **єдина «ефекторно-вольова сфера»**, а не дві окремі функції. Ланцюг **«потреба → потяг → мотив → бажання → намір → воля → дія»** має точки поломки на кожному рівні. L3 каталогізує всі типи цих поломок.

**4 групи порушень емоцій** (структурний кістяк уроку):

1. **Сила↑** (гіпертимія, ейфорія, морія, депресія, тривога, гнівливість)
2. **Сила↓** (апатія, емоційне сплощення, емоційна тупість, параліч емоцій)
3. **Рухливість** (лабільність, слабодушність, ригідність, експлозивність)
4. **Адекватність** (неадекватність, амбівалентність, фобії, дисфорія, дистимія, патологічний афект)

**12 секцій slides**: класифікація емоцій → афект фізіол./патол. → 4 групи розладів → окремі терміни → ефекторно-вольова сфера → ланцюг «потреба→дія» → харчова поведінка → інстинкт самозбереження → статеві потяги → нав'язливі/імпульсивні дії → гіпо/гіпер/абулія → психомоторика → ступор → епілог.

## Key claims (top 15 — пріоритет для тесту)

1. **4 критерії патологічного емоційного прояву** [C-003-030a]: інтенсивність + відхилення від норми + порушення функціонування + поведінка уникнення
2. **Афект патологічний** [C-003-018]: незначний привід + порушення свідомості (сутінковий стан) + руйнівні дії + сон + амнезія епізоду (vs фізіологічний — свідомість збережена)
3. **Анорексія**: BMI Кетле ≤17,5 або вага ↓ ≥15% від норми [C-003-065]; кейси Луісель Рамос (Уругвай, 2006) [C-003-066e] і Ізабель Каро (Франція, 2010, 25 кг) [C-003-066d]
4. **Self-harm** [C-003-073] = самоушкодження **БЕЗ суїцидальної мети** (≠ суїцид [C-003-070])
5. **Амбівалентність** [C-003-038] — найважливіший діагностичний критерій шизофренії: одночасно дві протилежні емоції до одного об'єкта
6. **Кататонічний ступор** [C-003-096-097]: воскова гнучкість + каталепсія + симптом **«повітряної подушки»** + мутизм
7. **Гіпо/гіпер/булія/абулія** [C-003-087-089]: ↑↑↑ → ↓ → ↓↓↓ → апато-абулічний синдром (шизофренія, ЧМТ, інтоксикації)
8. **Трансгендери МКБ-10 vs МКБ-11** [C-003-080]: у МКБ-10 — психічний розлад, у МКБ-11 виключені, перенесені у рубрику сексуального здоров'я
9. **Топ-10 фобій** [C-003-044]: авіа / клаустро / акро / танато / канцеро / ахлуо (нікто) / кіно / арахно (музо) / аблюто / ауто
10. **Гнівливість** [C-003-025] — найвищий ступінь дратівливості, входить у структуру дисфорії + сутінкових станів + психоорганічного синдрому
11. **Дромоманія / Клептоманія / Піроманія / Дипсоманія / Трихотиломанія** [C-003-084-086c] — імпульсивні розлади
12. **Морія** [C-003-023] — підйом настрою + дурашливість + плоскі жарти → ураження **лобових часток мозку**
13. **Ефекторно-вольова сфера** [C-003-045-046]: ефекторне (рух) + вольове (саморегуляція) → ланцюг «потреба → потяг → мотив → бажання → намір → воля → дія» [C-003-047-056]
14. **«Терміни → симптоми → синдроми»** [C-003-105] — методологічний принцип усього курсу психіатрії
15. **Шизофренія L7 — preview**: емоційна тупість [C-003-033] + амбівалентність [C-003-038] + гебефренічне збудження [C-003-092] + кататонія + апато-абулія [C-003-089]

## Coaching application (DETECTIVE FM)

7 actionable правил для Юрія-Детектива (детально у `synthesis.md` §7):

1. **4 критерії патологічного — default-чек-ліст** [C-003-030a]: інтенсивність / відхилення від норми / порушення функціонування / уникнення. ≥2 з 4 = делегувати психіатру.
2. **Червоні прапори патологічного афекту** [C-003-018]: незначний привід + амнезія + сон + ЧМТ в анамнезі = психіатр + невролог, не коучинг.
3. **Self-harm ≠ суїцид** — окремі поломки інстинкту, обидва вимагають психіатра + сімейного контексту.
4. **Клінічна депресія за феноменологією** [C-003-026, C-003-026b]: «п'явка на душі», «існую не живу», думки про смерть як вихід → психіатр + антидепресанти. Коучинг паралельно або після, не замість.
5. **Амбівалентність** [C-003-038] (одночасні протилежні почуття до одного об'єкта) + ≥1 з: емоційна тупість / стереотипії / дезорганізоване мислення = диференціювати шизофренію, психіатрична зона.
6. **Розлад харчової поведінки** [C-003-064-066e]: BMI <17.5 + спотворений образ тіла + знає калорії 1/4 полуниці = психіатр + дієтолог + сімейна терапія.
7. **Психо-соматика в обидва боки**: завжди питай сон / їжу / тіло / інтоксикацію. ≥2 з 4 системно порушені → медикаментозна стабілізація **перед** коучинговою роботою.
