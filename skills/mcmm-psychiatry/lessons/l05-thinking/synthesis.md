## §0 — Quick thesis

**Мислення = поняття + судження + висновок. Поломки бувають за темпом / формою / змістом / мовою — і кожна поломка є маркером конкретної нозології.** L5 — найбагатший за термінами урок усього модуля 10: ~80 окремих feno-категорій, які лікар-психіатр і коуч мусять розпізнавати «з голосу» клієнта за перші 5-10 хвилин.

Лектор Світлана Ісаєнко вибудовує лекцію як **8-блочний каскад «порушень»**: (1) утворення понять → (2) темп → (3) форма → (4) зміст → (5) психічні мовні розлади → (6) органічні мовні розлади (афазії) → (7) невротичні мовні розлади → (8) розлади інтелекту (олігофренія / деменція). Кожен блок має 5-15 термінів, кожен термін має класичний приклад зі стилем хворого ([C-005-028, C-005-037-038, C-005-046-049, C-005-062]).

Core insight для коуча: **«коли клієнт говорить дивно — питай, який саме рівень поламано»**. Слова є, а смислу нема — це резонерство (шизо), шизофазія (шизо), або сенсорна афазія (інсульт лівої скроні). Все три виглядають як «нісенітниця», але **категорично різні нозології** з різним прогнозом і різною дією. L5 дає коучу і психіатру **дифдіагностичний скрін мовно-мисленнєвого статусу** клієнта — найважливіший feedback-канал у будь-якій сесії, оскільки мова = найбільш доступний продукт мислення.

L5 — **парний урок до L4** (увага+пам'ять як умова мислення) і **підготовка до L7** (шизофренія: всі form-disorders уроку 5 = шизо-маркери). Це найрясніший за claims урок модуля — після нього клініка L7-L13 «розкладається» термінологічно автоматично.

## §2 — Key insights / paradigm narrative

### 2.1. Мислення як 3-форменна структура (поняття / судження / висновок)

**Перша теза уроку** — нормальне мислення збудовано з 3 елементів ([C-005-013, C-005-014, C-005-015]):

| Форма        | Визначення                                                                               | Що ламається в патології                                    |
| ------------ | ---------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| **Поняття**  | абстракція, що відображає загальні ознаки; включає те, що не сприймається органами чуття | псевдопоняття / аглютинація / неологізми ([C-005-021..025]) |
| **Судження** | висловлювання чогось про щось — ствердження або заперечення зв'язків                     | паралогіка / афективне мислення ([C-005-054, C-005-063])    |
| **Висновок** | нове судження, виведене з кількох вихідних                                               | паралогіка / аморфне зісковзування ([C-005-053, C-005-054]) |

**Inversion для слухача**: коли коуч/психіатр чує «клієнт мислить нелогічно» — це насправді 3 різні поломки на 3 різних рівнях. **Не можна сказати «нелогічно» без уточнення**, де саме збій. Це і є **граматика дифдіагностики мислення**.

### 2.2. 3 типи мислення за змістом задачі — від конкретики до абстракції

Класифікація **за змістом розв'язуваної задачі** ([C-005-007, C-005-009, C-005-011]):

| Тип                                | Опис                                               | Онтогенез                                 | Дорослі (приклади)                                   |
| ---------------------------------- | -------------------------------------------------- | ----------------------------------------- | ---------------------------------------------------- |
| **Наочно-дієве**                   | через зовнішні рухові проби, метод проб і помилок  | до 3 років                                | експериментатор, конструктор, винахідник             |
| **Конкретно-образне**              | оперування образами без прямої дії                 | 4-7 років, молодша школа                  | письменники, художники, музиканти, актори            |
| **Абстрактно-логічне (понятійне)** | вищі форми абстракції, складні судження і висновки | 8-10 років старт → 14-16 років формування | основа свідомості і самосвідомості, наука, філософія |

**Парадокс уроку**: лектор окремо наголошує, що наочно-дієве — **НЕ виключно дитяче**. Коуч може це використати в роботі — клієнт зі складною ситуацією, де передбачити неможливо, природньо повертається у наочно-дієвий режим (експеримент малими кроками, не «прорахуй усе наперед»). **Це норма, не регрес**.

**Coaching application**: ЦА Юрія = коучі / психологи / експерти ([memory rule #29 «AI-for-experts»]). Багато з них переоцінюють абстрактно-логічне як «вищу» форму. L5 нагадує: **3 рівні координовано працюють у дорослого мозку**, і вибір рівня — функція задачі, не функція «розвиненості».

### 2.3. Інтелект ≠ мислення (важлива різниця)

Інтелект — **ємнісна характеристика** ([C-005-016, C-005-017]):

```
ІНТЕЛЕКТ = досвід + знання + здатність переносити у НОВІ контексти + рішення складних завдань
```

3 форми інтелектуальної поведінки ([C-005-018, C-005-019]):

1. **Вербальний** — запас слів, ерудиція, розуміння прочитаного
2. **Здатність до вирішення проблеми** (problem-solving)
3. **Практичний інтелект** — адаптація до зовнішніх обставин

Мислення — **процес**. Інтелект — **накопичений ресурс + швидкість**. Тому при деменції зберігається мислення (нейрон-нейрон) на повільному темпі, але втрачається інтелект (пам'ять+гнучкість). При шизофренії — навпаки, інтелект формально може бути збережений, але **мислення дезорганізоване**.

**Coaching application**: коли клієнт каже «я тупий» — питай, **що саме**. Низький лексикон і ерудиція? Це вербальний інтелект (можна тренувати). Не можу розв'язати конкретну задачу? Це problem-solving (часто перфекціонізм-блок). Не адаптуюсь до нової роботи? Це практичний інтелект (часто тривога). **3 різні зони втручання — 3 різні стратегії**.

### 2.4. Порушення утворення понять — найтонший рівень

Початок патологічного блоку ([C-005-020..025]) — 3 типи:

| Тип               | Механізм                                              | Нозологічний маркер                           |
| ----------------- | ----------------------------------------------------- | --------------------------------------------- |
| **Псевдопоняття** | слова збираються за випадковими, несуттєвими ознаками | шизо, органіка                                |
| **Аглютинація**   | ущільнення-злиття далеких уявлень («шоколадно»)       | шизофренія + органічні ураження ([C-005-022]) |
| **Неологізми**    | створення нових слів, яких немає в мові               | **ендогенний (шизо) процес** ([C-005-025])    |

**Класичний приклад аглютинації** [C-005-023]: «На питання про самопочуття хвора відповіла «шоколадно» — після інсулінових шоків мені краще = шок + здоров'я → шок-олад → шоколадно. Це **щільне історичне відлуння** інсулінокоматозної терапії Закеля 1933 — патологія мислення зберігає сліди парадигми лікування (cross-ref L1).

**Класичний неологізм** [C-005-025]: «це не життя, а афеїди і полторанії» — слова не існують поза мовою хворого. **Це маркер ендогенного процесу — шизофренії**.

### 2.5. 4 порушення темпу — найшвидший дифдіагностичний скрін

Це **перший фільтр**, який працює уже в перші 30 секунд розмови з клієнтом ([C-005-027..033]):

| Порушення                                   | Опис                                                                             | Нозологія                                   |
| ------------------------------------------- | -------------------------------------------------------------------------------- | ------------------------------------------- |
| **Тахіфренія / скачка ідей** (fuga idearum) | прискорення, перескакування з теми на тему за асоціативним/фонетичним зчепленням | **манія (БАР)** ([C-005-028])               |
| **Брадифренія / уповільнення**              | думки течуть повільно, скарга «мало думок», «порожнеча»                          | **депресія** ([C-005-029, C-005-030])       |
| **Шперрунг** (sperrung, thought-blocking)   | раптовий обрив, після паузи — інша думка                                         | **шизофренія** ([C-005-031, C-005-032])     |
| **Ментизм**                                 | мимовільний нав'язливий потік, не контролюється волею                            | синдром Кандинського-Клерамбо ([C-005-033]) |

**Класичний приклад скачки ідей** [C-005-028]: «Доктор, я вас люблю. Любов не порок, а большое свинство. Посмотрите на неї, у неї під халатом внука рубашка, із-під п'ятниці субота. Завтра субота і прийде мій чоловік. Ха-ха, чоловік об'ївся груш.» Зчіпки: фонетичні (любов→порог→свинство), прислів'я (з-під п'ятниці субота), асоціативні (субота→чоловік).

**Coaching application**: оцінити темп клієнта = маркер його психічного фону:

- Швидкий, перескакує = можлива гіпоманія / тривога (підняти питання сну, енергії, lithium-anamnesis)
- Уповільнений, паузи >2 сек на просте запитання = можлива депресія
- Раптові обриви + «забув про що» + «порожнеча» = шизо-маркер → психіатр
- Нав'язливий потік + «не можу зупинити» = психіатр (можливо ОКР, КП-С)

### 2.6. Порушення форми мислення — найрясніший блок (10+ термінів)

Це **серце уроку L5**. Лектор перелічує ~12 явищ, кожне з прикладом ([C-005-034..063]):

| Порушення                            | Що бачимо                                                                 | Нозологія                                                     |
| ------------------------------------ | ------------------------------------------------------------------------- | ------------------------------------------------------------- |
| **Патологічна обставинність**        | в'язке мислення, надмірна деталізація, втрата ієрархії головне/другорядне | **епілепсія** ([C-005-035])                                   |
| **Резонерство**                      | порожні «філософствування», нібито науково, але без смислу                | шизо (на старті продуктивних змін) ([C-005-040])              |
| **Розірваність / шизофазія**         | смисловий зв'язок відсутній, граматика збережена                          | **шизофренія** ([C-005-044])                                  |
| **Словесна окрошка**                 | дезорганізація грубша — порушується вже граматика                         | глибока шизо-дезорганізація ([C-005-045])                     |
| **Безв'язність**                     | відсутні навіть базові асоціації; дезорієнтація                           | **аменція (затьмарення свідомості)** ([C-005-050, C-005-051]) |
| **Аморфне / зісковзуюче**            | головна думка зникає, побічна її замінює                                  | продромальна шизо ([C-005-053])                               |
| **Паралогічне**                      | порушення причинно-наслідкових зв'язків у висновках                       | шизо (схизис маркер) ([C-005-054, C-005-055])                 |
| **Аутистичне (Блойлер)**             | опора не на реальні факти, а на внутрішні переживання                     | **шизо (одне з 4А Блойлера)** ([C-005-056, C-005-057])        |
| **Символічне**                       | колір/предмет = знак, зрозумілий тільки хворому                           | шизо ([C-005-058, C-005-059])                                 |
| **Вербігерація** (як форма мислення) | стереотипне повторення слів/фраз + одночасні протилежні думки             | амбівалентність (Блойлер) ([C-005-060])                       |
| **Персеверація**                     | застрягання («Іванович→Іванович→Іванович»)                                | **органічні ураження (лобові долі)** ([C-005-061, C-005-062]) |
| **Афективне мислення**               | логіка підпорядкована поточним емоціям, не фактам                         | афективні розлади ([C-005-063])                               |

**Найважливіше методологічне зерно** [C-005-055]: «паралогіка + зісковзування = маркери схизису». Схизис — це **розщеплення** як ядро шизофренії (за Блойлером 1911). Тобто **зловити schizo-структуру можна на рівні дрібних мовно-логічних обмовок** ще до маячення / галюцинацій. Це найтонший скрін шизофренії.

**Дидактичне зерно для коуча**: мова клієнта = **продукт» мислення. Розрізнення «дивних» мовних патернів вимагає **слухати ЯК ламається структура\*\*, не лише ЩО говориться:

- Граматика ціла, смислу нема → **шизофазія** (шизо)
- Слова правильні, наука → **резонерство** (шизо)
- Деталі, гілки, повернення → **обставинність** (епілепсія)
- Стрибки за фонетикою → **скачка ідей** (манія)
- Зависання на слові → **персеверація** (органіка)
- Раптовий обрив → **шперрунг** (шизо)

### 2.7. Зміст мислення: нав'язливі / домінуючі / надцінні / маячні — 4-ступенева ескалація

Це **критична секція** уроку — 4 рівні **за критерієм збереженості критики** ([C-005-064..074]):

| Рівень              | Критика                                                             | Структура                                                                                         | Нозологія                                                   |
| ------------------- | ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| **Нав'язливі ідеї** | **збережена**, активне прагнення позбутися                          | мимовільні, чужі свідомості                                                                       | **невроз (ОКР, тривога)** ([C-005-065, C-005-066])          |
| **Домінуючі ідеї**  | збережена                                                           | правильні думки, що витісняють інші (мати про хвору дитину)                                       | побутова норма / акцентуація ([C-005-067])                  |
| **Надцінні ідеї**   | частково збережена, але корекції майже не піддається                | виникають з реальних обставин, але мають непропорційно велике значення через емоційну насиченість | параноидні особистості, психопатії ([C-005-068, C-005-069]) |
| **Маячні ідеї**     | **повністю відсутня**, переконати неможливо (спроби посилюють бред) | виникають на хворобливій основі, повністю заволодівають свідомістю, не піддаються корекції        | **психоз (шизо, БАР, органічний)** ([C-005-071..074])       |

**Ключове клінічне правило** [C-005-073]: «**спроби переконати хворого посилюють бред**». Це не «дискусія» — це **протипоказання** при маяченні. Аргумент інтегрується у фабулу як «опір ворогів». Для коуча це **категорична межа делегування**: якщо клієнт описує систему, яку ти не можеш похитнути жодним аргументом — це маячення, а не «упертість». Не сперечайся, делегуй психіатру.

**Лекторський особистий коментар** [C-005-070]: «любов — це теж надцінна ідея... я готова з цим погодитися, але любов **не є патологічною**». Тобто граматика подібна (емоційно насичена ідея, що захоплює свідомість), без патологічного знаку. Це гарне нагадування коучу — **сама структура «емоційна одержимість» — не патологія**, патологія — у **наслідках для життя** і **відсутності критики**.

| **Індукований**                         | бред «передається» від хворого до здорового близького (folie à deux) | індукція ([C-005-086])                               |

**Каміла Клодель — рознімана клінічна модель** ([C-005-087..091]) — кейс параноидної шизофренії з прогресуючою фабулою:

```
1898 — розрив з Роденом
↓
~1900-1905 — бред відношення (звичайні події → мені шкодять)
↓
1905-1913 — бред переслідування (Роден = переслідувач)
↓                              ↓
                         бред отруєння (родичі труять їжу)
↓                              ↓
                         бред впливу (натурники, критики = змова)
↓
1905+ — деструктивна поведінка (щорічно знищує свої роботи каменем)
↓
1913 — примусова госпіталізація (тиждень після смерті батька-захисника)
↓
1913-1943 — 30 років у психіатричній лікарні Montdevergues до смерті
```

**Вступний термін лектора** [C-005-087]: «**фабула** = структура бреду» — це слово важливо запам'ятати. Психіатр не каже «вона мала маячення», психіатр каже «у пацієнтки маячна фабула переслідування + впливу». Це **технічна точність опису**.

**Coaching application** — Камінла Клодель як **типовий жіночий-творчий кейс**:

- Жінка-творчиня, талановита, у тіні відомого чоловіка-партнера
- Розрив зі значущим партнером = тригер
- Соціальна ізоляція = поглиблення
- Сім'я не розуміє, ставиться як до «дивацтва»
- Без своєчасної допомоги — повний розпад особистості за 8-15 років

Це **рольова модель сценарію** для коуча: якщо клієнтка-жінка-творчиня описує феноменологію бреду відношення / переслідування після розриву — це **не «творча криза», це симптом, потрібен психіатр**.

### 2.9. Психічні vs органічні vs невротичні мовні розлади — 3 категорії

Лектор робить **категоричну категоризацію** мовних розладів за етіологією ([C-005-092, C-005-110, C-005-119]):

| Категорія              | Природа                                        | Приклади                                                                                                                                                                              | Що думати при зустрічі                                |
| ---------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| **Психічні**           | вторинні до мисленнєвих порушень               | брадифазія, вербігерація, глосолалія, логорея, мимоговоріння, монолог, мутизм + 3 підтипи, дзеркальна, манерна, олігофазія, пуерильна, ехолалія + ехопалілалія + ехофразія, шизофазія | психічна нозологія (шизо, манія, депресія, кататонія) |
| **Органічні (афазії)** | ураження кори мозку (інсульт, травма, пухлина) | афазія Брока (моторна), Верніке (сенсорна), амнестична, парафазія, дизартрія, логоклонія                                                                                              | **гостра органіка** — невідкладна неврологія!         |
| **Невротичні**         | психогенна травма + збережена структура        | афонія (шепіт збережений), психогенна / істерична афонія, заїкання                                                                                                                    | психоневроз, дисоціативний розлад                     |

**Найважливіше дифдіагностичне зерно** [C-005-111]: при афазії **артикуляційний апарат і слух збережені** — це принципова різниця від глухоти, дизартрії, мутизму. Якщо клієнт каже «не можу підібрати слово», але слух і артикуляція норм — і це раптово почалося — **це афазія = інсульт = швидка**.

**Афазія Брока vs Верніке — найважливіше розрізнення** ([C-005-114, C-005-115]):

| Афазія                 | Зона мозку (L2)                                         | Розуміння     | Продукція мовлення       | Феноменологія                                              |
| ---------------------- | ------------------------------------------------------- | ------------- | ------------------------ | ---------------------------------------------------------- |
| **Брока (моторна)**    | нижня лобова звивина лівої півкулі, поле Бродмана 44/45 | **збережене** | **порушена**             | «знаю що сказати, не можу»; телеграфна, без службових слів |
| **Верніке (сенсорна)** | верхня скронева звивина лівої півкулі, поле 22          | **порушене**  | плавна, але беззмістовна | «жонглює» словами, парафазії, виглядає як шизофазія!       |

**Cross-ref L2**: лектор у L2 не розгортав ці зони — у L5 з'являється **запит на анатомію L2**. Це означає, що **в реальному курсі L2 і L5 — нерозривні**, лектор очікує, що слухач уже знає Брока/Верніке.

**Афонія психогенна vs органічна** ([C-005-120, C-005-121]): **шепіт збережений → психогенна**. Якщо шепіт теж відсутній → органіка (рак гортані, голосові зв'язки).

### 2.10. Інтелект-розлади: олігофренія vs деменція + 2 типи кожного

**Дихотомія за етіологією** ([C-005-123, C-005-124]):

```
СЛАБОУМСТВО (стійке зниження інтелекту)
├── ВРОДЖЕНЕ → ОЛІГОФРЕНІЯ (малоуміє)
│   ├── ІДІОТІЯ (IQ ≤ 20)
│   ├── ІМБЕЦИЛЬНІСТЬ (IQ 21-50)
│   └── ДЕБІЛЬНІСТЬ (IQ 51-70)
│
└── НАБУТЕ → ДЕМЕНЦІЯ
    ├── ЛАКУНАРНА (часткова, з критикою, особистість зберігається)
    └── ТОТАЛЬНА (повний розпад особистості, критика відсутня)
```

**Олігофренія — 3 ступені** ([C-005-135..142]):

| Ступінь           | IQ    | Мова                                        | Самообслуговування        | Навчання                         |
| ----------------- | ----- | ------------------------------------------- | ------------------------- | -------------------------------- |
| **Ідіотія**       | ≤ 20  | відсутня                                    | нездатні                  | неможливе                        |
| **Імбецильність** | 21-50 | стартує 3-5 років, словник убогий           | прості навички з зусиллям | рахунок до 20, букви без читання |
| **Дебільність**   | 51-70 | стереотипні фрази, шепелявість, аграматизми | прості форми праці        | допоміжна школа                  |

**Деменція — 2 типи з категоричною різницею ([C-005-127..134])**:

| Параметр           | **Лакунарна**                                                    | **Тотальна**                                                   |
| ------------------ | ---------------------------------------------------------------- | -------------------------------------------------------------- |
| Критика дефекту    | **збережена** ([C-005-129])                                      | **відсутня** ([C-005-134])                                     |
| Особистість        | зберігає «силует», коло інтересів, мораль, ставлення до близьких | **повний розпад особистості** ([C-005-132])                    |
| Інтереси           | звужені, але різноманітні                                        | зводяться до елементарних біологічних потреб (їжа, фізіологія) |
| Що страждає першим | пам'ять, навички, гнучкість                                      | **вищі рівні особистості, вищі емоційні прояви** ([C-005-133]) |
| Концепт            | «залишкова особистість» ([C-005-131])                            | принцип Джексона: дисолюція згори вниз                         |

**Cross-ref L1**: принцип **Джексонівської дисолюції** ([C-005-133]) — згори вниз руйнується нервова система. Це Hughlings Jackson 1880-х, історично — основа динамічної неврології. У тотальній деменції найшвидше зникає неокортекс (мораль, абстракція), останнім — рептильний мозок (життєзабезпечення).

**Coaching application**: відрізнення двох типів = критичне:

- **Лакунарна** — клієнт страждає від свого дефекту, може обговорювати, мотивований на компенсацію → робота можлива (підтримка, адаптація, тренування)
- **Тотальна** — клієнт не усвідомлює дефект, біологічна редукція потреб → коучингу нема місця, лише догляд + супровід родичів

### 2.11. Діагностика — 4 practical techniques

Лектор дає **4 інструменти**, які працюють у будь-якому форматі (бесіда, кабінет, коучингова сесія) ([C-005-143..146]):

1. **Бесіда + спостереження** — стандарт. Уважно слухаєш темп, форму, зміст, мову.
2. **Експериментально-психологічні методики**:
   - Узагальнення / виключення понять
   - Класифікація
   - Сюжетні картини + послідовність подій
   - Асоціативний експеримент
3. **Тест Векслера (WAIS)** — David Wechsler 1939, шкала інтелекту. Стандарт для кількісної оцінки IQ.
4. **Прислів'я і скоромовки** ([C-005-145]) — як клієнт розуміє «без труда не витягнеш рибки з пруда» / «протягуй ножки по одягу»?
   - Дослівно («не можна впіймати без зусиль») — конкретно-операціональний рівень
   - Переносно («складне дається працею») — абстрактно-логічний рівень
5. **Авторський test «острів vs півострів»** [C-005-144] — швидкий bedside-тест ерудиції+інтелекту.

**Цінність методу** [C-005-146]: «ви можете розуміти, з якою особистістю ви маєте справу, **кому із спеціалістів передати, або у себе залишити**». Це **маршрутизаційний прийом**: за 5 хвилин розмови — рішення про делегування.

**Coaching application**: на першій сесії з клієнтом протестувати на прислів'я (як побутову гру, не як тест) — отримати **підкову характеристику абстрактного мислення**. Це особливо корисно з клієнтами, що описують страждання у нібито «філософських» категоріях.

## §3 — Cross-cutting concepts

### 3.1. «Темп-форма-зміст-мова» — універсальна рамка дифдіагностики

L5 закладає **4-точкову рамку оцінки** клієнта на будь-якій сесії:

```
ТЕМП — як швидко мислить? (фаст / норм / повільно / обриви / нав'язлива хвиля)
   ↓
ФОРМА — як побудована послідовність? (логіка ціла / зісковзує / резонерство / окрошка)
   ↓
ЗМІСТ — про ЩО думає? (нав'язливі / домінуючі / надцінні / маячні)
   ↓
МОВА — як виходить наззовні? (логорея / мутизм / ехолалія / афазія / заїкання)
```

Кожна точка дає окремий сигнал. **Це і є structured mental status** — те, чого вчать у медичних університетах. Для коуча — спрощена версія, але **на ту саму карту**.

### 3.2. Differential map: «слова є, але смисл відсутній»

Найважливіша дифдіагностична трудність — багато порушень виглядають як «нісенітниця»:

| Феномен                     | Граматика  | Смисл    | Швидкість        | Нозологія                       |
| --------------------------- | ---------- | -------- | ---------------- | ------------------------------- |
| **Резонерство**             | ціла       | пустий   | норм / повільна  | шизо ([C-005-040])              |
| **Шизофазія**               | ціла       | нема     | норм             | шизо ([C-005-044])              |
| **Окрошка**                 | зруйнована | нема     | швидко           | шизо (грубша) ([C-005-045])     |
| **Безв'язність**            | зруйнована | нема     | повільно/паузами | аменція ([C-005-050])           |
| **Скачка ідей**             | ціла       | плинне   | дуже швидко      | манія ([C-005-027])             |
| **Сенсорна афазія Верніке** | плинна     | нема     | швидко           | органіка інсульт ([C-005-115])  |
| **Манерна мова**            | ціла       | плутаний | норм             | шизо (гебефренія) ([C-005-104]) |
| **Глосолалія**              | власна     | свій код | норм             | шизо ([C-005-095, C-005-096])   |

**Як розрізняти на практиці**:

- Запитай факт, що клієнт мусить знати (день тижня, де ми зараз). Якщо не знає → **аменція** (затьмарення). Якщо знає → не аменція.
- Слухай ритм: швидко з фонетичними зчіпками → манія; нормально, але «філософія ні про що» → резонерство; обірвано на півфразі → шперрунг.
- Слухай словник: «чи є слова, яких не існує» → неологізми (шизо). «Чи є власна стійка лексика» → глосолалія (шизо).
- Зверни увагу на час: **раптово почалось у дорослої адекватної людини** → ймовірно афазія (інсульт), не шизо.

### 3.3. Каміла Клодель як архетип жіночої творчої кризи з ризиком психозу

**Чому лектор вибирає саме її**:

- Жінка-творчиня (резонує з ЦА коучингу Юрія: коучі, психологи, експерти)
- Розрив з відомим партнером (Огюст Роден)
- Соціальна ізоляція (родина не приймає)
- Талант (скульптор світового рівня, частково затьмарений тінню Родена)
- Прогресуюче маячення з 1900-х до 1913
- Примусова госпіталізація після смерті захисника (батька)
- 30 років у лікарні до смерті 1943

**Це рольова модель** для коуча, який працює з жінкою-творчинею в кризі. Маркери для делегування психіатру:

- Бред відносин («колеги-критики змовляються проти мене»)
- Бред впливу («хтось руйнує мою кар'єру цілеспрямовано»)
- Деструктивна поведінка щодо власних робіт
- Соціальна ізоляція + переконаність у ворожнечі найближчого кола

### 3.4. Зв'язок з Блойлерівськими 4А шизофренії (cross-ref L7)

L5 — це **передкатедральне місце L7**. 4 ядерні симптоми Блойлера (Bleuler 1911) — всі присутні у L5:

| Блойлер                                                    | L5 термін                                             |
| ---------------------------------------------------------- | ----------------------------------------------------- |
| **Асоціації** (зрив асоціативного процесу)                 | паралогіка ([C-005-054]), зісковзування ([C-005-053]) |
| **Афект** (емоційна тупість + неадекватність)              | афективне мислення ([C-005-063]) ↔ L3                 |
| **Амбівалентність** (одночасні протилежні думки/прагнення) | вербігерація ([C-005-060]) ↔ L3 амбітендентність      |
| **Аутизм** (опора на внутрішнє, не на реальність)          | аутистичне мислення ([C-005-056, C-005-057])          |

Це означає, що **L5 диктує діагностичну тригери для шизофренії**. У L7 ці тригери будуть розгорнуті у синдромологію — але уже зараз у L5 коуч/психіатр може **зловити шизо** за дрібними мовно-логічними обмовками, не чекаючи маячення.

### 3.5. Критика як універсальний дифдіагностичний параметр

L5 використовує **збереженість критики** як **категоричний фільтр**:

| Критика збережена                 | Критика втрачена                 |
| --------------------------------- | -------------------------------- |
| Нав'язливі ідеї ([C-005-065])     | Маячні ідеї ([C-005-071])        |
| Лакунарна деменція ([C-005-129])  | Тотальна деменція ([C-005-134])  |
| Іпохондричний синдром невротичний | Іпохондричний бред ([C-005-083]) |
| Невротична депресія               | Психотична депресія              |

**Це і є межа коучингу** — поки критика збережена, **можна обговорювати, опрацьовувати, тренувати**. Як тільки критика втрачена — **не сперечайся, делегуй** (психіатр).

## §4 — Diagnostic logic

L5 закладає **5 ключових точок розгалуження** для коуча/психіатра при «дивних мовно-мисленнєвих» проявах клієнта:

### 4.1. «Клієнт говорить довго і нерелевантне»

| Картина                                                            | Імовірна нозологія                               |
| ------------------------------------------------------------------ | ------------------------------------------------ |
| Дидактично-методично, деталі, гілки, повертається до основної теми | **обставинність → епілепсія** ([C-005-035..039]) |
| Філософствує наукоподібно, але без предметного смислу              | **резонерство → шизо** ([C-005-040..043])        |
| Багатослівність + швидкі стрибки за асоціаціями                    | **скачка ідей → манія** ([C-005-027, C-005-028]) |
| Просто стиль розмови, без структурної патології                    | особистісно-нормативне                           |
| Намагається догодити, заплутується, але корекція допомагає         | тривога / соціальний шок                         |

**Differentiator**: повернення до основної теми (повертається через час) = обставинність. Не повертається ніколи = резонерство / скачка ідей.

### 4.2. «Клієнт повторює фразу/слово»

| Картина                                                               | Імовірна нозологія                                                 |
| --------------------------------------------------------------------- | ------------------------------------------------------------------ |
| Застрягання на правильній відповіді на всі питання                    | **персеверація → органіка лобових долей** ([C-005-061, C-005-062]) |
| Стереотипне повторення слів/фраз/вигуків + одночасно протилежні думки | **вербігерація → шизо / амбівалентність** ([C-005-060, C-005-094]) |
| Автоматичне повторення слів інших                                     | **ехолалія → кататонія / шизо / аутизм** ([C-005-108])             |
| Судомне повторення складу («та-та-та»)                                | **логоклонія → органіка / Туретт** ([C-005-117])                   |
| Викрикування коротких фраз                                            | **вербігерація як мовний → кататонія** ([C-005-094])               |

**Differentiator**: персеверація = одна правильна відповідь застрягає на всі наступні питання (інші зміст ігноруються). Вербігерація = повторення «незалежно від» питань. Ехолалія = повторення саме слів співрозмовника.

### 4.3. «Клієнт не може назвати слово / каже не те слово»

| Картина                                                     | Імовірна нозологія                                                 |
| ----------------------------------------------------------- | ------------------------------------------------------------------ |
| «Знаю, але забув як називається» — описує функцію, не слово | **амнестична афазія → органіка скроні** ([C-005-112, C-005-113])   |
| Особливо — не може назвати пальці рук                       | **початкова амнестична афазія + синдром Герстманна** ([C-005-113]) |
| Хочу сказати, але не виходить (моторика мовлення)           | **афазія Брока → інсульт лівої лоби** ([C-005-114])                |
| Говорю плавно, але не розумію співрозмовника, плутаю слова  | **афазія Верніке → інсульт лівої скроні** ([C-005-115])            |
| Заміняє звуки/слова неправильними                           | **парафазія → Верніке-ураження** ([C-005-118])                     |
| Раптом не можу нічого сказати, шепіт йде                    | **психогенна афонія** ([C-005-120, C-005-121])                     |
| Не виходить плавно, повторюю звуки/склади                   | **заїкання → невроз** ([C-005-122])                                |
| Втома, нічого нового, давно так                             | виснаження уваги (L4) / нормальна забудькуватість                  |

**Differentiator**: гострий початок у дорослої адекватної людини + порушення мовлення = **інсульт = швидка невідкладна**. Якщо плавна мова без смислу + раптовий початок = афазія Верніке (не шизофазія, бо у останньої немає гострого початку).

### 4.4. «Клієнт говорить дивне»

| Картина                                                     | Імовірна нозологія                                             |
| ----------------------------------------------------------- | -------------------------------------------------------------- |
| Створює нові слова, яких не існує                           | **неологізми → шизо ендогенне** ([C-005-024, C-005-025])       |
| Власна стійка мова (словник стабільний у часі)              | **глосолалія → шизо** ([C-005-095, C-005-096])                 |
| Звичайні предмети мають для нього алегоричні значення       | **символічне мислення → шизо** ([C-005-058, C-005-059])        |
| Каже фрази, граматично правильні, але смислу нема           | **шизофазія → шизо** ([C-005-044, C-005-109])                  |
| Слова розсипаються повністю                                 | **словесна окрошка → шизо груба** ([C-005-045])                |
| Каже з кінця (читає у зворотному порядку)                   | **дзеркальне мовлення → рідкісне** ([C-005-103])               |
| Дорослий говорить як дитина (сюсюкання, 3-я особа про себе) | **пуерильна мова → регрес істерія / гебефренія** ([C-005-107]) |
| Незвичні / неподходящі слова                                | **манерна мова → шизо гебефренія** ([C-005-104])               |
| Творчий парадокс, метафора                                  | креативність (норма)                                           |

**Differentiator**: неологізми = слів НЕ існує поза мовою хворого. Манерна мова = слова існують, але вжиті дивно. Символічне = звичайні слова мають **приватний смисл**. Шизофазія = смислу нема взагалі.

### 4.5. «Низький інтелект / „тупість"»

| Картина                                                        | Імовірна нозологія                        |
| -------------------------------------------------------------- | ----------------------------------------- |
| З дитинства, в анамнезі — школа допоміжна / спеціальна         | **олігофренія** ([C-005-135])             |
| IQ ≤ 20, без мови, без самообслуговування                      | **ідіотія** ([C-005-136, C-005-137])      |
| IQ 21-50, мова з 3-5 років, прості навички                     | **імбецильність** ([C-005-138..140])      |
| IQ 51-70, стереотипні фрази, шепелявість, допоміжна школа      | **дебільність** ([C-005-141, C-005-142])  |
| Раніше функціонував добре, поступово гірше, ще критикує дефект | **лакунарна деменція** ([C-005-128..131]) |
| Раніше функціонував добре, тепер повний розпад, не помічає     | **тотальна деменція** ([C-005-132..134])  |
| «Тупий» = низька вербальна ерудиція, але solving норм          | вербальний дефіцит, не інтелект           |
| «Тупий» = тривожно блокується на задачах, але потім розв'язує  | тривожний нейроз, не інтелект             |

**Differentiator**: чи були ці прояви з дитинства? Так → олігофренія. Ні, з'явилось після події (інсульт, травма, хвороба) → деменція. Чи усвідомлює свій дефект? Так → лакунарна. Ні → тотальна. Чи не може взагалі або не може саме у цьому контексті? Не може взагалі → інтелект; не може саме тут → афект / тривога.

| «зберігання мислення»    | змісту мислення                  | C-005-064            |

### 6.2. Slide-помилки

- Slide 3 «Концепція» (для «поняття») — OCR-артефакт або переклад «концепт» → правильно «поняття» (для української філософської термінології).
- Slide 11 «Бред виробництва» — помилка перекладу російського «бред изобретательства» → правильно «бред винахідництва».
- Slide 14 «Слабоумствосо» — OCR-перенос.
- Slide 13 «що задаються ним» — словосполучення зрослося («що задаються ним»).
- Slide 16 «опанувати читання і написання» — правильно «читання і письма».

### 6.3. Лакуни (negative claims)

- **Зони Брока і Верніке з анатомією** ([C-005-114, C-005-115]) — згадані лише як назви, без локалізації / поля Бродмана. Лекторка очікує, що слухач уже знає з L2 — але L2 цього не давала. **Запит на крос-апдейт**.
- **Сучасна DSM-5 / МКБ-11 термінологія для розладів інтелекту**: ідіотія/імбецильність/дебільність — застарілі терміни. У DSM-5 — Intellectual Developmental Disorder (IDD) з рівнями mild/moderate/severe/profound (відповідно дебільність/імбецильність/тяжка інтелектуальна РІ/ідіотія). У МКБ-11 — F70-79.
- **Тест IQ — Векслер (WAIS) згадано, але без структури**: Verbal IQ + Performance IQ + загальний; підшкали (інформація, лексика, аналогії і т.д.). Лектор просто згадала ім'я.
- **Делірій vs аменція**: лектор згадує безв'язність-аменція, але не дає повної дифдіагностики делірію (затемнення з галюцинаціями). У L9 розгорнуть.
- **Когнітивні скринінги**: MMSE (Folstein), MoCA — не згадано. Це міжнародні стандарти когнітивного скринінгу.
- **Шизофренічна неологія + глосолалія** — згадано, але не з'явилася концепція **«мова як перший і найрясніший продуктивний симптом»**.
- **Афазія Брока vs Верніке + анатомія + Бродман**: треба знати з L2, але L2 цього не давала.

### 6.4. Відкриті питання

- Чому лектор не атрибутує **Bleuler 1911** «Schizophrenia» при перших розповідях про резонерство, шизофазію, аутизм?
- Чому в розділі олігофренії не згадано **синдром Дауна, фенілкетонурію, мікроцефалію** — поширені етіології?
- Чому **гіпотетична деменція FTD (фронтотемпоральна)** як модель чистих лобових порушень — не згадана? Cross-ref персеверація.
- Чому **афазія прогресуюча первинна (PPA)** — не згадана? Сучасна категорія, не лише вогнищева.
- Чи знає лектор про **псилоцибін / кетамін у депресивних брадифренічних станах**? Сучасна тенденція 2020-х.
- **Чи різниця між «фантастичні концепції» творчого процесу і символічним мисленням** на конкретному прикладі? У клініці буває важко.

## §7 — Applied to coaching (DETECTIVE FM)

Юрій-Детектив працює з клієнтами в коучинговій рамці. ЦА — **коучі / психологи / помагаючі / експерти** (CLAUDE.md: SYNTHESIS — головний фокус). L5 дає **7 actionable правил** з найвищим клінічним пріоритетом — це другий за «делегувальністю» урок усього модуля (після L2).

### 7.1. Чек-ліст темпу мислення клієнта (перші 5 хвилин)

Слухай **темп**, не лише зміст:

| Темп                                              | Інтерпретація                                                              | Дія                                                                |
| ------------------------------------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| Норм + збалансовано                               | Adapt. мислення                                                            | Стандартна коучингова робота                                       |
| **Швидкий, перескакує, фонетичні зчіпки**         | Можлива тахіфренія / скачка ідей (гіпоманія, БАР) ([C-005-027, C-005-028]) | **Сон/енергія/lithium-anamnesis → психіатр**, не коучинг гіпоманії |
| **Уповільнений, паузи >3 сек, одно-складові**     | Брадифренія (депресія) ([C-005-029, C-005-030])                            | **Cross-check L2 чек-ліст депресії → SSRI/SNRI зона**, не коучинг  |
| **Раптові обриви + «забув про що» + «порожнеча»** | Шперрунг (шизо-маркер) ([C-005-031, C-005-032])                            | **Психіатр невідкладно**, не коучинг                               |
| Нав'язливий потік + «не можу зупинити»            | Ментизм / нав'язливі ідеї ([C-005-033, C-005-065])                         | **Психіатр (ОКР, КП-С)**, можливі SSRI                             |

### 7.2. Резонерство — red flag (шизо), а не «креативна філософія»

Лектор у [C-005-040..043] чітко: резонерство — «порожні безплідні міркування». Якщо клієнт у сесії розгортає **наукоподібний потік** про «магнітне поле любові / енергетичні потоки / квантові вібрації душі» — без предметного зв'язку з його реальною ситуацією — це **шизо-маркер на старті продуктивних змін**, не «глибока філософська думка».

**Differentiator** від нормальної рефлексії:

- Рефлексія: «я зрозумів, що...» → конкретний інсайт, можна перевірити досвідом
- Резонерство: довгий потік, кожна теза підкріплюється новою тезою, **смислу нема**, до конкретної ситуації не повертається

**Дія**:

- Спокійно повернути до конкретики: «А як це проявляється в твоєму понеділку?»
- Якщо клієнт не може приземлити — це сигнал для делегування
- Не «розкручуй» далі резонерство — це не глибина, це симптом

### 7.3. Обставинність — епілептоїдний маркер

Якщо клієнт говорить надмірно деталізовано, з гілками, повертається до основної теми («Світланочка-чка-чка, Сонечко моє лясненьке») — це **епілептоїдні зміни особистості** ([C-005-035..039]). Особливо якщо: зменшувальні + повторення + втрата дистанції лікар/пацієнт.

**Differentiator** від нормальної дитячості:

- Нормальна теплота — ситуаційна, гнучка, дозована
- Епілептоїдна — нав'язлива, прилипка, без чутливості до межі

**Дія**:

- В анамнезі — судоми / аури / déjà vu / «голова не своя»?
- Якщо є — **епілептолог + психіатр**
- Якщо немає — це може бути особистісне акцентуйована (стиль), коучингова робота можлива з обережним підтримкою меж

### 7.4. Маячні фабули — НЕ переконувати, делегувати

[C-005-073]: «спроби переконати посилюють бред». Це **категоричне правило**. Якщо клієнт описує:

- Переслідування («коліектив проти мене», «начальник цілеспрямовано шкодить»)
- Впливу («хтось через інтернет читає мої думки», «телефон прослуховується»)
- Ревнощів («партнер мені 100% зраджує», без об'єктивних даних)
- Гріховності («я найгірша людина у світі, тому я хвора»)
- Іпохондричні (стійка впевненість у тяжкій хворобі без критики)
- Отруєння («сім'я труї мою їжу»)
- Інсценування («все навкруги — постановка»)

→ **НЕ обговорювай зміст, не сперечайся, не «розкривай очі». Заплануй візит до психіатра**.

**Coaching framing**:

> «Те, що ти описуєш, виходить за рамки моєї роботи як коуча. Це той рівень, де психіатр може допомогти швидше — і ми з тобою тоді зможемо продовжити після стабілізації. Я допоможу обрати спеціаліста».

**Кейс Каміла Клодель** ([C-005-087..091]) — приклад **типового жіночого сценарію**: жінка-творчиня, розрив з партнером, поступове наростання бреду відносин → переслідування → отруєння → деструктивна поведінка щодо власних робіт → ізоляція. **Якщо клієнтка-творчиня описує таку траєкторію — це невідкладна психіатрична допомога**.

### 7.5. Олігофренія у дорослого — стиль роботи з різним IQ

Якщо клієнт явно має знижений інтелект з дитинства ([C-005-135..142]) — стиль роботи різний:

| Ступінь                | IQ     | Можливості                                   | Коучингова стратегія                                                       |
| ---------------------- | ------ | -------------------------------------------- | -------------------------------------------------------------------------- |
| **Ідіотія**            | ≤20    | без мови, без самообслуговування             | Коучингу нема, лише догляд + супровід родичів                              |
| **Імбецильність**      | 21-50  | проста мова, побутові навички з керівництвом | Не Юрієва ЦА. Робота — лише з родичами/опікунами                           |
| **Дебільність**        | 51-70  | стереотипні фрази, ручна праця               | Дуже структуроване, дуже конкретне, дуже коротке. Не абстрактна філософія. |
| Норма-нижче-середнього | 71-89  | повна функціональність, але не до абстракції | Конкретні приклади, не складна термінологія                                |
| Норма середня          | 90-109 | стандарт                                     | Стандарт                                                                   |
| Висока                 | 110+   | абстракція, метарефлексія                    | Юрієва ЦА (коучі, експерти, СЕО)                                           |

Тест на прислів'я ([C-005-145]) — швидкий орієнтир: чи розуміє переносний смисл?

### 7.6. Як говорити з людиною з афазією

Якщо клієнт раптово став **погано розуміти** або **погано говорити** — це може бути **інсульт** (афазія Брока або Верніке) ([C-005-114, C-005-115]). **Швидка невідкладна** — діагностує і лікує тільки невролог.

Якщо афазія вже діагностована, людина в реабілітації — коуч може бути корисним:

**З моторною афазією (Брока)**:

- Розуміє все, але говорити важко
- НЕ закінчуй за нього речення (дай час)
- Питання так/ні замість відкритих
- Підтримуй ритм, не показуй роздратування паузами

**З сенсорною афазією (Верніке)**:

- Може говорити плавно, але не розуміє
- Жести, картинки, простіші слова
- Перевіряй розуміння через дії, не через «зрозумів?»
- Терплячість + альтернативні канали комунікації

### 7.7. Каміла Клодель — рольова модель сценарію жінки-творчині

Найважливіший кейс для коуча, який працює з ЦА Юрія (психологи, коучі, експерти). Структурно:

| Етап                                                          | Маркери                                              | Дія коуча                                                                  |
| ------------------------------------------------------------- | ---------------------------------------------------- | -------------------------------------------------------------------------- |
| **Розрив зі значущим партнером + творча криза**               | смуток, переоцінка, страждання — норма               | стандартна коучингова робота                                               |
| **Поступова соціальна ізоляція**                              | «вони мене не розуміють», обмеження кола спілкування | червоний прапор, посилити підтримку, чек-ін                                |
| **Бред відношення** («колеги-критики змовляються»)            | стійка непохитна впевненість, незмінна аргументацією | психіатр                                                                   |
| **Бред переслідування + впливу**                              | конкретні «вороги», конкретний механізм впливу       | психіатр невідкладно                                                       |
| **Бред отруєння + деструктивна поведінка щодо власних робіт** | руйнує власне творче, ізолюється повністю            | психіатр невідкладно, родичі — інформувати про необхідність госпіталізації |

**Ключове правило**: **друг або родич, що захищає клієнтку від системи, — ризик-фактор**. Як тільки захисник вмирає / зникає / змінює позицію — клієнтка може опинитися без підтримки і у примусовій госпіталізації, де провести 30 років (як Каміла з 1913 до 1943).

**Що робить коуч**:

- Не лише слухає клієнтку, але **інформує близьке коло** про необхідність професійної допомоги (з її згоди — або поетапно вибудовуючи довіру до лікаря)
- Робить **завчасну консультацію психіатра** ще на етапі «відносинного бреду», не чекаючи переслідування
- Будує **мережу підтримки**, не лише дує-роботи з клієнтом

## §8 — Key facts чек-ліст для тесту

1. **Мислення** ([C-005-001]) — психічний процес, що **полягає в узагальненому та опосередкованому відображенні предметів та явищ навколишнього світу, у їх закономірних зв'язках та відносинах**.
2. **3 форми мислення** ([C-005-013..015]): поняття / судження / висновок (concept / judgment / inference).
3. **3 типи мислення за змістом задачі** ([C-005-007..011]): наочно-дієве (до 3 років, винахідник) / конкретно-образне (4-7+ років, художник) / абстрактно-логічне (8-10 років старт → 14-16 років формування).
4. **4 порушення темпу** ([C-005-027..033]): тахіфренія (скачка ідей, манія) / брадифренія (депресія) / шперрунг (шизо) / ментизм (Кандинський-Клерамбо).
5. **Порушення утворення понять** ([C-005-021..025]): псевдопоняття / **аглютинація (шизо+органіка, приклад «шоколадно»)** / **неологізми (ендогенне шизо, «афеїди і полторанії»)**.
6. **Порушення форми мислення** ([C-005-034..063]) — 12 термінів: обставинність (епілепсія) / резонерство (шизо) / розірваність-шизофазія (шизо) / окрошка (груба шизо) / безв'язність (аменція) / аморфне-зісковзуюче (шизо продром) / паралогічне (шизо схизис) / аутистичне (Блойлер) / символічне (шизо) / вербігерація (амбівалентність) / персеверація (органіка лобових, «Іванович→Іванович») / афективне.
7. **4 рівні порушень змісту мислення** ([C-005-064..074]) — за критерієм критики:
   - **Нав'язливі ідеї** — критика збережена → невроз / ОКР
   - **Домінуючі ідеї** — критика збережена → акцентуація
   - **Надцінні ідеї** — частково збережена → параноидні особистості
   - **Маячні (бредові) ідеї** — повністю відсутня → психоз
8. **Спроби переконати посилюють бред** ([C-005-073]) — клінічне правило.
9. **16 видів маячення** ([C-005-075..086]): переслідування / впливу / відношення / інсценування / збитку / самозвинувачення / самопринижування / нігілістичний (Котар) / іпохондричний / ревнощів (Отелло) / винахідництва / реформаторства / сутяжництва / експансивний / індукований (folie à deux).
10. **Каміла Клодель (1864-1943)** ([C-005-087..091]) — параноидна шизофренія з прогресуючою фабулою: розрив з Роденом ~1898 → бред відношення → переслідування → отруєння → знищення власних робіт → примусова госпіталізація 1913 → 30 років у Montdevergues до смерті 1943. **Фабула = структура бреду**.
11. **3 категорії мовних розладів** ([C-005-092, C-005-110, C-005-119]): психічні (вторинні до мислення) / органічні (афазії, ураження кори) / невротичні (психогенні).
12. **Афазія Брока (моторна)** ([C-005-114]) — порушення продукції мовлення, розуміння збережене; зона Брока (нижня лобова звивина лівої півкулі, поле Бродмана 44/45).
13. **Афазія Верніке (сенсорна)** ([C-005-115]) — порушення розуміння мовлення, плавна, але беззмістовна продукція; зона Верніке (верхня скронева звивина лівої півкулі, поле 22).
14. **Амнестична афазія** ([C-005-112, C-005-113]) — не може назвати, може описати; **початковий маркер — порушення називати пальці** (синдром Герстманна).
15. **Афонія психогенна / істерична** ([C-005-120, C-005-121]) — **шепіт збережений** (відрізнення від органічної).
16. **Слабоумство (стійке зниження інтелекту)** ([C-005-123, C-005-124]) → 2 види: **олігофренія** (вроджене) + **деменція** (набуте).
17. **Олігофренія — 3 ступені** ([C-005-135..142]): **ідіотія IQ ≤ 20** (без мови, без самообслуговування); **імбецильність IQ 21-50** (мова з 3-5 років, побутові навички); **дебільність IQ 51-70** (стереотипні фрази, допоміжна школа).
18. **Деменція — 2 типи** ([C-005-127..134]):
    - **Лакунарна**: критика збережена, особистість зберігає «силует» + морально-етичні властивості («залишкова особистість»)
    - **Тотальна**: критика відсутня, повний розпад особистості, інтереси зводяться до елементарних біологічних потреб; **першими страждають вищі рівні** (Джексонівська дисолюція)
19. **Діагностика мислення/інтелекту** ([C-005-143..146]): бесіда + спостереження + експериментально-психологічні методики (узагальнення/виключення понять, класифікація, прислів'я, асоціативний експеримент, сюжетні картини, послідовність подій) + **тест Векслера (WAIS)** + bedside-тест «острів vs півострів».
20. **Quiz Q1 — патологічна обставинність** ([C-005-035, C-005-147]): епілептична пацієнтка описує абсансний епізод через надмірну деталізацію (бабуся / село / дівчата / ліс / гриби) — over-inclusion of irrelevant detail.

## §9 — Mnemonic devices for the exam

### 9.1. «ТФЗМ» — 4-точкова рамка оцінки мисленнєвого статусу

- **Т**емп → тахі / брадi / шперрунг / ментизм
- **Ф**орма → обставинність / резонерство / шизофазія / окрошка / безв'язність / аморфне / паралогіка / аутизм / символічне / вербігерація / персеверація / афективне
- **З**міст → нав'язливі / домінуючі / надцінні / маячні
- **М**ова → психічна / органічна / невротична

### 9.2. «П-С-В» — 3 форми мислення

- **П**оняття (concept)
- **С**удження (judgment)
- **В**исновок (inference)

### 9.3. «ОР-ШО-БА-АП-СВ-ПА» — 12 форм порушень мислення

- **О**бставинність — епілепсія
- **Р**езонерство — шизо
- **Ш**изофазія / розірваність — шизо
- **О**крошка — шизо груба
- **Б**езв'язність — аменція
- **А**морфне / зісковзуюче — шизо продром
- **П**аралогічне — шизо схизис
- **А**утистичне — шизо (Блойлер)
- **С**имволічне — шизо
- **В**ербігерація — амбівалентність
- **П**ерсеверація — органіка лобових
- **А**фективне — афективні розлади

### 9.4. «П-В-Р-Г-І-О-В + інші» — 7 ключових + 9 інших фабул маячення

- **П**ереслідування → параноидна шизо
- **В**пливу → Кандинський-Клерамбо
- **Р**евнощів → синдром Отелло (алкогольний галюциноз)
- **Г**ріховності/самозвинувачення → депресія психотична
- **І**похондричний → шизо/депресія
- **О**труєння → шизо (іноді у Каміли Клодель)
- **В**еличі (експансивний) → манія/шизо

* інші: відношення, інсценування, збитку, самопринижування, нігілістичний (Котар), винахідництва, реформаторства, сутяжництва, індукований (folie à deux).

### 9.5. «БВ-АА-ПД» — 3 групи органічних розладів мовлення

- **Б**рока (моторна афазія) — лоба ліва, продукція ламається
- **В**ерніке (сенсорна афазія) — скроня ліва, розуміння ламається
- **А**мнестична афазія — забуває слова, описує функцію
- **А**фазія взагалі — артикуляція+слух збережені
- **П**арафазія — заміна звуків/слів неправильними
- **Д**изартрія — артикуляційний апарат уражений (ЦНС / черепно-мозкові нерви)

### 9.6. «ІІ-Д-Д» — інтелектуальні градації

- **І**діотія (IQ ≤ 20) — без мови, без самообслуговування
- **І**мбецильність (IQ 21-50) — мова з 3-5 років, побутові навички
- **Д**ебільність (IQ 51-70) — стереотипні фрази, допоміжна школа
- **Д**еменція — набуте слабоумство (лакунарна vs тотальна)

### 9.7. «Критика» як універсальний дифдіагностичний параметр

Збережена критика → невроз / лакунарна деменція / нав'язливі ідеї → **коучингова зона можлива**.
Втрачена критика → психоз / тотальна деменція / маячні ідеї → **психіатр + делегування**.

### 9.8. «Граматика + смисл» — швидкий вибір серед «нісенітниць»

| Граматика  | Смисл  | Швидкість   | Висновок                           |
| ---------- | ------ | ----------- | ---------------------------------- |
| ціла       | пустий | норм        | резонерство (шизо)                 |
| ціла       | нема   | норм        | шизофазія (шизо)                   |
| ціла       | нема   | дуже швидка | сенсорна афазія Верніке (інсульт!) |
| ціла       | плинне | дуже швидка | скачка ідей (манія)                |
| зруйнована | нема   | швидко      | окрошка (шизо груба)               |
| зруйнована | нема   | паузи       | безв'язність (аменція)             |

### 9.9. Каміла Клодель — мнемонічна траєкторія

**1898 (розрив) → 1900-1905 (відношення) → 1905-1913 (переслідування + отруєння + руйнування робіт) → 1913 (примусова госпіталізація) → 1913-1943 (30 років у Montdevergues до смерті)**
