## Quick summary

Лекція ~33:28 хв від Світлани Володимирівни Ісаєнко. **Найбагатший термінологічно урок** модуля 10 — ~80 окремих feno-категорій порушень мислення / мови / інтелекту. Без нього всі наступні нозологічні уроки (L7 шизо, L8 БАР, L9 депресія, L13 особистість) залишаються без термінологічного скаффолду.

**Ключова теза**: мислення = поняття + судження + висновок. Поломки бувають за **темпом / формою / змістом / мовою** — і кожна поломка є **маркером конкретної нозології**. L5 дає коучу і психіатру **дифдіагностичний скрін мовно-мисленнєвого статусу** за перші 5-10 хвилин.

**8 секцій лекції** за slide 2 «Зміст»:

1. Визначення мислення + класифікація типів (наочно-дієве / конкретно-образне / абстрактно-логічне)
2. 3 форми мислення (поняття / судження / висновок) + інтелект
3. Порушення утворення понять (псевдопоняття / аглютинація «шоколадно» / неологізми «афеїди і полторанії»)
4. Порушення темпу (тахіфренія / брадифренія / шперрунг / ментизм)
5. Порушення форми (12 термінів: обставинність / резонерство / шизофазія / окрошка / безв'язність / аморфне / паралогіка / аутизм Блойлера / символічне / вербігерація / персеверація / афективне)
6. Порушення змісту (нав'язливі / домінуючі / надцінні / маячні) + 16 фабул маячення + Каміла Клодель
7. Психічні + органічні + невротичні мовні розлади (брадифазія, ехолалія, мутизм + 3 підтипи, афазія Брока, афазія Верніке, амнестична, парафазія, дизартрія, афонія, заїкання)
8. Розлади інтелекту: слабоумство → деменція (лакунарна vs тотальна) + олігофренія (ідіотія IQ≤20 / імбецильність IQ 21-50 / дебільність IQ 51-70)

## Key claims (top 15 — пріоритет для тесту)

1. **3 форми мислення** [C-005-013..015]: поняття (концепт) / судження / висновок
2. **3 типи за змістом задачі** [C-005-007..011]: наочно-дієве (до 3 років, винахідник) / конкретно-образне (4-7+, художник) / абстрактно-логічне (8-10 років старт, 14-16 формування)
3. **Порушення утворення понять** [C-005-021..025]: псевдопоняття / **аглютинація «шоколадно» (шизо+органіка)** / **неологізми «афеїди і полторанії» (ендогенне шизо)**
4. **4 порушення темпу** [C-005-027..033]: тахіфренія (манія) / брадифренія (депресія) / шперрунг (шизо) / ментизм (Кандинський-Клерамбо)
5. **Патологічна обставинність** [C-005-035..039] — епілептоїдний маркер, в'язке мислення, зменшувальні («Світланочка-чка-чка»), приклад барон Мюнхгаузен про волосся → казка про ріпку
6. **Резонерство** [C-005-040..043] — шизо-маркер; «трактат про любов і магнітне поле» — наукоподібний потік без смислу
7. **Розірваність / шизофазія** [C-005-044..049] — граматика збережена, смислу нема («тістечко імперіалізму — сорок курчат»); словесна окрошка («Хюмала рюмала») — крайній ступінь, граматика зруйнована
8. **Персеверація** [C-005-061, C-005-062] — застрягання, органіка лобових долей («Петро Іванович → Іванович → Іванович»)
9. **4 рівні порушень змісту за критикою** [C-005-064..074]:
   - Нав'язливі (критика збережена) → невроз / ОКР
   - Домінуючі (збережена) → акцентуація
   - Надцінні (частково) → параноидні особистості
   - Маячні (відсутня, спроби переконати посилюють) → психоз
10. **16 видів маячення** [C-005-075..086]: переслідування / впливу / відношення / інсценування / збитку / самозвинувачення / самопринижування / нігілістичний (Котар) / іпохондричний / ревнощів (Отелло) / винахідництва / реформаторства / сутяжництва / експансивний / індукований (folie à deux)
11. **Каміла Клодель (1864-1943)** [C-005-087..091] — параноидна шизофренія: розрив з Роденом 1898 → бред відношення → переслідування → отруєння → знищення робіт → примусова госпіталізація 1913 → 30 років у Montdevergues. **Фабула = структура бреду**.
12. **3 категорії мовних розладів** [C-005-092, C-005-110, C-005-119]: психічні (вторинні до мислення) / органічні (афазії — інсульт, травма) / невротичні (психогенні)
13. **Афазія Брока (моторна)** [C-005-114] — порушення продукції мовлення, розуміння збережене (зона Брока: нижня лобова звивина лівої півкулі, поле Бродмана 44/45). **Афазія Верніке (сенсорна)** [C-005-115] — порушення розуміння, плавна беззмістовна продукція (зона Верніке: верхня скронева звивина лівої півкулі, поле 22). **При афазії артикуляційний апарат і слух збережені** [C-005-111]
14. **Олігофренія** [C-005-135..142] — 3 ступені: ідіотія (IQ ≤ 20) / імбецильність (IQ 21-50) / дебільність (IQ 51-70). **Деменція** [C-005-127..134] — 2 типи: лакунарна (критика збережена, особистість зберігається — «залишкова особистість») vs тотальна (критика відсутня, повний розпад, страждають вищі рівні згори вниз — Джексонівська дисолюція)
15. **Діагностика** [C-005-143..146]: бесіда + спостереження + експериментально-психологічні методики (узагальнення/виключення понять, прислів'я переносне значення, асоціативний експеримент, сюжетні картини, Векслер WAIS) + bedside «острів vs півострів»

## Coaching application (DETECTIVE FM)

7 actionable правил для Юрія-Детектива (детально у `synthesis.md` §7):

1. **Чек-ліст темпу мислення клієнта** — слухай як швидко мислить:
   - Швидкий+перескакує+фонетика → можлива гіпоманія/БАР → психіатр
   - Уповільнений+паузи+одно-складові → можлива депресія → SSRI зона
   - Раптові обриви+порожнеча → шперрунг (шизо) → психіатр невідкладно
   - Нав'язливий потік → ОКР/КП-С → психіатр
2. **Резонерство — red flag (шизо), не «креативна філософія»** — якщо клієнт розгортає наукоподібний потік про «магнітне поле любові» без зв'язку з реальною ситуацією, **не розкручуй**, повертай до конкретики; якщо не приземлюється — делегуй.
3. **Обставинність — епілептоїдний маркер**, не «дитячість» — зменшувальні+повторення+втрата дистанції → запитай про судоми/аури → епілептолог+психіатр.
4. **Маячні фабули — НЕ переконувати, делегувати** ([C-005-073]) — спроби переконати посилюють бред. Каміла Клодель як рольова модель сценарію жінки-творчині (розрив→ізоляція→бред відносин→переслідування→отруєння→руйнування власних робіт→примусова госпіталізація).
5. **Олігофренія у дорослого — стиль роботи з різним IQ**: дебільність (51-70) — структурно, конкретно, коротко; норма-нижче (71-89) — без складної термінології; норма+ (90+) — стандарт; ЦА Юрія — 110+ (коучі, експерти). Тест на прислів'я — швидкий орієнтир абстрактного мислення.
6. **Як говорити з людиною з афазією**: моторна (Брока) — не закінчуй за нього речення, питання так/ні; сенсорна (Верніке) — жести+картинки+простіші слова, перевіряй через дії. Раптовий гострий початок = інсульт = швидка.
7. **Каміла Клодель — рольова модель**: жінка-творчиня в кризі + розрив зі значущим партнером + соціальна ізоляція + бред відношення/переслідування → **друг/родич-захисник = ризик-фактор** (коли він зникає, клієнтка опиняється в примусовій госпіталізації на 30+ років). Будь не лише для клієнтки — інформуй близьке коло про необхідність професійної допомоги.
