### P1 — Панічна атака (Q1 prediction)

**Q**: Пацієнт 30 років у переповненому метро раптово відчув різку колючу боль у грудях, серце «вискакувало», важко було дихати, з'явився страх смерті. Тривалість приступу — 25 хвилин, симптоми пройшли самостійно. ЕКГ норма, тропонін негативний. Який це симптом?

**Варіанти**:

1. Гострий коронарний синдром
2. Тромбоемболія легеневої артерії
3. **Панічна атака (Панічний розлад F41.0)**
4. Генералізований тривожний розлад
5. Соматизаційний розлад

**Correct**: 3 (Панічна атака / Панічний розлад F41.0)

**Пояснення**: За claim [C-010-018]: «Основні симптоми – чрезмерний страх, чувство надвигаючоїся смерті, спровождаючіся тахікардією, віддишкою, потливостю. Більний намагається покинути місце». **Ключові ознаки**:

1. **Раптовий** початок (без тригера або після стресу)
2. **Тяжка тривога / паніка** (extreme fear)
3. **Sense of impending death** — pathognomonic [C-010-018]
4. **Тахікардія** + **задишка** + **пітливість** (sympathetic activation)
5. **Тривалість 20-30 хвилин** + симптоми **зменшуються** з часом [C-010-021]
6. **Спонтанне зникнення**

**Differential з ГКС** [C-010-021]:

| Параметр      | Панічна атака     | Серцевий приступ        |
| ------------- | ----------------- | ----------------------- |
| Характер болю | **різка, колюча** | **стискаюча, давляча**  |
| Динаміка      | **↓ зменшується** | **↑ збільшується**      |
| Тривалість    | 20-30 хв          | довше                   |
| Іррадіація    | рідко             | в руку, щелепу, лопатку |
| ЕКГ           | норма             | ST↑/↓, зміни Т          |
| Тропонін      | негативний        | позитивний              |

**ЕКГ норма + тропонін негативний** — ⭐ критичні маркери для excluding ГКС.

**Класифікація МКБ-10** [C-010-024]:

- **F41.00** — помірний (≥4 атаки/місяць)
- **F41.01** — важкий (≥4 атаки/тиждень)

**Differentials excluded**:

- **ГКС** — болі зменшилися, ЕКГ норма
- **ГТР** — симптоми епізодичні, не chronic worry ≥6 міс
- **Соц. фобія** — нема тригера social performance
- **Соматизаційний** — episodic anxiety attack, не >2 років multi-system

**Coaching pearl** [C-010-019]: між атаками — **anticipatory anxiety** («тривожне очікування повторення»), що генерує avoidance behavior + хронізацію + еволюцію в агорафобію.

**Source**: C-010-017 → C-010-024, C-010-090 / transcript [02:30-05:00] + slides 4-6

### P2 — Тест відрізнення психогенної задишки від органічної

**Q**: Який тест дозволяє відрізнити психогенну задишку від органічної природи?

**Варіанти**:

1. ЕКГ протягом 24 годин (Холтерівське моніторування)
2. Спірометрія з визначенням FEV1
3. **Затримка дихання ≥30 секунд + рахунок вголос >10-20**
4. Газовий аналіз крові з визначенням pCO2
5. Бронхоскопія

**Correct**: 3 (Затримка дихання ≥30 секунд + рахунок вголос >10-20)

**Пояснення**: За claim [C-010-022]: «при психогенній віддихі лікар може задержувати дихання не менше, ніж на 30 секунд, і медліно засчитати вслух більше, ніж 10-20, що неможливо при удуші органічної природи».

**Diagnostic logic**:

| Стан                               | Затримка ≥30 сек | Рахунок >10-20 вголос |
| ---------------------------------- | ---------------- | --------------------- |
| **Психогенна задишка**             | ✅ МОЖЕ          | ✅ МОЖЕ               |
| **Органічна задуха** (астма, ХОЗЛ) | ❌ НЕ МОЖЕ       | ❌ НЕ МОЖЕ            |
| **ТЕЛА**                           | ❌ НЕ МОЖЕ       | ❌ НЕ МОЖЕ            |
| **Набряк легень**                  | ❌ НЕ МОЖЕ       | ❌ НЕ МОЖЕ            |

⭐ **Clinical pearl лектора**: «**можеш порахувати — значить психогенне**». Цей тест проводиться у швидкій допомозі за 30 секунд і скорочує дорогу діагностики.

**Додаткові diagnostic тести** для anxiety:

1. **Тест відвертання уваги розмовою** [C-010-023]: при паніці увага захоплена дихальною дисфункцією → відволікати розмовою → нормалізується дихання. При органічній — НЕ змінюється.
2. **Тест зміни положення тіла** [C-010-023]: при панічній атаці зміна положення НЕ впливає на самопочуття. При кардіальній — position matters (стенокардія гірше лежачи).
3. **ЕКГ + тропонін** [C-010-021]: gold standard для excluding ГКС.

**Mnemonic для тестів — БВЗ**:

- **Б** — Breath-hold ≥30c
- **В** — Відвертання розмовою
- **З** — Зміна положення

**Чому не варіанти 1, 2, 4, 5**:

- Холтерівське (1), спірометрія (2), газовий аналіз (4), бронхоскопія (5) — це **дорогі і часозатратні** дослідження, ↑ затримка діагнозу. Лектор spec.: розмова + breath-hold = **безкоштовний рапид-тест** на місці.

**Source**: C-010-020, C-010-022, C-010-023 / transcript [04:00-05:00] + slide 6

### P3 — Генералізований тривожний розлад: критерії

**Q**: Який з нижче перелічених симптомів НЕ є характерним для генералізованого тривожного розладу (ГТР)?

**Варіанти**:

1. Постійна напруженість + неможливість розслабитися
2. Внутрішнє тремтіння + боязкість + катастрофізація
3. Прокручування в голові подій при засинанні
4. **Раптові непередбачувані атаки тяжкої тривоги тривалістю 20-30 хв з anticipatory anxiety між атаками**
5. Постійна перевірка пульсу

**Correct**: 4 (Раптові атаки 20-30 хв з anticipatory anxiety — це **панічний розлад F41.0**, не ГТР)

**Пояснення**: ГТР [C-010-026] — це **хронічний** розлад з **free-floating** тривогою, що **не обмежується обставинами**. DSM-5 gate — тривалість ≥**6 місяців**. Panic attacks 20-30 хв — це **F41.0 панічний розлад**, окрема нозологія.

**Класична тріада ГТР** [C-010-087]:

| Компонент                            | Phenomenology                         | Маркери              |
| ------------------------------------ | ------------------------------------- | -------------------- |
| **Apprehensive expectation** (worry) | Catastrophizing, anticipatory dread   | C-010-027, C-010-028 |
| **Motor tension**                    | М'язова напруга, тремор, restlessness | C-010-012, C-010-030 |
| **Autonomic hyperactivity**          | Тахікардія, піт, ШКТ симптоми         | C-010-010..015       |

**Inзісти ГТР, відсутні в інших розладах**:

1. **Внутрішнє тремтіння + боязкість + catastrophizing** [C-010-027]: «у всіх справах передбачують найгірший результат» — central CBT target
2. **6 worry topics** [C-010-028]: запізнення / робота / **здоров'я** / **діти** / фінанси / ... — multifocal worry
3. **Pre-sleep rumination** [C-010-029]: «прокручування в голові» — patognomonic ГТР. 2 джерела матеріалу — ретроспективне («що сталося сьогодні») + проспективне («що буде поганого»)
4. **Pulse-checking** [C-010-031] — ⭐ pearl: «якщо ви бачите людину, яка меряє постійно свій пульс — це людина з тривожним розтройством»
5. **9 об'єктивних рухових ознак** [C-010-030]: fidgeting + tremor пальців + sighing + блідість + ковтальні рухи

**Differential з depressive insomnia** (cross-ref L9): depression has **early-morning waking primary**; ГТР has **sleep-onset insomnia primary** + ruminative pre-sleep cognition.

**Mnemonic ГТР = «ГТР=6м-FF-MT»**:

- **6м** — мінімум 6 місяців тривалість
- **FF** — Free-Floating (не обмежена ситуацією)
- **MT** — Motor Tension (м'язова напруга)

**Source**: C-010-026 → C-010-031, C-010-087 / transcript [05:30-07:00] + slide 7

### P4 — Агорафобія: симптоми + тригерні ситуації

**Q**: Які з нижче перелічених ситуацій є типовими тригерами агорафобії?

**Варіанти**:

1. Розмова з близькими членами родини
2. Перебування на самоті у власній квартирі
3. **Метро, магазин, натовп, ліфт, літак, театр, кінозал**
4. Контакт з тваринами (собаки, павуки)
5. Виступ перед аудиторією

**Correct**: 3 (метро, магазин, натовп, ліфт, літак, театр, кінозал — 7 типових тригерів агорафобії)

**Пояснення**: За claim [C-010-033, C-010-034]: агорафобія F40.0 = «**боязнь открытых пространств, транспорта, а также толпы**». Сучасне розуміння ширше — **страх ситуацій, з яких важко вийти або де нема допомоги**.

**7 типових тригерів агорафобії**:

| #   | Тригер  | Спільна риса                          |
| --- | ------- | ------------------------------------- |
| 1   | Метро   | Замкнутий + рух + натовп              |
| 2   | Магазин | Натовп + черга + комерц. expectations |
| 3   | Натовп  | Велика concentration людей            |
| 4   | Ліфт    | Замкнутий простір + відсутність exit  |
| 5   | Літак   | Замкнутий + неможливість вийти        |
| 6   | Театр   | Замкнутий + соц. expectations         |
| 7   | Кінозал | Замкнутий + темрява + натовп          |

⭐ **Common ключ**: **escape-impossibility + help-distance**. Пацієнт не може швидко вийти або отримати допомогу при панічній атаці.

**Cluster симптомів агорафобії** (3 групи) [C-010-035, 036, 037]:

1. **4 вегетативних**: сухість у роті + тахікардія + **профузний піт** + тремор
2. **5 торако-абдомінальних**: задишка + задуха + біль у грудях + нудота + дискомфорт ШКТ
3. **3 психічних**: **дереалізація** + **деперсоналізація** + страх втратити контроль

**Behavioral pattern** [C-010-038]:

- **Уникнення** як core mechanism
- **Супровід близької людини** як safety signal — частковий compromise
- У важких випадках — **housebound** (не виходить з дому місяцями-роками)

**Чому не варіанти 1, 2, 4, 5**:

- **Розмова з близькими** (1) — це **навпаки соціальна фобія** диференціація: при соц. фобії з близькими **комфортно** [C-010-042]
- **Перебування на самоті у квартирі** (2) — не агорафобія; може бути депресією або обсесивним самостворенням
- **Тварини** (4) — це **специфічна фобія F40.2** (зоофобія)
- **Виступ** (5) — це **соціальна фобія F40.1**

**Pearl**: ступінь агорафобії = «scope of avoidance» — від «не їжджу в метро» до «не виходжу з квартири 3 місяці».

**Source**: C-010-033, C-010-034, C-010-038 / transcript [07:00-08:00] + slide 8

### P5 — Соціальна фобія: ключове diferential питання

**Q**: Яка особливість дозволяє ВИКЛЮЧИТИ соціальну фобію при наявності страху спілкування?

**Варіанти**:

1. Маніфестація у підлітковому віці
2. Страх виступів і іспитів
3. **Дискомфорт у спілкуванні зі близькими членами родини**
4. Збереження критики до власного страху
5. Наявність вегетативних симптомів (тремор рук, почервоніння)

**Correct**: 3 (Дискомфорт у спілкуванні з близькими — соц. фобія саме з близькими ВІДСУТНЯ)

**Пояснення**: За claim [C-010-042]: «**Спілкування з близьким страха не викликає**». Це **ключове diagnostic differentiation criterion**.

**Diferential table — страх спілкування**:

| Розлад                  | Страх з близькими?             | Страх з посторонніми? | Підказка                              |
| ----------------------- | ------------------------------ | --------------------- | ------------------------------------- |
| **Соц. фобія F40.1**    | ❌ НІ — комфортно              | ✅ ТАК                | Близькі OK = соц. фобія               |
| **Autism / РАС**        | ✅ ТАК — global проблеми       | ✅ ТАК                | Global communicative проблеми         |
| **Avoidant PD**         | ✅ ТАК — core sense inadequacy | ✅ ТАК                | Personality-rooted уникнення          |
| **Шизо-аутизм**         | ✅ ТАК — withdrawal global     | ✅ ТАК                | + інші продуктивні/негативні симптоми |
| **Депресія withdrawal** | ✅ ТАК — anhedonia + isolation | ✅ ТАК                | + інші маркери депресії               |

⭐ **Diagnostic question лектора**: «Як ви відчуваєте себе у розмові з родиною?» — якщо комфортно → соц. фобія більш ймовірна.

**Інші ознаки соц. фобії** [C-010-039 → C-010-048]:

1. **Дебют** [C-010-040]: підлітковий + юнацький вік (12-22 роки typically)
2. **5 тригерів школи/університету** [C-010-041]: дошка / іспит / сцена / вчителі / **протилежна стать**
3. **5 feared actions** [C-010-043]: говорити / їсти / писати / громадський туалет (paruresis) / вечірки
4. **Meta-fear** [C-010-044]: страх що оточуючі помітять страх → secondary fear → ↓ self-esteem
5. **5 comorbidities** [C-010-045]: ГТР / інші фобії / афективна / **алкоголізм** (self-medication «розкутися») / розлади харчової поведінки

**Класифікація** [C-010-046]:

| Підтип                | Зміст                                                           |
| --------------------- | --------------------------------------------------------------- |
| Ізольована (specific) | страх 1-2 specific ситуацій (виступи, написання при людях)      |
| Генералізована        | страх більшості соц. ситуацій + ідеї малоцінності + скоптофобія |

**Ерітофобія** [C-010-047]: страх почервоніти — ізольована form (self-fulfilling prophecy).
**Скоптофобія** [C-010-048]: страх здаватися смішним — core syndrome генералізованої.

**Pearl для коуча**: при алкогольній залежності у молодого пацієнта обов'язково питати про соц. фобію (~50% comorbidity).

**Source**: C-010-039, C-010-040, C-010-041, C-010-042, C-010-043, C-010-046 / transcript [08:00-10:00] + slide 8

### P6 — Іпохондричні фобії (нозофобії)

**Q**: Пацієнт середніх років постійно звертається до різних лікарів, вимагає обстеження, переїхав в «екологічно чистий район», обговорює з друзями «що йому залишилось недовго» через підозру на рак. Який це розлад?

**Варіанти**:

1. **Іпохондрична фобія (нозофобія) — канцерофобія**
2. Іпохондричний розлад (соматоформний F45.2)
3. Депресивний епізод з нігілістичним маяченням (Котар)
4. Маячіння переслідування при шизофренії
5. Маніакальний епізод з manической ідеєю

**Correct**: 1 (Іпохондрична фобія — канцерофобія)

**Пояснення**: За claim [C-010-049]: «Іпохондричні фобії, назофобії, нав'язковий страх важкого заболівання. Найбільше бачиться **кардіо, канцер, сифіла, спіда, інсульто**-фобія».

**Top-5 нозофобій (Mnemonic = ККСНІ)**:

1. **К**ардіофобія — страх інфаркту / кардіальної смерті
2. **К**анцерофобія — страх раку
3. **С**ифілофобія — страх сифілісу (historic high prevalence)
4. **С**Н**І**Дофобія — страх ВІЛ/СНІД
5. **І**нсультофобія — страх інсульту

**5 поведінкових патернів** [C-010-050]:

| #   | Pattern                                                    | Mechanism                        |
| --- | ---------------------------------------------------------- | -------------------------------- |
| 1   | **«Doctor shopping»** — обхід різних лікарів               | Search for reassurance           |
| 2   | Обговорення з родичами/друзями («мені залишилось недовго») | Externalization of fear          |

### P8 — ОКР: ego-dystonic природа обсесій

**Q**: Який з ознак найточніше характеризує природу нав'язливих думок при ОКР?

**Варіанти**:

1. Пацієнт усвідомлює, що думки нав'язали ззовні (хтось ВКЛАВ їх)
2. Думки приймаються як свої, узгоджуються з ціннісною системою
3. **Думки сприймаються як чужі, абсурдні; пацієнт намагається їм протистояти**
4. Думки супроводжуються імперативними голосами ззовні
5. Пацієнт виконує дії за «зовнішнім наказом»

**Correct**: 3 (Думки сприймаються як чужі, абсурдні; пацієнт активно протистоїть = ego-DYSTONIC природа)

**Пояснення**: За claim [C-010-060]: «Нав'язчі думки з'являються помімо болі хворого. Восприймається їм як **чужди, абсурдні**, він намагається їм протистояти. Пацієнти описують, як-будто **дрелью** входить ця думка».

**3 phenomenological ознаки обсесій**:

1. **Поза волею** (intrusive, unwilled) — з'являються незалежно від бажання пацієнта
2. **Ego-dystonic** — сприймаються як **чужі**, не мої
3. **Абсурдні** — пацієнт усвідомлює **нерациональність**

**Пацієнт активно протистоїть** обсесії.

**⭐⭐⭐ Критичний differential з маяченням впливу (шизо, cross-ref L7 C-007m10-032)** [C-010-082]:

| Параметр        | Обсесія (ОКР F42)                 | Маячіння впливу (шизо параноїдна F20.0)       |
| --------------- | --------------------------------- | --------------------------------------------- |
| Ego-syntonicity | **ego-DYSTONIC** (відразлива)     | **ego-SYNTONIC** (внутрішньо логічна)         |
| Критика         | збережена («я знаю що це абсурд») | відсутня (anosognosia)                        |
| Resistance      | пацієнт активно бореться          | пацієнт не бореться, accept reality           |
| Source          | «моя думка, але чужа»             | «**хтось ВКЛАВ** цю думку у мою голову»       |
| Behavior        | safety behavior (ховання ножів)   | response to external command (виконує)        |
| Voice quality   | внутрішня intrusive thought       | псевдогалюцинація Кандинського (cross-ref L7) |
| Imperative      | НЕМАЄ команд                      | Так, імперативні голоси (cross-ref L7 ст. 14) |

⭐ **Pearl**: обсесія = «я **БОЮСЯ**, що зроблю»; маячіння впливу = «мені **НАКАЗУЮТЬ** зробити».

**Метафора лектора «дрилем»** [C-010-060]: «як-будто дрилем входить ця думка» — потужна clinical metaphor, передає invasive nature. Корисно для пояснення пацієнтам.

**Чому не варіанти 1, 2, 4, 5**:

- **«Хтось ВКЛАВ» (1)** — це **маячіння впливу шизофренії** (Beeinflussungswahn, Schneider's first-rank symptom)
- **Думки як свої + узгоджуються** (2) — це **ego-syntonic**, характерно для маячіння або OCPD (perfectionism)
- **Імперативні голоси ззовні** (4) — це **псевдогалюцинація Кандинського з імперативним змістом** (cross-ref L7 C-007m10-028, C-007m10-038)
- **«Виконує за зовнішнім наказом» (5)** — це **made volition / impulse imposed** (Schneider 1-rank symptom шизо)

**Pearl для emergency psychiatry**: пацієнт з ego-dystonic обсесіями ховає ножі = **НЕ небезпечний**. Пацієнт з ego-syntonic маяченням впливу + імперативними голосами = **потенційно небезпечний**, ст. 14.

**Source**: C-010-060, C-010-066, C-010-067, C-010-082, C-010-092 / transcript [13:00-15:30] + slides 10-11

### P9 — Контрастні обсесії — emergency psychiatry differential

**Q**: Молода мати скаржиться, що у неї з'являються нав'язливі думки «нанести шкоду власній дитині». Вона бореться з цими думками, ховає ножі і виделки в шафу подалі, бо боїться. Що це?

**Варіанти**:

1. Шизофренія з маяченням впливу — невідкладна ст. 14
2. Психотична депресія з нігілістичним маяченням
3. Маніакальний епізод з агресивними тенденціями
4. **Обсесивно-компульсивний розлад з контрастними обсесіями (F42)**
5. Параноїдний розлад особистості

**Correct**: 4 (ОКР з контрастними обсесіями F42)

**Пояснення**: За claim [C-010-066]: «Чрезвичайно неприємними є **контрастні нав'язчивості**, коли у хворих з'являється непреодолиме влечення зробити дійсність або произнести фразу, протиречуючи їхнім власним встановкам і взагалі прийнятої моралі. Наприклад, **нанести увечі своїм близьким, дітям**. Ці мисли викликають страх, втрату контролю над собою... Більні просять близьких **прятати ножі, вілки, топори**».

**3 типи контрастних обсесій**:

| Тип                | Зміст                                         | Trigger                   |
| ------------------ | --------------------------------------------- | ------------------------- |
| **Обсценні**       | Вигукнути нецензурне у церкві / при дітях     | Soc/religious context     |
| **Агресивні**      | Нанести каліцтва близьким, **особливо ДІТЯМ** | Vulnerable family members |
| **Самоушкоджуючі** | Стрибнути з висоти, кинутися під поїзд        | Heights, transport        |

**Safety behavior** [C-010-066]: ховання гострих предметів (**ножі, виделки, сокири**) — це **ОЗНАКА ОКР**, не plan to harm.

**⭐⭐⭐ КРИТИЧНА differential**:

**Контрастна обсесія ≠ намір. Пацієнт БОЇТЬСЯ, що зробить — НЕ ХОЧЕ зробити.**

| Ознака             | ОКР контрастна обсесія          | Шизо маячіння впливу + імператив |
| ------------------ | ------------------------------- | -------------------------------- |
| Хочe зробити?      | **❌ НІ — бориться**            | ✅ ТАК — accept                  |
| Ховає ножі?        | **✅ ТАК — safety behavior**    | ❌ НІ — НЕ безпекує              |
| Голос?             | Своя intrusive думка            | Зовнішня команда / голос         |
| Критика збережена? | **✅ ТАК — «я знаю це абсурд»** | ❌ НІ — anosognosia              |
| Risk to others?    | **❌ НЕ небезпечний**           | ⚠️ Потенційно небезпечний        |

**❌❌❌ Пейтрашня помилка emergency psychiatry**:

**НЕ госпіталізувати пацієнта з контрастними обсесіями як «суїцид/гомицид risk»** — це **maintenance OCD by validating fear**. Госпіталізація:

1. Підтверджує пацієнтський страх «я небезпечний»
2. Заохочує **avoidance behavior**
3. Виключає **ERP** як терапію (через стресс ситуації)
4. Може trigger compensatory rituals

**Pearl лектора (implicit)**: treat as ОКР з ERP. Нормалізувати: «Це ОКР, він лікується. Ви НЕ небезпечні».

**Чому не варіанти 1, 2, 3, 5**:

- **Шизо маячіння впливу (1)** — ego-syntonic, не бориться, не ховає ножі; чути голос «вбити»; критика відсутня
- **Психотична депресія з Котаром (2)** — нігілістичне маячіння («у мене немає тіла»), suicidal не гомицидальний
- **Маніакальний епізод (3)** — підвищена самооцінка + euphoria, не страх власних думок
- **Параноїдний PD (5)** — зовнішні переконання про злий намір ОТОЧУЮЧИХ, не власні агресивні думки

**Терапія** [C-010-076]:

- **SSRI high dose** (2-3× від депресивних) — sertraline, fluoxetine, fluvoxamine
- **Clomipramine** (TCA) — classic anti-OCD
- **ERP** (Exposure-Response Prevention) — gold standard psychotherapy
- НЕ BZD long-term (можуть посилити avoidance)

**Treatment-resistant warning** [C-010-075]: контрастні обсесії — одна з **5 resistant subtypes** ОКР. Може потребувати augmentation (quetiapine low-dose).

**Pearl для коуча**: при описі клієнтом «у мене думки нанести шкоду» + ego-dystonic + safety behavior → **mandatory referral до психіатра з ERP-trained CBT**. **НЕ медитація** (uplifts attention on intrusive thoughts → ↑ obsessions). **НЕ «ну ви ж не хочете»** (посилить doubt). **НОРМАЛІЗУВАТИ**: «Це ОКР, лікується, ви не небезпечні».

### P10 — Мізофобія + cleaning rituals

**Q**: Пацієнт миє руки 30-40 разів на день до тріщин на шкірі, протирає всі поверхні в квартирі, не пускає родичів, бо «вони можуть принести інфекцію». Який це розлад?

**Варіанти**:

1. **Мізофобія (ОКР F42) з cleaning rituals**
2. Іпохондричний розлад (соматоформний F45.2)

**Correct**: 1 (Мізофобія — частина ОКР F42 з cleaning compulsions)

**Пояснення**: За claim [C-010-068, 069, 070]:

- **Мізофобія** [C-010-068] (грец. mysos = бруд) — «нав'язчі мислі і страх загрізнення, мізофобія. Вони бояться загрізнення пилю, мочою, землею, нечистотами, а також проникнення в організм ядовитих віществ, мікроорганізмів»
- **5 cleaning compulsions** [C-010-069]:
  1. **Часте миття рук** (signature — десятки разів/день, до тріщин шкіри)
  2. Часта зміна білизни
  3. Щоденне прибирання
  4. Ретельна обробка харчових продуктів
  5. Уникнення «забруднених» поверхонь
- **Severe мізофобія** [C-010-070]: housebound + **rejection of family** (не допускають родичів)

**6 типових тригерів забруднення**:

| #   | Тригер               | Категорія            |
| --- | -------------------- | -------------------- |
| 1   | Пил                  | Інертні забруднення  |
| 2   | Сеча                 | Біологічні рідини    |
| 3   | Земля                | Природне забруднення |
| 4   | Нечистоти            | Загальні забруднення |
| 5   | **Отруйні речовини** | Токсини              |
| 6   | **Мікроорганізми**   | Germophobia          |

**⭐ Physical sign**: **тріщини на руках** від частого миття — це **фізичний marker** з anamnesis.

**Pattern severe мізофобії**:

```
страх забруднення → миття рук → temporary relief
   ↓
повторне забруднення (реальне або уявне) → ще миття
   ↓
↑ scope avoidance → не торкається ручок дверей
   ↓
не пускає родичів → soc. ізоляція
   ↓
housebound + family rejection
   ↓
secondary depression
```

**Терапія мізофобії** [C-010-075, 076]:

- **SSRI high dose** — сильніший anti-OCD ефект
- **ERP**: gradual graded exposure to dirt without washing
  1. Сходи Subway (легке забруднення) — без миття 5 хв
  2. Громадський туалет — без миття 10 хв
  3. Земля голими руками — без миття 30 хв
  4. Без миття після їжі
- **Pearl**: **escape exposure тільки коли тривога ↓ сама** (response prevention)

**Чому не варіанти 2, 3, 4, 5**:

- **Іпохондричний розлад (2)** — переконання що вже хворий (не страх ЗАРАЗИТИСЯ); немає ритуалів cleaning
- **Соц. фобія (3)** — страх центру уваги; уникнення СОЦ. контактів, не торкання
- **Агорафобія (4)** — страх escape-impossibility, не cleaning; немає миття рук
- **Шизо маячіння забруднення (5)** — маячіння з втратою критики; ego-syntonic; без ritualized cleaning

**Cross-ref до COVID-era spike**: модерна паралель — pandemic-related OCD spike (germophobia + contamination obsessions ↑ після COVID-19).

**Pearl для коуча**: коли клієнт згадує **тріщини на руках** від частого миття + не пускає родичів → strong marker мізофобії. **Mandatory referral** до психіатра з ERP-trained CBT.

| --------- | ------------------------------------ | ----------------------------------------------------------------- |
| **F42.0** | Переважно нав'язливі думки/руминації | «mental rumination» («умственная жвачка»), без значних компульсій |
| **F42.1** | Переважно компульсивні дії           | ритуали, обсесивні дії (cleaning, checking, counting)             |
| **F42.2** | Змішані обсесії та компульсії        | both significant (most common in clinical practice)               |

⭐ **Pearl**: **F42.0 (pure obsessions) — терапевтично складніше**, бо нема behavior як target ERP. Часто потребує:

- Higher SSRI doses
- Cognitive techniques замість behavioral
- Imaginal exposure (для pure-O contamination obsessions)
- ACT (acceptance and commitment therapy)

**МКБ-10 → МКБ-11 → DSM-5 shift** [C-010-056]:

| Класифікація | Розташування ОКР                                                              |
| ------------ | ----------------------------------------------------------------------------- |
| МКБ-10       | F42 — у розділі **невротичних розладів** (поруч з тривожними)                 |
| МКБ-11       | **окрема нозологічна категорія** — Obsessive-Compulsive and Related Disorders |
| DSM-5        | **вже окремий розділ** — OCD and Related Disorders                            |

**Логіка зсуву**: ОКР має різний нейробіологічний субстрат (**cortico-striato-thalamo-cortical loop**) ніж тривожні розлади (амигдала-domінант). Тому ОКР тепер групують з:

- Body dysmorphic disorder
- Trichotillomania (hair pulling)
- Excoriation disorder (skin picking)
- Hoarding disorder

**Чому не варіанти 1, 3, 4, 5**:

- **F40.0 (1)** — це **агорафобія**, не ОКР
- **F42.1 (3)** — переважно компульсивні дії (ритуали), не думки
- **F42.2 (4)** — змішані обсесії + компульсії
- **F41.0 (5)** — це **панічний розлад**, не ОКР

**Прогноз ОКР** [C-010-074]:

| Сценарій          | Опис                                                                            |
| ----------------- | ------------------------------------------------------------------------------- |
| Хронічний перебіг | norm — повне одужання рідкісне                                                  |
| Мономорфні прояви | (один тип обсесій/компульсій) — можлива тривала стабілізація + соц. реадаптація |
| Поліморфні прояви | гірший прогноз — багато обсесій-компульсій                                      |

**5 treatment-resistant subtypes ОКР** [C-010-075]:

1. Фобія зараження
2. Фобія забруднення (мізофобія)
3. Фобія гострих предметів (аіхмофобія)
4. **Контрастні обсесії** (harm obsessions)
5. Численні ритуали (poly-ритуал)

Для resistant — augmentation: low-dose antipsychotics (quetiapine, risperidone), lithium, DBS для extreme cases.

**Source**: C-010-056, C-010-073, C-010-074, C-010-075 / transcript [12:00, 17:00-18:00] + slide 12

### P12 — Терапія тривожних розладів — комплексне

**Q**: Який підхід є золотим стандартом для лікування ОКР?

**Варіанти**:

1. Бензодіазепіни (alprazolam, clonazepam) тривало + динамічна психоаналіз
2. **Високодозовий SSRI (sertraline, fluoxetine, fluvoxamine) + ERP (Exposure-Response Prevention)**
3. Антипсихотики (haloperidol, olanzapine) як монотерапія
4. Літій + нормотиміки (вальпроат)
5. Гомеопатія + медитація

**Correct**: 2 (SSRI high dose + ERP)

**Пояснення**: За claim [C-010-076]: «Терапія ОКР така ж, як і при всіх невротичних розстрійствах. Це **антидепресанти, анксіолітики, транквілізатори і обов'язково психотерапія**».

**Standard OCD treatment**:

| Компонент           | Препарати/методи                                                                                                                          |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **Антидепресанти**  | **SSRI first-line** (sertraline, fluoxetine, fluvoxamine) — **high doses 2-3× від депресивних**; **clomipramine** (TCA, classic anti-OCD) |
| **Анксіолітики**    | Бензодіазепіни **короткостроково** при гострій тривозі (4-6 тижнів max — ризик dependence)                                                |
| **Транквілізатори** | Додаткові для гострих епізодів                                                                                                            |
| **Психотерапія**    | **ERP (Exposure-Response Prevention)** — **gold standard** psychotherapy ОКР                                                              |

**⭐ Pearl SSRI для ОКР**:

- **Дози вищі** ніж для депресії (sertraline 200 мг/добу, fluoxetine 60-80 мг/добу)
- **Ефект пізніше**: 8-12 тижнів до відповіді (vs 4-6 при депресії)
- **Patient education**: попередити що буде довго

**ERP — Exposure-Response Prevention** (gold standard):

1. **Гранична hierarchy of fears** — пацієнт ранжує тригери за тривогою (0-100 SUDS)
2. **Gradual graded exposure** — поетапна exposure to feared stimulus
3. **Response prevention** — заборона компульсивного ритуалу
4. **Habituation** — тривога ↓ сама за 30-60 хв (extinction learning)
5. **Generalization** — exposure to varied contexts

**Example ERP для checking ОКР** (двері):

- Step 1: Закрити двері 1 раз → не повертатися перевіряти 5 хв
- Step 2: Те саме → 30 хв без перевірки
- Step 3: Те саме → 2 години без перевірки
- Step 4: Закрити і вийти на цілий день
- Step 5: Без перевірки декілька днів

**Чому не варіанти 1, 3, 4, 5**:

- **BZD тривало (1)** — ❌ **ризик dependence**, **maintenance avoidance** (BZD блокує emotional processing у ERP). Психоаналіз тривало — не evidence-based для ОКР
- **Антипсихотики моно (3)** — ❌ ОКР не психоз; антипсихотики low-dose тільки як **augmentation для resistant**
- **Літій + нормотиміки (4)** — ❌ це БАР (cross-ref L8), не ОКР; lithium може бути augmentation, але не first-line
- **Гомеопатія + медитація (5)** — ❌ гомеопатія = ZERO evidence; **медитація може посилити обсесії** (uplifts attention on intrusive thoughts)

**Cross-ref до L14 фарма-арсенал** [C-010-086]:

| Клас                        | Препарати                                        | Місце у терапії                                      |
| --------------------------- | ------------------------------------------------ | ---------------------------------------------------- |
| **SSRI**                    | sertraline, escitalopram, fluoxetine, paroxetine | first-line ГТР, паніка, фобії, **ОКР (high dose)**   |
| **SNRI**                    | venlafaxine, duloxetine                          | second-line, ГТР                                     |
| **Benzodiazepines**         | alprazolam, lorazepam, clonazepam, diazepam      | short-term для acute anxiety/panic, ризик dependence |
| **Buspirone**               | 5-HT1A partial agonist                           | non-addictive alternative                            |
| **Beta-blockers**           | propranolol                                      | performance anxiety, situational                     |
| **Pregabalin**              | альфа-2-дельта ligand                            | GAD second-line                                      |
| **TCA**                     | **clomipramine**                                 | **ОКР** classic                                      |
| **Antipsychotics low-dose** | quetiapine, risperidone                          | **augmentation TR-OCD**                              |

**Loose end історичні атрибуції**:

- **Aaron Beck (1921-2021)** — для CBT (cognitive behavioral therapy)
- **Joseph Wolpe (1915-1997)** — для систематичної десенсибілізації
- **Edna Foa (born 1937)** — для ERP як gold standard ОКР
- **Pierre Janet (1849-1947)** — психастенія + neurosis of obsessions [C-010-057, 078]

**Pearl для коуча**: при ОКР клієнт часто пробував багато речей до правильного лікування (медитація, гомеопатія, психоаналіз). Підкреслити SSRI + ERP як evidence-based gold standard + терпіння на 8-12 тижнів. **Не робити терапію коучингово** — це **посилить розлад** (validation страху або інструкція уникати — обоє ↑ avoidance).

**Source**: C-010-054, C-010-074, C-010-075, C-010-076, C-010-086 / transcript [12:00, 18:00] + slide 13
