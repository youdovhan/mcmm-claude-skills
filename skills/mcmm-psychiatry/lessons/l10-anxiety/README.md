## Quick summary

Лекція ~18 хв 53 сек від **Світлани Володимирівни Ісаєнко** — **третій великий нозологічний блок** курсу після L7 (шизо, ендогенний психоз з дефектом) і L8 (БАР, ендогенний афективний фазний). На відміну від обох — **тривожні розлади РЕАКТИВНІ**: запускаються «на фоні сильного психоемоційного стресу» [C-010-002], не за біологічним циклом.

**Ключова теза**: тривожні розлади — це коли механізм страху (амигдала + BNST + locus coeruleus + ГАМК↓ / норадреналін↑ / серотонін-модулятор) запускається БЕЗ реальної загрози або непропорційно до неї, з повним збереженням критики (пацієнт усвідомлює нерациональність), вираженою соматичною (вегетативною) симптоматикою і прогресуючою функціональною дезадаптацією. **4 базові форми**: ГТР (F41.1) / панічний (F41.0) / фобії (F40) / ОКР (F42). Лікування: **SSRI/SNRI + КПТ + експозиція + бензодіазепіни короткостроково**.

**Лектор-як-авторитет**: 8,5 років практики у відділенні неврозів + тисячі пацієнтів — це створює рамку для багатих clinical pearls (pulse-checking spotter, breath-hold test, distraction test, subfebrile 37.0°C).

**Дидактичний стиль L10**: найбільш **практично-діагностично** орієнтована лекція модуля. Замість 1 nosological одиниці глибоко (як L7/L8) — **5 нозологій вертикально** з акцентом на diferential і clinical pearls.

## Coaching application (DETECTIVE FM)

7 actionable правил для Юрія-Детектива (детально у `synthesis.md` §7):

1. **⭐ Direct ask при першій сесії** — screening на anxiety: сон / панічні епізоди / pulse-checking / страх виступів / обсесії / checking behaviors. ≥2 yes → психотерапевт; контрастні обсесії + housebound + 6+ міс ГТР → психіатр
2. **Експозиція як паттерн рекомендацій** — gradual graded exposure без avoidance є core mechanism CBT для anxiety. Юрій НЕ робить терапію, але **підкреслює уникнення = підсилює тривогу**
3. **Дихання як перший інструмент при панічній атаці** — distraction test, breath-hold test, box breathing 4-4-4-4, 5-4-3-2-1 grounding. При повторних атаках → mandatory psychiatrist
4. **КПТ-чек-ліст** для коуча — 4 техніки: cognitive defusion + decatastrophizing + worry postponement + behavioral experiment. **Підкріплює** CBT з психотерапевта, не робить сам
5. **Бензодіазепіни watch** — flag коли клієнт пише «без них не сплю» >4-6 тижнів. НЕ радити «припиніть» (withdrawal небезпечний); уточнити план відміни з психіатром; запропонувати SSRI long-term альтернативу
6. **⭐ Агорафобія red flag** — housebound > 1 міс → mandatory referral. НЕ нормалізуй («COVID-era»), НЕ пропонуй «давайте через інтернет» (reinforces avoidance)
7. **⭐ ОКР делегувати, не робити коучингово** — контрастні обсесії / magical thinking / мізофобія / folie de doute → психіатр + ERP-trained CBT. НЕ медитація (uplifts attention), НЕ «ну ви ж не хочете» (посилить doubt). ⭐ Нормалізувати: «Це ОКР, він лікується, ви НЕ небезпечні»
8. **⭐ Pulse-checking spotter [C-010-031]** — quick anxiety detection: якщо клієнт перевіряє пульс smartwatch / app / manual → ~80% ймовірність anxiety disorder. Diagnostic clue + CBT seed + referral hint
