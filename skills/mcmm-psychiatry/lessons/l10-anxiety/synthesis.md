## §0 — Quick thesis

**Тривожні розлади — це коли механізм страху (амигдала + BNST + locus coeruleus + ГАМК↓ / норадреналін↑ / серотонін-модулятор) запускається БЕЗ реальної загрози або непропорційно до неї**, з повним збереженням критики (пацієнт усвідомлює нерациональність), вираженою соматичною (вегетативною) симптоматикою і прогресуючою функціональною дезадаптацією. У ландшафті нозології модуля 10 це **третій великий нозологічний блок** після L7 (шизофренія — ендогенний психоз з дефектом) і L8 (БАР — ендогенний афективний фазний). На відміну від обох — **тривожні розлади РЕАКТИВНІ**: запускаються «на фоні сильного психоемоційного стресу» [C-010-002], а не за біологічним циклом.

Лектор Світлана Володимирівна Ісаєнко відкриває урок методологічно потужною заявою — **8,5 років у відділенні неврозів + тисячі пацієнтів** [C-010-001]. Це створює авторитетну рамку для багатих клінічних pearls, які отримаємо протягом 18 хв 53 сек.

**Core insight для коуча**: коли клієнт каже «у мене серце вискакує», «не вистачає повітря», «помру», «не виходжу з дому», «миаю руки 50 разів на день», «двері перевіряю 7 разів» — це **5 різних рівнів тривожно-фобічного спектру**:

1. **Норма + ситуативна тривога** («хвилююся перед іспитом», «трохи нервую перед польотом») — коучингова зона
2. **Тривога з функціональним impairment, без панічних атак** (ГТР) — пограничний коучинг + психотерапевт + SSRI
3. **Панічна атака з anticipatory anxiety** (панічний F41.0) — психіатр + SSRI + BZD short-term + CBT
4. **Avoidance + housebound** (важка агорафобія) — обов'язково психіатр + інтенсивна експозиційна терапія
5. **Контрастні обсесії з aggressive content** (ОКР з harm obsessions) — ОБОВ'ЯЗКОВО психіатр, але **НЕ госпіталізувати «з ризику»** — це посилить розлад через validation страху

L10 дає **диференційну рамку для всіх 5 рівнів** і — головне — підтримує **дисципліну делегації + знання межі коучингу + soматичних масок**, бо саме маршрут «кардіолог → невролог → ендокринолог → психіатр» [C-010-004] = пайплайн втрати часу клієнта.

**Message лектора в фіналі** [C-010-077]: «**XXI вік = вік тривожних розладів**. Кількість випадків патологічної тривоги росте в геометричній прогресії». Тому навіть «непрофіл» (коучи, психологи, експерти) ОБОВ'ЯЗКОВО мають знати diferential і diferential indication до медичної допомоги.

## §2 — Key insights / paradigm narrative

### 2.1. Тривога ≠ страх — головне термінологічне роз'яснення

**Перший inversion для слухача**: у побуті «тривога» і «страх» = синоніми. У клінічній психіатрії:

- **Тривога (anxiety)** — free-floating, об'єкт відсутній або дифузний, **anticipatory** (про майбутнє)
- **Страх (fear)** — фокусований на specific stimulus, реакція на конкретну загрозу

**Cross-ref до L3 C-003-030a (4 критерії патологічної тривоги)**:

| #   | Критерій                     | Норма                           | Патологія                         |
| --- | ---------------------------- | ------------------------------- | --------------------------------- |
| 1   | **Адекватність stimulus**    | пропорційна загрозі             | непропорційна або без stimulus    |
| 2   | **Тривалість**               | короткочасна, минає з ситуацією | persists, **>6 міс при ГТР**      |
| 3   | **Функціональне impairment** | mobilізує до дій                | паралізує, заважає функціонуванню |
| 4   | **Контрольованість**         | можна заспокоїтися              | неконтрольована, automatic        |

Це **4 критерії**, які лектор експліцитно не повторює (експерт від L3), але імпліцитно використовує в кожному діагностичному дискурсі. Cross-ref **C-010-080**.

**Coaching application**: коли клієнт каже «у мене тривога перед запуском продукту», вірте — це норма. Коли каже «вже 8 місяців у мене тривога по всьому, не можу спати, постійно перевіряю пульс, бачила 4 кардіологів» — це 6 міс + неконтрольована + impairment + soматичні маски = **переадресуй до психіатра**, не «давай попрацюємо з вашим страхом».

### 2.2. Тривожні розлади — РЕАКТИВНІ, не ендогенні

[C-010-002]: «**В відрічі від ендогенних процесів, тривожні стоянки виникають на фоні сильного психоемоціонального стресу**». Це fundamental differential від L7 (шизо — ендогенне без видимого тригера) і L8 (БАР — ендогенне фазне).

**Implication**:

- **Тригер видимий** — психіатр може його ідентифікувати (втрата, стрес, conflict)
- **Критика збережена** [C-010-003] — пацієнт усвідомлює нерациональність симптомів (vs манія L8 з anosognosia + маячіння L7 з втратою критики)
- **Психотерапія** — equally important з фармакотерапією (vs шизо, де психотерапія secondary до антипсихотиків)
- **Прогноз кращий** — реактивне → з усуненням тригера + psy + pharma → можлива повноцінна ремісія (vs шизо: 1/3 — 1/3 — 1/3 rule)

**L11 (ПТСР) — найближчий родич** в межах модуля: специфічно реактивне на acute trauma. L10 + L11 = **парний блок реактивних тривожно-стресових розладів** [C-010-095].

### 2.3. Маршрут «кардіолог → невролог → ендокринолог → психіатр» — економічний burden

[C-010-004]: classic clinical pattern — пацієнт з anxiety disorders приходить до психіатра **в останню чергу**. Чому:

1. **Соматичні маски** домінують (тахікардія, задишка, тремор, парестезії) → суб'єктивно «це фізична хвороба»
2. **Stigma «у мене проблеми з головою»** — особливо у пострадянському просторі
3. **Maps до спеціалістів**: ↑ ЧСС → кардіолог; ↑ тремор → невролог; субфебрилітет → ендокринолог
4. **Negative findings** після обстежень накопичуються → лікар лякає або відмахується
5. **Маршрут місяці-роки** — тільки потім психіатр

**Coaching pearl**: при ANY паніко-подібному епізоді у клієнта **з нормальним ЕКГ + тропоніном** — направляти у психіатра, не у «продовжимо до кардіолога». Це збереже клієнту місяці часу і десятки тисяч на обстеження. Cross-ref C-010-081 — soматичні маски vs соматизаційний розлад L6 — diferential.

### 2.4. 3 групи клінічних компонентів — diagnostic schema

[C-010-006]: клінічна картина тривожних розладів = **3 групи**:

1. **Психічні** (емоційні + когнітивно-поведінкові + страхи)
2. **Вегетативні** (6 систем — CV / дих / неврол / ШКТ / урогеніт / терморегул)
3. **Порушення сну**

**1. Психічні компоненти**:

**Емоційний кластер** [C-010-007]: пригніченість + безпорадність + невпевненість + **відчуття небезпеки** (signature anxiety feeling — sense of impending threat) + напруженість + скутість.

**Когнітивно-поведінковий кластер** [C-010-008] — 7 симптомів, що відповідають критеріям ГТР DSM-5:

- Занепокоєння дрібницями (worry over trivia)
- Нездатність розслабитися (restlessness)
- Дратівливість + нетерплячість (irritability)
- Збудженість («взвінченість» = on edge)
- Неможливість сконцентруватися
- Розсіяність
- Швидка стомлюваність

**Страхи** [C-010-009] — окремий пункт, передвісник класифікації фобій.

**2. Вегетативні компоненти** [C-010-010 → C-010-015] — 6 систем:

| Система              | Симптоми                                                                                                   | Біологія                              |
| -------------------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------- |
| **Серцево-судинна**  | Порушення серцевого ритму (тахікардія), кардіалгії, коливання АТ, припливи, піт, **холодні вологі долоні** | Sympatic activation                   |
| **Дихальна**         | Відчуття нестачі повітря, **задишка**                                                                      | Hyperventilation responding           |
| **Неврологічна**     | Запаморочення, головні болі, **тремор**, здригання, парестезії, **м'язова напруга**                        | Norepinephrine via locus coeruleus    |
| **ШКТ**              | Нудота, **сухість у роті**, диспепсія, порушення апетиту                                                   | Sympatic + parasympatic dysregulation |
| **Сечостатева**      | Прискорене сечовипускання, ↓ лібідо, імпотенція                                                            | Pelvic floor + libido                 |
| **Терморегуляторна** | **Безпричинні субфебрилітети 37.0-37.2°C** + озноби                                                        | Hypothalamus + stress response        |

**⭐ Clinical pearl лектора** [C-010-015]: «**Температура 37,0 — це наша симптоматика**» — психогенний субфебрилітет. Багато пацієнтів роками блукають через інфекціоністів і онкологів, поки хтось не подумає про anxiety.

**3. Порушення сну** [C-010-016] — 4 типи:

- **Sleep onset insomnia** — утруднене засинання (CARDINAL ГТР)
- **Sleep maintenance insomnia** — поверхневий сон + часті пробудження
- **Кошмарні сновидіння**
- **Sleep fragmentation + early morning awakening + day-time sleepiness**

**Differential з depressive insomnia (cross-ref L9)**: depression has **early-morning waking primary**; ГТР has **sleep-onset insomnia primary** + ruminative pre-sleep cognition (cross-ref C-010-029).

### 2.5. Панічний розлад F41.0 — найдраматичніша форма

[C-010-017]: **повторювані непередбачувані напади тяжкої тривоги**, не обмежені ситуацією. Це ключове розрізнення:

- **Повторювані** (recurrent) — не одиночні
- **Непередбачувані** (unexpected) — нема trigger
- **Тяжка тривога** — не легкий епізод
- **НЕ обмежені ситуацією** (situationally unbound) — vs фобії

**Core симптоми** [C-010-018]:

1. **Надзвичайний страх** (extreme fear)
2. ⭐ **«Fear of impending death»** — патогномонічний sense of impending doom
3. Тахікардія (cardiac symptom #1)
4. Задишка
5. Пітливість
6. Спроба покинути місце нападу (escape behavior)
7. Пошук допомоги (звертання у швидку, до сусіда)

**Тривалість** [C-010-019]: до 1 години (pure peak — 10-15 хв, але «продовжена» — до години).

**Anticipatory anxiety** [C-010-019] — другий core feature: між атаками пацієнт **боїться наступної**. Це генерує:

- Avoidance behavior
- Хронізацію
- Еволюцію в агорафобію

**«Страх страху»** (phobophobia) — лікувати потрібно не тільки атаку, але й проміжки.

### 2.6. Психогенна задишка — «дихання загнаного собаки»

[C-010-020] — найдетальніший клінічний опис у лекції, ~30 сек тексту:

1. Відчуття нестачі повітря
2. Поверхневе дихання + неповноцінність вдиху
3. Відчуття «грудна клітина не відкривається»
4. **«Дихання загнаного собаки» — 50-70 вдихів/хв** (норма 12-20)
5. Свідомий контроль дихання
6. Грудка в горлі (globus hystericus)
7. Сухий настирливий невротичний кашель
8. Болі в міжреберних проміжках
9. Розмах руками + вирівнювання плечей — спроба «відкрити грудну клітку»

**Біологія**: hyperventilation → respiratory alkalosis → ↓ pCO2 → парестезії + тетанічні судоми + ↑ паніки → закріплює coupling (reinforcement loop).

**Образ «загнаного собаки»** — потужна clinical metaphor, корисна для пояснення пацієнтам що з ними відбувається. Вона також підкреслює як ⭐ **дихання — НЕ ознака реальної гіпоксемії**, а спроба знайти «правильне» дихання.

### 2.7. 3 diagnostic тести панічної атаки vs органічної патології

**Тест 1 — Затримка дихання ≥30 сек** [C-010-022]: при психогенній задишці пацієнт МОЖЕ затримати дихання ≥30 сек і повільно порахувати вголос ≥10-20. При **органічній задусі** (астма, ХОЗЛ, набряк) це фізично неможливо. ⭐ Pearl: «**можеш порахувати — значить психогенне**».

**Тест 2 — Відвертання уваги розмовою** [C-010-023]: при паніці увага захоплена дихальною дисфункцією → відволікати розмовою → нормалізується дихання. При органічній — розмова НЕ змінює дихання.

**Тест 3 — Зміна положення тіла** [C-010-023]: при панічній атаці зміна положення НЕ впливає на самопочуття. При кардіальній — position matters (стенокардія гірше лежачи, ТЕЛА інакше).

**Тест 4 (cross-ref C-010-021) — ЕКГ + тропонін**: gold standard для виключення ГКС перед діагнозом панічного розладу. ⭐ **Завжди виключати кардіальне** — пропустити інфаркт під маскою «панічної атаки» — невідкладна помилка.

### 2.8. Differential панічна атака vs серцевий приступ — таблиця

[C-010-021]: критична таблиця для невідкладної допомоги:

| Параметр      | Панічна атака                          | Серцевий приступ                          |
| ------------- | -------------------------------------- | ----------------------------------------- |
| Характер болю | **різка, колюча**                      | **стискаюча, давляча**                    |
| Локалізація   | середина грудної клітки                | за грудиною                               |
| Тригер        | раптово або після стресу               | раптово або при фіз. навантаженні (сходи) |
| Динаміка болю | **зменшується**                        | **збільшується**                          |
| Тривалість    | 20-30 хв                               | довше                                     |
| Іррадіація    | рідко                                  | в руку, щелепу, лопатку                   |
| Супутні       | задишка, піт, шаткість, **парестезії** | задишка, піт, нудота, **блювота**         |

**4 ключові flags для серця** (за ↑ priority):

1. Тригер фіз. навантаження → серце
2. Іррадіація в руку/щелепу → серце
3. Болі **збільшуються** в часі → серце
4. Парестезії в руках з симетрією (гіпервентиляція) → паніка

### 2.9. ГТР F41.1 — найхитріший розлад

[C-010-026]: **хронічний характер** + **надмірна тривога по всьому** + **не обмежується обставинами** (free-floating).

DSM-5 critical criterion: тривалість ≥**6 місяців** (лектор не озвучує, але це стандарт диференціації від ситуативної тривоги).

**Класична тріада ГТР** [C-010-087]:

| Компонент                            | Phenomenology                         | Маркери              |
| ------------------------------------ | ------------------------------------- | -------------------- |
| **Apprehensive expectation** (worry) | Catastrophizing, anticipatory dread   | C-010-027, C-010-028 |
| **Motor tension**                    | М'язова напруга, тремор, restlessness | C-010-012, C-010-030 |
| **Autonomic hyperactivity**          | Тахікардія, піт, ШКТ симптоми         | C-010-010..015       |

**6 «classical worry topics» ГТР** [C-010-028]:

1. Запізнення
2. Якість виконання роботи (perfectionism component)
3. Легке фізичне нездужання (health anxiety component)
4. **Безпека дітей** (типово для жінок-матерів — частий клінічний приклад)
5. Фінансові питання
6. «І так далі» — opens у DSM-5

**Differential з іпохондрією**: іпохондрія = ОДИН health worry домінує; ГТР = diffuse multifocal worry.

**Patognomonic for ГТР** [C-010-029] — **«прокручування в голові» при засинанні** (ruminative pre-sleep cognition). 2 джерела матеріалу:

- Ретроспективне («що сталося сьогодні»)
- Проспективне («що буде поганого»)

**⭐ Clinical pearl лектора — pulse-checking** [C-010-031]: «Якщо ви бачите людину, яка меряє постійно свій пульс — це людина з тривожним розтройством». Психодинаміка:

```
тахікардія → інтерпретація як ознака небезпеки → check pulse
→ перевірка stoking the fire → петля
```

**Therapy implication**: одне з перших домашніх завдань у CBT панічного/ГТР — **заборонити pulse-checking** (та інші checking/avoidance behaviors).

**Об'єктивні рухові ознаки ГТР** [C-010-030] — physical exam findings, видимі при огляді:

1. Неспокійні рухи
2. Метушливість
3. **Звичка щось смикати руками** (fidgeting — критерій DSM-5)
4. Тремор пальців (postural tremor — норадреналінова активація)
5. Напружене обличчя (m.frontalis, m.masseter)
6. Глибокі зітхання (sighing)
7. Прискорене дихання
8. Блідість обличчя (vasoconstriction)
9. Часті ковтальні рухи (xerostomia + dysphagia)

### 2.10. Фобії F40 — 3 види з різною кінематикою

[C-010-032]: фобія = страх **конкретного об'єкту/ситуації**, який **зараз не небезпечний**, але переживається з страхом або уникається.

3 features:

1. Тривога пов'язана з конкретним об'єктом/ситуацією
2. Об'єкт у цей момент НЕ небезпечний (irrational fear — критичний)
3. Пацієнт або переживає страх при контакті, або **уникає** (avoidance core maintenance)

**Агорафобія F40.0** [C-010-033, C-010-034]:

- Етимологія: agora (площа) + phobos (страх)
- Сучасне розуміння — **страх ситуацій, з яких важко вийти або де нема допомоги**
- Триєдиний об'єкт: відкриті простори / транспорт / натовп
- **7 типових тригерів**: метро / магазин / натовп / ліфт / літак / театр / кінозал
- Спільна риса — **escape-impossibility + help-distance**
- Pattern: panic attack в одному з контекстів → avoidance → expansion
- Часто розвивається з панічного розладу

**Cluster симптомів агорафобії** [C-010-035 → C-010-037]:

- 4 вегетативних: сухість у роті / тахікардія / профузний піт / тремор
- 5 торако-абдомінальних: задишка / задуха / біль у грудях / нудота / дискомфорт ШКТ
- 3 психічних: **дереалізація** / **деперсоналізація** / страх втратити контроль

**Avoidance + safety signal + housebound** [C-010-038]:

- **Уникнення** як core mechanism
- **Супровід близької людини** як safety signal — частковий compromise
- У важких випадках — **housebound** (не виходить з дому)
- ⭐ Pearl: ступінь агорафобії = «scope of avoidance»

**Соц. фобія F40.1** [C-010-039 → C-010-048]:

- **Страх опинитися в центрі уваги**
- Замішання + сором в присутності інших
- Маніфестує у **підлітковому + юнацькому віці** (12-22 роки typically)
- 5 тригерів школи/університету: дошка / іспит / сцена / вчителі / протилежна стать
- **Спілкування з близькими — комфортне** ← ⭐ diagnostic differential з autism і avoidant PD
- 5 feared actions: говорити / їсти / писати / громадський туалет (paruresis) / відвідувати вечірки
- **Meta-fear** — страх що оточуючі помітять страх → secondary fear → ↓ self-esteem
- 5 comorbidities: ГТР / інші фобії / афективна патологія / **алкоголізм** / розлади харчової поведінки

**⭐ Алкогольна self-medication** — у молодого пацієнта з алкоголізмом обов'язково питати про соц. фобію.

**Класифікація соц. фобій**: ізольовані (1-2 ситуації) vs генералізовані (більшість соц. ситуацій). Severity hierarchy.

**Ерітофобія** [C-010-047] — ізольована форма: страх почервоніти. Self-fulfilling prophecy: страх → симпатична активація → почервоніння → confirm fear → ще червоніє. CBT target.

**Скоптофобія** [C-010-048] — core syndrome генералізованої соц. фобії: страх здаватися смішним, виявити неповноцінність. Cluster: ідеї малоцінності + ідеї відносин + хронічний сором + avoidance контактів. Часто прелюдія до соц. ізоляції + secondary depression.

**Іпохондричні фобії (нозофобії)** [C-010-049, C-010-050]:

- **Top-5**: **кардіофобія** / **канцерофобія** / сифілофобія / **СНІДофобія** / **інсультофобія**
- Differential з іпохондричним розладом (соматоформний F45.2): фобія = страх отримати; іпохондрія = переконання, що вже хворий
- **5 поведінкових патернів**:
  1. **«Doctor shopping»** — обхід різних лікарів, повторні обстеження
  2. Обговорення хвороби з родичами/друзями («мені залишилось недовго»)
  3. Переїзд у «екологічно чистий район»
  4. Зміна роботи на «менш шкідливу»
  5. **Щадний спосіб життя** + обмеження активності

**Специфічні (ізольовані) фобії F40.2** [C-010-051, C-010-052]:

- Strах обмежений ОДНІЄЮ specific ситуацією/об'єктом
- Поза тригером — функціонує нормально
- **Top-5 examples**: тварини (зоофобії) / висоти (акрофобія) / грози (астрафобія) / нудота (емтефобія) / стоматологічні маніпуляції (одонтофобія)
- ~7-9% lifetime prevalence — найпоширеніший тип фобій
- **Лікування**: експозиційна терапія — gold standard, VR exposure highly effective

### 2.11. ⭐ ОКР F42 — особливий статус (МКБ-10 невроз → МКБ-11 окрема нозологія)

[C-010-055, C-010-056]: ОКР традиційно у тривожних розладах за МКБ-10, але phenomenologically — це більше **волевий + мисленнєвий розлад**:

- **Волеві порушення → компульсії** (cross-ref L3 — гіпербулія/гіпобулія)
- **Порушення мислення → обсесії** (cross-ref L5 — типи мислення)

**Класифікаційний зсув**:

| Класифікація | Розташування ОКР                                                              |
| ------------ | ----------------------------------------------------------------------------- |
| МКБ-10       | F42 — у розділі **невротичних розладів** (поруч з тривожними)                 |
| МКБ-11       | **окрема нозологічна категорія** — Obsessive-Compulsive and Related Disorders |
| DSM-5        | **вже окремий розділ** — OCD and Related Disorders                            |

**Логіка зсуву**: дослідження показали різний нейробіологічний субстрат ОКР (**cortico-striato-thalamo-cortical loop**) vs тривожні (амигдала-дoмінант). ОКР тепер групують з body dysmorphic disorder, trichotillomania, hoarding.

**Психостенічна конституція як ґрунт** [C-010-057] — за **Pierre Janet (1903)**: характерологічний препідсередник ОКР. **5 рис психостеніків**:

1. Недовірливість
2. Тривожність як baseline
3. Емоційність
4. Сором'язливість
5. Боязкість

**Розвиток за умовним рефлексом (Pavlovian 3-stage)** [C-010-058]:

| Стадія | Trigger                                                                              |
| ------ | ------------------------------------------------------------------------------------ |
| 1      | Страх лише при наявній патогенній ситуації                                           |
| 2      | Страх при **спогаді** про ситуацію (cue-conditioning)                                |
| 3      | Страх **заповнює все мислення** — стає нав'язливістю (generalized intrusive thought) |

**Pavlovian conditioning + operant maintenance**: страх → ritual → temporary relief → reinforcement → стійкий патерн. Це теоретична основа exposure-response prevention (ERP) therapy.

**3 компоненти синдрому нав'язливості** [C-010-059]:

| Компонент                  | Зміст                 | Англ. термін       |
| -------------------------- | --------------------- | ------------------ |
| Нав'язливі страхи          | фобічні нав'язливості | Obsessive fears    |
| **Обсесії**                | нав'язливі думки      | Obsessive thoughts |
| **Імпульсії / компульсії** | нав'язливі дії        | Compulsions        |

⭐ ОКР відрізняється від простої фобії наявністю **компульсивних дій (ритуалів)**, що тимчасово знімають тривогу від обсесій.

### 2.12. Природа обсесій — ego-dystonic (КРИТИЧНИЙ DIFFERENTIAL)

[C-010-060]: 3 phenomenological ознаки обсесій:

1. **Поза волею** (intrusive, unwilled)
2. **Ego-dystonic** — сприймаються як чужі, не мої
3. **Абсурдні** — пацієнт усвідомлює нерациональність

**Пацієнт активно протистоїть**. Метафора лектора — «**як-будто дрилем входить ця думка**» — потужна clinical metaphor.

**Differential table (cross-ref C-010-082)** — критичний для emergency psychiatry:

| Параметр        | Обсесія (ОКР)                     | Маячіння впливу (шизо L7)                             |
| --------------- | --------------------------------- | ----------------------------------------------------- |
| Ego-syntonicity | **ego-DYSTONIC** (відразлива)     | **ego-SYNTONIC** (внутрішньо логічна)                 |
| Критика         | збережена («я знаю що це абсурд») | відсутня                                              |
| Resistance      | пацієнт активно бореться          | пацієнт не бореться, accept reality                   |
| Source          | сам пацієнт («я можу зробити...») | external entity («хтось ВКЛАВ цю думку у мою голову») |
| Behavior        | safety behavior (ховання ножів)   | response to external command                          |

⭐ **Pearl**: контрастна обсесія = «**я боюся, що зроблю**»; маячіння впливу = «**мені наказують зробити**».

### 2.13. Контрастні обсесії — найбільш distressing форма

[C-010-066]: impulse зробити те, **що повністю суперечить** ціннісній системі пацієнта. **3 типи**:

1. **Обсценні** — вигукнути нецензурне у церкві / при дітях
2. **Агресивні** — нанести каліцтва близьким, особливо ДІТЯМ
3. **Самоушкоджуючі** — стрибнути з висоти, кинутися під поїзд

**Safety behavior**: ховання гострих предметів (ножі, виделки, **сокири**).

**⭐⭐⭐ КРИТИЧНА differential**: контрастна обсесія ≠ намір. Пацієнт **боїться, що зробить — НЕ хоче зробити**.

**Pearl лектора (impliciт)**: НЕ госпіталізувати у психіатрію при контрастних обсесіях як «суїцид/гомицид risk» — це **maintenance OCD** by validating fear. Treat as ОКР з ERP.

**Cross-ref на quiz prediction**: типове Quiz Q — пацієнт з думками «нанести шкоду дитині» + ховає ножі = **ОКР з контрастними обсесіями**, НЕ шизофренія, НЕ небезпечний.

### 2.14. Класичні форми обсесій + компульсій

**Нав'язливі сумніви (folie de doute)** [C-010-061] — найпоширеніша форма ОКР. Невпевненість у правильності дій, persists despite logical reassurance.

**Checking compulsions** [C-010-063] — top-5: двері / газ / електрика / **крани** / документи. Pattern: doubt → check → temporary relief → renewed doubt → recheck.

**Нав'язлива повільність** [C-010-064] — ритуалізація заповільнює рутину: одягання / їжа / гоління — на години.

**Counting compulsion + magical thinking** [C-010-065] — «хороші vs погані числа» (3,7 — добрі; 4,13 — погані); пацієнт must «закрити» дію хорошим числом.

**Мізофобія + cleaning rituals** [C-010-068, C-010-069] — найпоширеніша sub-форма. **6 тригерів забруднення**: пил / сеча / земля / нечистоти / отруйні речовини / мікроорганізми. **5 cleaning compulsions**: часте миття рук (signature) / зміна білизни / прибирання / обробка продуктів / уникнення «забруднених». **Physical sign**: тріщини на руках від частого миття.

**Severe мізофобія** [C-010-070] → housebound + rejection of family.

**Motor tics + protective rituals** [C-010-071, C-010-072]: 4 типові: поштовхи головою / **моргання очима** (most common у дітей) / рухи по волоссю / імітація розчісування. **Critique preserved** — пацієнт розуміє марність, але не може зупинити.

### 2.15. Лікування тривожних розладів — комплексне

[C-010-054, C-010-076]: 4 компоненти:

| Компонент           | Препарати/методи                                                                                                                             |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| **Психотерапія**    | КПТ (CBT), expoziційна, **ERP для ОКР** — gold standard                                                                                      |
| **Антидепресанти**  | **SSRI first-line** (sertraline, escitalopram, fluoxetine, paroxetine) + SNRI (venlafaxine, duloxetine) + **clomipramine TCA** для ОКР       |
| **Анксіолітики**    | Бензодіазепіни (alprazolam, lorazepam, clonazepam, diazepam) — **КОРОТКОСТРОКОВО 4-6 тижнів max**, ризик dependence + buspirone (non-addict) |
| **Транквілізатори** | Додаткові для гострих епізодів + beta-blockers (propranolol) для performance anxiety + pregabalin (GAD second-line)                          |

**⭐ Pearl для ОКР** [C-010-076]: **дози SSRI вищі** (2-3× від депресивних) + **ефект пізніше** (8-12 тижнів vs 4-6 при депресії).

**Treatment-resistant ОКР** [C-010-075] — 5 subtypes:

- Фобія зараження
- Фобія забруднення
- **Фобія гострих предметів (aichmophobia)**
- **Контрастні обсесії (harm obsessions)**
- Численні ритуали (poly-ritual)

Для resistant OCD — augmentation: антипсихотики low-dose (quetiapine), lithium, DBS для extreme cases.

### 2.16. Знаменитості як destigmatization tools

**Джонні Депп** [C-010-025] — chronic panic disorder багато років. Pearl: «успіх + слава + гроші ≠ імунітет від тривожних розладів» — біологія важливіша за зовнішні обставини.

**Ніколь Кідман** [C-010-053] — ситуативні панічні атаки + agoraphobia features (страх переповнених місць). Класична combination panic + agoraphobia (F41.0 + F40.0 comorbidity). Safety strategy — «достатньо місця для переміщення».

**Differential pattern Депп vs Кідман**:

- Депп — chronic panic disorder (recurrent + unexpected)
- Кідман — situational panic attacks при stress events (премʼєри)

### 2.17. XXI вік = вік тривожних розладів

[C-010-077]: **епідеміологічне твердження лектора** + global data WHO/Lancet:

- 1990: lifetime prevalence anxiety ~5%
- 2020: ~13-18%

**Фактори**: urbanization / social media / COVID-19 / **war** (для української популяції — особливо актуальне) / economic instability.

**Профілактика** — 3 areas: sleep + exercise + social connection. + healthy diet + обмеження alcohol/caffeine + mindfulness.

**Pearl для коуча**: при prevention інтервенціях фокус на 3 базах, не на «думай позитивно».

## §3 — Cross-cutting concepts

### 3.1. Нейробіологія — амигдала + BNST + locus coeruleus + ГАМК + серотонін

Cross-ref L2 [C-010-079] — нейробіологічний субстрат:

| Структура                               | Роль                                                        |
| --------------------------------------- | ----------------------------------------------------------- |
| **Амигдала**                            | Core fear processing, fear conditioning, threat detection   |
| **Locus coeruleus**                     | Норадреналінергічна активація → fight-or-flight, тахікардія |
| **BNST (bed nucleus stria terminalis)** | Sustained anxiety (vs phasic fear of amygdala)              |
| **vmPFC**                               | Top-down inhibition fear, deficient в PTSD/anxiety          |
| **Гіпокамп**                            | Контекстуальне навчання, fear extinction                    |
| **ГАМК (GABA)**                         | Inhibitory NT — основа дії бензодіазепінів                  |
| **Серотонін**                           | Модуляція anxiety, SSRI target                              |
| **Норадреналін**                        | Sympathetic activation, propranolol для performance-anxiety |

**⭐ Різні розлади — різні домінантні структури**:

- **Панічний** — locus coeruleus
- **ГТР** — BNST + vmPFC
- **ОКР** — striatum + OFC (cortico-striato-thalamo-cortical loop)
- **Фобії** — амигдала + insula

Це обґрунтовує **класифікаційний зсув ОКР** з тривожних розладів — інший нейробіологічний субстрат.

### 3.2. Hierarchy тривожних за «boundedness» тригера

[C-010-088] — synthesis hierarchy за specificity тригера:

| Розлад                       | Trigger                                   | Boundedness                    |
| ---------------------------- | ----------------------------------------- | ------------------------------ |
| **ГТР (F41.1)**              | nothing specific — pervasive              | **unbounded (free-floating)**  |
| **Панічний (F41.0)**         | nothing predictable, unexpected attacks   | unpredictable                  |
| **Агорафобія (F40.0)**       | specific situations (open spaces, crowds) | bounded                        |
| **Соціальна фобія (F40.1)**  | social/performance situations             | bounded                        |
| **Специфічна фобія (F40.2)** | one object/situation                      | **maximally bounded**          |
| **ОКР (F42)**                | obsessive thoughts (internally generated) | **inverted (internal source)** |

**⭐ Treatment implication**: менш bounded → більше pharmacology; більше bounded → exposure therapy dominant.

### 3.3. 3 «волни» тривожного епізоду

[C-010-089]: phenomenological sequence:

| Волна           | Зміст                                  | Час                       |
| --------------- | -------------------------------------- | ------------------------- |
| **Психічна**    | Cognitive worry, fear, catastrophizing | First, often anticipatory |
| **Вегетативна** | Тахікардія, піт, тремор                | Second, escalates rapidly |
| **Поведінкова** | Avoidance, escape, safety behaviors    | Last, maintains disorder  |

**Trigger → reaction → maintenance** sequence. Кожна волна = target therapy:

- Cognitive → CBT
- Pharmacological → autonomic
- Behavioral → exposure

**Оптимальна** therapy targets **all 3** — чому combined therapy = gold standard.

### 3.4. Критика збережена як differential з психозами

Cross-ref **C-010-003** + диференціал з L7 (шизо — anosognosia) + L8 (манія — анозогнозія):

| Розлад            | Критика збережена?                            |
| ----------------- | --------------------------------------------- |
| Тривожні          | **ТАК** (пацієнт усвідомлює нерациональність) |
| ОКР (обсесії)     | **ТАК** ego-dystonic — знає що абсурд         |
| Депресія          | TAK (хіба що F32.3 з нігілістичним маяченням) |
| Манія БАР         | **НІ** anosognosia (пацієнт «добре собі»)     |
| Шизо параноїдна   | **НІ** anosognosia + маячіння впливу          |
| Психоз органічний | **НІ** — confusion + втрата критики           |

⭐ Це **anchor для боротьби з помилковою діагностикою** контрастних обсесій ОКР як шизофренії з гомицидальною загрозою.

### 3.5. Соматичні маски — найбільший diagnostic pitfall

Cross-ref **C-010-081** + L6 (соматоформні розлади):

| Параметр          | Тривожний розлад (соматичні маски) | Соматизаційний розлад (F45.0)          |
| ----------------- | ---------------------------------- | -------------------------------------- |
| Тривалість        | Епізодична, з anxiety episodes     | Хронічна, >2 років                     |
| Кількість систем  | Переважно автономні (CV, GI)       | Many systems (≥6)                      |
| Тривога           | Головний симптом                   | Secondary or absent                    |
| Response to SSRI  | Хороший                            | Moderate                               |
| Pacient narrative | «У мене тривога з симптомами»      | «У мене соматичні скарги без діагнозу» |

Pearl: pacijent з anxiety скаже «**я хвилююся**, серце б'ється»; pacijent з somatization скаже «у мене **болить серце**, лікарі не знаходять причин».

## §4 — Diagnostic logic

L10 задає **5 ключових диференційних точок** для коуча/непсихіатра:

### 4.1. «Нормальна тривога» vs ГТР — 6 міс гейт

```
КЛІЄНТ КАЖЕ «У МЕНЕ ТРИВОГА»
├── < 1 міс + конкретний стресор → НОРМА / ситуативна → коучинг
├── 1-6 міс + поліфокусна + impairment → ПІДОЗРА → психотерапевт + screening
├── 6+ міс + free-floating + всі 3 групи компонентів (псих/веg/сон) + impairment → ГТР (F41.1)
│   → Психіатр + SSRI + CBT
└── При наявності розлоtcмlу пульсу-перевірок → C-010-031 PEARL — ↑ ймовірність ГТР
```

### 4.2. «Серце вискакує + помру» — паніка vs ГКС

```
КЛІЄНТ В ПАНІЦІ: «СЕРЦЕ, ЗАДИШКА, ПОМРУ»
├── ⚠️ ОБОВ'ЯЗКОВО ЕКГ + тропонін
├── Тропонін +, ST↑/↓, біль збільшується, іррадіація → ГКС → невідкладна допомога
├── ЕКГ норма, тропонін −, біль ↓ за 20-30 хв, парестезії в руках → ПАНІЧНА АТАКА (F41.0)
│   → 3 diagnostic тести: breath-hold ≥30c, відвертання розмовою, change position
│   → Психіатр + SSRI + BZD коротко
├── 4+ атаки/міс → F41.00 помірний
├── 4+ атаки/тиждень → F41.01 важкий
└── + анамнез манії → передоцінка БАР змішаного (cross-ref L8 C-010-083)
```

### 4.3. «Не виходжу з дому» — агорафобія vs мізофобія vs соц. фобія vs депресія

```
КЛІЄНТ HOUSEBOUND
├── Страх паніки в магазині/метро/натовпі + safety signal (супровід) → АГОРАФОБІЯ (F40.0)
│   → Психіатр + експозиційна терапія + SSRI
├── Страх забруднення + миття рук десятки разів + не пускає родичів → ⭐ МІЗОФОБІЯ (ОКР F42)
│   → Психіатр + SSRI high dose + ERP
├── Страх ока обличчя (зустрічі, виступи, людні місця) + дома з родичами OK → СОЦ. ФОБІЯ (F40.1)
│   → Психіатр + SSRI + CBT для соц. ситуацій
├── Ангедонія + анergia + втрата інтересу + рання пробудження → ТЯЖКА ДЕПРЕСІЯ (F32.2/.3, cross-ref L8/L9)
│   → Психіатр невідкладно (suicide risk!)
└── + impairment всіх соц. контактів + втрата критики → ШИЗО ПРОСТА ФОРМА (cross-ref L7)
    → Психіатр невідкладно
```

### 4.4. «Боюся нашкодити дитині / нанести каліцтва» — контрастна обсесія ОКР vs маячіння впливу

```
КЛІЄНТ КАЖЕ «У МЕНЕ ДУМКИ ВРАЗИТИ БЛИЗЬКОГО»
├── Ego-DYSTONIC (відразливо, бореться) + критика збережена + ховає ножі (safety behavior) → ⭐ КОНТРАСТНА ОБСЕСІЯ ОКР (F42)
│   → Психіатр + SSRI high dose + ERP. ❌ НЕ госпіталізувати «з ризику» — це посилить розлад
├── Ego-SYNTONIC (так і треба) + «хтось ВКЛАВ цю думку» + втрата критики → МАРЕННЯ ВПЛИВУ ШИЗО (cross-ref L7 C-007m10-032)
│   → НЕВІДКЛАДНО психіатр + швидка психіатрична допомога
├── + плаксивість + ангедонія + руминація гріхів → ТЯЖКА ДЕПРЕСІЯ З МАЯЧЕННЯМ ВИНИ (F32.3)
│   → Психіатр невідкладно
└── + анамнез манії + impulsivity + irritability → БАР ЗМІШАНИЙ (cross-ref L8)
    → Психіатр невідкладно
```

⭐ **Найкритичніший differential L10** — ego-dystonic vs ego-syntonic.

### 4.5. «Постійно перевіряю» — ОКР vs anxiety vs OCPD

```
КЛІЄНТ ПОСТІЙНО ПЕРЕВІРЯЄ (двері/газ/пульс)
├── Pulse-checking без іншого + worry over trivia → ГТР (F41.1) — C-010-031 PEARL
├── Checking двері/газ 7+ разів + folie de doute + ego-dystonic → ОКР (F42)
│   → Психіатр + SSRI high dose + ERP
├── Подружню перевірку (де він був, з ким говорив) → revновіcть/JEALOUSY → не ОКР, але anxiety overlap
├── Ego-SYNTONIC орderness + перфекціонізм + контроль інших → OCPD (cross-ref L13, відсутній у L10)
│   → НЕ ОКР, не лікується SSRI
└── Magical thinking ритуали + хороші/погані числа → ОКР z ритуалами
```

### 4.6. «Голос всередині голови у дитини» — обсесія vs першоепізод психозу

```
ПІДЛІТОК «У МЕНЕ В ГОЛОВІ ДУМКИ»
├── Ego-dystonic + бориться + cleaning rituals → ОКР дитячий онсет (F42)
│   → Підлітковий психіатр + SSRI low + family ERP
├── Ego-syntonic + командує + втрата критики + dezorganized behavior → ПЕРШИЙ ЕПІЗОД ПСИХОЗУ
│   → Невідкладно (cross-ref L7 C-007m10-028, C-007m10-032)
├── + дитяча безглуздя + кривляння + неологізми → ГЕБЕФРЕНІЯ (cross-ref L7)
│   → Невідкладно
└── + worry over школа + dynashмики дому → НОРМАЛЬНА ПІДЛІТКОВА ТРИВОГА
    → психотерапевт, не психіатр
```

## §7 — Applied to coaching (DETECTIVE FM)

Юрій-Детектив працює з клієнтами в коучинговій рамці. L10 — урок про **межу коучингу + соматичні маски + diferential з психотиками**. На відміну від L7 (rare extreme cases) — anxiety disorders **широко поширені** (XXI вік — вік тривожних розладів). Юрій буде зустрічати клієнтів з різними рівнями anxiety **майже в кожній сесії**.

**8 actionable правил**:

### 7.1. ⭐ Direct ask при першій сесії — screening на anxiety

На першій сесії питай **прямо** про anxiety markers — не чекай, поки клієнт сам розкаже:

1. «Як у вас зі сном — засинаєте легко?» (sleep-onset insomnia → ГТР)
2. «Чи буває у вас раптові епізоди серцебиття + страх смерті?» (панічний)
3. «Чи перевіряєте ви часто пульс / тиск?» ([C-010-031] pearl)
4. «Чи відомо вам, де у вашому місті швидка кардіологія?» (foretells health anxiety)
5. «Ви могли б розповісти, що відчуваєте перед публічним виступом?» (соц. фобія)
6. «Чи бувають у вас думки, які видаються вам чужими, абсурдними, і ви їх боретесь?» (обсесії)
7. «Чи перевіряєте ви двері/газ/електрику кілька разів перед виходом?» (compulsions)

**Делегація**: при ≥2 yes → психотерапевт; при панічних атаках + 6+ міс ГТР + контрастних обсесіях + housebound → психіатр.

### 7.2. Експозиція як паттерн рекомендацій

Більшість anxiety disorders лікуються через **експозицію** (gradual graded exposure to feared stimulus + response prevention). Це паттерн, який Юрій може **транслювати у коучинговий мову**:

- **Соц. фобія**: «Ви боїтеся виступати → почнемо з відео 2-х хвилин для себе → друг → 3 друзі → 10 друзів → стрім»
- **Специфічна фобія літаків**: «Поетапно: відео польоту → VR симуляція → аеропорт без польоту → політ з другом → політ сам»
- **ОКР checking**: «Ви перевіряєте 7 разів → почнемо з 6 → 5 → 4 → 3 → 2 → 1 → 0»

⭐ Pearl: експозиція **БЕЗ avoidance** (не виходити з ситуації до того, як тривога згасне) — це core mechanism CBT для anxiety. Юрій НЕ робить терапію, але **підкреслює: уникнення = підсилює тривогу**.

### 7.3. Дихання як перший інструмент при панічній атаці

При гострій паніці у клієнта на сесії (zoom або очно):

1. **Не панікувати самому** — паніка не вбиває, минає 20-30 хв
2. **Розмова як distraction test** [C-010-023] — продовжуй говорити нормальним тоном
3. **Breath-hold test** [C-010-022] — попроси затримати дихання, повільно порахувати вголос до 10
4. **Box breathing** — 4 сек вдих / 4 затримка / 4 видих / 4 затримка × 5 циклів
5. **5-4-3-2-1 grounding** — 5 речей бачу / 4 чую / 3 торкаюся / 2 нюхаю / 1 смак
6. **Position change test** [C-010-023] — попроси встати або сісти інакше

**Якщо панічна атака повторюється > 1 раз** → mandatory referral до психіатра + screening на панічний розлад / агорафобію.

### 7.4. КПТ-чек-ліст для коуча — 4 базові інтервенції

CBT — gold standard для anxiety. 4 техніки, які Юрій може **скеровувати клієнту після делегації психотерапевту**:

1. **Cognitive defusion** — «Думка ≠ факт. Я маю думку Х, але це не реальність»
2. **Decatastrophizing** — «Що найгірше станеться? А якщо це справді станеться, як ви впораєтесь?»
3. **Worry postponement** — «Призначте "час хвилювання" — 15 хв вечером, тільки тоді переживайте»
4. **Behavioral experiment** — «Якщо ваша думка правильна, то Х. Перевіримо?»

⭐ Pearl: **Юрій НЕ робить CBT** — він **підкріплює** CBT, з яким клієнт працює у психотерапевта.

### 7.5. Бензодіазепіни watch — flag для коуча

Якщо клієнт говорить «мені прописали реланіум / феназепам / алпрозолам — без них не сплю»:

- **Час прийому** — якщо > 4-6 тижнів regular → ⚠️ dependence risk [C-010-076 + L14]
- **Дози ↑ з часом** → tolerance + dependence
- **Намагання припинити** → withdrawal symptoms (паніка, безсоння, навіть судоми)

**Що НЕ робити**:

- ❌ Не радити «припиніть, бо це шкідливо» — withdrawal небезпечний
- ❌ Не радити збільшити дозу

**Що робити**:

- ✅ Уточнити чи призначив психіатр з планом відміни
- ✅ Запропонувати запитати психіатра про SSRI як long-term альтернативу
- ✅ Підкреслити, що **психотерапія + SSRI** — це **гadl standard**, а BZD — bridge medication

### 7.6. ⭐ Агорафобія red flag — housebound клієнт

Якщо клієнт каже «я останні 3 місяці не виходжу з дому, замовляю все на доставку» — **це невідкладна делегація** [C-010-038]:

1. **Не нормалізуй** «це COVID-era, всі стали такі»
2. **Не пропонуй «давайте через інтернет»** — це **reinforces avoidance**
3. **Питай scope avoidance**: «А коли востаннє виходили? До магазину? До родичів? До поліклініки?»
4. **Якщо housebound > 1 місяць** → mandatory referral до психіатра. Це **критично функціональне імпейрмент**.

⭐ Severe agoraphobia → ризик secondary depression + suicide.

### 7.7. ⭐ ОКР делегувати — НЕ робити коучингово

Якщо клієнт описує:

- **Контрастні обсесії** («у мене думки нанести шкоду дитині, ховаю ножі»)
- **Magical thinking ритуали** (3-7-13 числа)
- **Mіzофобія** (миття рук десятки разів, тріщини на руках)
- **Folie de doute** (двері 7 разів)

→ **mandatory referral до психіатра + ERP-trained CBT психотерапевта**.

**Що НЕ робити**:

- ❌ НЕ «давайте через медитацію» — медитація може **посилити обсесії** (uplifts attention on intrusive thoughts)
- ❌ НЕ «давайте через позитивне мислення» — ego-dystonic не помагається cognitive reframe
- ❌ ❌ ❌ **НЕ говорити «ну ви ж не хочете цього робити»** при контрастних обсесіях — клієнт sам це знає, і це посилить doubt

**Що робити**:

- ✅ Нормалізувати: «Це ОКР, він лікується. Ви НЕ небезпечні»
- ✅ Передати психіатру з ERP-trained CBT
- ✅ Продовжувати коучингово паралельно з дозволу психіатра

### 7.8. ⭐ Pulse-checking spotter [C-010-031] — quick anxiety detection

Якщо клієнт під час сесії **постійно дивиться на годинник, smartwatch, перевіряє пульс через app, відчуває пульс на зап'ясті** — це майже завжди anxiety disorder [C-010-031]. Юрій може використати це як:

1. **Diagnostic clue** — питай прямо «Я помічаю, ви часто перевіряєте пульс — чи турбує вас серце?»
2. **CBT seed** — «Дослідження показують, перевірка пульсу підтримує тривогу. Спробуєте на 1 сесії не перевіряти?»
3. **Behavioral experiment** — клієнт спробує не перевіряти 24 години → запис того, що відчував
4. **Referral hint** — якщо клієнт визнає тривогу + checking → screening на ГТР/панічний + психіатр

**Cross-ref до SYNTHESIS / МАЙСТЕРНЯ**: можлива тема для AI-мастермайнду — «**Як коуч/психолог/експерт розпізнає anxiety-розлади у клієнта без діагностики**» як міні-модуль для помагаючих практиків. XXI вік = вік anxiety + великий ринок.

## §8 — Key facts чек-ліст для тесту

1. **Тривожні розлади — РЕАКТИВНІ** [C-010-002], не ендогенні, виникають «на фоні сильного психоемоційного стресу»
2. **Критика збережена** [C-010-003] — diferential з шизо anosognosia і манією
3. **Маршрут діагнозу** [C-010-004]: кардіолог → невролог → ендокринолог → психіатр (місяці-роки)
4. **Визначення тривожного розладу** [C-010-005]: група розладів, де тривога — головний симптом, не обмежена ситуацією
5. **3 групи клінічних компонентів** [C-010-006]: психічні / вегетативні / порушення сну
6. **6 вегетативних систем** [C-010-010 → C-010-015]: CV / дих / неврол / ШКТ / урогеніт / **терморегул**
7. **⭐ Субфебрилітет 37.0°C** [C-010-015] — психогенний, наша симптоматика
8. **4 типи sleep disturbance ГТР** [C-010-016]: sleep-onset insomnia primary + поверхневий + кошмари + рання пробуджень + day sleepiness
9. **Панічний розлад F41.0** [C-010-017]: повторювані, **непередбачувані** атаки тяжкої тривоги, не обмежені ситуацією

## §9 — Mnemonic devices for the exam

### 9.1. «ГТР=6м-FF-MT» — ключ ГТР

- **6м** — мінімум 6 місяців тривалість (DSM-5 gate)
- **FF** — Free-Floating (не обмежена ситуацією)
- **MT** — Motor Tension (м'язова напруга — обов'язково)

### 9.2. «4 форми = ГПФО» — 4 базові тривожні розлади

- **Г** — Генералізований тривожний (ГТР, F41.1)
- **П** — Панічний розлад (F41.0)
- **Ф** — Фобії (F40: агорафобія / соц / специфічні)
- **О** — Обсесивно-компульсивний (ОКР, F42)

### 9.3. «3 нейробіо = АБЛ» — 3 ключові структури

- **А** — Амигдала (fear processing)
- **Б** — BNST (sustained anxiety)
- **Л** — Locus coeruleus (sympathetic activation, тахікардія)

### 9.4. «3 групи компонентів = ПВС» — клінічна картина

- **П** — Психічні (емоційні + когнітивні + страхи)
- **В** — Вегетативні (6 систем: CV / дих / неврол / ШКТ / урогеніт / терм.)
- **С** — Сонні (4 типи insomnia)

### 9.5. «6 вегетатики = СДНШУТ» — 6 систем

- **С** — Серцево-судинна
- **Д** — Дихальна
- **Н** — Неврологічна
- **Ш** — Шлунково-кишкова
- **У** — Урогенітальна
- **Т** — Терморегуляторна

### 9.6. «Панічна атака vs ГКС = РКЗ vs СДЗ»

- **Паніка**: **Р**ізка, **К**олюча, **З**меншується
- **ГКС**: **С**тискаюча, **Д**авляча, **З**більшується

### 9.7. «3 диагностичні тести панічної» — БВЗ

- **Б** — Breath-hold ≥30c
- **В** — Відвертання уваги розмовою
- **З** — Зміна положення тіла

### 9.8. «7 тригерів агорафобії = МММЛЛТК»

- **М**етро / **М**агазин / нато**М**п / **Л**іфт / **Л**ітак / **Т**еатр / **К**інозал

### 9.9. «6 worry topics ГТР = ЗРХДФ...»

- **З**апізнення / **Р**обота / **Х**вороби / **Д**іти / **Ф**інанси / **...** (і так далі)

### 9.10. «5 feared actions соц. фобії = ГПЕТВ»

- **Г**оворити / **П**исати / **Е**сти / **Т**уалет / **В**ечірки

### 9.11. «Top-5 нозофобії = ККСНІ»

- **К**ардіофобія / **К**анцерофобія / **С**ифілофобія / СН**І**Дофобія / **І**нсультофобія

### 9.12. «Top-5 специфічних фобій = ТВГНС»

- **Т**варини / **В**исоти / **Г**рози / **Н**удоти / **С**томатологія

### 9.13. «Тріада ГТР = WMA» (англ.)

- **W**orry (apprehensive expectation)
- **M**otor tension
- **A**utonomic hyperactivity

### 9.14. «3 компоненти ОКР = СОК»

- **С**трахи нав'язливі
- **О**бсесії (думки)
- **К**омпульсії (дії)

### 9.15. «Top-5 checking ОКР = ДГЕКД»

- **Д**вері / **Г**аз / **Е**лектрика / **К**рани / **Д**окументи

### 9.16. «Ego-dystonic vs ego-syntonic» — критичний differential

- **Обсесія ОКР**: «я БОЮСЯ, що зроблю» — ego-DYSTONIC, бориться
- **Маячіння впливу шизо**: «мені НАКАЗУЮТЬ» — ego-SYNTONIC, не бориться

### 9.17. «3 волни anxiety episode = ПВП»

- **П**сихічна (когнітивна) — anticipatory
- **В**егетативна — escalating
- **П**оведінкова — maintains disorder

### 9.18. Pulse-checking spotter [C-010-031]

Якщо клієнт постійно перевіряє пульс — **ГТР / панічний розлад / іпохондрична фобія** з ~80% ймовірністю. Quick diagnostic clue.

### 9.19. «Loose end» whisper-метафора

«Як дрилем входить ця думка» [C-010-060] — clinical metaphor для обсесій. Корисна для пояснення пацієнтам.

### 9.20. «XXI вік = anxiety» — епідемія + 3 профілактичні цілі

- **Sleep** — sleep hygiene + 7-8 годин
- **Exercise** — 30-60 хв кардіо 3-5 разів/тиждень
- **Social connection** — quality, not quantity
