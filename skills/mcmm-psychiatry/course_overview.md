## Coaching usage pattern

Скіл `mcmm-psychiatry` тепер працює у двох режимах:

1. **Knowledge mode** (як було) — Юрій питає про урок/тему/post Світлани Ісаєнко → відповідаю з claims.md/synthesis.md з посиланнями.

2. **Coaching mode** (новий) — у живій клієнтській сесії Юрія я проактивно:
   - Слухаю опис клієнта
   - Якщо є психіатрично-релевантне → grep `symptom_atlas.md` → suggestion «дивись L<N> §<X>»
   - Якщо red-flag → попередження про routing до психіатра
   - Стиль: короткий nudge, не лекція

Активаційні тригери для coaching mode (auto-trigger без явного запиту):

- Клієнт описує голоси / марення / автоматизми / містичну місію
- Клієнт описує суїцидальні думки з планом
- Клієнт описує маніакальні ознаки (без сну 4+ днів, ризикована поведінка)
- Клієнт описує дисоціативні симптоми
- Юрій сам ставить питання типу «це психіатрія?»

Деталі ритуалу — у `SKILL.md` секція «Coaching mode».
