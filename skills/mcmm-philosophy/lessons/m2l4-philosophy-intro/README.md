## Top-5 claims

1. **Філософія vs наука = пояснення vs розуміння.** Наука пояснює (Erklärung) явища через математично описані приховані причини. Філософія розуміє (Verstehen) феномени через інтерпретацію (тлумачення). Це Гайдеґерове розрізнення (l705-803).
2. **Феномен ≠ явище.** Явище (Erscheinen) — відсилає до прихованої причини. Феномен — те, що "саме себе показує", "стоїть перед мною" — без прихованого "звідки". На питання "що це?" про феномен (сором, кохання, шлюб) відповідь типу "тестостерон+окситоцин" — правда, але не відповідає на "що" (l700-790).
3. **Філософія народжується з подиву.** Подив — усвідомлення, що ми живемо у світі одних і тих самих речей (стіл-взагалі, диван-взагалі), а причина цієї тотожності перебуває **поза цим світом** (l896-980). Це первинна формула філософської проблематики.
4. **Неперекладність — предмет гуманітаристики.** Гуманітарні науки не мають універсальної мови (як математика у природничих). Mind, Geist, душа, ум, розум, mens, свідомість — слова що **не повністю перекладаються** і саме тому є предметом дослідження. Lust (Фройд) → задоволення / приємність / втіха — кожен переклад втрачає аспект (l231-650).
5. **Феноменологія = засада екзистенційної + клієнт-центрованої + особо-орієнтованої психотерапії.** Гуссерль → Гайдеґер → Бінсвангер/Босс (Daseinsanalyse) → Роло Мей/Ялом (екзистенц-психотерапія) → Карл Роджерс (PCT — лектор включає у феноменологічну традицію). Філософія для коуча → "універсальна наука, що служить розумінню" (l13-16, 656-657, 875-891).
