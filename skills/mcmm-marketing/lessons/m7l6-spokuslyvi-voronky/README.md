## Glossary (46 термінів)

### Воронки

- **Воронка** — шлях клієнта від першого дотику до покупки (3 частини: кроки + інсайти + матеріали)
- **Авто-воронка** — те ж саме, тільки автоматизована (≠ окремий тип; "просто продавець у async форматі")
- **Спокуслива воронка** — внутрішня назва Mind Master / Махонінської команди; механізм зваби
- **Low Ticket Funnel** — $1-10 entry воронка
- **High Ticket Funnel** — довгий прогрів (1-1.5 роки) до high-ticket close
- **Evergreen Funnel** — постійно-працююча, незалежна від сезону
- **Webinar Funnel** — продаж через вебінар (works for ПОСЛУГ, не курсів)
- **Free Trial Funnel** — тестовий доступ 7 днів → авто-charge
- **Product Launch Funnel** — через запуск книги/курса/секретної концепції
- **Membership Funnel** — підписочна модель, recurring revenue
- **Hybrid Funnel** — combo вебінар + міні-продукт
- **Free + Shipping Funnel** — клієнт платить лише за доставку (UA НЕ працює per Mind Master test)
- **Affiliate Funnel** — партнерські розміщення, $-share per lead
- **Event Funnel** — соло-івент / спільний з 4-5 сумежних ніш
- **Content Funnel** — volume video/каруселі + вплітання продажів
- **Gamified Funnel** — gamification монети/рівні (зараз з ринку "ушла, але працює")

### Метрики

- **CTR** (Click-Through Rate) — кликабельність; **>3-4% = bad sign**
- **CR** (Conversion Rate) — % конверсії на кожному кроці
- **LTV** (Lifetime Value) — життя клієнта; для додатків ~3 міс
- **CPL** (Cost Per Lead) — вартість заявки
- **CPC** (Cost Per Click) — вартість кліка
- **CPM** (Cost Per Mille) — вартість 1000 показів
- **Churn** — % відписок з підписки; для membership 30% 1й міс = baseline

### Продуктова термінологія (continuity з M6L5)

- **БВП** (Безкоштовний Відкриваючий Продукт) — рілс / безкоштовний контент
