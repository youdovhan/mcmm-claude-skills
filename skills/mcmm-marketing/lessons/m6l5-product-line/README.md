## Top-5 claims (найважливіше з уроку)

1. **PMF (Product-Market Fit) = "глибина продукту" + 30% правило (line 145-152, 315-317).** PMF — "це фішка, глибина" продукту, перевіряється через опитування активних користувачів з 3 варіантами відповіді: "Дуже розчарований / Частково розчарований / Не розчарований" якщо ви припините продукт. **Якщо >30% відповіли "дуже розчарований" — PMF знайдено**, масштабуйте бюджет. Якщо ні — копайте далі. Олексій: "В Академії з PMF нет проблем" (line 324), "приблизно 35%" (line 323), "Якщо це бачу — взагалі не думаю, просто маштабую бюджет, лупашу як могмога сильніший" (line 318-319). Найбільший корпорації світу зараз цим опитуванням користуються (line 251).

2. **Customer Journey Map (CJM) — 8 етапів просунення клієнта (line 153-154, 682-985).** CJM — це **карта шляху клієнта** через продукт або послугу. 8 етапів: (1) **Увага** = людина побачила креатив/рилс/рекламу; (2) **Залучення** = вона зацікавилась, читає; (3) **Заявка / Лід / Підписка** = транзакція (коментар, підписка, обмін контактом); (4) **Перша транзакція** (платна $1-10 або безкоштовна — час); (5) **Емоційне залучення** = "наше побачення з квіточкою"; (6) **Пропозиція основна / Upsell / Downsell**; (7) **Купівля основного продукту**; (8) **Адвокат бренду / Промоція**. **Метафора з пікап-стратегією — погляд → очі в очі → рука в руці → губи в губи → секс — це та сама послідовність 8-12 етапів, не можна пропускати більше 2** (line 682-733). Якщо пропустиш — "це як писати в трафіку 'купи мою консультацію за 150 доларів'" (line 727-731).

3. **Сходинка ідей — 5 рівнів свідомості клієнта (line 1290-1389).** Кожен etap CJM відповідає певному рівню свідомості, і на кожному клієнт **приймає одну ідею** щоб піти далі: (1) **Не знає проблему** → "у тебе є проблема X"; (2) **Знає проблему** → "ця проблема вирішується"; (3) **Знає рішення (загальне)** → "є метод"; (4) **Знає метод** → "цей метод підходить для тебе"; (5) **Знає продукт** → "конкретно тобі це допоможе". **Ключова помилка більшості:** одразу скакати на рівень 5 ("у мене крутий продукт, купуй!") замість провести клієнта через всі 5 рівнів. "Тільки в самому низу, коли вже на сайті, ми кажемо, що конкретно йому допоможемо." (line 1372-1376).

4. **Продуктова лінійка — 5 продуктів-сходинок (line 1397-1640).** 5 типів продуктів послідовно: (1) **Безкоштовний відкриваючий продукт (БВП)** = рилс/стаття/сторіс що знайомить з проблемою (рівень 1); (2) **Ресурсно-безкоштовний продукт (РБП)** = вебінар/гайд/мапа/тест/чек-лист — клієнт інвестує час замість грошей (рівень 2-3); (3) **Дешевий продукт (ДП)** = міні-курс $5-20 — перша транзакція, тест-драйв (рівень 3-4); (4) **Основний продукт** = наставництво / курс / 10 консультацій (рівень 5); (5) **Допродаж (Upsell / Profit Maximizer)** = річний супровід, закритий клуб, інструмент-якір (фізичний подарунок). **Правило X10** (line 1903-1906): дешевий продукт = 1/10 від основного. Якщо основний = $1200, ДП = $120. Якщо $500, ДП = $50.

5. **Стратегія = "що ми робимо / чого не робимо / якими ніколи не будемо" (line 585-614).** Прописана стратегія = 3 питання-фільтри. Приклад Академії MCMM (line 585-614): **Що робимо?** Допомагаємо людині вибудувати внутрішню опору. **Чого не робимо?** Поверхневих продуктів, легких рішень, "що написав за два дні". **Якими не будемо?** Швидким рішенням. **Якщо стратегія за 2-3 місяці не змінюється — система не жива** (line 642-644). Стратегія = організм, що еволюціонує. Олексій: "Інтуіція — це не якась ефемерна чутливість, а саме твій пережитий досвід, який трансформувався" (line 657-658) — якщо чуйка каже "не так" — переробіть навіть якщо показники здаються ОК (line 671-672 кейс "влетели нормально" коли проігнорували Казачкову).
