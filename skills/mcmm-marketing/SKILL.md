## Top-15 операційних концептів Маркетингу (для quick lookup)

### Креатив + Бренд (m5l5)

1. **Креатив через рамки, не свободу** (counterintuitive, m5l5 line 78-82): "Самый лучший способ достать свою креативность — это поставить рамки. Креатив — это не про свободу. Это про очень чуткие рамки." Кейс "касовий розрив на 200 тисяч доларів — креативні рішення летять, як ракети".
2. **Framework "Бренд → Інсайт → Ідея → Реалізація"** (m5l5 line 153-160) — стержень всього маркетингу. На кожному кроці рычаг (одна точна система, не 10).
3. **Бренд = 4 складові:** місія / ворог / архетип / енергія (m5l5 line 153-169). "Хороший бренд рівно настільки, наскільки сильний його антагоніст." Прописана канва → завантажуй у ChatGPT через призму ВАШОГО бренду.
4. **Інсайт = "правда, яка чепляє"** + 4 форми: (a) неочекувана правда, (b) енергетично заряджене спостереження, (c) починається після "Але", (d) "От, а це ж я" / тінь (m5l5 line 316-330).
5. **Інсайт → Ідея: 2 механіки — підсилення або злам** (m5l5 line 533-557). Кейси: Orbit (Бренсон-баннер NYC), Snickers ("коли голодний — ти не ти"), Tampon Book (Німеччина 19%→7% податок).

### Продуктова лінійка + CJM (m6l5)

6. **PMF 30% правило** (m6l5 line 145-152): опитування активних користувачів — "Дуже розчарований / Частково / Не". Якщо >30% "дуже розчарований" якщо припините — PMF знайдено → масштабуй бюджет.
7. **Customer Journey Map — 8 етапів:** Увага → Залучення → Заявка → Перша транзакція → Емоційне залучення → Пропозиція → Купівля → Адвокат (m6l5 line 153-154, 682-985). Метафора "пікап-стратегії": не пропускати більше 2 етапів.
8. **Сходинка ідей — 5 рівнів свідомості клієнта** (m6l5 line 1290-1389): Не знає проблему → Знає проблему → Знає рішення → Знає метод → Знає продукт. Ключова помилка — скакати на рівень 5.
9. **Продуктова лінійка 5-tier** (m6l5 line 1397-1640): БВП (рилс/безкоштовний) → РБП (вебінар/гайд — інвестує час) → ДП (міні-курс $5-20, тест-драйв) → Основний (наставництво) → Допродаж (річний клуб/Profit Maximizer). **Правило X10:** ДП = 1/10 від основного.
10. **Стратегія = 3 фільтри:** що робимо / чого не робимо / якими ніколи не будемо (m6l5 line 585-614). Якщо за 2-3 міс не змінюється → система не жива.

### Оффер (m8l6)

11. **7 компонентів спокусливого оферу** (m8l6 line 372-379, 1162-1168): продукт + 3 шари вигод + ціна/рассрочка + бонуси/преміум + перенесення ризику + причина діяти прямо зараз + call to action.
12. **Формула оферу** (m8l6 line 559-561): "Я допомагаю **кому?** **тому як?** Велика обіцянка. Ще одна велика обіцянка. **За який час?** Без однієї речі, яку боїться клієнт".
13. **3 шари вигод** (m8l6 line 759-808): функціональна (що отримає конкретно) + матеріальна (що відчує одразу після) + емоційна (як зміниться стан).
14. **Цінність ≠ ціна** (m8l6 line 1039-1052): Ferrari $20K vs Ferrari $20K — той самий продукт, тільки очікування різні. Кейс книги "Астрологическая любовь" → "Как каждый раз задовольняти женщину" → 2.5M копій після зміни обкладинки.
15. **"Китайська методологія"** (m8l6 line 24-35): на противагу європейсько-американському "якщо не працює — додай напору". "Іноді потрібно дозріти" — однакові ролики через рік починають залітати, бо аудиторія дозріла.

## AI-boundary тут (для виступу)

⚠️ Олексій явно ставить етичний поріг (m8l6 line 2166-2179): **"Якщо у вас херовий продукт — не робіть маніпуляції. Якщо ви впевнені у продукті — можете користуватись усіма маніпуляціями світу."**

- AI може допомогти **прописати** Бренд-канву / Інсайти / Оффер — НЕ створити ваш бренд / характер / місію
- AI генерує 100 інсайтів — людина обирає той що чепляє (тінь, "от а це ж я") бо AI не має тіні
- AI пише копірайт — людина вирішує етичний поріг (з/без маніпуляцій)

**Marketing для SYNTHESIS:** "AI допомагає коучу прописати бренд-канву, не замінює внутрішню опору коуча."
