## Top-15 операційних концептів НЛП (для quick lookup)

### Рапорт + VAKOG (m1l5)

1. **VAKOG + Digital** — 6 модальностей репрезентації (Visual / Audial / Kinesthetic / Olfactory / Gustatory / Digital). Контекстуальна провідна система — не статичний ярлик. Verbatim demo "В лесу родилась елочка" у 5 версіях.
2. **Рапорт як 4-та ICF-компетенція** — слухати → чути → почути → повага → довіра. 5 типів підлаштування включаючи мікром'язове.
3. **Калібрування + очні ключі доступу + парафраз** — 3-й рівень слухання.

### Інструменти (m2l5)

4. **Логічні рівні Ділтса** — 6 рівнів (environment / behavior / capabilities / beliefs / identity / mission). Кубик Ділтса 60 точок (5×4×3).
5. **Метамодель НЛП** — 6 базових паттернів (неконкретні іменники / номіналізація / неконкретні дієслова / модальні оператори / надузагальнення / порівняльні) на основі 3 механізмів моделювання (узагальнення / упущення / спотворення). Bandler+Grinder 1971.
6. **Трикутник Карпмана як НЛП-інструмент** — 3 ролі P/V/R + вихід через 4-ту позицію спостерігача. (Cross-ref: ТА Vlada аналогічна модель.)

### Самоуправління (m3l6)

7. **Асоціація / Дисоціація / Подвійна дисоціація** — для роботи з ПТСР (кінотеатр-метафора + кабінка киномеханіка).
8. **Якорі** — Павлов-рефлекс. Бетті Еріксон 3-3-3 (3 бачу / 3 чую / 3 відчуваю). Стопка / Ланцюжок / Коллапс. 21 день звичка / 90 днів клітинне закріплення.
9. **Конгруентність / неконгруентність** — перші 30 секунд = правда від тіла. Якщо не покерфейс (1 з мільйону) — все в тілі видно.
10. **Метапрограми "до/від цілі"** — морква спереду vs кнут ззаду.

### Магія / Технологія бажань (m4l6)

11. **Формула Бекхарда** — D × V × F > R (Dissatisfaction × Vision × First steps > Resistance). Будь-яка зміна потребує всіх 3 компонентів — якщо хоч один 0, добуток 0.
12. **Стратегія Уолта Діснея** — 3 позиції (Dreamer / Realist / Critic) + 4-та (Observer). Ділтс модельував Уолта як генія креативу.
13. **Піраміда Ділтса extension** — поглиблення з m2l5 + просторове моделювання (Юрієве breakthrough "Яхти я не бачу" на TOTE-Exit).
14. **TOTE з 9-м AKE-пунктом** — Test1 → Operations → Test2 → Exit + AKE (anchor / kinesthetic / energy).
15. **30000-35000 рішень / день** — якість визначається переконаннями і цінностями. Стан > мислення.
