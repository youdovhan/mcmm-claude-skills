## Top-5 claims (найважливіше з уроку)

1. **НЛП = моделювання геніальності.** Стратегії успішних людей (Walt Disney, Einstein) можна декомпозувати на patterns мислення, тілесних/мовних/перцептивних дій — й передати іншим. У бізнесі це benchmarking. Базова presupposition НЛП (line 602-614).

2. **Рапорт = динамічний стан довірливих стосунків.** Створюється через підлаштування (тіло/голос/слова/предикати), формується ланцюжком "слухати → чути → почути → повага → довіра". Це 4-та компетенція ICF — створення довірливих відносин (line 327-333, 919-925, 1327-1329).

3. **VAKOG = 5 репрезентативних систем + 1 дигітальна.** Visual / Auditory / Kinesthetic + Olfactory + Gustatory + Digital (цифрове внутрішнє мислення). Ведуча репсистема — та, через яку клієнт **тут і зараз** приймає рішення; залежить від контексту (масажний кабінет → кінестетика, картинна галерея → візуал, орган → аудіал). НЕ "вішати ярлики" "ти візуал". Демо — пісенька "В лесу родилась елочка" у 5 версіях (line 2204-2247).

4. **Калібрування = відстеження мікрозмін поведінки.** Дихання, колір шкіри, тонус м'язів, руки очей, мікрорухи губ/брів/повік, тональність/темп голосу, поза, жести. Очні ключі доступу (95% правші): праворуч-вгору = конструюємо (vis-c), ліворуч-вгору = згадуємо (vis-r), посередині = аудіальне, вниз = кінестетика. Мета — створювати точніші коучингові питання (line 1339-1346, 2040-2050).

5. **Мета-повідомлення (мета-spitch) = підтекст + конгруентність.** 7% вербальна (лінгвістика), 93% невербальна (мова тіла + голос). Конгруентність = збіг слів-тіла-енергії. Інконгруентність → повертати клієнту те що бачимо. Перші 30 секунд реакції — справжні, далі надумано (line 1751-1791, 568-571).

- **Коучинг (Лана+Махонін):** рапорт = 4-та компетенція ICF; третій рівень слухання = калібрування невербалики; 5 принципів Erickson = "5 переконань коуч-стану" (line 610, 915, 1327, 1497-1498). Метафора "як слухати клієнта так щоб клієнт сам себе почув" (line 1941-1942).
