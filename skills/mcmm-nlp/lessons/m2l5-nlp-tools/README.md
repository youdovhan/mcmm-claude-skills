## Контекст і призначення уроку

m2l5 — **продовження m1l5 через місяць.** Перші ~300 рядків — debrief учасників (Снежана, Оксана, Анастасия et al.) про те, що вдалось втілити з м1l5 (VAKOG, рапорт, калібрування). Основний матеріал уроку — **3 інструменти НЛП:**

1. **Цінносний граф** (ієрархія цінностей через 3-5 питань "чому це важливо?")
2. **Логічні рівні Роберта Ділтса** (6 рівнів: оточення → поведінка → здібності → переконання та цінності → ідентичність → місія) + **Кубик Ділтса** (60 точок впливу = 12 точок × 5 логічних рівнів × 1 лінія часу)
3. **Метамодель** (6 базових паттернів: неконкретні іменники / номіналізація / неконкретні дієслова / модальні оператори / надузагальнення / порівняння)
4. **Трикутник Карпмана** (Переслідувач / Жертва / Рятовник) як НЛП-інструмент свідомого вибору ролі та розподілу відповідальності

## Top-5 claims (найважливіше з уроку)

1. **Логічні рівні Ділтса = 6 рівнів організації внутрішнього досвіду.** Оточення (хто/де/коли) → поведінка (що робиш) → здібності (як, що вмієш) → переконання та цінності (чому, що важливо) → ідентичність (ID-картка, хто ти, яка унікальність, яку роль виконуєш) → місія (заради чого, сенс життя, життєві цілі). Вищі рівні завжди вмикають нижчі; зміна на вищому автоматично перебудовує нижчі. Розробка Ділтса на основі праць Грегорі Бейтсона, Бертрана Рассела і Маслоу (line 1347-1352, 1488-1505).

2. **Кубик Ділтса = 60 точок впливу на клієнта.** 12 точок на одному логічному рівні × 5 рівнів вище = 23 точки для 1 фрази клієнта. Логічний рівень × позиція сприйняття (1-2-3-4: я/ти/вони/ми) × лінія часу (минуле / теперішнє / майбутнє) = 60 точок усього. Завдання коуча — побачити маркеровану клієнтом точку + задати питання з сусіднього квадрату (1 рівень вище, не 2; інша позиція; інша точка часу) (line 3475-3607, 3711-3715).

3. **Метамодель = серце НЛП.** Інструмент вербального збору інформації через 3 механізми моделювання реальності: **узагальнення** (повертаємо в деталізацію), **упущення** (заповнюємо що відсутнє), **спотворення** (повертаємо до професійного формату). Створена Бендлером + Гриндером з відео Фріца Перлза, вересень 1971. 6 базових паттернів. Не плутати з метамоделюванням SCORE (line 2407-2454, 162-167).

4. **Трикутник Карпмана = соціальні ролі (НЛП-фрейм).** Переслідувач / Жертва / Рятовник. Виходимо через **розподіл відповідальності** + **позицію спостерігача** + маркер 75 ICF (frame через "мені здається / я побачив / а ти що про це думаєш"). НЕ давати поради, повертати відповідальність клієнту. Кожна людина автоматично заходить в одну з 3 ролей; задача — заходити свідомо, або не заходити взагалі (line 3041-3328).

5. **Ціль НЛП — many choice (більше виборів).** "Дати клієнту більший вибір" (Гриндер, цитата Ходякова line 873-874). Якщо клієнт мислить шаблонно — НЛП відкриває 250 інших варіантів. Метамодель й логічні рівні — інструменти створення поля вибору, далі клієнт сам обирає найкраще для себе рішення (line 888-891, 909-912).

## Coaching application для Detective FM (Юрій)

- **Цінносний граф на €39 first-session:** 3-5 питань "чому це для тебе важливо?" → корнева цінність клієнта → формула мотивації для €1469/€2969 пакетів (line 617-620). "Знаю корневу цінність → знаю через що клієнт буде приймати справжні рішення."
- **Кубик Ділтса як коуч-навігатор:** клієнт каже фразу → визнач 3 координати (позиція + рівень + час) → задай питання з сусідньої точки → клієнт побачить більше. "23 точки впливу на 1 фразу клієнта" — гранично потужна структура для розслідування.
- **Метамодельні питання як коуч-розслідник:** "Я хочу щастя" → "Що для тебе щастя? Як ти знаєш що щасливий?" (номіналізація → процес). "Всі чоловіки козли" → "Всі-всі? Ніколи не зустрічала іншого?" (надузагальнення → виключення). "Я повинен" → "Хто сказав? Що буде якщо ні?" (модальний оператор).
- **Карпман як декодер сесії:** клієнт у позиції жертви ("я не можу", "він мене") → не входити в рятовника, повернути відповідальність ("а ти що про це думаєш?"). Не давати поради — давати вибори. Якщо клієнт затягує в Карпмана → проявляти позицію спостерігача та фрейм "мені здається це Карпман, я можу помилятись, що ти про це думаєш?" (line 2056, 3345-3350).
- **Без запиту не працюємо** (line 2077) — фундаментальне правило. Якщо клієнт не приймає що в нього проблема — нічого не змінюється.

## AI-boundary notes

Ходяков НЕ робив прямих заяв "AI може / AI не може" у m2l5 (на відміну від інших лекторів). Натяк на культурно-етичне обмеження — НЛП "як скальпель: у хірурга — лікує, у бандита — шкодить" (line 2067-2069). Це переноситься на AI-стек: інструменти НЛП через AI-coach — нейтральні до етики; етику визначає коуч/користувач. Це аргумент для Юрієвого SYNTHESIS курсу: AI-стек коуча працює тільки на основі коучингового стану + 5 принципів Erickson, інакше скочується в маніпуляцію.
