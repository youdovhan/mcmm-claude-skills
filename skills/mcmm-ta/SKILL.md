## Top-5 операційних концептів (production-tested через 10-Q self-quiz, 96.25%)

### 1. 3 рівні контракту (Адмін / Профес / Психо) — M1L3

**Use case:** рамка кожної першої сесії €39 + кожна сесія супроводу.
**Структура:** (1) **Адміністративний** — де/коли/як, оплата, форс-мажори, конфіденційність; (2) **Професійний** — що змінюємо, як вимірюємо успіх, інструменти, на що НЕ витрачаємо час; (3) **Психологічний** — навіщо людина насправді тут, підсвідомі очікування. Психо-рівень переважає (правило #3 Берна).
**Verbatim Влади:** «Психологический уровень контракта, это означает, что на самом деле стоит за этим запросом и какую потребность люди хотят от вас получить и удовлетворить.» [Влада Березянська, M1L3, line 2605]
**Deep dive:** `lessons/m1l3-contracts/synthesis.md` §3.2 + claims TA-M1L3-031-037.

### 2. Mapping драйвер → процес → міф → розплата — M8L3

**Use case:** за 5 хв розмови → повна сценарна гіпотеза + специфічний антидот.
**Інструмент:** таблиця "Драйвер → Процес → Міф → Розплата" з §2 Шар 4. Найбільш actionable mapping всього скіла.
**Verbatim Влади (приклад Майже-2 = Кассандра — "наша група коучів"):** коуч-психолог-ментор досягає мети → не цінує → біжить до нової гори. Антидот: «Як ти себе порадуєш сьогодні?» [Влада Березянська, M8L3, §3.7]
**Deep dive:** `script_atlas.md` Part 6 (нова) + `lessons/m8l3-mini-scripts/synthesis.md` §9.3.

### 3. 4 форми пасивної поведінки Schiff — M9L3

**Use case:** діагностика "що клієнт уникає" + точна інтервенція за формою.
**4 форми:** Doing Nothing (не реагує) / Agitation (тремтить, ходить, курить) / Over-adaptation (піклується про інших, забуває себе) / Incapacitation or Violence (агресія = максимальна пасивність).
**Counter-intuitive verbatim Влади:** «И это является наибольшей формой пассивности. Агрессия — это наибольшая форма пассивности.» [Влада Березянська, M9L3, line 975]
**Deep dive:** `lessons/m9l3-passivity-autonomy/synthesis.md` §6 + Schiff Discount Matrix §13.

### 4. 6 маркерів автентичне vs рекет — L5 (M6L3)

**Use case:** головний бар'єр coach vs psychotherapy + self-check коуча через його роздратування.
**Швидкий тест:** "Я відчуваю роздратування замість співпереживання" → перед тобою рекет. Не потребує аналізу історії клієнта.
**6 маркерів:** короткочасне vs хронічне / тут-і-зараз vs з минулого / адекватна vs драматизація / веде до розв'язку vs ні / природна vs навчена / викликає співпереживання vs роздратування.
**Технологія докопати:** "слоєний пиріг" — питання "Що під цим?" × 3-5 разів. Поверх. сум → під ним гнів → під ним страх відкинення.
**Deep dive:** `feelings_atlas.md` + `lessons/m6l3-feelings-racket/synthesis.md` §3.3-3.4.

### 5. Маркери у мові — 2 фрази за 5 хв сесії

**Use case:** 2 типи фраз, які Юрій ловить у перші 5 хвилин кожної сесії — миттєво вказують на структуру.

- **"Всі / завжди / ніколи / повинен"** → батьківська контамінація Дорослого. Метафора Влади: "окуляри батьків, які носиш не своїми". Інтервенція — батерні питання: "Завжди? З якого року? Хто конкретно? Приклади протилежного?" [claims TA-L1-024-029 + `ego_state_atlas.md`]
- **"Я попробую" / "Я постараюся"** → script defense, замаскований відмов. Гіпно-вправа Влади з дверима: "відкрий двері" vs "пробуй відкрити" — фізично показати різницю. [M1L3 line 2789-2810]

### M10L2 — CAPSTONE TA-discipline (Влада Березянська) — 2026-05-24 atomized

**M10L2 «Адаптації та процесуальна модель в ТА» = 8-й і фінальний TA-урок MCMM I потік** (Влада explicitly: «в нас це останнє заняття» line 3296). НЕ M9L3 як було у попередніх references — capstone змістився.

**Що нове у CAPSTONE:**

1. **6 особистісних адаптацій** (psychiatry-name → Kahler reframe):
   - Шизоїдна → Творчий Мрійник (survival, 0-6 міс)
   - Антисоціальна → Чарівний Маніпулятор (survival, 0-18 міс)
   - Параноїдна → Блискучий Скептик (survival, 0-18 міс)
   - Пасивно-агресивна → Грайливий Бунтар/Шапокляк (approval, 18-36 міс)
   - Обсесивно-компульсивна → Відповідальний Трудоголік (approval, 3-6 років)
   - Істерична → Надреагуючий Емпатик (approval, 3-6 років)
2. **3+3 frame** — survival adaptations (0-18 міс) vs approval adaptations (18 міс - 6 років); у стресі survival перемикається primary, overrides approval (line 389-397)
3. **Doors of Contact 3×3 (Pol Ware)** — Vlada-named «найголовніше у нашому семінарі» (line 183-184):
   - 3 канали: behavior / feelings / thinking
   - 3 типи дверей: open (легкий вхід) / target (для змін) / trap (найглибша зміна, але обережно)
   - Universal entry rule: open → target → trap (НІКОЛИ зразу через trap)
4. **5 драйверів Kahler** — Please Others / Be Strong / Try Hard / Hurry Up / Be Perfect (line 479-481) — поглиблено vs M8L3 (cross-ref)
5. **2x2 матриця Kahler** — активність × залученість (line 770-866)
6. **P-A-C structural analysis 6 адаптацій** — contamination + exclusion patterns per adaptation (line 1945-2123)
7. **Specific interventions per adaptation** — глибокі intervention scripts для шизоїд / маніпулятор / скептик / трудоголік / емпатик (line 2750-3166)
8. **Перерішення (redecision)** — фінальна терапевтична концепція з Goulding tradition (line 3197-3211)
9. **Тест Кайлера 72-Q (3rd edition, ⚠️ COPYRIGHT-PROTECTED)** — Vlada explicit warning, attribution to Tobi Kahler + Pol Ware + Vann Joines обов'язкова (line 1567-1717, 2563-2569)

### Cardinal rules для coaching з ТА (адаптовано з принципів Берна+Crossman 3P)

1. **Permission, Protection, Potency** (Crossman 1966): коуч дає **permission** клієнту порушити заборону → дає **protection** від внутрішнього Батька клієнта (який буде карати за порушення) → робить це з **potency** (внутрішня впевненість коуча в правомірності).
2. **НЕ давати ярлики** ("у тебе сценарій Бідняка / гра NIGYSOB / драйвер Try Hard"). ТА-діагностика **гіпотетична** і перевіряється у діалозі, не оголошується.
3. **НЕ розкопувати дитинство** без контракту. ТА йде глибоко — це територія психотерапії, не коучингу. Якщо клієнт сам пропонує — peremptly check: "ти готовий зараз туди йти? Це може забрати кілька сесій."
4. **Ціль ТА у коучингу = автономія клієнта** (Берн): свобода від сценарію + усвідомленість + спонтанність + інтимність. Не "виправити людину", а "повернути їй вибір".
5. **При суїцидальному регістрі / психотиці / маніакальній фазі** → mandatory routing → див. `mcmm-psychiatry`. ТА не лікує психоз.
6. **НЕ використовувати ТА як зброю** в стосунках з третіми особами. Якщо клієнт хоче "розшифрувати" партнера/боса/маму — обережно, ризик переносу позиції Переслідувача.
