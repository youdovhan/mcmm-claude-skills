# Client Decoder — від фрази клієнта до ТА-інтервенції

Робочий інструмент для Юрія: коли клієнт у сесії каже / робить щось — як швидко розпізнати ТА-патерн і запропонувати інтервенцію.

> **Принцип:** це **гіпотеза**, не діагноз. Завжди формулюй у голові як "схоже на X", "ймовірно Y", "можливо це Z". Перевіряй у діалозі, не оголошуй клієнту як вирок.

> **Цикл реакції:** маркер → ТА-decode (про себе) → гіпотеза → перевір через питання → якщо підтвердилась → запропонуй інтервенцію.

---

## Як читати таблицю

Кожен рядок:

- **Клієнт каже / робить** — verbatim або поведінковий маркер
- **ТА-decode** — який концепт ТА це відображає (для робочої гіпотези Юрія)
- **Урок** — L1-L6 (де теорія) + atlas (де швидкий lookup)
- **Гіпотеза** — що це ймовірно означає під капотом
- **Intervention** — конкретна вправа / питання / рамка (з `interventions.md` де є код INT-XXX)
- **Red flag check** — чи треба переключитись з ТА на `mcmm-psychiatry` / mandatory routing

## Маркери коли ТА = ПРАВИЛЬНИЙ інструмент (зелене світло)

- Клієнт описує **повторювану** ситуацію (3+ разів схожий сценарій з різними людьми/контекстами)
- Клієнт **усвідомлює** що щось повторюється і питає "чому"
- Хронічне знайоме почуття БЕЗ зовнішнього тригера
- "Я мушу / я повинен / я не маю права" → драйвер/заборона
- Внутрішні голоси в мові ("одна частина мене каже…, інша…") — без галюцинацій!
- Запит про відносини (партнер / батьки / робота) з повторюваністю
- Запит на самопізнання у форматі "чому я така"

## Маркери коли ТА = НЕПРАВИЛЬНИЙ інструмент (червоне світло)

- Активна психотика / манія / важка депресія з суїцидальністю (Розділ G)
- Гостра травма (свіжа, < 3 місяців, дитина потребує гострої стабілізації)
- Запит на медичну рекомендацію ("чи мені пити SSRI?") → психіатр
- Запит на бізнес-стратегію / тактику ("як мені продавати курси?") → інший коучинг
- Запит на конкретний skill (виступати / писати / переговори) → відповідні інструменти (mcmm-oratorske, тренери комунікації)
