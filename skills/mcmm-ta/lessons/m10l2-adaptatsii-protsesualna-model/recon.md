## Glossary термінів TA (зустрінутих у транскрипті)

### Базові ТА-концепти

- **Особистісна адаптація** — стиль почуттів / мислення / поведінки, який формується внаслідок вродженої схильності + сімейного досвіду (Влада, line 358-360)
- **Adaptation for survival** — формуються 0-6/12/18 міс, щоб ВИЖИТИ в родині (line 389-396)
- **Adaptation for approval** — формуються 18 міс - 6 років, щоб ОТРИМАТИ СХВАЛЕННЯ батьків (line 393-396)
- **Контамінація (зараження)** — у структурній моделі ego-states, коли одне ego-state «заражене» іншим (line 2004-2017, M2L2 cross-ref)
- **Виключення (exclusion)** ego-state — коли одне ego-state функціонально «вимкнено» (line 2018-2019)
- **Дитячий стан / Внутрішня дитина** — `C` (Child) у P-A-C моделі (line 1949-1962)
- **Батьківський стан** — `P` (Parent) (line 2012-2017)
- **Дорослий стан** — `A` (Adult) (line 2004-2016)
- **Драйвер** — захисна функція, стрес-поведінка; «яким ти стаєш у стресі» (line 493)
- **Заборона (injunction)** — батьківські послання типу «не існуй», «не радій», «не близький» (line 2754-2757)
- **Рекет (racket feeling)** — навчена замінна емоція замість автентичної (line 2806)
- **Гра (psychological game)** — повторюваний серіал транзакцій з підступним поворотом і виграшем-розплатою (line 2807)
- **Сценарій (life script)** — план життя, прийнятий у дитинстві (line 2760)

### Адаптації — psychiatry vs Kahler names

- **Mrtийник = шизоїдна** (line 1947)
- **Маніпулятор чарівний = антисоціальна** (line 1998)
- **Блискучий скептик = параноїдна** (line 2044)
- **Бунтар грайливий / Шапокляк = пасивно-агресивна** (line 2216)
- **Трудоголік / Працеголік = обсесивно-компульсивна** (line 2240)
- **Емпатик / Ентузіаст надреагуючий = істерична** (line 2270)

### Doors of Contact (Pol Ware)

- **Двері контакту (door of contact)** — 3 канали: behavior / feelings / thinking (line 867-874)
- **Відкрита двір (open door)** — perше, через що людина легко вступає у контакт
- **Двері ціль (target door)** — friendly second door, куди ведемо для змін
- **Двері пастка (trap door)** — третя door, де найглибші зміни, але обережно входити (line 1042-1045)

### Process Model (Tobi Kahler)

- **5 драйверів Кайлера**: Be Strong / Be Perfect / Try Hard / Please Others / Hurry Up (line 479-481)
- **2x2 матриця Kahler**: активність × залученість (line 770-784)
- **Опитувальник 72-Q (third edition)** — авторство Tobi Kahler + Pol Ware, оптимізований Vann Joines (line 2563-2569)
