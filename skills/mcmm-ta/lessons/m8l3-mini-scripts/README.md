## Теза

**Міні-сценарій = драйвер + сценарний процес + заборона = мікроцикл, що запускається у дистресі і веде до передбачуваного фіналу. Знаючи драйвер клієнта, ти за 5 хв розмови виводиш (а) його сценарний процес з Berne, (б) міфологічний образ, (в) фінальну розплату, (г) специфічний антидот.**

Це не «5 драйверів окремо» + «12 заборон окремо» + «6 сценарних процесів окремо», а **інтегрована система мікроциклу** — найбільш операційна частина ТА для коуч-сесії.

## Ключові концепти

- **OK / не-OK батарейка (Kahler)** — енергетичний шар; формується у віці 0-3-5 років, «маленький професор». Без заряду = смерть, тому дитина чіпляється навіть за не-OK заряд.
- **12 заборон Goulding 1979 → 15 (доповнення) → 25 (McNeel)** — інструкційний шар. Заборона = «правдоподібна брехня», яку дитина почула і повірила. Якщо це брехня — її можна спростувати.
- **5 драйверів Kahler 1974** — поведенково-захисний шар. Активуються у дистресі. У спокої = «риса характеру», у стресі = патологічний шаблон. Прикривають заборону знизу.
- **6 сценарних процесів = 4 Berne + 2 Kahler** — куди веде мікроцикл. Кожен має свій міф: Геракл / Тантал / Сізіф / Дамокл / Арахна / Кассандра + Бавкіда.
- **Mapping драйвер ↔ процес ↔ міф** — операційний інструмент M8L3. Be Perfect = Геракл («Пока ні»). Please Others = Бавкіда («Після»). Be Strong = Тантал («Ніколи»). Try Hard = Сізіф («Завжди»). Hurry Up = Кассандра («Знов і знов»).
- **5 категорій McNeel** для заборон: Виживання / Прив'язаність / Ідентичність / Компетентність / Безпека.
- **3П Crossman** (антидот): Permission + Protection + Potency — без цих трьох дозвіл не «прилипає».
- **Опитувальник Kahler — 5 шкал по 5 питань** (≥3 = драйвер). Be Perfect: 3,7,14,16,21. Please Others: 4,8,11,12,24. Hurry Up: 5,10,15,20,22. Be Strong: 1,2,13,19,23. Try Hard: 6,9,17,18,25.
- **«Майже-2» сценарний процес** — це наша група (особистості, що ходять по тренінгах і коучингах). Кожна нова мета починається до завершення попередньої.
- **Українська культура зараз — тотальний Don't Feel** (війна, мобілізація, виживання). Антидот: дозвіл відчувати + Crossman 3П з боку коуча.
- **«Слабкість — це сила»** (Влада, антидот Be Strong) — тільки сильні люди можуть показати свою вразливість.

## Cross-refs

### Всередині дисципліни (mcmm-ta):

- **L1 (M2 L2, его-стани)** — драйвер активується у Дитячому es; Crossman 3П = дозвіл від внутрішнього Батьківського.
- **L2 (M3 L3, транзакції)** — заборона часто передається невербальною прихованою транзакцією (Don't Feel «глянь так як я не глянула»).

- **L5 (M6 L3, рекетні почуття)** — рекет = «дозволене» батьками почуття; драйвер прикриває справжнє. Erskine-Zalcman 4 authentic vs racket.
- **L6 (M7 L3, сценарна матриця)** — M8L3 ОПЕРАЦІОНАЛІЗУЄ L6. L6 = карта (статична). M8L3 = GPS (динаміка). Без L6 неможливо зрозуміти M8L3, без M8L3 L6 залишається теорією.
- **M1L3 (контракти)** — Crossman 3П у антидоті повторює структуру контракту: Згода/Гарантія/Сила. Хороший контракт = первинна 3П-захисна рамка.
