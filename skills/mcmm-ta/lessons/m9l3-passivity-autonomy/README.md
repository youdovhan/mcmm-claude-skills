## Теза

**Пасивність — це не "лежати на дивані", а будь-яка поведінка, через яку людина уникає вирішення проблеми (Schiff).** 4 форми: doing-nothing / over-adaptation / agitation / incapacitation-or-violence. Пасивність формує симбіоз (двоє людей блокують свої его-стани, разом мають 3 з 6). Вихід — Berne автономія (awareness + spontaneity + intimacy). Інструмент діагностики — матриця знецінення Schiff (T1-T6), за яку отримано Eric Berne Memorial Award.

M9L3 = **передостанній урок ТА у MCMM, смисловий синтез усієї дисципліни** — як сценарій (M7L3), его-стани (M2L2), транзакції (M3L3) та ігри (M5L3) проявляються через пасивну поведінку та симбіоз у клієнтській роботі.

## Ключові концепти

- **Pasivnist' за Schiff** — поведінка, через яку людина уникає розв'язання проблем; включає **неефективні дії** (не лише бездіяльність)
- **4 форми пасивної поведінки** — Doing Nothing / Over-adaptation / Agitation / Incapacitation-or-Violence
- **Агресія = найбільша форма пасивності** (counter-intuitive insight Влади)
- **Catexis** — перетікання психічної енергії між его-станами (НЕ контамінація)
- **Симбіоз** — двоє людей як одна "ціла людина", разом мають 3 его-стани з 6
- **3 типи симбіозу** — здоровий (тимчасовий, усвідомлений) / конкурентний (змагальний за роль) / симбіоз 2-го порядку (соц + псих рівні)
- **Frame of reference** (свiтоприйняття) — стратегія виживання у родині, фільтр реальності
- **Перевизначення (redefinition)** — клієнт переопределяє факти, щоб підтримувати сценарій. 3 механізми: знецінення, грандіозність, порушення мислення
- **Відхиляючі/блокуючі транзакції** — як клієнт перекриває коуча
- **3 areas знецінення** — себе / інших / ситуацію. Кожна має payoff: хвороба / самотність / безсилля
- **Berne 3C автономія** — Awareness + Spontaneity + Intimacy
- **Матриця знецінення Schiff** — Eric Berne Memorial Award; 3 area × 4 type, діагональ T1-T6
- **100% потреб на 100% озвучено** — operational діагностика пасивності
- **Мета симбіозу** — задовольнити неотримані у дитинстві потреби
- **Healing test** — драматичні фільми стають нудними після терапії
