# L6 — Сценарій та сценарна матриця

> Модуль 7, Урок 3 курсу MCMM. Лектор — Влада Березянська (КН, EATA, USATAA, європейський CTA — primary-source M1L3 line 99-114). Тема: **«ТА. Сценарій та сценарна матриця»**.
> Епіграф контекстний: **«П'єса, написана дитиною, поставлена батьками і зіграна дорослою людиною»** (Eric Berne).

## Що цей урок дає

Це — **найскладніший і найщільніший урок** курсу з ТА. Він зводить разом усе попереднє (его-стани, транзакції, strokes, рекет) у **єдину карту життєвого програмування**.

1. **Сценарій (Berne)** — план життя 0-6 років, неусвідомлений, керує вибором професії / друзів / партнерів
2. **Послідовність формування**: Протокол → Ранні рішення → Палімпсест (улюблені казки) → Кульмінація (по 6-7 років)
3. **4 життєві позиції (Ernst, OK Corral)** — Я+/Ти+ Winner; Я+/Ти- Persecutor/Rescuer; Я-/Ти+ Loser; Я-/Ти- Hopeless
4. **5 механізмів сценарію**: Резинка / Контрсценарій / Антисценарій / Епісценарій / Трансгенераційний
5. **Сценарна матриця (Steiner)** — центральний фреймворк уроку:
   - **Зверху: 5 драйверів (Kahler 1974)** — Be Strong / Be Perfect / Please Others / Try Hard / Hurry Up
   - **Знизу: 12 заборон (Goulding & Goulding 1979)** — Don't Exist / Be Close / Think / Do / Feel / Be You / Grow Up / Achieve / Belong / Be Important / Be Well / Be a Child
   - **Посередині: Програма** («При якій умові я можу існувати?»)
6. **Трагічна петля рятувальника** — «якщо не порадую — вони помруть»
7. **Види сценаріїв (Berne)**: Переможець / Переможений / Банальний / Відкритий кінець
8. **3 типи сценаріїв (Steiner)**: Без любові / Без розуму / Без радості
9. **Ступені сценарію**: Незначні втрати → Сильні втрати → **Гамартичний** (трагедія)
10. **Шкала стресу (Вульмс)**: сценарій включається при 6.5-7/10
11. **4 рівні змін Berne**: Поведінковий / Фізіологічний / Когнітивний / Афективний
12. **9 діагностичних вправ**: Фільм життя, Улюблена казка, Предмет у кімнаті, Протокол, Резинка, Шкала стресу, Опитувальник Julie Hay, Заповнення матриці, Народження
13. **Правило вразливості**: відкривайся там, де безпечно
