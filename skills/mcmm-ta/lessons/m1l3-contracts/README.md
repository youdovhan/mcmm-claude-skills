## Теза

**Контракт у ТА — це угода двох дорослих про зміну з позиції "я окей, ти окей", де кожен бере 50% відповідальності. Без контракту немає роботи.** Контракт працює на 3 рівнях: **адміністративному** (де/коли/скільки), **професійному** (що змінюємо/як вимірюємо), **психологічному** (навіщо насправді людина тут). Психологічний рівень — головний для ефективності.

## Ключові концепти

- **Класичний контракт Берна** — двоє дорослих домовляються про зміну, 50/50 відповідальність, позиція "я окей, ти окей" — anti-патерналістська рамка проти старого "я бідолашка → ти мене лікуй".
- **3 рівні контракту**: Адміністративний / Професійний / Психологічний.
- **4 типи контрактів за Charlotte Sills**: прояснюючий (clarification) / поведінковий / дослідницький / на розвиток (зростання).
- **4 школи ТА у підходах до контракту**: класична (Берн), реляційна (контакт → контракт), психодинамічна (Mозе Новеліно, 3 рівні: тут-і-зараз / з іншими / з минулим), інтегративна (партнерство, "ми разом творимо").
- **4 вимоги контракту (Берн через Штайнера)**: взаємна згода + адекватна винагорода + компетентність + законність.
- **Глибинний особистий контракт (Muriel James)** — self-coaching tool з 5-7 питань.
- **4 сценарні контракти, що НЕ працюють**: батьківський (родинний), на зміну інших, ігровий, вічний.
- **Маркер прихованого контракту в мові**: "Я попробую" / "Я постараюся" (гіпно-демонстрація з дверима — line 2789-2810).
- **3 аварійні люки за Гулдінгами**: вбити себе / вбити інших / з'їхати з розуму. Контракт на безпеку = антисоціальний/антивигорання/антиаварія/антизникнення.
- **Трикутний (3-cornered) контракт**: Замовник + Виконавець + Учасники. Конфіденційність МІЖ сторонами.
- **План A/B/C переможця (Берн)**: переможець — той, у кого кілька варіантів вирішення; не той, хто впав і встав.
- **Формула контракту як захист**: Ясність + Згода + Дорослість.
